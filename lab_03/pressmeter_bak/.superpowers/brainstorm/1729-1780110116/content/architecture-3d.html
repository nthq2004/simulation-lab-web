第二层：3D 模块设计 (Three.js)

机舱空间布局 + 设备模型 + 交互控制

模块结构

engineroom3d/
├── EngineRoom3D.js          # 主控: 场景/相机/渲染器/动画循环
├── models/                  # 3D 设备模型
│   ├── ModelLoader.js       # glTF/GLB 加载器 (DRACO压缩)
│   ├── ModelRegistry.js     # 模型注册表 (type → mesh factory)
│   └── primitives/          # 基础几何体工厂 (无外部模型时使用)
│       ├── DieselEngine.js
│       ├── Generator.js
│       ├── Pump.js
│       ├── Compressor.js
│       ├── HeatExchanger.js
│       ├── Pipe3D.js
│       └── Tank.js
├── controls/
│   ├── OrbitControl.js      # 俯视旋转 (鸟瞰)
│   ├── WalkControl.js       # 第一人称漫游
│   └── CameraManager.js     # 视角切换 / 自动聚焦
├── visualization/
│   ├── StateColors.js       # 设备状态→颜色映射 (正常绿/告警黄/故障红)
│   ├── FlowParticles.js     # 管路流体粒子动画
│   ├── LabelSystem.js       # 设备标签 + 实时数值显示 (CSS2DRenderer)
│   └── HeatMap.js           # 温度/压力热力图叠加
├── layout/
│   ├── DeckManager.js       # 多层甲板管理
│   ├── RoomPartition.js     # 舱室分隔 / 防火墙
│   └── LayoutData.js        # 机舱布局配置数据
└── integration/
    ├── EventBridge.js       # ↔ 事件总线连接
    └── StateSync.js         # ↔ 数字孪生层状态同步

三种观察模式

🌐

鸟瞰模式

轨道控制，360° 旋转俯视全机舱，适合总体观察和教学讲解

🚶

漫游模式

第一人称 WASD 行走，模拟巡检路线，贴近观察设备细节

🎯

聚焦模式

点击设备自动拉近，显示详细参数面板，2D 原理图同步高亮

设备状态可视化

3D 模型中每个设备根据实时状态改变外观：

颜色映射
正常运行■绿色
预警■橙色
故障/报警■红色 (闪烁)
停机/待机■灰色
运行中■蓝色脉冲
附加效果
  • 管路: 流体粒子流动动画 (颜色=介质类型)
  • 设备标签: CSS2DRenderer 悬浮显示温度/压力/转速
  • 报警: 设备外发光 + 顶部感叹号标记
  • 选中: 外轮廓高亮 (OutlinePass)

与 2D 层的协同

用户在 3D 场景点击某个泵 → 事件总线发出 equipment:select {id: "pump-01"} → 2D 原理图中该泵的 Konva 组件高亮闪烁 → 右侧属性面板显示实时参数。

反之，在 2D 原理图点击设备符号 → 3D 相机自动聚焦到对应设备。

两者显示的是同一个数字孪生对象的同一组状态数据，只是视图不同。
