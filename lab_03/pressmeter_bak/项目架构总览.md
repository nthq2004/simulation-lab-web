# 项目架构总览

> 工业仪表与过程控制仿真教学平台  
> Konva.js (Canvas) 2D 电路/气路/数字逻辑仿真 + Three.js 3D 船舶机舱数字孪生  
> 源文件 332 个，构建模块 260 个

## 2. 系统架构层次

### 2.1 入口层

```
index.html
    ↓ 加载
main.js ──→ ControlSystem (window.sys)
    │
    ├── 工具栏按钮事件绑定
    ├── 2D/3D 视图切换（动态 import Three.js 模块）
    ├── 故障弹窗 / 仪表弹窗 UI
    ├── 报警面板 / 回放面板 / 报告面板 / 网关面板
    └── 工况场景下拉框
```

### 2.2 主控层 (`consys.js`)

```
ControlSystem
│
├── Konva 渲染
│   ├── stage (Konva.Stage)
│   ├── layer (组件层)
│   └── lineLayer (连线层)
│
├── 组件与连线管理
│   ├── comps = {}     # 组件字典
│   └── conns = []     # 连线数组
│
├── 子模块
│   ├── HistoryManager     # 撤销/重做
│   ├── ConnectionManager  # 连线交互
│   ├── Renderer           # 连线渲染
│   ├── UIManager          # 右键菜单
│   ├── WorkflowManager    # 流程控制
│   ├── StateSync          # → 3D 场景同步
│   ├── AlarmLogger        # → IndexedDB 报警
│   ├── HistoryRecorder    # → IndexedDB 快照
│   ├── ReplayController   # ← 读取快照回放
│   ├── ScenarioManager    # → 批量写设备状态
│   ├── SessionManager     # 学员会话上下文
│   ├── ActionLogger       # → IndexedDB 操作日志
│   ├── ScoringEngine      # ← 读日志计算评分
│   ├── ReportGenerator    # → HTML/JSON 报告
│   ├── ReportUI           # 报告查看面板
│   └── GatewayController  # ↔ 外部硬件
│
└── 仿真循环 (20fps setInterval)
    CircuitSolver → PneumaticSolver → DigitalSolver
    → MicrocontrollerSolver → MCS51Solver → ThermalSolver
    → stateSync.sync() → _tickAll()
```

### 2.3 仿真引擎 (`tools/`)

| 求解器 | 职责 | 核心方法 |
|--------|------|----------|
| `CircuitSolver` | 电路 MNA 求解 | `_buildTopology()` → `_solve()` → `_updateDeviceCurrents()` |
| `PneumaticSolver` | 气路/液压网络 | 阻抗网络 + BFS 压力传播 |
| `DigitalSolver` | 数字逻辑门 | 事件驱动，拓扑序计算 |
| `MicrocontrollerSolver` | MCU 仿真 | ADC/DAC/定时器/中断 |
| `MCS51Solver` | 8051 指令仿真 | 指令译码执行 |
| `ThermalSolver` | 热力网络 | 热节点温度求解 |

### 2.4 组件层 (`components/`)

所有组件继承 `BaseComponent`（Konva.Group），提供：

- 端口系统：`addPort(x, y, id, type, polarity)` → 自动生成 `{compId}_{type}_{portName}`
- 配置对话框：`getConfigFields()` + `onConfigUpdate()`
- Canvas 缓存：`cache='fixed'` 启用静态位图缓存
- ~230 个组件覆盖：传感器、变送器、执行器、仪表、电源、逻辑元件

## 3. 3D 数字孪生 (`engineroom3d/`)

### 3.1 场景生命周期

```
new EngineRoom3D(container)
  ├── _initScene()     → THREE.Scene + Fog
  ├── _initCamera()    → PerspectiveCamera(45°)
  ├── _initRenderer()  → WebGLRenderer(pixelRatio 1.5, NoToneMapping)
  ├── _initLights()    → Ambient + Directional + Fill + Point灯阵
  ├── _initControls()  → OrbitControls
  ├── _initHelpers()   → GridHelper + 地面
  └── _animate()       → requestAnimationFrame 循环

addDevice(id, type, pos, opts)
  ├── ModelLoader.createDevice(type) → THREE.Group
  ├── 添加到场景 + 创建设备标签
  └── 如果是 diesel_engine → 注册 EngineAnimator
```

### 3.2 动画循环

```
_animate() [~60fps]
  ├── cameraManager.update()
  ├── AnimationManager.update(dt)   # 引擎活塞/曲轴
  ├── FlowParticles.update(dt)      # 管道流体粒子
  ├── renderer.render(scene, camera)
  └── LabelSystem.render(camera)    # CSS2D 独立标签场景
```

### 3.3 模型系统

| 模型 | 几何体结构 |
|------|-----------|
| `DieselEngine3D` | 机体 + 气缸盖 + 排烟管 + 增压器 + 飞轮 + 运动部件（曲轴+4活塞） |
| `Pump3D` | 泵体 + 进出口法兰 |
| `Generator3D` | 定子 + 转子 + 端盖 |
| `Pipe3D` | CylinderGeometry 管段 + TorusGeometry 弯头 |

### 3.4 状态同步

```
20fps Physics Tick
  ↓
StateSync.sync() → diff 检测
  ↓
EventBus.emit('equipment:stateChange')
  ↓
EventBridge (订阅者)
  ├── updateDeviceState() → 材质颜色
  └── updateDeviceLabel() → 标签文字
```

## 4. 报警/回放系统

### 4.1 数据流

```
设备异常 → EventBus 'equipment:alarm'
  ↓
AlarmLogger → IndexedDB [PressmeterDB.alarms]

每 1 秒 → HistoryRecorder 快照
  ↓
IndexedDB [PressmeterDB.snapshots] (3600条上限)

回放时 → ReplayController.load(snapshots)
  → play/pause/seek/setSpeed(1x/2x/4x)
  → 逐帧注入 equipmentPool
```

### 4.2 IndexedDB Schema

- **Database:** `PressmeterDB`
- **Stores:** `alarms`, `snapshots`, `actions`, `reports`
- **alarms:** `{ id, timestamp, deviceId, message, severity, acknowledged }`
- **snapshots:** `{ id, timestamp, state: { devId: { key: value } } }`

## 5. 硬件网关 (`gateway/`)

### 5.1 双通道架构

```
SerialGateway (Web Serial API)
  └── connect(115200) → send(data) → 读循环

WebSocketGateway (后备桥接)
  └── connect(url) → 自动重连 (指数退避×5, 10s超时)
```

### 5.2 协议映射

| 方向 | 方法 |
|------|------|
| 总线 → 设备 | `onFieldbusData(frame)` → 解析 CAN ID/Modbus 地址 → 更新设备状态 |
| 设备 → 总线 | `toFieldbusFrame(devId, key, value)` → 构造 CAN 帧 |
| 设备 → Modbus | `toModbusFrame(devId, key, value)` → 构造 Modbus 帧 |

CAN ID 映射示例: `0x110→me-01`, `0x111→gen-01`, `0x120→pump-sw-01`

## 7. 学员报告系统

### 7.1 会话生命周期

```
SessionManager.start(studentId, workflowId)
  ↓
ActionLogger (订阅 equipment:select / workflow:step / session:action)
  ↓
SessionManager.end()
  ↓
ScoringEngine.calculate(sessionId)
  ├── 测验正确率 (40%)
  ├── 步骤完成度 (30%)
  ├── 故障修复时间 (20%)
  └── 操作效率 (10%)
  ↓
ReportGenerator.toHTML() / toJSON() / saveToDB()
  ↓
ReportUI 面板查看/导出
```

### 7.2 Workflow.js 集成

- `_onStepPass()` → `sessionManager.logStep()` + EventBus `workflow:step`
- `showQuiz()` 提交 → `sessionManager.logQuiz()`
- `WorkflowManager.openWorkflowPanel('train'|'eval')` → 自动开始会话

## 10. 教学流程

| 模式 | 说明 | 执行方式 |
|------|------|---------|
| `show` | 自动演示 | 顺序执行，Show.js 视觉辅助 |
| `step` | 单步演示 | 用户点"下一步" |
| `train` | 演练 | 用户操作，check 检测 |
| `eval` | 评估 | 隐藏未执行步骤 |

**步骤类型:** `find`（点击组件）、`quiz`（选择题）、`check`（行为检测）  
**视觉展示:** `Show.js` 提供箭头闪烁、连线高亮、暗场聚焦、信号动画、镜头缩放
