## 🎯 快速开始

### 方式 1：直接打开HTML

在现代浏览器中打开以下文件之一：
- `ptc-fuse-demo.html` - 推荐新手
- `ptc-complete-demo.html` - 推荐深入学习
- `index-ptc.html` - 项目导航

### 方式 2：启动本地服务器

```bash
# 进入项目目录
cd ptcprotect

# 启动HTTP服务器
python -m http.server 8000

# 在浏览器打开
http://localhost:8000/index-ptc.html
```

### 方式 3：集成到项目

```javascript
import { PTCResettableFuseSimulator } from './ptc-fuse-simulator.js';

const ptc = new PTCResettableFuseSimulator({
    Vsupply: 12,
    Rload: 5,
    Tswitch: 80,
    Tcurie: 110,
    Rmin: 10,
    Rmax: 1e6
});

// 运行仿真
for (let t = 0; t < 10; t += 0.01) {
    ptc.update(0.01);
    const state = ptc.getState();
    console.log(`T: ${state.temperature.toFixed(1)}°C, R: ${state.resistance.toFixed(1)}Ω`);
}
```

## 📝 核心工作流

### 正常工作状态
```
Vsupply=12V, Rload=5Ω
↓
I = 12/(10+5) = 0.8A
↓
P = 0.8² × 10 = 6.4W
↓
T ≈ 25°C（恒定）
↓
正常工作 ✓
```

### 短路故障过程
```
Rload 5Ω → 0.1Ω（短路）
↓
I: 0.8A → 10.9A（瞬间）
↓
P: 6.4W → 1188W（焦耳热爆炸）
↓
T: 25°C → 80°C（100ms内）
↓
R: 10Ω → 100Ω → 1MΩ（急剧增大）
↓
I: 10.9A → 1.1A → 0.01A（切断）
↓
过流被保护 ✓
```

### 自动恢复过程
```
故障消除（Rload回到5Ω）
↓
I: 0.01A → 0.8A（恢复）
↓
P: 0.1W → 6.4W（恢复）
↓
T: 110°C → 25°C（自然冷却）
↓
R: 1MΩ → 10Ω（自动恢复）
↓
电路恢复正常工作，可重复使用 ♻️
```
