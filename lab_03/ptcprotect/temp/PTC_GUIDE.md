# PTC 自恢复保险丝仿真电路 - 完整指南

## 📋 概述

PTC（Positive Temperature Coefficient）热敏电阻是一种具有正温度系数的被动器件，当温度升高到一定值时，电阻值会急剧增大。这个特性使其成为理想的**自恢复保险丝**，广泛应用于电子设备的过流保护。

## 🔬 工作原理

### 四阶段工作过程

```
正常状态          短路发生          保护激活          自动恢复
Rmin (10Ω)   →   I↑ 焦耳热↑   →   R↑ (1MΩ)    →   R↓ 恢复
I ≈ 1.09A        I ↑ T↑           I↓ 0.01A        I→1A
T = 25°C         T > 80°C        T = 110°C       T↓ 25°C
```

### 关键工作机制

#### 1️⃣ 第一区域：NTC 区（正常工作，T < Tswitch）

- **电阻特性**：电阻随温度**轻微下降**
- **公式**：`R(T) = Rmin × exp[-α×(T - Tswitch)]`
- **特点**：半导体特性（负温系数）
- **应用**：正常电流通过，设备正常工作

**示例数据**：
- 温度：25°C（环境温度）
- 电阻：10Ω（Rmin）
- 电流：I = 12V / (10Ω + 5Ω) = 0.8A
- 功率：P = 0.8² × 10 = 6.4W

#### 2️⃣ 第二区域：居里点突变区（过流保护，Tswitch ~ Tcurie）

- **物理本质**：铁电→顺电相变
- **电阻变化**：数个数量级增大（10³～10⁸倍）
- **公式**：`R(T) = Rmin × exp[β×(T-Tswitch)²]`
- **关键参数**：
  - β = ln(Rmax/Rmin) / (Tcurie - Tswitch)²
  - 上述例子中：β = ln(10⁶/10) / 30² ≈ 0.0099

**关键时刻分析**：

| 温度 | 电阻 | 电流 | 功率 | 状态 |
|------|------|------|------|------|
| 80°C | 100Ω | 0.73A | 53W | 进入保护 |
| 90°C | 1kΩ | 0.12A | 14W | 限流中 |
| 100°C | 10kΩ | 0.012A | 1.4W | 强力限流 |
| 110°C | 1MΩ | 0.001A | 1mW | 完全切断 |

#### 3️⃣ 第三区域：高温饱和区（T > Tcurie）

- **电阻特性**：达到最大值后略微下降
- **特点**：陶瓷材料本身的导电性增加
- **作用**：防止无限升温

#### 4️⃣ 自动恢复区（故障消除后）

当外部短路消除后：
1. 过流停止 → 电流↓
2. 焦耳热消失 → 温度↓
3. T 降至 Tswitch 以下 → 离开居里点
4. 电阻自动恢复 → R 回到 Rmin
5. 电路恢复正常工作 → 可重复使用

## 📊 热动力学模型

### 热平衡方程

```
焦耳热输入  -  对流散热  =  温度上升
P_joule    -  P_cool   =  C_th × dT/dt

其中：
• P_joule = I² × R（焦耳热）
• P_cool = ΔT / R_th（对流散热）
• C_th = 热容量（J/°C）
• R_th = 热阻（°C/W）
```

### 参数示例

```
热容量 (C_th)：0.5 J/°C
  - 影响：值越大，升温越慢（响应时间越长）
  - 典型值：0.3～1.0 J/°C

热阻 (R_th)：15 °C/W
  - 影响：值越大，散热越差（保护效果越好）
  - 典型值：5～50 °C/W

散热面积：100 mm²
  - 增大散热面积 → 散热系数↓ → 恢复更快
```

## ⚡ 故障场景仿真

### 场景 1：突发短路

**时序图**：
```
0-1s：     短路发生
t=0：      Rload: 5Ω → 0.1Ω
           I: 1.09A → 10.9A （瞬间）
           P: 11.9W → 1188W（瞬间）

0-0.5s：   温度快速上升
           T: 25°C → 80°C
           电阻开始增大：R ≈ 10～100Ω

0.5-1.0s：  进入居里点
           T: 80°C → 110°C
           电阻急剧增大：R ≈ 100Ω → 1MΩ
           电流急剧下降：I ≈ 10A → 0.01A
           功率下降：P ≈ 1000W → 0.1W

1s-：      保护状态
           短路被切断，无过流
           电路受到保护
```

**保护效果分析**：
- 无保护时：1188W × 1s = 1188焦耳，可能烧毁设备
- PTC保护：平均功率从1000W下降到100W，再到1W，能量释放被限制
- 恢复时间：约1～2秒（取决于散热）

### 场景 2：过载工作

```
降级负载：Rload: 5Ω → 1Ω
• 正常电流：I = 12/(10+1) = 1.09A
• 过载时：I = 12/(10+1) = 1.09A （几乎相同！）

结论：小的负载变化不会立即触发保护，
      但会通过温度缓慢上升最终激活保护。
      这是"热保护"而非"电流保护"。
```

### 场景 3：间歇性故障

```
时间线：
0.0-0.5s：  正常工作
0.5-1.0s：  短路（故障1）→ PTC保护 → 恢复
1.0-1.5s：  正常工作
1.5-2.0s：  短路（故障2）→ PTC保护 → 恢复
2.0-3.0s：  正常工作
...

PTC优势：无需人工干预，自动处理多次故障
```

## 💡 仿真特征

### 非线性特性

```
R(T) 的非线性：
• 线性区（NTC）：ΔR/ΔT ≈ 0.1Ω/°C
• 突变区（PTC）：ΔR/ΔT ≈ 10Ω/°C → 1000Ω/°C
• 饱和区（高温）：ΔR/ΔT ≈ 0.1Ω/°C

这种非线性确保：
- 温度变化范围内快速响应
- 提供稳定的保护
```

### 滞后效应

```
升温路径（短路激发）：
25°C → 80°C (Tswitch) → 110°C (Tcurie)

降温路径（自然冷却）：
110°C → 80°C → 25°C

•升温快（焦耳热驱动）
• 降温慢（自然散热受限）

这确保了"过冲"和稳定保护
```

### 温度梯度

```
短路时的最高温度：
ΔT ≈ P_joule × R_th
   = 1188W × 15°C/W
   = 17820°C （瞬间理论值，实际会饱和）

实际温度受限于：
• PTC本身的热熔点（陶瓷 ~200°C）
• 接触不良导致的串联电阻
• 散热条件改善（温度高时表面辐射增加）
```

## 📈 性能指标

### 关键参数

| 参数 | 符号 | 典型值 | 单位 | 影响 |
|------|------|--------|------|------|
| 最小电阻 | Rmin | 10 | Ω | 正常工作时的导通损耗 |
| 最大电阻 | Rmax | 1M | Ω | 过流限制能力 |
| 切换温度 | Tswitch | 80 | °C | 保护触发点（低→灵敏，高→容忍过载） |
| 居里温度 | Tcurie | 110 | °C | 最大保护点（高→响应快，低→温度安全） |
| 热容量 | Cth | 0.5 | J/°C | 响应时间（小→响应快，大→缓冲过冲） |
| 热阻 | Rth | 15 | °C/W | 散热能力（小→恢复快，大→保护稳定） |
| 切换温度范围 | ΔT | 30 | °C | 居里点宽度（小→响应快，大→容差大） |

### 保护能力评估

```
过流限制比：
Limit Ratio = I_normal / I_limited
           = (V / (Rmin+Rload)) / (V / (Rmax+Rload))
           ≈ Rmax / Rmin（当Rload ≪ Rmax）
           ≈ 1e6 / 10 = 100,000×

这意味着PTC可以将短路电流从10A降低到0.01mA！
```

## 🎯 应用案例

### 1. USB充电端口保护

```
应用：防止用户错误连接、短路充电
工作条件：
• 供电：5V
• 正常电流：0.5A
• 保护阈值：2.5A（5倍过载）
• Tswitch：50°C（低温快响应）

预期效果：
• 短路时限流至 5mA
• 恢复时间：~1秒
```

### 2. 电池管理系统

```
应用：保护电池组免受过流、短路
工作条件：
• 电池电压：12V/24V/48V
• 充放电电流：20A～100A
• 短路保护：< 1A

保护流程：
过充 → 电流增大 → 温度升高 → PTC限流
↓
电池过热得以避免
```

### 3. 工业控制电源

```
应用：三相电源的单相故障保护
工作条件：
• 供电：380V（工业）
• 分支电流：30A
• 故障隔离：< 10ms

优势：
• 自动化程度高
• 成本低
• 可靠性好
```

### 4. 通信基站电源

```
应用：多路直流分配保护
工作条件：
• 主电源：48V
• 模块数：8个（每个6A）
• 单模块故障隔离：< 50ms

设计：
每个模块输入并联一个PTC
→ 故障模块自动限流
→ 其他模块继续工作
```

## 🔄 对比分析

### vs 传统熔断丝

```
熔断丝：
  优点：成本低、可靠性好
  缺点：一次性、需要维护、常备库存

PTC：
  优点：可重复使用、无维护、自动恢复
  缺点：成本高、响应时间稍长、规格需匹配
```

### vs 电磁继电器

```
继电器：
  优点：功能灵活、响应快
  缺点：需要电源、控制复杂、可靠性一般

PTC：
  优点：无需电源、被动器件、集成简单
  缺点：响应慢10倍、功能固定
```

### vs 电子熔断（电流限制IC）

```
电流限制IC：
  优点：精度高、可编程
  缺点：成本很高、设计复杂

PTC：
  优点：成本低、设计简单
  缺点：精度低、功能简单
```

## 📞 技术支持

### 常见问题

**Q: 为什么温度不下降？**
- A: 检查Tambient（环境温度）设置，确保高于PTC当前温度

**Q: 为什么保护没有触发？**
- A: 检查Rload和Tswitch参数，可能需要更大的短路幅度或降低Tswitch

**Q: 波形显示有异常？**
- A: 刷新页面，检查浏览器控制台是否有错误信息
