## 📊 物理模型核心公式

### 电阻随温度的变化

**分段模型**：

```
区域 1 (T < Tswitch)：NTC区
R(T) = Rmin × exp[-α×(T - Tswitch)]
• α = 0.02（衰减系数）
• 电阻轻微下降

区域 2 (Tswitch ≤ T ≤ Tcurie)：居里点突变
R(T) = Rmin × exp[β×(T - Tswitch)²]
• β = ln(Rmax/Rmin) / (Tcurie - Tswitch)²
• 电阻急剧增大

区域 3 (T > Tcurie)：高温饱和
R(T) = Rmax × (1 - 0.1×(T - Tcurie)/50)
• 电阻略微下降
```

### 热平衡方程

```
焦耳热输入 - 对流散热 = 温度上升

I²R - (T - T_ambient)/R_th = C_th × dT/dt

其中：
• I = 电流 (A)
• R = PTC电阻 (Ω)
• T = 器件温度 (°C)
• T_ambient = 环境温度 (°C)
• R_th = 热阻 (°C/W)
• C_th = 热容量 (J/°C)
```

### 保护效能

```
过流限制比 = I_normal / I_limited
          ≈ (V/(Rmin+Rload)) / (V/(Rmax+Rload))
          ≈ Rmax / Rmin
          ≈ 1,000,000 / 10
          = 100,000 ×

示例：将10A短路电流限制到0.1mA！
```
