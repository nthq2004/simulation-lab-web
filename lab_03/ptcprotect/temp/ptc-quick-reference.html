🔌 PTC 自恢复保险丝

快速参考卡 v1.0

Positive Temperature Coefficient Thermistor — Resettable Fuse

📊 核心参数表

参数名称 符号 典型值 单位 关键作用
最小电阻 Rmin 10 Ω 正常工作损耗
最大电阻 Rmax 1M Ω 过流限制
切换温度 Tswitch 80 °C 保护触发点
居里温度 Tcurie 110 °C 最大保护点
热容量 C_th 0.5 J/°C 响应速度
热阻 R_th 15 °C/W 散热能力

🔄 工作状态机

① 正常状态
T < 75°C
R = Rmin
I ≈ 1A
② 过渡状态
75°C ≤ T < 85°C
R ↑↑ 指数增长
I ↓ 快速下降
③ 限流状态
85°C ≤ T < 110°C
R ≈ 1k～100kΩ
I ≈ 10～100mA
④ 保护状态
T ≥ 110°C
R ≈ Rmax = 1MΩ
I ≈ 0.01mA

⚡ R-T 特性公式

区域 1 (T < Tswitch)：NTC 区
R(T) = Rmin × exp[-α×(T - Tswitch)]
其中 α = 0.02（NTC衰减系数）
区域 2 (Tswitch ≤ T ≤ Tcurie)：居里点突变
R(T) = Rmin × exp[β×(T - Tswitch)²]
其中 β = ln(Rmax/Rmin) / (Tcurie - Tswitch)²
区域 3 (T > Tcurie)：高温饱和
R(T) = Rmax × (1 - 0.1×(T - Tcurie)/50)

🌡️ 热动力学模型

热平衡方程：
I²R - (T - T_amb)/R_th = C_th × dT/dt

组成部分：
• I²R = 焦耳热输入功率 (W)
• (T - T_amb)/R_th = 对流散热功率 (W)
• C_th × dT/dt = 热容造成的温度变化率
✓ 物理意义： 输入热量 - 散失热量 = 温度上升速率

⚠️ 短路故障时间线

t = 0ms： 短路发生（Rload: 5Ω → 0.1Ω）
t = 0~100ms： 电流瞬间从1A跳到10A，功率1188W
t = 100~500ms： 温度快速上升（25°C → 80°C），电阻开始增大
t = 500~1000ms： 进入居里点，电阻急剧增加（10Ω → 1MΩ）
t = 1000~2000ms： 电流急剧下降（10A → 0.01A），过流被切断
t > 2000ms： 电路被保护，功率稳定在0.1W
⚡ 保护效果： 防止1188W的功率释放，电路被有效保护！

🔄 自动恢复时间线

t = 2000ms： 故障消除（短路被移除）
t = 2000~2500ms： 电流恢复→电阻下降→温度快速降低
t = 2500~3500ms： 温度从110°C降至80°C（离开居里点）
t = 3500~5000ms： 温度继续自然冷却（80°C → 25°C）
t > 5000ms： 电阻恢复至Rmin，电路恢复正常工作
✓ 可重复使用： 无需更换，无限次恢复，完全自动化！

🧮 计算示例

正常工作状态 (T = 25°C)：
• Vsupply = 12V, Rload = 5Ω
• R(25°C) = 10 × exp[-0.02×(25-80)] = 10 × exp[1.1] ≈ 30Ω
• I = 12/(30+5) = 0.3A
• P = 0.3² × 30 = 2.7W
临界点 (T = 80°C)：
• R(80°C) = 10Ω (从NTC切换到PTC)
• I = 12/(10+5) = 0.8A
• P = 0.8² × 10 = 6.4W
保护激活 (T = 100°C)：
• β = ln(10⁶/10) / 30² ≈ 0.0099
• R(100°C) = 10 × exp[0.0099×(100-80)²] ≈ 10×exp[3.96] ≈ 520Ω
• I = 12/(520+5) ≈ 0.023A
• P = 0.023² × 520 = 0.275W
完全保护 (T = 110°C)：
• R(110°C) ≈ 1MΩ
• I = 12/(1M+5) ≈ 0.000012A = 12μA
• P ≈ 0.00012W

🔧 PTC选型三步法

第一步：确定保护电流Ilimit
设 Ilimit = 1.5～2.0 × Inormal（过载倍数）
选择Rmin使得 V/(Rmin+Rload) ≈ Ilimit
第二步：确定Tswitch和Tcurie
• 应用温度越高 → Tswitch越高
• 响应需求越快 → Tswitch越低
• 通常 Tcurie = Tswitch + 20~40°C
第三步：验证过流限制
当Rload降到最坏值时，确认R(T_max)足够大
使得I_limited < 器件额定电流 × 0.1

🐛 常见问题排查

❓ 保护不触发

⚡ 30秒快速理解

PTC = 温度控制的电阻

✓ 正常时：电阻小 (10Ω) → 电流大 (1A) → 设备正常工作
✓ 过流时：焦耳热多 → 温度高 → 电阻大 (1MΩ) → 电流小 → 设备保护
✓ 故障消除：电流小 → 热量少 → 温度降 → 电阻复原 → 自动恢复

💡 核心：利用器件自身发热改变电阻，被动保护，无需控制！
