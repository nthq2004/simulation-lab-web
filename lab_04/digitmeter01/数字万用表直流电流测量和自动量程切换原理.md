# 数字万用表直流电流测量和自动量程切换原理

## 1. 直流电流测量原理

数字万用表（DMM）测量直流电流（DCA）的核心原理是**电流-电压转换法**，即让被测电流流过一个已知阻值的精密**分流电阻**（Shunt Resistor），测量该电阻两端的电压降，再通过欧姆定律计算电流：

```
I = V / Rs
```

其中 `I` 为被测电流，`V` 为分流电阻两端的电压降，`Rs` 为分流电阻的阻值。

### 电流路径

```
被测电流 I_in
      │
      ▼
  ┌─────────────┐
  │    COM 端    │ ← 电流从 DMM 的 COM 端流入
  └──────┬──────┘
         │
    ┌────┴────┐
    │ Smart   │
    │ Analog  │ ← 多路模拟开关，选择当前量程对应的分流电阻
    │ Switch  │
    └────┬────┘
         │
    ┌────┴────┐
    │ 分流电阻 Rs │ ← 将电流转换为电压
    │ (4Ω/0.4Ω/0.04Ω)
    └────┬────┘
         │
    ┌────┴────┐
    │  GND    │ ← 电流返回
    └─────────┘

电压测量点：分流电阻两端
Vin+ ─── Rs 高端 ───→ DMM 控制器 Vin+
Vin- ─── Rs 低端 ───→ DMM 控制器 Vin- (GND 参考点)
```

### 具体实现

在仿真平台中，直流电流测量由三个核心部件协同完成：

| 部件 | 作用 |
|------|------|
| `SmartAnalogSwitch`（智能模拟开关） | 负责功能选择（DCA/DCV/ACV/R/C/Diode）和量程切换 |
| 分流电阻组（4Ω / 0.4Ω / 0.04Ω） | 将不同量程范围的电流转换为 0~200mV 电压 |
| `DMMController`（DMM 控制器） | 读取电压、计算电流值、控制自动量程、显示结果 |

接线关系：

```
dc_current (电流源) → SmartSwitch.COM → SmartSwitch.T1→ shunt_50mA(4Ω) → GND
                                       → SmartSwitch.T2→ shunt_500mA(0.4Ω) → GND
                                       → SmartSwitch.T3→ shunt_5A(0.04Ω) → GND

SmartSwitch.COM → DMMController.Vin+   (测分流电阻高端电压)
GND             → DMMController.Vin-   (测分流电阻低端电压)
```

### 档位与分流电阻的匹配

三个电流档位各自匹配一个分流电阻，每个分流电阻的设计原则是：**当电流达到该档位满量程时，电阻两端电压降恰好为 200mV**（即 ADC 的满量程电压）。

| 档位 | 满量程电流 | 分流电阻值 | 满量程电压 | 电流计算公式 |
|------|-----------|-----------|-----------|------------|
| 50mA | 50mA | 4Ω | 200mV | I = V / 4 |
| 500mA | 500mA | 0.4Ω | 200mV | I = V × 2.5 （即 V / 0.4） |
| 5A | 5A | 0.04Ω | 200mV | I = V × 25 （即 V / 0.04） |

可见三个档位均满足 `I_fs × Rs = 200mV`，即满量程时电压都统一在 200mV。这是数字万用表的经典设计——只要 ADC 的量程是 200mV，三个档位可共用同一个 ADC 电路。

## 2. 自动量程切换原理

### 为什么需要自动量程？

手动量程需要用户根据被测电流大小选择合适的档位。若档位选择过低（电流超出满量程），ADC 会饱和；若档位选择过高，测量分辨率会降低。自动量程让 DMM 自动选择最合适的档位，在保证不饱和的同时获得最佳分辨率。

### 自动量程的判断标准

自动量程的决策依据是**分流电阻两端的电压**（即 ADC 读数的物理量）。通过判断该电压是否超过上升阈值或低于下降阈值，决定是否切换量程。

### 阈值设计

以 200mV ADC 为参考（满量程 = 200mV）：

| 阈值 | 电压值 | 占满量程比例 | 含义 |
|------|--------|-------------|------|
| 上升阈值（Up-Threshold） | 180mV | 90% | 超过此值 → 切到更高档位 |
| 下降阈值（Down-Threshold） | 12mV | 6% | 低于此值 → 切到更低档位 |

**上升阈值（180mV）**：当电压达到满量程的 90% 时，说明当前电流接近量程上限，需要切换到更大的档位以避免测量溢出。

**下降阈值（12mV）**：当电压降至满量程的 6% 以下时，说明当前电流很小，换到更低档位可以获得更好的分辨率。例如 5A 档的 12mV 对应电流 I = 0.012V / 0.04Ω = 0.3A = 300mA，此时切换到 500mA 档（分辨率高 10 倍）。

### 量程切换逻辑（伪代码 + 对应电流值）

```
当前档位 = 50mA (Rs=4Ω)
  if V > 180mV → 电流 > 45mA → 切换到 500mA 档

当前档位 = 500mA (Rs=0.4Ω)
  if V > 180mV → 电流 > 450mA → 切换到 5A 档
  if V < 12mV  → 电流 < 30mA  → 切换到 50mA 档

当前档位 = 5A (Rs=0.04Ω)
  if V < 12mV  → 电流 < 300mA → 切换到 500mA 档
```

### 防振荡机制（冷却时间）

系统设定了 `_autoRangeCooldown = 0.5 秒`，每次执行自动量程判断后必须等待 0.5 秒才能再次判断。这避免了电流在阈值附近波动时频繁切换量程（来回振荡）。

### 显示分辨率匹配

不同档位使用不同的显示精度：

| 档位 | 显示格式 | 示例 |
|------|---------|------|
| 50mA | xxx.xx mA | 25.34 mA |
| 500mA | xxx.xx mA | 345.67 mA |
| 5A | x.xxx A | 2.345 A |

并且当电流小于 0.5mA 时统一显示 "0.000"，避免微小噪声导致的非零显示。

## 3. 200mV 模数转换器的低位

### ADC 原理简述

200mV ADC 是 DMM 的核心器件，它的输入范围是 0~200mV，输出为数字量。对于常见的 3½ 位（1999 计数）ADC：

- 满量程读数：1999
- 分辨率：200mV / 1999 ≈ 0.1mV（100μV）
- 即输入每变化 0.1mV，数字读数增减 1

### ADC 转换公式

```
ADC_Digital = (Vin / Vref) × MaxCount

其中：
  Vin    = 输入电压（即分流电阻两端电压）
  Vref   = 参考电压（200mV）
  MaxCount = ADC 最大计数值（1999）
```

### "低位"的含义

数字万用表的 "低位"（Least Significant Digit, LSD）指显示值的最末一位数字。对于 3½ 位 DMM：

- **高位（½ 位）**：最高位只能显示 0 或 1
- **低位（3 位）**：后三位从 000 到 999

以测量 5A 档为例，ADC 读数的低位对应：

```
ADC 读数 = V_in × 1999 / 0.2

例如：Vin = 100mV → ADC = 1000
      对应电流 I = 0.1V / 0.04Ω = 2.5A
      显示 "2.500"

      Vin = 100.1mV → ADC = 1001
      对应电流 I = 0.1001V / 0.04Ω = 2.5025A
      显示 "2.503"

低位数字每变化 1，对应电流变化约 2.5mA（5A 档）
```

### 低位 vs 分辨率的物理意义

不同档位下，ADC 低位每变化 1 对应的电流变化量不同：

| 档位 | 分流电阻 | ADC 分辨率 | 电流分辨率（1 LSD） |
|------|---------|-----------|-------------------|
| 50mA | 4Ω | 0.1mV | 0.1mV / 4Ω = 0.025mA = 25μA |
| 500mA | 0.4Ω | 0.1mV | 0.1mV / 0.4Ω = 0.25mA = 250μA |
| 5A | 0.04Ω | 0.1mV | 0.1mV / 0.04Ω = 2.5mA = 2500μA |

可见，**同一 ADC 采样 200mV 满量程信号时，档位越低（分流电阻越大），电流分辨率越高**。这就是为什么测量小电流时要选择低量程档位——能分辨更小的电流变化。

### 在本仿真平台的简化实现

本仿真平台的 DMM 控制器并未直接使用 200mV ADC 芯片模型，而是通过电路求解器（MNA）直接获得分流电阻两端的电压值（双精度浮点数），然后据此计算电流值。这是仿真的合理简化——避免了仿真一个完整 ADC 转换过程的开销，直接得到了理想化的精确电压结果，使学员聚焦于理解测量原理而非 ADC 器件的细节。

仿真与实际 DMM 的对应关系：

| 实际 DMM | 本仿真平台 |
|---------|-----------|
| 200mV ADC（ICL7106/7107） | `sys.getVoltageBetween(vin_p, vin_n)` 直接获取电压 |
| ADC 转换时间 | 无延迟（理想电压采样） |
| ADC 量化误差 | 无（浮点精度） |
| 数字显示 | 按档位格式化浮点数值 |

## 4. DMM 获取当前档位的方法

DMM 需要知道当前处于哪个档位，才能选择正确的分流电阻值并计算电流。在本仿真平台中，档位信息的获取通过以下机制实现：

### 4.1 档位信息的来源

`DMMController` 通过 `SmartAnalogSwitch` 获取当前档位信息：

```javascript
// DMMController.tick() 中
const sw = this._getSwitch();      // 获取开关对象引用
const pos = sw.getPosition();       // 获取档位位置 (1, 2, 3, 4)
```

`getPosition()` 返回的值为 1~4，对应关系：

| 位置 | 档位 | 分流电阻 | 控制刀闸连接 |
|------|------|---------|-------------|
| 1 | 50mA | 4Ω | COM → T1 |
| 2 | 500mA | 0.4Ω | COM → T2 |
| 3 | 5A | 0.04Ω | COM → T3 |
| 4 | 预留 | 未连接 | COM → T4（DCA 中未使用） |

### 4.2 档位的物理实现——模拟开关

`SmartAnalogSwitch` 内部使用刀闸（Blade）模型实现通道选择：

```
                    T1(4Ω)  T2(0.4Ω)  T3(0.04Ω)  T4(空)
                       ▲       ▲         ▲         ▲
                       │       │         │         │
                       │       │         │         │
        ┌──────────────┤       │         │         │
        │   Blade      ├───────┤         │         │
        │  (刀闸)       ├───────┼─────────┤         │
        │              ├───────┼─────────┼─────────┤
        └──────────────┘       │         │         │
               ▲               │         │         │
               │               │         │         │
              COM ─────────────┴─────────┴─────────┘
```

当位置为 1 时，COM 端通过刀闸连接到 T1（4Ω 分流电阻），其余端口断开。DMM 控制器通过 `sw.getPosition()` 得知当前位置后，即可从预先定义的 `_shuntValues` 数组取得对应的分流电阻值：

```javascript
this._shuntValues = [4, 0.4, 0.04];    // 分流电阻值
this._rangeNames = ['50mA', '500mA', '5A'];  // 档位名称
// pos 从 1 开始，所以用 pos-1 索引
const Rs = this._shuntValues[pos - 1];
const rangeName = this._rangeNames[pos - 1];
```

### 4.3 档位切换的完整流程

1. **DMM 启动**：默认位于 50mA 档（pos=1）
2. **自动量程判断**：`DMMController.tick()` 在每个仿真步读取分流电压，调用 `_autoRange()` 检测是否需要换档
3. **切换指令**：`_autoRange()` 调用 `sw.setPosition(newPos)` 修改开关内部位置
4. **电路拓扑变更**：开关位置变化后，刀闸连接到新的分流电阻
5. **MNA 求解器自动响应**：开关位置变化改变了电路拓扑（不同分流电阻接入），下一次 MNA 求解时自动计算新的电压分布
6. **DMM 继续读取**：下一帧 `DMMController.tick()` 用新位置对应的分流电阻值进行计算

### 4.4 实际 DMM 中的实现对比

在实际数字万用表中，档位获取通常通过以下方式之一实现：

| 方法 | 说明 |
|------|------|
| **旋转开关编码** | 机械旋转开关带有多位编码输出，MCU 通过 GPIO 读取编码值确定档位 |
| **模拟开关 + ADC 采样** | 使用模拟多路复用器（如 4051），MCU 通过 GPIO 控制通道选择 |
| **继电器组** | 大电流档位使用继电器切换分流电阻 |

本仿真平台采用的 `SmartAnalogSwitch` + `setPosition()` / `getPosition()` 模式，抽象了上述物理实现，使学员可以专注于理解量程切换的逻辑本身。

## 5. 总结

本数字万用表直流电流测量系统的完整工作流程：

```
DC Current Source → Smart Analog Switch (量程选择)
                               │
                    ┌──────────┴──────────┐
                    │ 刀闸连接到分流电阻     │
                    │ COM → T1/T2/T3       │
                    └──────────┬──────────┘
                               │
                    ┌──────────▼──────────┐
                    │ 分流电阻 (4/0.4/0.04Ω) │
                    │ 将 I → V (I×Rs)      │
                    └──────────┬──────────┘
                               │ (电压: 0~200mV)
                    ┌──────────▼──────────┐
                    │ DMM Controller       │
                    │ 1. 读取电压 V          │
                    │ 2. 查询档位 pos        │
                    │ 3. I = V / Rs[pos]    │
                    │ 4. 自动量程判断         │
                    │ 5. LCD 显示            │
                    └──────────────────────┘
```

三大设计要点：

1. **分流电阻匹配**：每个量程的分流电阻值 Rs = 200mV / Ifs，确保满量程时电压统一为 200mV
2. **自动量程双阈值**：上升阈值 180mV（90%）和下降阈值 12mV（6%），配合 0.5s 冷却时间防振荡
3. **档位查询机制**：通过模拟开关的 `getPosition()` 获取当前档位，查表得到对应的分流电阻值和显示格式
