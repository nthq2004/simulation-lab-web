# 数字万用表直流电压测量原理

## 一、概述

本仿真工程（`project/digitmeter_DCV.js`）完整实现了数字万用表直流电压测量与自动量程切换的全过程。其核心思想是：**所有档位的被测电压最终都通过电阻分压网络衰减到 200mV 以内，再由模数转换器（ADC）进行测量**。

---

## 二、测量链路总览

```
被测电压 (0~200V)
       │
       ▼
  电阻分压网络        ← 将任意输入电压衰减至 ≤200mV
       │
       ▼
  智能模拟开关        ← 选择当前档位的分压电阻（档位切换）
(SmartAnalogSwitch)
       │
       ▼
  DMM 数字控制器       ← 测量分压中点电压 V_mid，根据分压比反算输入电压
(DMMController)
       │              ← 内含 200mV ADC 转换 + 自动量程逻辑
       ▼
  数字万用表显示      ← 万用表组件接收电压值，按档位格式化显示
(Multimeter.js)
```

---

## 三、电阻分压网络详解

### 3.1 电路结构

分压网络由一个公共上电阻 `r_common`（10kΩ）和四个可选下电阻组成：

```
Vin ──┬── r_common (10kΩ) ──┬── V_mid (接 DMM 控制器 Vin+)
      │                     │
      │               ┌─────┴─────┐
      │               │  模拟开关  │
      │               │   (选通)   │
      │               └─────┬─────┘
      │                     │
      │               ┌─────┴─────┐
      │         ┌─────┤    GND    ├─────┐
      │         │     └───────────┘     │
      │    div_200mV  div_2V   div_20V  div_200V
      │     (10MΩ)   (1111Ω)  (100Ω)   (10Ω)
      │         │       │       │       │
      └─────────┴───────┴───────┴───────┘
                                         │
                                        GND
```

### 3.2 各档位分压比

| 档位 | 下电阻值 | 分压比 `V_mid / Vin` | 等效满量程 |
|------|---------|---------------------|-----------|
| 200mV | 10MΩ | 0.999 ≈ 1 | 200mV × 1 = 200mV |
| 2V | 1111Ω (≈1kΩ) | 0.0999 ≈ 1/10 | 200mV × 10 = 2V |
| 20V | 100Ω | 0.0099 ≈ 1/100 | 200mV × 100 = 20V |
| 200V | 10Ω | 0.001 = 1/1000 | 200mV × 1000 = 200V |

> 分压比计算：`V_mid / Vin = R_div / (R_common + R_div)`

**关键观察**：无论输入电压多高，经过分压后到达 DMM 控制器 Vin+ 端的电压 **始终不超过 200mV**。

## 四、200mV 模数转换器（ADC）的核心作用

### 4.1 为什么是 200mV？

数字万用表内部使用一个 **满量程为 200mV 的 ADC**，这是整个测量系统的"基准量程"。选择 200mV 的原因：

- **分辨率高**：200mV 满量程对应一个较小的电压范围，ADC 的每一位（bit）代表的电压值更小，测量精度更高
- **量程扩展灵活**：通过外部分压电阻可以等比扩展量程，且误差仅取决于电阻精度
- **工业标准**：200mV 是数字万用表 ADC 的经典满量程值（如 ICL7106/7107 系列芯片）

### 4.2 ADC 在仿真中的体现

在本项目的 `DMMController.js` 中，ADC 的测量工作由 `tick()` 方法的以下代码完成：

```javascript
// 读取 Vin+ 与 Vin- 之间的电位差（即分压中点电压 V_mid）
voltage = this.sys.getVoltageBetween(vp, vn);

// 根据当前档位的分压比反算实际输入电压
const ratio = this._dividerRatios[pos - 1];
const V_src = voltage / ratio;  // 反算实际输入电压
```

这里 `getVoltageBetween()` 返回的值相当于 ADC 转换后的数字量换算回模拟电压的结果。**核心等式**：

```
V_actual = V_mid / ratio
```

- `V_mid` = ADC 测量到的分压中点电压（≤200mV）
- `ratio` = 当前档位的分压比
- `V_actual` = 被测电压的真实值

### 4.3 各档位 ADC 输入与实际电压对应关系

| 档位 | ADC 测量范围 | 分压比 | 实际电压范围 | 显示举例 |
|------|-------------|--------|-------------|---------|
| 200mV | 0~200mV | 0.999 | 0~200mV | 100.0 mV |
| 2V | 0~200mV | 0.0999 | 0~2V | 1.500 V |
| 20V | 0~200mV | 0.0099 | 0~20V | 12.50 V |
| 200V | 0~200mV | 0.001 | 0~200V | 100.0 V |

例如 20V 档输入 12.5V 时：
- `V_mid = 12.5 × 0.0099 = 0.12375V = 123.75mV`
- ADC 测得 123.75mV
- `V_actual = 123.75mV / 0.0099 = 12.5V`

## 五、自动量程切换原理

### 5.1 控制信号路径

DMMController 通过两根控制线 A、B 连接 SmartAnalogSwitch，以二进制编码选择档位：

```javascript
// DMMController 端口
this.addPort(0, 140, 'a', 'wire', 'p');
this.addPort(0, 190, 'b', 'wire');

// SmartAnalogSwitch 端口
this.addPort(W, 100, 'a', 'wire', 'p');
this.addPort(W, 140, 'b', 'wire');
```

### 5.2 档位编码

| 档位号 `pos` | 对应量程 | A 电平 | B 电平 | 说明 |
|-------------|---------|--------|--------|------|
| 1 | 200mV | L | L | 最灵敏档 |
| 2 | 2V | H | L | |
| 3 | 20V | L | H | |
| 4 | 200V | H | H | 最不灵敏档 |

### 5.3 自动量程决策逻辑

在 `DMMController._autoRange()` 中实现，基于分压中点电压 `V_mid`（即 ADC 输入电压）做判断：

```javascript
_autoRange(voltage, pos) {
    // 升档：V_mid > 180mV → 当前量程太小，切换到更大量程
    if (pos === 1 && voltage > 0.18)     setPosition(2);  // 200mV→2V
    else if (pos === 2 && voltage > 0.18) setPosition(3);  // 2V→20V
    else if (pos === 3 && voltage > 0.18) setPosition(4);  // 20V→200V

    // 降档：V_mid < 12mV → 当前量程太大，切换到更小量程
    else if (pos === 2 && voltage < 0.012) setPosition(1); // 2V→200mV
    else if (pos === 3 && voltage < 0.012) setPosition(2); // 20V→2V
    else if (pos === 4 && voltage < 0.012) setPosition(3); // 200V→20V
}
```

**关键阈值**：
| 参数 | 值 | 含义 |
|------|-----|------|
| 升档阈值 | 0.18V (180mV) | ADC 输入超过满量程的 90% 时升档 |
| 降档阈值 | 0.012V (12mV) | ADC 输入低于满量程的 6% 时降档 |
| 冷却期 | 0.5s | 每次切换后等待 0.5s 再判断，防止频繁跳变 |

### 5.4 自动量程工作示例

假设初始为 200mV 档，输入电压从 0 逐渐升高：

```
时间轴：
1. Vin = 50mV  → V_mid ≈ 50mV  → 200mV 档，正常显示
2. Vin = 200mV → V_mid ≈ 200mV → 180mV 阈值触发升档 → 切至 2V 档
3. 切至 2V 档 → V_mid = 200mV/(10) = 20mV → 在 12~180mV 之间 → 保持
4. Vin = 5V    → V_mid = 5V/10 = 500mV → 180mV 阈值触发升档 → 切至 20V 档
5. 切至 20V 档 → V_mid = 5V/100 = 50mV → 在 12~180mV 之间 → 保持
```

## 六、档位信息的获取与传递

### 6.1 智能模拟开关（SmartAnalogSwitch）

`SmartAnalogSwitch.js` 维护两个关键状态：

```javascript
this.currentFunction = 'DCV';  // 功能选择：DCA / DCV / ACV / R / C / Diode
this.position = 1;             // 档位位置：1-4（对应四个分压电阻）
```

外部通过 `getFunction()` 和 `getPosition()` 读取当前状态。

### 6.2 DMM 控制器获取档位

DMMController 的 `tick()` 方法在每个仿真循环中：

```javascript
tick(dt) {
    const sw = this._getSwitch();
    const func = sw.getFunction();   // 获取当前功能（DCV、DCA...）
    const pos = sw.getPosition();     // 获取当前档位位置(1-4)

    if (func === 'DCV') {
        const ratio = this._dividerRatios[pos - 1];       // 查分压比
        const V_mid = Math.abs(voltage);                   // ADC 测量值
        const V_src = V_mid / ratio;                       // 反算真实电压
        const rangeName = this._rangeNamesDCV[pos - 1];    // 获取档位名称
    }
}
```

### 6.3 万用表组件获取档位

`Multimeter.js` 通过旋钮物理角度确定档位：

```javascript
_updateModeByAngle(angle) {
    // 角度归一化后映射到档位字符串
    // 30°步进，12个档位均匀分布在 360° 圆周
    switch (true) {
        case (normalizedAngle >= 320 && normalizedAngle < 340):
            this.mode = 'DCVmv';    // 200mV 档
            break;
        case (normalizedAngle >= 290 && normalizedAngle < 310):
            this.mode = 'DCV20';    // 20V 档
            break;
        case (normalizedAngle >= 260 && normalizedAngle < 280):
            this.mode = 'DCV200';   // 200V 档
            break;
        // ...
    }
}
```

### 6.4 数据传递全路径

```
用户操作旋钮
    │
    ▼
SmartAnalogSwitch.setPosition(pos)   ← 模拟开关接通对应触点
    │
    ▼
DMMController.tick()                 ← 读取 Vin+ 与 Vin- 间电压
    │  ├─ sw.getPosition() → 查分压比 ratio
    │  ├─ getVoltageBetween → 获取 V_mid（ADC 输入）
    │  └─ V_src = V_mid / ratio → 反算输入电压
    │
    ▼
InstrumentUpdater._updateMultimeter()  ← 读取 V 与 COM 端口电位差
    │
    ▼
Multimeter.update(V_src)             ← 按档位格式化显示
    ├─ DCVmv: V_src × 1000 → "XXX.X mV"
    ├─ DCV20: V_src → "XX.XX V"
    └─ DCV200: V_src → "XXX.X V"
```

## 八、总结

```
                   ┌────────────────────────────────────┐
                   │  数字万用表直流电压测量核心原理       │
                   │                                      │
                   │  任何输入电压 → 分压至 ≤200mV        │
                   │                  → ADC 转换          │
                   │                  → 分压比反算原值     │
                   │                  → 按档位格式化显示   │
                   └────────────────────────────────────┘

自动量程本质：
  监测 ADC 输入电压 V_mid
  V_mid > 180mV → 升档（增大分压比，减小 V_mid）
  V_mid < 12mV  → 降档（减小分压比，增大 V_mid）
  始终将 V_mid 保持在 12mV ~ 180mV 的最佳测量区间
```
