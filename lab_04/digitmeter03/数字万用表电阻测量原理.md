# 数字万用表电阻测量原理

## 一、概述

本仿真平台完整实现了**数字万用表**（DMM）电阻测量与**指针式万用表**（MF47）电阻测量的仿真，涵盖：

- DMM 自动量程切换（恒流源法）
- 指针式万用表欧姆档电路（半偏法）
- 普通数字万用表 Multimeter 组件的被动测量（等效电阻法）

---

## 二、数字万用表电阻测量原理（恒流源法）

### 2.1 基本原理

数字万用表测量电阻的核心原理：

1. 向被测电阻 **Rx** 注入已知恒定电流 **I_test**
2. 测量 Rx 两端的电压降 **V_meas**
3. 根据欧姆定律计算：**Rx = V_meas / I_test**

这种方法的优点：
- 精度高，不受表头内阻影响
- 适合自动化量程切换
- 测量结果线性，无需半偏法折算

### 2.2 系统组成

在 `project/digitmeter_OHM.js` 中，电阻测量系统由以下组件构成：

| 组件 | 作用 |
|------|------|
| `ConstantCurrentSource` | 提供 4 档恒流测试电流（1mA、100µA、10µA、1µA） |
| `SmartAnalogSwitch` | 4 选 1 模拟开关，选择其中一档电流注入 |
| `DMMController` | 读取电压、计算电阻、执行自动量程 |
| `RealResistor (test_r)` | 被测电阻 Rx，通过滑块调节（0 ~ 2MΩ） |

### 2.3 四档量程设计

| 档位 | 测试电流 | 满量程 | 显示精度 |
|------|----------|--------|----------|
| 位置 1 | **1mA** | 200Ω | 0.1Ω |
| 位置 2 | **100µA** | 2000Ω | 1Ω |
| 位置 3 | **10µA** | 20kΩ | 0.01kΩ |
| 位置 4 | **1µA** | 200kΩ | 0.1kΩ |

测试电流与量程的对应关系：**满量程电压 = I_test × R_max ≈ 0.2V**。

例如位置 1：1mA × 200Ω = 0.2V，即 ADC 最多测量 0.2V，等效于 200Ω 量程。

### 2.4 恒流源实现

`ConstantCurrentSource` 组件定义 4 个电流输出端口 `i1~i4`，对应的电流值在 `DeviceStamps.js` 中注入：

```js
const CURRENTS = [0.001, 0.0001, 0.00001, 0.000001]; // 1mA, 100µA, 10µA, 1µA
```

`stampCCSources()` 方法（第 909-929 行）为每个电流端口注入 MNA stamper：

- **标准模式**：电流源直接注入，`G · V = B` 中的 B 增加电流项
- **电压限幅模式**：如果 `R_req × I_test > 1.0V`（超过恒流源顺应电压），则自动切换为 **1V 电压源模式**，防止开路时电压无限升高

顺应电压（Compliance Voltage）是恒流源的重要参数：当负载电阻过大时，恒流源无法继续维持恒定电流，本仿真将限幅值设为 1.0V。

### 2.5 自动量程切换 (Auto-Ranging)

核心实现在 `DMMController.js` 的 `_autoRange()` 方法（第 98-112 行）：

```js
_autoRange(voltage, pos) {
    // 升档条件：电压 > 0.18V → 量程过小，增大量程
    if (pos === 1 && voltage > 0.18)  setPosition(2);
    if (pos === 2 && voltage > 0.18)  setPosition(3);
    if (pos === 3 && voltage > 0.18)  setPosition(4);
    // 降档条件：电压 < 0.012V → 量程过大，减小量程
    if (pos === 2 && voltage < 0.012) setPosition(1);
    if (pos === 3 && voltage < 0.012) setPosition(2);
    if (pos === 4 && voltage < 0.012) setPosition(3);
}
```

**升/降档逻辑**：

| 条件 | 含义 | 操作 |
|------|------|------|
| V_meas > **0.18V** | 测试电流过大→ Rx 两端电压超过满量程 | 升档（降低测试电流） |
| V_meas < **0.012V** | 测试电流过小→ Rx 两端信噪比不足 | 降档（增大测试电流） |

**防抖机制**：每次量程切换后，强制冷却 **0.5 秒**，避免频繁振荡切换（第 135-138 行）。

**物理意义**：
- 0.18V 阈值 ≈ 满量程电压（0.2V）的 90%，留出测量裕量
- 0.012V 阈值 ≈ 满量程电压的 6%，保证低端信号有足够分辨率

### 2.6 完整工作流程

```
用户调节 Rx → 恒流源注入 I_test → SmartAnalogSwitch 选通
    → 电流流过 Rx 产生 V_meas
    → DMMController 读取 V_meas
    → 计算 R = V_meas / I_test
    → 判断是否超量程？是→切换档位（不同电流）
    → 格式化显示（Ω/kΩ 自动切换）
    → 下一帧重复
```

每帧 (`tick(dt)`，第 114-216 行) 的完整流程在图中清晰展示：

1. 读取 `vin_p` 与 `vin_n` 之间的电位差 `voltage`
2. 从开关获取当前量程位置 `pos`
3. 取得对应测试电流 `I_test = _ohmsTestCurrents[pos-1]`
4. 计算 `R = V_meas / I_test`
5. 执行 `_autoRange(V_meas, pos)`，必要时切换量程
6. 在 LCD 显示区域更新：
   - 函数指示：`R`
   - 量程指示：`200Ω` / `2000Ω` / `20kΩ` / `200kΩ`
   - 测量数值及单位（Ω 或 kΩ 自动切换）
7. 溢出（R > 满量程）时显示 `OL`

## 三、指针式万用表（MF47）电阻测量原理（半偏法）

### 3.1 基本原理

MF47 指针式万用表使用**半偏法**测量电阻，核心是磁电式表头：

- 表头满偏电流：**Ig = 46.2µA**
- 表头内阻：**Rg = 5000Ω**

电路模型：**电池 → 限流电阻 R_series → (分流电阻 R_shunt ‖ 表头 Rg) → 被测电阻 Rx → 电池负极**。

### 3.2 四档欧姆量程

| 档位 | 倍率 | 电池电压 | R_series | R_shunt | R_mid |
|------|------|----------|----------|---------|-------|
| ×10 | ×10 | 1.5V | 169Ω | 31Ω | 200Ω |
| ×100 | ×100 | 1.5V | 1692Ω | 328Ω | 2000Ω |
| ×1K | ×1000 | 1.5V | 16920Ω | 8021Ω | 20000Ω |
| ×10K | ×10000 | 9V | 190000Ω | 无 | 195000Ω |

### 3.3 半偏法原理

1. **Rx = 0**（表笔短路）：电流最大，表头指针**满偏**（偏转角 100%）

2. **Rx = R_mid**（中值电阻）：电流减半，表头**半偏**（偏转角 50%）

   中值电阻 R_mid = 倍率 × 20Ω，这是 MF47 的标尺设计值。

3. **Rx = ∞**（表笔开路）：电流为零，指针不偏转（偏转角 0%）

### 3.4 读取公式

在 `MF47Multimeter.js`（第 663-680 行），通过测得的电压差反算 Rx：

```
V_measured = V(COML) - V(v)          // 测量 COM 与 V 端口电压差
R_int = getInputImpedance()          // 当前档位等效内阻（中值电阻）
V_bat = 1.5V (或 9V for ×10K 档)     // 电池电压
Rx = V_measured × R_int / (V_bat - V_measured)
```

其中 `R_int = multiplier × 20`，即中值电阻。

### 3.5 指针偏转计算

指针偏转角由表头电流决定（第 723-727 行）：

```
deflection = Rmid / (Rmid + Rx)
```

- Rx = 0 时：deflection = 1（满偏）
- Rx = Rmid 时：deflection = 0.5（半偏）
- Rx = ∞ 时：deflection = 0（不偏）

### 3.6 MNA 注入模型

在 `DeviceStamps.js` 的 `stampMF47()`（第 931-957 行），电阻档等效为**诺顿等效电路**：

```
内阻 R = R_int 并联在 VΩI 与 COM 之间
电流源 I = V_bat / R_int 从 COM 流向 VΩI
```

这种注入方式将指针万用表视为一个带电池的"主动电阻"网络，由 CircuitSolver 统一求解。

## 四、普通数字万用表（Multimeter 组件）的被动测量

### 4.1 等效电阻法

在 `InstrumentUpdater.js` 的 `_measureResistance()`（第 149-189 行），Multimeter 的电阻测量采用**等效电阻计算法**：

1. 检查 COM 与 V 端口之间是否有电压偏置（<0.1V）
2. 若无偏置，认为电路处于"无外部激励"状态
3. 使用 `_getEquivalentResistance()` 计算 COM 与 V 端口簇之间的等效电阻

### 4.2 等效电阻计算实现

在 `CircuitUtils.js` 的 `getEquivalentResistance()`（第 92-272 行），采用**矩阵注入试探法**：

```
1. 以 COM 端为参考地，建立节点映射
2. 遍历所有电阻类设备，收集电阻列表：
   - 普通电阻、PT100、热电偶内阻
   - 继电器触点电阻
   - 压力传感器、CAN 总线终端
   - 校准仪（SRC_RES/SRC_RTD 模式）
   - MF47 万用表内阻
3. 在 V 端注入 1A 测试电流
4. 构建仅含电阻的导纳矩阵 G
5. 高斯消元求解 V 端电压
6. R_eq = V / 1A = V
```

结果被缓存到 `_equivResCache`，仅当拓扑签名变化时清空，避免重复计算。

### 4.3 显示处理

Multimeter 组件（`Multimeter.js`，第 517-671 行）的电阻显示规则：

| 模式 | 单位 | 精度 | 最大显示值 |
|------|------|------|-----------|
| RES200 | Ω | 0.01Ω | 200.00Ω |
| RES2k | kΩ | 0.001kΩ | 1.999kΩ |
| RES200k | kΩ | 0.1kΩ | 199.9kΩ |

## 五、三种测量方式对比

| 特性 | DMM 恒流源法 | MF47 半偏法 | Multimeter 等效电阻法 |
|------|-------------|------------|---------------------|
| 是否需要电池 | 否（外部恒流源） | 是（1.5V/9V） | 否（被动测量） |
| 刻度线性 | 线性（Rx ∝ V） | 非线性（Rx = f(1/偏转-1)） | 线性 |
| 自动量程 | ✅ 支持（智能切换） | ❌ 手动切换 | ❌ 手动切换 |
| 精度 | 高（电流源稳定） | 中（受电池电压影响） | 中（受网络拓扑影响） |
| 测量原理 | 恒流 + 测电压 | 恒压 + 测电流（半偏） | 注入 1A 试探电流 |

## 六、CircuitSolver 中的关键支持

### 6.1 拓扑感知缓存

`CircuitSolver._invalidateCacheIfNeeded()`（第 131-186 行）构建拓扑签名：

```
签名 = 所有连接串 + 所有电阻值 + 开关位置 + 万用表模式 ...
```

签名变化时自动清空等效电阻缓存，保证测量数据的实时性。

### 6.2 MNA Stamp 注入

在 `_solve()` 中，电阻档相关的 stamp 注入依次为：

1. 第 353 行：`stampResistors()` — 普通电阻
2. 第 412 行：`stampCCSources()` — 恒流源（电流源/电压源自适应）
3. 第 416 行：`stampMF47()` — 指针万用表等效诺顿源

### 6.3 求解后仪表更新

`InstrumentUpdater.update()`（第 117-147 行）对所有仪表执行求解后更新：

```js
_updateMultimeter(dev) {
    if (dev.mode.startsWith('RES'))  dev.update(this._measureResistance(dev));

    if (dev.mode.startsWith('DCV')) dev.update(solver.getPD(v, com));
    // ...
```

## 七、总结

本仿真平台实现了两种电阻测量方法的完整教学仿真：

1. **数字万用表 DMM**：采用**恒流源法**，通过 SmartAnalogSwitch 切换四档测试电流（1mA~1µA），DMMController 根据电压自动选择最优量程，模拟真实数字万用表的自动量程功能

2. **指针式 MF47 万用表**：复现经典的**半偏法**电路，包含电池、限流电阻、分流电阻网络，指针偏转遵循 `Rmid / (Rmid + Rx)` 非线性规律

3. **底层支持**：CircuitSolver 通过 MNA 改进节点分析法统一求解，DeviceStamps 完成各器件的矩阵注入，InstrumentUpdater 负责求解后的仪表数值更新

教学中可通过调节滑块改变 Rx，观察量程自动切换过程和指针偏转变化，直观理解"恒流测压"和"半偏法"两种电阻测量原理的本质区别。
