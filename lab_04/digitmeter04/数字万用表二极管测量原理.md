# 数字万用表二极管测量原理

## 一、概述

数字万用表（DMM）的二极管测量档（通常以二极管符号标识）用于检测半导体二极管的单向导电性、判断管脚极性并估测其正向导通压降（Vf）。本文从电路原理出发，分析两种常见的实现方案：**恒流注入法**（本仿真采用）和**电压源串联电阻法**，并加以比较。

## 二、二极管的基本特性

理想二极管正向导通时压降恒定（硅管约 0.6~0.7 V，锗管约 0.2~0.3 V，肖特基管约 0.3~0.4 V）；反向偏置时电流几乎为零，呈现高阻态。实际 DMM 利用这一特性：**施加一个已知的测试电流，测量二极管两端的电压，从而判断其好坏与极性**。

## 三、方法一：恒流注入法（本仿真采用）

### 3.1 电路拓扑

```
恒流源 (1mA) ──→ 量程开关 ──→ 限流保护电阻 Rₚ (1kΩ)
                                        │
                                   ┌────┴────┐
                                   │  被测    │
                                   │  二极管  │
                                   └────┬────┘
                                        │
                                    ┌───┴───┐
                                    │  GND  │
                                    └───────┘

分压网络（并联在二极管两端）：

  二极管阳极 ──→ R₁ (19kΩ) ──→ 分压中点 ──→ R₂ (1kΩ) ──→ GND
                                        │
                                    DMM Vin+
```

### 3.2 正向偏置

1. 恒流源输出 1 mA 测试电流，经量程开关和保护电阻 Rₚ 注入二极管阳极。

2. 二极管正向导通，两端产生约 0.6 V 的压降 Vf（硅管典型值）。

3. 压降 Vf 被 19kΩ + 1kΩ 电阻网络分压：

   $$
   V_{\text{mid}} = V_f \times \frac{R_2}{R_1 + R_2} = V_f \times \frac{1}{20}
   $$
   当 Vf = 0.6 V 时，分压中点电压为 30 mV。

4. DMM 内部的 ADC 测量分压中点电压，再由 MCU 乘以 20 还原显示：

   $$
   V_{\text{display}} = V_{\text{mid}} \times 20 = V_f
   $$
屏幕显示 `0.600` V。

### 3.3 反向偏置（二极管反接）

1. 二极管反接时处于截止状态，等效电阻极大（约 10⁸ Ω）。

2. 恒流源检测到负载电阻超过顺从电压阈值（本仿真设为 10V），即：

   $$
   I_{\text{test}} \times R_{\text{load}} > V_{\text{compliance}}
   $$
   自动切换为电压源模式，输出顺从电压上限 10 V。

3. 此时二极管两端电压为 10 V，分压后为 500 mV，经 20 倍还原为 10V。

4. DMM 控制器判定 10 V > 0.8 V（OL 阈值），屏幕显示 **OL**（Over Load），表示被测端为开路或二极管反接。

### 3.4 关键技术特点

| 特性 | 说明 |
|------|------|
| **测试电流** | 固定 1 mA（对大多数 PN 结安全，不会损坏器件） |
| **顺从电压** | 约 10 V（超过此电压则 CC 转为 CV 模式，防止过压） |
| **保护电阻** | 1kΩ 串联限流，即使误测已通电电路也有限流保护 |
| **检测精度** | 电流恒定，测量结果不受引线和接触电阻影响 |
| **自动量程** | 无需手动切换，OLED 亮起即自动执行检测 |

## 四、方法二：电压源串联电阻法

### 4.1 电路拓扑

```
电池 (3 V) ──→ 限流电阻 Rₛ (1kΩ) ──→ 被测二极管 ──→ GND
                                        │
                                     DMM Vin+
                                        │
                                     GND Vin-
```

这是一种更简单的实现方案，常见于低成本的指针式万用表或简易 DMM。

### 4.2 工作原理

1. 电压源通过限流电阻 Rₛ 向二极管施加正向电压。
2. 二极管正向导通时，回路电流为：

   \[
   I = \frac{V_{\text{bat}} - V_f}{R_s}
   \]

   当 Vbat = 3 V、Rs = 1kΩ、Vf = 0.6 V 时，I ≈ 2.4 mA。
3. DMM 测量二极管两端的电压 Vf 并直接显示。
4. 反接时二极管截止，回路电流几乎为零，Vf = Vbat ≈ 3 V，屏幕显示 OL。

### 4.3 局限性

| 问题 | 分析 |
|------|------|
| **电流不恒定** | 回路电流随 Vf 变化（Vf 越小电流越大），不同种类二极管测量条件不一致 |
| **引线电阻影响** | 小 Vf 测量时引线压降会引入显著误差 |
| **功率偏高** | 3V 电池通过 1kΩ 短路时电流可达 3 mA，功耗高于恒流法 |
| **保护不足** | 缺少恒流源的顺从电压限制机制，误操作时易损坏 |

## 五、两种方法对比

| 对比维度 | 恒流注入法（本仿真） | 电压源串联电阻法 |
|----------|---------------------|-----------------|
| **激励源** | 1 mA 恒流源 | 3 V 电池 + 1kΩ 电阻 |
| **测量原理** | 电流固定，测电压 | 电压固定，电流由 Vf 决定 |
| **Vf 显示精度** | 高（电流恒定 × 20 缩放） | 中（受 Rs 精度和温度影响） |
| **反接检测** | CC 顺从电压 1V → OL | 截止电压 ≈ Vbat → OL |
| **电路复杂度** | 需要恒流源电路 + 分压网络 + MCU 缩放计算 | 仅需电阻分压，ADC 直接读取 |
| **功耗** | 低（1 mA 测试电流） | 中（短路可达 3 mA） |
| **抗干扰能力** | 强（共模抑制比高） | 弱 |
| **典型应用** | 中高端数字万用表 | 简易万用表、指针表 |

## 六、本仿真项目的实现要点

1. **恒流源**（`ConstantCurrentSource`）：提供 1 mA / 100 μA / 10 μA / 1 μA 四档测试电流，本工程使用 1 mA 档位，顺从电压 1 V。
2. **分压网络**：19kΩ + 1kΩ 构成 1/20 分压，将 Vf 缩放至 DMM 控制器的 ADC 量程范围（约 200 mV 满量程），再由软件乘以 20 还原显示。
3. **DMM 控制器**（`DMMController`）：在 `Diode` 模式下读取分压中点电压 → ×20 还原 → 判定 OL 阈值（>0.8V）→ 输出显示。
4. **正反向切换**：通过"反向测试"复选框切换二极管与回路的连接极性，同时旋转二极管图形 180° 以直观反映接线状态。
5. **导通压降可调**：滑块在 200 mV ~ 800 mV 范围内调节二极管的 vForward 参数，模拟不同类型二极管（肖特基、硅管、LED 等）的教学演示。

## 七、总结

恒流注入法是现代数字万用表二极管测量的主流方案。其核心优势在于：**测试电流恒定 → 测量条件统一 → 结果可重复、可对比**。分压和软件缩放技术使得 ADC 可以在最佳量程范围内工作，兼顾精度与分辨率。相比电压源串联电阻法，恒流法的测量一致性更好、保护机制更完善、对操作者更友好，这也是中高端 DMM 普遍采用此方案的原因。

本仿真工程在 Canvas 环境中完整还原了这一测量原理，操作者可以通过调节参数、切换正反向直观地观察电压变化与 DMM 显示结果之间的关系，深入理解数字万用表二极管测量的每一个环节。
