# 数字万用表电容测量原理

## 一、常用数字万用表电容测量方法

数字万用表测量电容主要有以下几种方法：

### 1. 恒流充电斜坡法（DC Ramp Method）

这是中低端数字万用表最常用的方法，适用于 **1µF 及以上** 的中大容量电容。

**原理：** 用已知的恒定电流 I 对被测电容 Cx 充电，同时用高精度比较器监视电容两端电压。当电压达到预设阈值 Vth（通常为 0.5V～2V）时停止计时，根据充电时间 t 计算电容值：

```
Cx = I × t / Vth
```

**典型参数：**
- 充电电流：1µA～1mA（根据量程自动切换）
- 阈值电压：0.5V～2V
- 测量范围：1µF～100mF

### 2. AC 阻抗法（AC Impedance Method）

适用于 **pF～µF 级** 小电容的高精度测量。

**原理：** 向被测电容施加已知频率 f 和幅值的正弦交流信号，测量流过电容的交流电流或电压降，通过容抗公式计算：

```
Zc = 1 / (2π × f × Cx)  →  Cx = I / (2π × f × V)
```

**典型参数：**
- 测试频率：100Hz～10kHz（自动量程选择）
- 测量范围：1pF～100µF

### 3. 振荡器法（Oscillator Method）

将电容接入 RC 振荡器或多谐振荡器，测量振荡频率变化推算电容值。常用于低端手持表。

**原理：** 电容与已知电阻 R 构成充放电路径，比较器控制充放电切换。振荡周期 T ∝ R × Cx，通过频率计测量周期计算：

```
f = 1 / (k × R × Cx)  →  Cx = 1 / (k × R × f)
```

### 4. 电桥法（Bridge Method）

传统高精度测量方法。通过调节已知元件使电桥平衡，利用平衡条件计算电容。

## 二、本仿真实现的测量原理

本仿真项目采用 **恒流充电斜坡法**，使用理想恒流源以 1mA 电流对被测电容充电，通过比较器（软件实现）检测电压达到 2V 的瞬间，计算电容值。

### 2.2 开关位置与工作模式

智能模拟开关（SmartAnalogSwitch）的 4 个端子对应不同工作模式：

| 开关位置 | COM 接通端子 | 工作模式 | 等效电路 |
|----------|-------------|----------|----------|
| 1 | T1 | **充电**（恒流源 1mA 接入） | CC 1mA → Cx → GND |
| 2 | T2 | **放电**（100Ω 电阻接入） | Cx → 100Ω → GND |
| 3 | T3 | **悬空**（未连接，等待状态） | 开路 |
| 4 | T4 | 未使用 | — |

### 2.4 核心计算公式

```
C = I × t / Vth

代入参数：
  I   = 0.001 A（1mA 恒流源）
  Vth = 2.0 V（阈值电压）
  t   = 仿真时间 = solver.currentTime - 起始时间（秒）

因此：  C = 0.001 × t / 2.0 = t × 0.0005 [法拉]
        C = t × 500 [微法]（t 以秒为单位时）
```

**示例计算：**

| 实际电容 | 理论充电时间至 2V | 步数（0.1ms/步） |
|----------|------------------|-----------------|
| 1 µF | 2.0 ms | 20 步 |
| 10 µF | 20 ms | 200 步 |
| 100 µF | 200 ms | 2000 步 |
| 470 µF | 940 ms | 9400 步 |
| 1000 µF | 2.0 s | 20000 步 |

### 2.5 MNA 数值求解

本仿真使用改进节点分析法（MNA）求解电路。电容测量的核心数值模型如下：

#### 恒流源的 Stamp

理想电流源在 MNA 中注入电流到右端项（RHS）B 向量，不增加矩阵维度：

```
B[节点_i1] += I_target    （+1mA）
B[节点_com] -= I_target   （-1mA）
```

#### 电容的伴随模型

电容采用向后欧拉法（Backward Euler）离散化为每步的伴随模型：

```
时域方程：  I(t) = C × dV/dt

离散化：    I ≈ (C/Δt) × (V_now - V_prev)

诺顿等效：
  等效电导：  gEq = C / Δt
  等效电流：  iEq = gEq × V_prev
  Stamp：    
    G[L][L] += gEq      G[L][R] -= gEq
    G[R][L] -= gEq      G[R][R] += gEq
    B[L] += iEq          B[R] -= iEq
```

其中 `V_prev` 为上一步的电容端电压，`Δt = 0.1ms` 为仿真步长。

#### 整体求解

```
G × V = B
```

矩阵 G 包含电阻、电容电导等所有线性元件的电导贡献；向量 B 包含恒流源注入电流和电容历史电流源。使用列主元高斯消元法求解节点电压 V。

## 三、仿真与实际 DMM 的对比

### 3.1 相同点

1. **基本原理一致**：都采用恒流充电 + 电压比较的方法
2. **放电保护**：测量前先放电，防止残余电荷影响精度
3. **计算公式一致**：C = I × t / Vth
4. **自动量程概念**：实际 DMM 自动切换测试电流，本仿真通过滑条手动选择量程

### 3.2 差异点

| 方面 | 实际数字万用表 | 本仿真 |
|------|--------------|--------|
| 恒流源实现 | 运算放大器 + 基准源 + 反馈电路 | 理想 MNA 电流注入（无顺从电压限制） |
| 比较器 | 硬件比较器（LM393）或 MCU ADC | 软件数值比较（`if (v >= 2.0)`） |
| 计时器 | 硬件定时器/计数器 | `solver.currentTime`（仿真时间步累计） |
| 测试电流 | 多量程自动切换（1µA～1mA） | 固定 1mA |
| 小电容测量 | AC 阻抗法/振荡器法（可测 pF 级） | 仅 DC 斜坡法（µF 级以上） |
| 归零补偿 | 开路归零消除杂散电容 | 无 |
| 保护电路 | 输入保护电阻、钳位二极管、保险丝 | 无 |
| 电解电容极性检测 | 有极性指示 | 无 |
| 导线电阻影响 | 大电容测量时存在 | 理想导线（零电阻） |

### 3.3 教学意义

本仿真尽管做了若干简化，但完整呈现了恒流充电法测量电容的 **核心原理**：

1. **恒流源**：理解电流源与电压源的差异，及其在测量电路中的作用
2. **时间-电压关系**：直观展示电容在恒流下的线性电压斜坡
3. **阈值检测**：比较器在测量中的角色——将模拟量转化为数字事件的触发点
4. **计算逻辑**：C = I × t / V 的物理含义与工程运用
5. **充放电管理**：测量前放电确保一致性，测量后放电保证安全

学生可以通过本仿真：
- 观察不同电容值下的充电波形
- 理解充电时间和电容值的正比关系
- 比较理论计算值与仿真测量值的偏差
- 分析仿真步长对测量精度的影响
