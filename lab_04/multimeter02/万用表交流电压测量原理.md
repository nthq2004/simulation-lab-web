# 万用表交流电压测量原理

## 1. 总体测量方案

本仿真项目以 **MF47 型指针式万用表** 为原型，展示交流电压测量全过程：

```
被测交流电压
    ↓
桥式全波整流（4×二极管）
    ↓
滤波电容平滑为直流（≈峰值电压）
    ↓
电阻分压链 + 磁电式表头
    ↓
指针偏转指示读数
```

### 核心元器件参数

| 元件 | 参数 | 说明 |
|------|------|------|
| 磁电式表头 `mf47-head` | 满偏电流 **46.2 μA**，内阻 **5 kΩ** | 满偏端电压 = 46.2μA × 5kΩ = **231 mV** |
| 整流桥 | 二极管 VF = 0.5V，全波桥式 | 两管同时导通，总压降 ≈ **1.0V** |
| 滤波电容 `c-filter` | 1 μF | 与分压链构成 RC 滤波，时间常数远大于 20ms（50Hz 周期） |
| 分压电阻链 | r-av50=1.5MΩ, r-av250=6.1MΩ, r-av500=7.6MΩ | 串联后经 SP4T 开关选择抽头 |
| 量程选择开关 SP4T | 4 档位：50V / 250V / 500V / 1000V | 切换分压链接入点 |

## 2. 交流电压测量原理

### 2.1 整流：AC → 脉动 DC

桥式全波整流将交流正弦波转换为单向脉动电压。

对于有效值为 $V_{rms}$ 的正弦交流电压：

- 峰值：$V_{peak} = V_{rms} \times \sqrt{2} \approx V_{rms} \times 1.414$
- 整流后经滤波电容保持，输出近似直流电压 $V_{DC} \approx V_{peak} - 2V_F$
- 代入二极管压降（每管 0.5V，两管导通）：$V_{DC} = V_{rms} \times \sqrt{2} - 1.0$

### 2.2 滤波：脉动 DC → 平滑 DC

滤波电容在整流后的半波间隙释放电荷，使电压基本维持峰值。RC 时间常数：
- 分压链总电阻约 1.5~15 MΩ（依量程而定）
- C = 1 μF
- τ = RC = 1.5 ~ 15 秒
- 50Hz 半波周期 = 10ms

τ >> 10ms，因此电容上的电压几乎等于峰值电压（纹波极小）。电容两端的 10MΩ 泄放电阻保证断电后安全放电。

### 2.3 分压：高压 → 表头可承受范围

磁电式表头满偏仅需 231 mV，不能直接测量高电压。采用电阻分压链将电压按比例衰减。

分压链结构（从表头正极向电源端看）：

```
表头 + (r-av50.L)
    │
  ┌──┴── r-av50 = 1.5MΩ ──┬── 抽头 t1 ──┐
  │                        │              │
  │                r-av250 = 6.1MΩ       │ SP4T
  │                        │              │ COM ─── V_DC
  │                   ──┬── 抽头 t2 ──┐  │
  │                     │              │  │
  │             r-av500 = 7.6MΩ       │  │
  │                     │              │  │
  │                   ──┴── 抽头 t3 ──┘  │
  │                                       │
  └──────────── 表头 - (GND) ─────────────┘
```

SP4T 公共端连接整流滤波后的直流电压 $V_{DC}$，切换不同抽头改变串入电路的电阻总值。

### 2.4 表头驱动

表头是电流灵敏器件，指针偏转角 $\alpha$ 正比于流过动圈的电流 $I$：

$$\alpha = k \cdot I = k \cdot \frac{V_{DC}}{R_{total}}$$

其中：
- $R_{total}$ = 分压电阻 + 表头内阻
- $k$ 为表头灵敏度常数
- 满偏时 $I = I_{fs} = 46.2 \mu A$

## 3. 三个档位分压电阻计算

### 3.1 计算原理

对于量程 $V_{rms}$，表头满偏时：

$$V_{DC} = V_{rms} \times \sqrt{2} - 1.0 \quad \text{(考虑整流压降)}$$

所需总电阻：

$$R_{total} = \frac{V_{DC}}{I_{fs}}$$

串联分压电阻：

$$R_{divider} = R_{total} - Rm \quad \text{(Rm = 5 kΩ)}$$

### 3.2 50V 档（SP4T 位置 0，抽头 t1）

SP4T 将 $V_{DC}$ 接入抽头 t1（r-av50 的右端）。电流路径：

$$V_{DC} \rightarrow t1 \rightarrow r\text{-av}50 \rightarrow \text{表头} \rightarrow \text{GND}$$

串入电路的仅有 r-av50（1.5MΩ），r-av250 和 r-av500 支路悬空。

计算过程：

| 步骤 | 公式 | 结果 |
|------|------|------|
| 整流后直流电压 | $V_{DC} = 50 \times 1.414 - 1.0$ | 69.71 V |
| 所需总电阻 | $R_{total} = 69.71 / 46.2 \times 10^{-6}$ | 1,508,874 Ω |
| 分压电阻 | $R_{div} = 1,508,874 - 5,000$ | 1,503,874 Ω |
| **实际取值** | | **1.5 MΩ** |

**误差**：(1,503,874 - 1,500,000) / 1,503,874 ≈ **0.26%**，可忽略。

### 3.3 250V 档（SP4T 位置 1，抽头 t2）

SP4T 将 $V_{DC}$ 接入抽头 t2（r-av250 的右端）。电流路径：

$$V_{DC} \rightarrow t2 \rightarrow r\text{-av}250 \rightarrow r\text{-av}50 \rightarrow \text{表头} \rightarrow \text{GND}$$

串入 r-av250 + r-av50 = 6.1MΩ + 1.5MΩ = 7.6MΩ。

| 步骤 | 公式 | 结果 |
|------|------|------|
| 整流后直流电压 | $V_{DC} = 250 \times 1.414 - 1.0$ | 352.50 V |
| 所需总电阻 | $R_{total} = 352.50 / 46.2 \times 10^{-6}$ | 7,629,870 Ω |
| 总需串联电阻 | $R_{div} = 7,629,870 - 5,000$ | 7,624,870 Ω |
| r-av50 已有 | | 1,500,000 Ω |
| **r-av250 取值** | $7,624,870 - 1,500,000$ | **6,124,870 Ω** → **6.1 MΩ** |

**误差**：(6,124,870 - 6,100,000) / 6,124,870 ≈ **0.41%**，可忽略。

### 3.4 500V 档（SP4T 位置 2，抽头 t3）

SP4T 将 $V_{DC}$ 接入抽头 t3（r-av500 的右端）。电流路径：

$$V_{DC} \rightarrow t3 \rightarrow r\text{-av}500 \rightarrow r\text{-av}250 \rightarrow r\text{-av}50 \rightarrow \text{表头} \rightarrow \text{GND}$$

串入三段电阻之和 = 7.6MΩ + 6.1MΩ + 1.5MΩ = 15.2MΩ。

| 步骤 | 公式 | 结果 |
|------|------|------|
| 整流后直流电压 | $V_{DC} = 500 \times 1.414 - 1.0$ | 706.00 V |
| 所需总电阻 | $R_{total} = 706.00 / 46.2 \times 10^{-6}$ | 15,281,385 Ω |
| 总需串联电阻 | $R_{div} = 15,281,385 - 5,000$ | 15,276,385 Ω |
| r-av50 + r-av250 已有 | | 1,500,000 + 6,100,000 = 7,600,000 Ω |
| **r-av500 取值** | $15,276,385 - 7,600,000$ | **7,676,385 Ω** → **7.6 MΩ** |

**误差**：(7,676,385 - 7,600,000) / 7,676,385 ≈ **1.0%**，仍在工程允许误差范围内。

### 3.5 计算结果汇总

| 档位 | 理算分压电阻 | 实际取值 | 相对误差 |
|------|-------------|---------|---------|
| 50V | 1.504 MΩ | 1.5 MΩ | 0.26% |
| 250V | 6.125 MΩ (含已有 1.5M) | 6.1 MΩ | 0.41% |
| 500V | 7.676 MΩ (含已有 7.6M) | 7.6 MΩ | 1.0% |

### 3.6 通用计算公式

对于任意交流电压量程 $V_{rms}$：

$$R_{add} = \frac{V_{rms} \times \sqrt{2} - 2V_F}{I_{fs}} - R_m - R_{existing}$$

其中：
- $V_{rms}$ — 量程满偏值（V，有效值）
- $V_F$ — 二极管正向压降（≈0.5V）
- $I_{fs}$ — 表头满偏电流（46.2 μA）
- $R_m$ — 表头内阻（5 kΩ）
- $R_{existing}$ — 本档位之前已串联的电阻值

## 4. 刻度与读数

### 4.1 磁电式表头的 AC 刻度

虽然表头本质是直流电流表，但使用**整流 + 滤波**后，流经表头的电流正比于被测交流电压的有效值。因此表盘上的 AC 刻度线可以直接按有效值标注。

### 4.2 数字万用表方案

本项目中同时还包含一个数字万用表组件（`Multimeter.js`），它采用不同的测量原理：通过 ADC（模数转换器）将整流后的直流电压转换为数字量，再由单片机查表或计算得到有效值，最后在 LCD 上显示。其 AC 档位为 ACV200（200V 量程，显示一位小数）和 ACV500（500V 量程，显示整数）。
