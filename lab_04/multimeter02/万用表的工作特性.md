# 万用表的工作特性：电流档内阻小、电压档内阻大

## 1. 根本原因：测量对象不同

| 测量模式 | 被测对象 | 对仪表的要求 |
|---------|---------|-------------|
| 电压档 | 两点之间的**电位差** | 内阻必须 **大**，以减小分流效应，不改变被测电路 |
| 电流档 | 回路中的**电荷流量** | 内阻必须 **小**，以减小压降效应，不改变被测电流 |

万用表接入被测电路时，本身就是一个额外的负载。为不干扰原电路的工作状态，需要：

- **测量电压**：与负载**并联** → 内阻越大，分流量越小 → 越接近理想 **开路**
- **测量电流**：与负载**串联** → 内阻越小，压降越小 → 越接近理想 **短路**

---

## 2. 磁电式表头基础

不论电压档还是电流档，最终都使用同一个磁电式表头。本仿真采用 MF47 型指针万用表的参数：

| 参数 | 符号 | 数值 |
|------|------|------|
| 满偏电流 | $I_g$ | **46.2 μA** |
| 表头内阻 | $R_g$ | **5000 Ω** |
| 满偏端电压 | $V_g = I_g R_g$ | 231 mV |

仅靠表头本身，其量程极小：**46.2 μA / 231 mV**。必须通过外围电阻变换量程。

---

## 3. 电压档：串联大电阻（分压）

### 原理

在表头正极端**串联**一个很大的分压电阻 $R_s$。

```
 V_in ── R_s ──┬── 表头 (R_g) ── COM
               │
               ↓  I = V_in / (R_s + R_g)
```

当 $R_s \gg R_g$ 时，电流主要由 $R_s$ 决定，表头偏转正比于被测电压。

### 档位计算

对于量程 $V_{fs}$，满偏时：

$$I_g = \frac{V_{fs}}{R_s + R_g} \quad\Longrightarrow\quad R_s = \frac{V_{fs}}{I_g} - R_g$$

| 量程 | 总需电阻 $V_{fs}/I_g$ | 分压电阻 $R_s$ | 输入阻抗 |
|------|----------------------|---------------|---------|
| 10V | 216 kΩ | 211 kΩ | 216 kΩ |
| 50V | 1.082 MΩ | 1.077 MΩ | 1.082 MΩ |
| 250V | 5.411 MΩ | 5.406 MΩ | 5.411 MΩ |

### 关键指标：灵敏度

MF47 的直流电压灵敏度：

$$\text{灵敏度} = \frac{1}{I_g} = \frac{1}{46.2 \,\mu\text{A}} \approx 21.6 \,\text{k}\Omega/\text{V}$$

即：每伏量程需要 21.6 kΩ 的输入电阻。这是磁电式仪表的重要性能指标。

### 影响

- 接入被测电路后，电压档产生**分流**（并联负载效应）
- 内阻越大，分流越小，测量越精确
- 测量高阻电路时，必须考虑仪表内阻的分流影响

---

## 4. 电流档：并联小电阻（分流）

### 原理

在表头两端**并联**一个很小的分流电阻 $R_{sh}$，使大部分电流从分流器通过。

```
 I_in ──┬── 表头 (R_g) ──┐
        │                │
        └── R_shunt  ────┘── COM
```

扩大后的量程：$I_{fs} = I_g + I_{sh}$，其中 $I_{sh} = I_g R_g / R_{sh}$。

### 档位计算

扩程至 $I_{fs}$，分流器电流 $I_{sh} = I_{fs} - I_g$，两端电压等于表头满偏压降 $I_g R_g$：

$$R_{sh} = \frac{I_g R_g}{I_{fs} - I_g}$$

| 量程 | $I_{sh}$ | 分流电阻 $R_{sh}$ | 输入阻抗 |
|------|---------|------------------|---------|
| 50 mA | 49.95 mA | $46.2\mu\text{A} \times 5000 / 49.95\text{mA} \approx$ **4.62 Ω** | 4.62 Ω |
| 500 mA | 499.95 mA | $46.2\mu\text{A} \times 5000 / 499.95\text{mA} \approx$ **0.462 Ω** | 0.462 Ω |

两个档位共用一个闭合式分流结构（**开路式转换**），量程越大分流电阻越小。

### 影响

- 电流档**串联**在被测回路中，会产生**电压降**（满偏时约 231 mV）
- 内阻越小，压降越小，对被测回路的影响越小
- 误将电流档**并联**到电压源上会烧毁仪表（内阻极小，相当于短路）

---

## 5. 内阻差异的数值对比

以 MF47 各档位为例：

| 档位 | 类型 | 输入阻抗 | 相对大小 |
|------|------|---------|---------|
| 10V DCV | 电压 | **216 kΩ** | 极高 |
| 50V DCV | 电压 | **1.08 MΩ** | 极高 |
| 250V DCV | 电压 | **5.41 MΩ** | 极高 |
| 50 mA DCmA | 电流 | **4.62 Ω** | 极低 |
| 500 mA DCmA | 电流 | **0.462 Ω** | 极低 |

**差 4~5 个数量级**，本质原因在于实现方式截然相反：

```
电压档：R_in = V_fs / I_g        （串联分压，内阻≈R_s）
电流档：R_in = (I_g·R_g) / I_sh  （并联分流，内阻≈R_sh）
```

---

## 6. 总结

| | 电压档 | 电流档 |
|--|-------|-------|
| 接入方式 | **并联**于被测两点 | **串联**于被测回路 |
| 理想状态 | 内阻 **∞**（开路） | 内阻 **0**（短路） |
| 实现手段 | 表头**串联**大电阻 **分压** | 表头**并联**小电阻 **分流** |
| 内阻量级 | **kΩ ~ MΩ** | **mΩ ~ Ω** |
| 计算依据 | $R_s = V_{fs}/I_g - R_g$ | $R_{sh} = I_g R_g / (I_{fs} - I_g)$ |
| 典型值 (MF47) | 216kΩ ~ 5.41MΩ | 0.46Ω ~ 4.62Ω |
| 使用禁忌 | 并联到高阻信号源时精度下降 | 严禁并联在电压源两端 |
