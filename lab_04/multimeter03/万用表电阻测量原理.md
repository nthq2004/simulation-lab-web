# 万用表电阻测量原理

## 一、概述

万用表测量电阻的核心原理是 **欧姆定律**：通过给被测电阻 Rx 施加一个已知的电压或电流，然后测量电路中的电流或电压，从而间接计算出 Rx 的阻值。

指针式万用表（如 MF47）采用 **串联法**：表内电池与 Rx 串联，通过测量回路电流来反映阻值。


---

## 二、磁电式表头（核心测量机构）

MF47 万用表的核心是一只 **磁电式电流表**（动圈式表头）：

| 参数 | 符号 | 值 |
|------|------|-----|
| 满偏电流 | Ig | 46.2 µA |
| 表头内阻 | Rg | 5000 Ω |
| 满偏电压 | Ug = Ig × Rg | 231 mV |

**工作原理**：载流线圈在永久磁铁的径向磁场中受到安培力矩，带动指针偏转。游丝产生反力矩，当两力矩平衡时，指针稳定。偏转角度 α ∝ 线圈电流 I，因此表头本身具有 **线性刻度**。

## 三、指针式万用表电阻测量原理（串、并联法）

### 3.1 基本电路结构

电阻档的简化等效电路：

```
电池(V_bat) → R_series → (R_shunt ‖ R_head) → 表笔(VΩ) → Rx → 表笔(COM) → 电池负极
```

其中：
- **R_series**：限流电阻（串联在主回路中）
- **R_shunt**：分流电阻（与表头并联，扩展量程）
- **R_head = Rg = 5000Ω**：表头内阻
- **R_eff = R_shunt ‖ R_head**：表头支路等效电阻
- **R_mid = R_series + R_eff**：中值电阻（欧姆档的总内阻）

### 3.2 关键条件

万用表电阻档的设计基于两个关键条件：

1. **Rx = 0（表笔短接）时，表头电流 I_head = Ig**，指针满偏
2. **Rx = R_mid 时，表头电流 I_head = Ig / 2**，指针半偏（中值位置）

### 3.3 推导过程

总回路电流：

# $$I_{total} = \frac{V_{bat}}{R_{series} + R_{eff} + R_x}$$

表头电流（分流关系）：

# $$I_{head} = I_{total} \times \frac{R_{shunt}}{R_{shunt} + R_g}$$



当 Rx = 0 时，要求 I_head = Ig：

# $$Ig = \frac{V_{bat}}{R_{series} + R_{eff}} \times \frac{R_{shunt}}{R_{shunt} + R_g}$$



当 Rx = R_mid 时，要求 I_head = Ig / 2：

# $$\frac{Ig}{2} = \frac{V_{bat}}{R_{series} + R_{eff} + R_{mid}} \times \frac{R_{shunt}}{R_{shunt} + R_g}$$

两式相除解得：

# $$R_{mid} = R_{series} + R_{eff}$$

即：**中值电阻等于欧姆档的总内阻**。此时外接 Rx = R_mid，回路总电阻加倍，电流减半，指针恰好指在刻度中央。

### 3.4 偏转规律

指针偏转量 d（0~1）与 Rx 的关系：

# $$d = \frac{I_{head}}{I_g} = \frac{R_{mid}}{R_{mid} + R_x}$$

> 这就是欧姆刻度 **非线性** 的根本原因——偏转量与 Rx 呈反比关系。

特别值：
| Rx | 偏转量 d | 指针位置 |
|----|----------|----------|
| 0 | 1.0 | 满偏（最右侧 0Ω） |
| R_mid / 3 | 0.75 | 1/4 处 |
| R_mid | 0.5 | **中央（中值）** |
| 3 × R_mid | 0.25 | 3/4 处 |
| ∞ | 0.0 | 最左侧（∞） |

## 四、各电阻档位分压分流电阻计算

MF47 的四个电阻档参数：

### ×10 档（倍率 10）

已知条件：V_bat = 1.5V，R_mid = 20 × 10 = 200Ω

由满偏条件：

# $$46.2 \times 10^{-6} = \frac{1.5}{R_{series} + 5000 \parallel R_{shunt}} \times \frac{R_{shunt}}{R_{shunt} + 5000}$$

又 R_series + R_eff = 200，求解得：
- **R_series = 169Ω**（限流电阻）
- **R_shunt = 31Ω**（分流电阻）
- **R_eff = 31Ω**（31Ω ∥ 5000Ω ≈ 30.8Ω）
- 中值电阻：**R_mid = 200Ω**
- 测量范围：0~2kΩ（有效读数区）
- 最大可测：约 20 × 50 = 1000Ω（刻度示值）

### ×100 档（倍率 100）

R_mid = 20 × 100 = 2000Ω

- **R_series = 1692Ω**
- **R_shunt = 328Ω**
- **R_eff = 328Ω ∥ 5000Ω ≈ 308Ω**
- 中值电阻：**R_mid = 2000Ω**
- 测量范围：0~20kΩ
- 最大可测：约 100 × 50 = 5000Ω

### ×1K 档（倍率 1000）

R_mid = 20 × 1000 = 20000Ω

- **R_series = 16920Ω**
- **R_shunt = 8021Ω**
- **R_eff = 8021Ω ∥ 5000Ω ≈ 3080Ω**
- 中值电阻：**R_mid = 20kΩ**
- 测量范围：0~200kΩ
- 最大可测：约 1000 × 50 = 50000Ω

### ×10K 档（倍率 10000）

此档使用 **9V 叠层电池**，无需分流电阻即可满足满偏条件。

满偏条件：

# $$Ig = \frac{9}{R_{series} + 5000}$$

解得 R_series = 9 / 46.2µA - 5000 ≈ 194805Ω

- **R_series = 190kΩ**（取整）
- **R_shunt = ∞（无分流电阻）**
- **R_eff = R_g = 5000Ω**
- **R_mid = 190kΩ + 5kΩ = 195kΩ**
- 刻度读数 ≈ 19.5（×10K 后 ≈ 195kΩ）
- 测量范围：0~2MΩ
- 最大可测：约 10000 × 50 = 500000Ω

## 五、中值电阻分析

**中值电阻 R_mid = 倍率 × 20Ω** 是 MF47 欧姆档的设计基准。

中值电阻的物理意义：
1. **内阻等于外阻**：当 Rx = R_mid 时，指针恰好指在刻度盘中央
2. **功率匹配**：此时 Rx 上消耗的功率最大
3. **灵敏度基准**：中值电阻决定了该档位的最佳测量区间

**测量误差分析**：指针式万用表在 Rx ≈ R_mid 附近时读数最准确，因为此时：
- dI/dRx 变化率适中，刻度分辩率最高
- 指针处于线性区（偏转约 45°~135°）
- 读数相对误差最小

经验法则：**测量时应选择量程使指针偏转在 1/3 ~ 2/3 范围内**，即 Rx 约为 0.5~2 倍 R_mid。

## 六、欧姆刻度分析

### 6.1 刻度非线性

欧姆刻度与电压/电流刻度的本质区别：

| 特性 | 电压/电流刻度 | 欧姆刻度 |
|------|-------------|---------|
| 函数关系 | 线性：d ∝ V 或 I | 非线性：d = R_mid/(R_mid+Rx) |
| 零位 | 左侧 | **右侧**（Rx=0 时满偏） |
| 无穷大 | 右侧 | **左侧**（Rx=∞ 时零偏） |
| 刻度密度 | 均匀 | 左密右疏 |
| 读数方向 | 从小到大 | **从右到左**（反向） |

### 6.2 刻度值计算

刻度值（偏转量对应的 Rx）：

# $$R_x = R_{mid} \times \frac{1 - d}{d}$$

刻度值（Rx 对应偏转量）：

# $$d = \frac{R_{mid}}{R_{mid} + R_x}$$

### 6.3 刻度分布示例（×1 倍率基准，R_mid = 20Ω）

| Rx(Ω) | 偏转量 d | 刻度位置 | 说明 |
|-------|----------|---------|------|
| 0 | 1.000 | 最右端 | 0Ω（满偏） |
| 1 | 0.952 | 右偏 | |
| 2 | 0.909 | | |
| 5 | 0.800 | | |
| 10 | 0.667 | | |
| **20** | **0.500** | **中央** | **中值** |
| 30 | 0.400 | | |
| 50 | 0.286 | | |
| 100 | 0.167 | | |
| 200 | 0.091 | 左端靠近∞ | |
| ∞ | 0.000 | 最左端 | ∞（零偏） |

> 可见：刻度左侧（大阻值区）非常密集，分辨力低；刻度右侧（小阻值区）较稀疏，分辨力高。这与欧姆档"精确测量中小阻值"的特点一致。

### 6.4 实际表盘刻度

MF47 表盘上直接标注的欧姆刻度值（以 ×1 档为基准）：
```
∞, 500, 200, 100, 50, 30, 20, 15, 10, 5, 2, 1, 0
```
（参见 `MagnetoelectricAmmeter.js` 第 447-467 行的刻度定义）

实际读数 = 刻度值 × 倍率。例如：
- ×1K 档，指针指在 20 → 读数 = 20 × 1000 = 20kΩ
- ×10K 档，指针指在 15 → 读数 = 15 × 10000 = 150kΩ

## 七、数字万用表电阻测量原理

### 7.1 比例法（恒流源法）

数字万用表（如本项目中的 `Multimeter.js`）采用不同的测量方法：

1. 表内产生一个 **精密恒流源** I_ref
2. 电流通过被测电阻 Rx，在其两端产生压降 V = I_ref × Rx
3. ADC 测量该压降，换算为电阻值

### 7.2 等效电阻法（仿真实现）

在本仿真中，数字万用表的电阻档实现方式为：

```javascript
// InstrumentUpdater.js - _measureResistance()
// 在 COM 与 V 端口之间注入 1A 测试电流
// 测量两端的电压差，电压值 = 等效电阻值
R = solver._getEquivalentResistance(cluster_com, cluster_v, clusters);
```

具体做法（`CircuitUtils.js` `getEquivalentResistance`）：
1. 在两端口之间注入 1A 的虚拟电流源
2. 以一端为参考地（0V），求解整个电路的节点电压
3. 另一端测得的电压数值即等于端口间的等效电阻（V = I × R = 1 × R = R）
4. 限制条件：两端电压差 < 0.1V（确保无外部电压源干扰）

### 7.3 数字万用表电阻档位

| 档位 | 最大显示 | 分辨力 | 典型应用 |
|------|---------|--------|---------|
| RES200 | 200.0Ω | 0.1Ω | 小电阻、导线通断 |
| RES2k | 2.000kΩ | 1Ω | 中等阻值 |
| RES200k | 200.0kΩ | 100Ω | 大阻值 |

## 八、MF47 的仿真实现细节

### 8.1 诺顿等效注入

在仿真中，MF47 的电阻档被建模为一个 **诺顿等效电路**（`DeviceStamps.js` `stampMF47`）：

```
VΩI ────╥──── COM
        ║
  I = V_bat/R_int
  R = R_int (= R_mid)
        ║
```

在 VΩI 与 COM 之间注入：
- 电导 G = 1 / R_int（R_int = R_mid = 倍率 × 20Ω）
- 电流源 I = V_bat / R_int（从 COM 流向 VΩI）

这样仿真求解器可以直接解出外部电路（含 Rx）的完整电压分布。

### 8.2 反推 Rx 公式

MF47 组件的 `tick` 方法（`MF47Multimeter.js:663-680`）通过测量到的端口电压反推 Rx：

```javascript
V_measured = V(COM) - V(VΩI)
V_bat = 1.5V (或 9V 用于 ×10K)
R_int = 倍率 × 20Ω

Rx = V_measured × R_int / (V_bat - V_measured)
```

**推导**：根据诺顿等效电路，VΩI 与 COM 之间的电压 V_measured 就是 R_int 与 Rx 的分压：

# $$V_{measured} = V_{bat} \times \frac{R_x}{R_{int} + R_x}$$

移项即得：

# $$R_x = V_{measured} \times \frac{R_{int}}{V_{bat} - V_{measured}}$$

### 8.3 指针偏转

得到 Rx 后，计算偏转量：

# $$d = \frac{R_{mid}}{R_{mid} + R_x}$$

指针通过二阶弹簧-阻尼系统平滑运动到目标位置（模拟真实表头的机械惯性）。

## 九、总结

| 项目 | 指针式（MF47） | 数字式 |
|------|---------------|--------|
| 测量原理 | 串联法（电池+电流表） | 比例法/恒流源法 |
| 核心器件 | 磁电式表头(46.2µA/5kΩ) | ADC + 恒流源 |
| 刻度特性 | 非线性（反向），右零左∞ | 数字直读，线性 |
| 电池 | ×10/×100/×1K: 1.5V, ×10K: 9V | 通常 9V 或更高 |
| 中值电阻 | 倍率 × 20Ω | 无（全量程线性） |
| 读数方式 | 刻度值 × 倍率 | 直接数字显示 |
| 最佳精度区 | Rx ≈ 0.5~2 倍 R_mid | 全量程均匀 |
| 仿真模型 | 诺顿等效注入 + 端口电压反推 | 矩阵试探法(1A源) |

欧姆表设计的核心思想是：**将未知电阻的测量转换为电流（指针式）或电压（数字式）的测量，通过精心设计的内部电路使读数与被测量建立确定的关系**。
