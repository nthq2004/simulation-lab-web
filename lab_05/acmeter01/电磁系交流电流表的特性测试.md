# 电磁系交流电流表的特性测试

## 一、概述

电磁系仪表（Electromagnetic Instrument）是利用通电线圈产生磁场、磁化内部铁片产生排斥力驱动指针偏转的测量机构。ACAmmeter 是本仿真平台中的电磁系交流电流表组件，型号 T42-A，量程 0~5A，精度 2.5 级，可直接测量交流电流有效值（I_rms），无需整流电路。

## 二、工作原理（排斥型电磁系机构）

### 2.1 基本结构

ACAmmeter 的测量机构由以下核心部件构成（对应仿真右侧原理区）：

| 部件 | 位置 | 功能 |
|------|------|------|
| **固定线圈** | 椭圆形截面，绕制在骨架外侧 | 通入被测电流，产生交变磁场 H ∝ I |
| **固定铁片（Fixed Vane）** | 嵌在线圈内腔左侧 | 被磁场磁化，极性随电流交变同步翻转 |
| **活动铁片（Moving Vane）** | 偏心安装于转轴，呈弯曲弧形 | 被磁场磁化产生与固定铁片相同的极性 → 同极排斥 |
| **转轴** | 垂直穿过线圈中轴 | 支撑活动铁片和指针，上下轴尖支撑以减小摩擦 |
| **游丝（螺旋弹簧）** | 安装于线圈腔体右方的轴上 | 提供反力矩 T_s = k·α，使指针稳定在平衡位置 |
| **阻尼翼片** | 铝制扇形，在封闭气室中运动 | 利用空气阻力消除指针振荡，缩短稳定时间 |
| **刻度盘** | 左侧表盘，210° 圆弧 | 指示电流值，刻度按平方律分布——前密后疏 |

### 2.2 工作过程

```
被测电流 I  →  固定线圈产生磁场 H ∝ I
                     ↓
      固定铁片被磁化（极性为 N/S）
      活动铁片被磁化（极性同为 N/S）
                     ↓
        同极相斥 → 活动铁片绕轴偏转
                     ↓
      驱动指针在刻度盘上指示电流值
                     ↓
      游丝反力矩与电磁力矩平衡 → 指针稳定
```

### 2.3 核心公式

- **磁化强度**：固定铁片与活动铁片同时被同一电流磁化，极性始终相同
- **电磁力矩**：T_d ∝ H² ∝ I² （与电流方向无关，故可测交流）
- **游丝反力矩**：T_s = k · α （k 为游丝刚度，α 为偏转角）
- **平衡条件**：T_d = T_s → α = k' · I²

## 三、关键特性

### 3.1 平方律刻度（刻度不均匀）

由于偏转角 α ∝ I²，刻度呈现"低端密集、高端稀疏"的非线性分布：

| 电流占比（I/I_max） | 20% | 40% | 60% | 80% | 100% |
|----------------------|-----|-----|-----|-----|------|
| 偏转角度占比（α/α_max） | **4%** | **16%** | **36%** | **64%** | **100%** |

- 低端（<20% 满量程）：刻度非常密集，读数误差大（表盘以红色弧标注低精度区）
- 中高端（20%~100%）：刻度逐渐稀疏，读数精度较高（表盘以绿色弧标注有效区）
- 建议使用量程：被测量值应 > 满量程的 20%

### 3.2 交直流两用

- 电磁系仪表测量的是有效值（平均值不反映真实能量）
- 由于排斥力 F ∝ I²，与电流方向无关，因此可直接测量交流电流，无需整流
- 频率范围：典型 15~100Hz，超过此范围时涡流损耗和集肤效应会导致误差增大

### 3.3 过载能力

- ACAmmeter 内部等效为 0V 理想电压源（MNA 求解器采用 0V 源采样方式）
- 串联接入回路时几乎不产生压降
- 可通过配电流互感器（CT）扩展量程（如 100/5 CT，二次侧 5A 对应一次侧 100A）

### 3.4 与磁电系仪表的对比

| 特性 | 电磁系（ACAmmeter） | 磁电系（DC Ammeter） |
|------|---------------------|---------------------|
| 测量电流 | 交流/直流 | 仅直流 |
| 刻度特性 | 平方律非线性 | 线性 |
| 准确度等级 | 1.0~5.0 | 0.5~2.5 |
| 磁场来源 | 被测电流本身 | 永久磁铁 |
| 消耗功率 | 较大 | 较小 |
| 频率响应 | 15~100Hz | 仅直流 |
| 过载能力 | 较强 | 较弱 |

## 四、仿真实验

### 4.1 电路组成

仿真电路为简单串联回路：

```
AC 220V/50Hz → ACAmmeter(A+ → A-) → 白炽灯(48.4Ω) → GND
```

### 4.2 实验步骤

**实验一：基本测量**

1. 选择"自动接线"，接好主电路回路
2. 合上电源（AC 220V/50Hz），观察电流表读数约为 4.55A
3. 降低电源电压至 100V，观察电流表读数减小（约为 2.07A）
4. 升高电压至 300V，白炽灯灯丝烧断，回路断路，电流表归零

**实验二：不同电压下的电流测量**

1. 更换烧毁的白炽灯，重新接通 220V
2. 分别在 100V、150V、200V 下记录电流表读数
3. 验证白炽灯作为线性电阻的伏安特性（电流近似正比于电压）

### 4.3 仿真动态观察要点

- **活动铁片偏转**：随电流增大，活动铁片逐渐被推开（偏转角 ∝ I²）
- **N/S 极性标注**：正半周时两铁片上端为 N、下端为 S；负半周时极性翻转，但同名端始终相对
- **电流方向符号**：线圈左侧和右侧交替显示 ⊙/⊗，指示电流方向的瞬时变化
- **排斥力箭头**：固定铁片指向活动铁片的箭头，强度随 I² 变化
- **数字读数**：实时显示电流有效值，低电流时呈橙色，正常范围呈绿色

## 五、练习题

### 5.1 工作原理

电磁系仪表（如 ACAmmeter）的工作原理是什么？

A. 线圈在磁场中受力带动指针偏转  
B. 铁片在通电线圈磁场中被磁化产生排斥力，带动指针偏转  
C. 热敏电阻受热变形驱动指针  
D. 霍尔效应检测磁场强度

> **正确答案：B**。电磁系仪表利用通电线圈产生磁场，内部固定铁片和活动铁片同时被磁化，产生排斥力驱动指针偏转。

### 5.2 刻度特性

电磁系仪表（如 ACAmmeter）刻度不均匀的主要原因是？

A. 指针随电流做线性偏转  
B. 偏转角与电流平方成正比（平方律特性）  
C. 弹簧游丝的非线性导致  
D. 电源电压波动引起

> **正确答案：B**。电磁系仪表中，排斥力 F ∝ I²，因此偏转角度与电流有效值的平方成正比。小电流时偏转较小（刻度密集），大电流时偏转较大（刻度稀疏），呈平方律刻度特性。

## 六、故障分析与排除

| 故障现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| 电流表无指示 | 回路未接通或灯丝烧断 | 检查连线，更换灯泡 |
| 指针偏转但读数偏小 | 电压过低 | 调高电源电压 |
| 指针振荡不止 | 阻尼翼片异常 | 检查气室是否堵塞 |
| 通电后指针反向偏转 | 交流接线极性颠倒（交流表虽无严格要求，但应保持一致） | 交换 A+/A- 接线 |
