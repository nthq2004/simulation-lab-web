# 电流互感器的使用

## 一、工作原理

电流互感器（Current Transformer，CT）是基于电磁感应原理工作的电流变换设备，用于将大电流变换为便于测量的小电流。

### 磁动势平衡原理

理想电流互感器满足**磁动势平衡方程**：

```
I₁ × N₁ = I₂ × N₂
```

其中：
- I₁ — 原边（一次侧）电流（A）
- I₂ — 副边（二次侧）电流（A）
- N₁ — 原边绕组匝数
- N₂ — 副边绕组匝数

由此可得变比关系：

```
I₂ = I₁ × N₁ / N₂ = I₁ / K
```

**K = N₂ / N₁** 称为**匝数比**（或变比），是本仿真工程中 CT 组件的核心可配置参数。

### 仿真模型中的数学实现

在本仿真平台中，CT 使用**改进节点分析法（MNA）** 进行电路求解，其注入策略为：

| 侧 | 仿真处理方式 | 作用 |
|---|---|---|
| 原边 | 注入 0V 电压源（等同于理想导线） | 监测原边电流 I₁ |
| 副边 | 注入受控电流源 I₂ = I₁ / K（前帧迭代收敛） | 模拟副边输出 |

副边电流源带有**顺从电压限制**（±1000V）：当副边负载电阻过高时，电流源切换为电压源模式，输出 ±1000V，模拟实际 CT 在副边开路时产生高压的物理现象。

## 二、基本特性

### 1. 变比特性

| 原边匝数 N₁ | 副边匝数 N₂ | 变比 K | 副边电流 I₂（I₁=45A 时） |
|---|---|---|---|
| 2 | 10 | 5 | 9.00 A |
| 2 | 20 | 10 | 4.50 A |
| 2 | 40 | 20 | 2.25 A |

> 原边匝数越少、副边匝数越多，变比 K 越大，相同原边电流下副边电流越小。

### 2. 外形与极性标记

```
           S1            S2
            │             │
   ┌────────┴─────────────┴────────┐
   │        副边绕组               │
   │   ┌─────────────────────┐    │
   │   │                     │    │
   │   │      铁芯            │    │
   │   │   变比 K:1           │    │
   │   │                     │    │
   │   └─────────────────────┘    │
   │        原边绕组               │
   └────────┬─────────────┬────────┘
            │             │
           P1            P2
```

- **P1、P2** — 原边端子（接大电流回路）
- **S1、S2** — 副边端子（接测量仪表）
- P1 与 S1 为**同名端**（加极性标记，电流同时流入时铁芯中磁通同向）

## 三、用 CT 扩大量程的方法

交流电流表的内阻很小，满偏电流有限。使用 CT 可以将电流表的量程扩大 K 倍。

### 接线方法

```
交流电源 ──→ 电流表₂ ──→ CT(P1─P2) ──→ 负载 ──→ 地
                                              │
CT(S1) ──→ 电流表₁(A⁺─A⁻) ──→ CT(S2) ──→ 地
```

以本仿真工程为例：

| 元件 | 标签 | 作用 |
|---|---|---|
| 交流电源 | AC 220V/50Hz | 提供主回路电源 |
| 电流表₂ | ac_amp2 | 测量原边电流 I₁（量程 100A） |
| CT | ct1（变比 K=10） | 将 I₁ 变换为 I₂ = I₁/K |
| 白炽灯 | lamp1（4.84Ω） | 主回路负载 |
| 电流表₁ | ac_amp1 | 测量副边电流 I₂（量程 5A） |

### 扩量程计算

已知白炽灯冷态电阻 R = 4.84Ω，电源电压 U = 220V：

```
主回路电流：I₁ = U / R ≈ 220 / 4.84 ≈ 45.45 A
副边电流（K=10）：I₂ = I₁ / K ≈ 45.45 / 10 ≈ 4.55 A
```

即：一个 5A 量程的电流表配合变比 K=10 的 CT，可以测量约 **45A** 的大电流，等效量程扩大 **10 倍**。

### 变比调整实验

将 CT 变比从 K=10 调整为 K=20：

```
K=10 时：I₂ ≈ 4.55 A
K=20 时：I₂ ≈ 2.27 A（副边电流减半）
```

验证了 `I₂ = I₁ / K` 的变比关系。

## 四、使用注意事项

### ⚠️ 副边绝对禁止开路

| 状态 | 副边电压 | 后果 |
|---|---|---|
| 正常（接电流表） | 很小（接近短路） | 安全工作 |
| 副边开路 | 可达数千伏（尖顶波） | 击穿绝缘、人身危险、铁芯过热 |

**原因**：正常工作时，副边电流 I₂ 产生的去磁磁通抵消原边 I₁ 的励磁磁通，铁芯中总磁通很小。一旦副边开路，I₂ = 0，去磁磁通消失，原边电流全部成为励磁电流，铁芯磁通急剧增加，副边感应出极高的尖顶波电压。

> 本仿真中 CT 的顺从电压上限设为 ±1000V，即模拟了开路时的高压限制——仍属危险电压。

### 安全操作规程

1. **先接负载，后通电源**：确保 CT 副边回路接通后再合上主电路电源
2. **副边必须可靠短接**：如需带电拆卸仪表，应先短路 CT 副边端子再操作
3. **副边一端接地**：防止高压对地放电，保障人身安全（本工程中 S2 接地）
4. **极性不能接反**：P1/S1 同名端对应，反接会导致测量相位错误
5. **CT 额定容量**：副边负载阻抗不能超过 CT 的额定容量，否则误差增大

### 本工程故障演示

仿真工程预置了两种CT相关故障，可在教学过程中演示：

| 故障 | 现象 | 教学要点 |
|---|---|---|
| 白炽灯灯丝烧断 | 主回路开路，I₁=0，I₂=0 | 负载故障对 CT 测量的影响 |
| CT 副边开路 | 副边电压升高至 ±1000V（顺从电压） | 理解开路高压的危险性 |

## 五、工程中的典型测量步骤

| 步骤 | 内容 | 观察要点 |
|---|---|---|
| 1 | 连接主回路：AC→电流表₂→CT 原边→负载→地 | 构建大电流回路 |
| 2 | 连接 CT 副边→电流表₁→地 | 构成测量回路 |
| 3 | 接通电源（220V/50Hz） | 读取 I₁ 和 I₂，验证变比 |
| 4 | 变比改为 20，观察 I₂ 变化 | I₂ 减半，验证 I₂ = I₁/K |
| 5 | 了解副边开路风险 | 分析开路高压原因及对策 |

## 六、小结

电流互感器是电力系统中不可或缺的测量设备，其核心要点可概括为：

1. **原理**：基于电磁感应和磁动势平衡，I₁ × N₁ = I₂ × N₂
2. **变比**：K = N₂/N₁，副边电流 I₂ = I₁ / K，扩大量程 K 倍
3. **特点**：副边近似短路状态下工作，正常运行时电压很低
4. **安全**：副边**绝对禁止开路**，运行中应先短路再拆卸仪表
