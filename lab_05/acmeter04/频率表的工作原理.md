# 频率表的工作原理

## 一、指针式发电机频率表

### 1.1 工作原理：谐振电路差动式

指针式频率表（又称发电机频率表）采用 **谐振电路差动式** 原理，属于电动式仪表。其核心结构由两个并联的 LC 谐振支路组成：

- **支路 A（L₁-C₁）**：谐振频率 \($f_A \approx 47.5\text{Hz}$\)，低频侧灵敏
- **支路 B（L₂-C₂）**：谐振频率 \($f_B \approx 52.5\text{Hz}$\)，高频侧灵敏

两路 LC 支路的电流分别经整流后送入交叉线圈测量机构。指针偏转角由两线圈电流之比决定：

| 输入频率 | 电流关系 | 指针位置 |
|----------|----------|----------|
| \($f = 50\text{Hz}$\) | \($I_A = I_B$\) | 居中（额定频率点） |
| \($f < 50\text{Hz}$\) | \($I_A > I_B$\) | 左偏（低频方向） |
| \($f > 50\text{Hz}$\) | \($I_A < I_B$\) | 右偏（高频方向） |

频率偏离额定值越大，差动电流越显著，指针偏转角越大。

### 1.2 测量机构：交叉线圈比率计

- **永磁铁**：固定磁钢产生非均匀磁场，N/S 极靴间形成气隙
- **可动线圈**：两套线圈互成约 60° 夹角，分别通入两路整流后的差动电流
- **比率型**：指针偏转角仅取决于两线圈电流之比，与输入电压幅值无关
- **无游丝**：无机械反力弹簧，断电后指针可停留在任意位置（比率计特性）

### 1.3 特性参数

| 参数 | 典型值 |
|------|--------|
| 测量范围 | 45~55 Hz |
| 额定频率 | 50 Hz |
| 额定电压 | 100 V |
| 精度等级 | 1.5 级 |
| 仪表型号 | D72-HZ |

### 1.4 特点

- **优点**：抗电压波动能力强（比率型），读数直观，无需辅助电源
- **局限**：量程窄（仅 ±5Hz），响应较慢（机械惯性），不适用于宽范围频率测量

## 二、数字频率计

### 2.1 工作原理：多周期平均过零检测

数字频率计采用 **过零检测法** 测量频率。通过对输入交流信号的正方向过零点进行计时，计算信号周期，进而换算为频率。

为提高测量稳定性，本仿真采用了 **去极值多周期平均** 算法：

1. 累计 5 次正方向过零时刻（对应 4 个完整信号周期）
2. 计算相邻过零之间的 4 个周期值
3. **去掉一个最大值、去掉一个最小值**
4. 剩余 2 个周期值取算术平均
5. 由平均周期换算为频率：\(f = 1 / T_{avg}\)

该算法能有效滤除因频率突变产生的单个异常周期毛刺，兼顾响应速度与测量稳定性。

### 2.2 实现流程

```
电压采样 → 正方向过零判断 → 记录过零时刻
  → 累计 5 次 → 计算 4 个周期 → 去极值平均 → 更新显示
```

- 采样源：电路求解器（MNA）节点电压
- 仿真步长：0.1ms/帧（求解器内部时间）
- 更新间隔：每 5 次过零（4 个周期）显示刷新一次

### 2.3 特性参数

| 参数 | 值 |
|------|-----|
| 测量范围 | 10~10000 Hz |
| 显示方式 | 黑底绿字 LCD 数字显示 |
| 显示精度 | ≥100Hz 显示整数，<100Hz 显示 1 位小数 |
| 更新策略 | 去极值多周期平均 |

### 2.4 特点

- **优点**：量程宽（10Hz~10kHz），读数精确无估读误差，响应平滑抗毛刺
- **局限**：需要稳定的输入信号，低频时更新速率较慢

## 三、两种频率表对比

| 对比项 | 指针式频率表 | 数字频率计 |
|--------|-------------|-----------|
| **测量原理** | LC 谐振差动法 | 过零检测法 |
| **显示方式** | 指针 + 刻度盘 + 数字副显 | LCD 数字直接显示 |
| **量程** | 45~55 Hz（窄带） | 10~10000 Hz（宽带） |
| **精度** | 1.5 级（约 ±0.75Hz） | 取决于过零计时精度 |
| **抗电压波动** | 强（比率型） | 需电路求解器提供准确电压 |
| **响应速度** | 机械惯性，较慢 | 多周期平均，可控 |
| **断电特性** | 指针自由停留 | 显示熄灭 |
| **适用场景** | 发电机频率监测 | 通用频率测量 |

## 四、仿真工程说明

本仿真工程（`multimeter_freq`）将交流电源、指针式频率表、数字频率计和大地组成简单测量电路：

```
交流电源 L ──┬── 指针频率表 L ──┐
             │                  │
             ├── 数字频率计 L ──┤
             │                  │
交流电源 N ──┴── 两频率表 N ───┴── 大地
```

- 改变交流电源的频率参数，指针表通过电路拓扑直接读取频率瞬时响应
- 数字频率计通过 MNA 求解器电压过零检测，多周期平均后更新显示
- 两者并联工作，可直观对比两种频率测量技术的差异
