# 功率表的工作原理

## 一、电动系功率表（模拟指针式）

### 1. 结构组成

电动系功率表由两组核心线圈构成，安装在同一转轴上：

| 线圈 | 导线规格 | 匝数 | 接法 | 符号 |
|------|----------|------|------|------|
| **固定线圈（电流线圈, CC）** | 粗导线 | 2~数匝 | 与负载**串联** | I⁺ / I⁻ |
| **活动线圈（电压线圈, VC）** | 细导线 | 数百~数千匝 | 串联限流电阻 Rv 后与负载**并联** | U⁺ / U⁻ |

两组线圈的"发电机端"（同名端）均标记 `*`，接线时应将带 `*` 端接于电源同极性侧。

其他组成部分：
- **转轴**：贯穿两组固定线圈中心，活动线圈固定于轴上
- **游丝**（螺旋弹簧）：安装在转轴顶部，产生与偏转角成正比的**反作用力矩**
- **指针**：固定在转轴上，随轴偏转指示功率值
- **阻尼翼片**：铝制空气阻尼器，抑制指针振荡
- **限流电阻 Rv**：与电压线圈串联，将电压线圈电流限制在毫安级

### 2. 力矩产生原理

#### 2.1 电流线圈产生的磁场

被测电流 I 流过固定线圈（电流线圈），在线圈内部空间产生磁场。该磁场为**脉动磁场**（与电流同频率的交流磁场），磁感应强度 B 正比于电流 I：

```
B ∝ I
```

由于固定线圈为上下两组对称结构，在两组线圈之间的气隙中形成近似均匀的磁场区域。

#### 2.2 电压线圈受到的安培力

电压线圈（活动线圈）串联 Rv 后并联于被测电压两端，其中流过的电流为：

```
Iᵥ = U / (Rv + Rᵥ_coil)
```

由于 Rv 远大于线圈内阻（通常 Rv 为数千欧至数万欧，而线圈内阻仅数十欧），可近似为：

```
Iᵥ ≈ U / Rv    ∝ U
```

活动线圈置于固定线圈的磁场中，载流导体在磁场中受到**安培力**：

```
F = B · Iᵥ · L
```

其中 L 为活动线圈的有效边长。两个竖直边受力方向相反（电流方向相反），形成**驱动力矩**：

```
T_d = F · d  ∝  B · Iᵥ  ∝  I · Iᵥ
```

代入 Iᵥ ∝ U，得到：

```
T_d ∝ I · U = P
```

即**驱动力矩与被测有功功率成正比**。

#### 2.3 交流情况下的平均转矩

当被测电路为交流时，电流 i(t) 和电压 u(t) 均为正弦量：

```
i(t) = Iₘ · sin(ωt)
u(t) = Uₘ · sin(ωt + φ)
```

电流线圈磁场 B(t) ∝ i(t)，活动线圈电流 iᵥ(t) ∝ u(t)，瞬时转矩：

```
T_d(t) ∝ i(t) · iᵥ(t) ∝ Iₘ · Uₘ · sin(ωt) · sin(ωt + φ)
```

平均转矩（仪表机械惯性响应平均值）：

```
T_d_avg = (1/T) ∫₀ᵀ T_d(t) dt  ∝  Iₘ · Uₘ · cosφ / 2  ∝  U · I · cosφ = P
```

式中 cosφ 为功率因数。可见，**电动系功率表可以直接测量有功功率**，其偏转角仅与有功功率有关，与频率无关。

#### 2.4 指针平衡位置

游丝产生的反作用力矩 T_s 与偏转角 α 成正比：

```
T_s = k · α
```

当驱动力矩与反力矩平衡时：

```
T_d_avg = T_s
→ k · α ∝ P
→ α = S · P
```

其中 S 为仪表灵敏度。因此**指针偏转角与被测有功功率成线性关系**，刻度均匀。

### 3. 同名端与功率方向

- 当功率输送方向为**电源→负载**时（cosφ > 0），指针正向偏转
- 当功率倒送时（如发电机工况，cosφ < 0），指针反向偏转
- 可通过按下换向按钮或交换 I⁺/I⁻ 接线来改变指针方向

### 4. 接线方式

本仿真中的接线方式（电流表前接法）：

```
AC(L) → I⁺(CC) → I⁻(CC) → 负载(R+L) → AC(N)
U⁺(VC) ← 并联接至 I⁺ 侧
U⁻(VC) ← 并联接至负载出线端
```

特点：
- 电流线圈直接反映负载电流
- 电压线圈测量负载两端电压
- 发电机端（`*`）均接电源侧，确保正向偏转

## 二、数字功率计的工作原理

数字功率计采用**交流采样**技术，通过微处理器对电压、电流信号进行实时采集和数学运算，计算有功功率及相关电参数。

### 1. 信号采集

- **电压通道**：通过分压电阻网络将高电压衰减至 ADC 可测量的范围（通常 ±10V 或 ±5V）
- **电流通道**：通过霍尔传感器或采样电阻将电流转换为电压信号
- **ADC 转换**：两路信号同步采样，采样率需满足奈奎斯特准则（至少为信号最高频率的 2 倍）

### 2. 有功功率计算

对采样的瞬时值进行数字乘法，并通过滑动窗口平均得到有功功率：

```
p(k) = u(k) · i(k)
P_avg = (1/N) · Σ p(k)    (N 为窗口长度)
```

其中 u(k) 和 i(k) 为同步采样的瞬时电压和电流。N 的选择需覆盖整数个周期以获得稳定读数。

### 3. 其他参数计算

| 参数 | 公式 | 说明 |
|------|------|------|
| 电压有效值 Vrms | √(Σ u²(k) / N) | 均方根计算 |
| 电流有效值 Irms | √(Σ i²(k) / N) | 均方根计算 |
| 有功功率 P | Σ u(k)·i(k) / N | 瞬时功率平均 |
| 功率因数 PF | \|P\| / (Vrms · Irms) | 有功/视在功率比 |

### 4. 数字功率计 vs 电动系功率表

| 特性 | 电动系功率表 | 数字功率计 |
|------|-------------|------------|
| 显示方式 | 指针+刻度 | LCD 数字显示 |
| 测量精度 | 一般（1.0~2.5 级） | 高（0.1~0.5 级） |
| 频率响应 | 宽（与频率无关） | 受采样率限制 |
| 附加功能 | 仅功率 | V/I/P/PF 多功能 |
| 过载能力 | 较强 | 需保护电路 |
| 响应速度 | 较慢（机械惯性） | 快（数字处理） |

## 三、本仿真电路说明

以项目"数字功率计"为例，电路参数如下：

```
交流电源 220V/50Hz → 功率表 I⁺ → 功率表 I⁻ → 电阻 40Ω → 电感 0.0955H → GND
功率表 U⁺ 并联于 I⁺ 侧（电源端）
功率表 U⁻ 并联于电阻出线端
```

在 100V 测试条件下：

```
总阻抗 Z = √(R² + XL²) = √(40² + 30²) = 50Ω
电流 I = U / Z = 100 / 50 = 2A
有功功率 P = I² · R = 2² × 40 = 160W
功率因数 PF = R / Z = 40 / 50 = 0.8
```

电动系功率表指针指在 160W 刻度处；数字功率计 LCD 同时显示 V=100.0V、I=2.000A、P=160.0W、PF=0.800。
