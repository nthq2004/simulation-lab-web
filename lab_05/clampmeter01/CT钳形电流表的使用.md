# CT 钳形电流表的使用

## 一、工作原理

钳形电流表的核心是利用**电流互感器（Current Transformer, CT）** 原理实现非接触式电流测量。

### 1.1 互感器原理

```
被测导线（一次绕组 N₁ = 1 匝）
        │
        ↓ 交变电流 I₁
   ┌───────────┐
   │  铁  心   │  ← 导磁环（硅钢片叠成）
   │ ╭───────╮ │
   │ │ Φ 磁通│ │
   │ ╰───────╯ │
   │  二次绕组  │  ← N₂ 匝（数百匝）
   └───────────┘
        ↓ 感应电流 I₂
      I₂ = I₁ × N₁ / N₂
```

- 被测导线穿过钳口，相当于**1 匝的一次绕组**（N₁ = 1）
- 铁心上绕有数百匝的**二次绕组**（N₂）
- 根据互感原理：**I₁ · N₁ = I₂ · N₂**，即 I₂ = I₁ / N₂
- 二次电流 I₂ 经整流后流入表头动圈，驱动指针偏转

### 1.2 本仿真的电路模型

仿真搭建了一个典型的 RC 串联交流电路用于演示：

```
AC 电源 (50Hz, 0–220V)
  │
  ├─── 100Ω 电阻 ─── 100μF 电容 ───┐
  │                                 │
  └────────────── 大地 ──────────────┘
```

- 电路总阻抗：Z = √(R² + Xc²)
- 容抗：Xc = 1 / (2πfC) ≈ 31.83Ω（f = 50Hz, C = 100μF）
- 在 100V 下：I = 100V / 104.9Ω ≈ **0.95A**
- 钳形电流表钳入导线即可读取此电流值

### 1.3 右侧原理示意

仿真右侧面板直观展示了内部电路结构：

1. **铁心 + 二次绕组** — 顶部环形，标注"二次绕组线径细，匝数N₂多"
2. **桥式整流** — 将二次侧的交流感应电流整流为直流
3. **分流电阻网络** — Ayrton 分流器，根据量程切换分流比
4. **永磁动圈表头** — N/S 磁极、动圈线圈、指针构成磁电式测量机构

## 二、结构组成

### 2.1 外观部件（参照 TCM 716Q）

| 部件 | 说明 |
|------|------|
| **钳口** | 黄色半环形铁心，分上下两半，用于夹持被测导线 |
| **扳机** | 左侧按钮，按下张开钳口，松开闭合 |
| **量程旋钮** | 中部圆形旋钮，切换 5A / 50A / 100A / 250A 档位 |
| **指针表盘** | 底部圆形表盘，刻度对应当前量程 |
| **机械调零螺丝** | 表盘左下方，用于校准无电流时的指针零位 |
| **数字显示** | 表头附近 LCD 显示实时电流值 |
| **表笔插孔** | COM（公共端）和 V/Ω（电压电阻端） |

### 2.2 内部构成（右侧原理图）

```
┌─────────────────────────────────┐
│   铁心 + 二次绕组                │
│   ┌─────────────────────┐       │
│   │   导线穿入 · 磁通 Φ │       │
│   └─────────────────────┘       │
│     ↓ 感应电流                    │
│   ┌─────────────────────┐       │
│   │   桥式整流电路       │       │
│   │   (AC → DC)         │       │
│   └─────────────────────┘       │
│     ↓ 直流电流                    │
│   ┌─────────────────────┐       │
│   │   分流电阻网络       │ ← 量程切换 |
│   │   (Ayrton shunt)    │       │
│   └─────────────────────┘       │
│     ↓ 分流后电流                  │
│   ┌─────────────────────┐       │
│   │   永磁动圈表头       │       │
│   │   N · 线圈 · S      │       │
│   └─────────────────────┘       │
│     ↓ 电磁力矩 → 指针偏转         │
└─────────────────────────────────┘
```

## 三、使用方法

### 3.1 操作流程（9 步法）

本仿真预设了完整的测量工作流程：

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | **连接电路** | 将电源、电阻、电容、大地依次连接 |
| 2 | **开启电源并调至 100V** | 调节交流电压至 100V |
| 3 | **检查并调整机械零点** | 无电流时指针应指零，偏离时用调零螺丝校准 |
| 4 | **打到 250A 档** | 选择最高量程档位（安全惯例：从大到小） |
| 5 | **钳入导线** | 按扳机 → 张开钳口 → 钳入导线 → 松开扳机合上钳口 |
| 6 | **移出导线** | 按扳机张开钳口，移出导线后合上（更换量程前必须脱开） |
| 7 | **切换至 5A 档** | 选择更接近实际电流的量程以提高精度 |
| 8 | **重新钳入导线** | 同上操作，钳入导线开始测量 |
| 9 | **读取数值** | 指针指向约 0.95A，答对选择题确认 |

### 3.2 操作要点

**扳机使用**：单击扳机切换张开/闭合状态。闭合时若之前是张开状态，自动切换测量开关。

**量程切换**：单击旋钮上半部分逆时针切换（250→100→50→5），单击下半部分顺时针切换（5→50→100→250）。

**零点调节**：单击机械调零螺丝，循环切换三种状态：
- `-0.05` → `0` → `+0.05` → 循环
- 正常使用时应保持为 `0`

### 3.3 故障模拟

| 故障 | 现象 | 排除方法 |
|------|------|----------|
| **零点偏移** | 无电流时指针偏离零位 | 调节机械调零螺丝归零 |
| **钳口油污** | 读数偏小（实际×0.55） | 清洁钳口接触面，确保铁心紧密闭合 |

## 四、注意事项

### 4.1 安全规范

1. **量程选择从大至小** — 不知被测电流大小时，先选最高量程，再逐步调整到合适档位
2. **换档前必须脱开被测导线** — 带电流切换量程可能损坏仪表或威胁安全
3. **钳口必须完全闭** — 铁心未完全闭合会增加磁阻，导致读数偏小
4. **只能测量交流电流** — CT 原理依赖变化的磁场，直流电流无法产生感应电动势

### 4.2 精度要点

1. **导线居中** — 被测导线应尽量位于钳口中心位置，偏离中心会引入误差
2. **单根导线** — 钳口内只能有一根被测导线（不能同时钳入回路的两根线）
3. **档位匹配** — 仪表量程应略高于被测电流值，指针位于满量程的 30%~80% 时精度最高
4. **读数结合量程** — 表盘刻度需乘以当前量程系数；例如 5A 档指针在 50% 处为 2.5A

### 4.3 保养维护

1. **钳口清洁** — 保持铁心接触面干净，油污、灰尘会增大磁阻
2. **避免跌落** — 指针式表头对机械冲击敏感，跌落可能导致指针卡滞或偏芯
3. **长期不用** — 应将档位置于最大档或"OFF"档位
4. **电池检查** — 数字显示部分依赖电池供电，显示暗淡时需更换

1. 为什么钳形电流表可以在**不断开电路**的情况下测量电流？其核心原理是什么？

3. 为什么在**切换量程**之前必须将钳口从导线上脱开？
4. 钳口油污为什么会导致读数**偏小**？（提示：磁阻）
5. 本仿真电路中，电流理论值约为 0.95A。如果改用 **250A 档**测量，指针的偏转角度是多少？改用 **5A 档**呢？哪个精度更高？
