# CT 数字钳形电流表的组成与工作原理

## 一、概述

数字钳形电流表（Digital Clamp Meter）是一种结合了电流互感器（CT）技术与数字测量技术的便携式仪表。它无需断开被测电路即可测量交流电流，是电气检修、工业现场中常用的测量工具。

本仿真工程完整还原了 CT 数字钳形电流表的内部结构，左侧面板为操作界面，右侧面板为原理结构示意。

## 二、整体组成

| 组成部分 | 功能说明 |
|---------|---------|
| 钳口（电流互感器铁心） | 夹持被测导线，形成磁路 |
| 二次绕组 | 感应出与一次电流成比例的电流 |
| 桥式整流电路 | 将交流感应电流转换为直流 |
| 信号调理电路 | 滤波、放大、真有效值转换 |
| ADC（模数转换器） | 将模拟电压转换为数字量 |
| MCU（微控制器） | 真有效值计算、量程切换、LCD 驱动 |
| LCD 数字显示屏 | 显示测量数值与单位 |
| 量程转换旋钮 | 切换 5A/50A/100A/250A 档位 |
| 钳口扳机 | 控制钳口开合 |
| HOLD/Hz 功能按钮 | 数据保持与频率测量切换 |

## 三、电流互感器（CT）工作原理

### 3.1 基本结构

电流互感器是数字钳形电流表的核心传感器，由以下三部分构成：

- **一次绕组**：被测导线直接穿过钳口，相当于 1 匝线圈（N₁ = 1）
- **环形铁心**：高导磁率的硅钢片叠制而成，闭合时形成磁路
- **二次绕组**：缠绕在铁心上的多匝线圈（N₂ = 数百至数千匝）

### 3.2 工作原理

根据电磁感应定律和安培环路定律：

**互感原理公式：**

```
I₁ × N₁ = I₂ × N₂
```

其中：
- I₁ — 被测导线中的一次电流（待测值）
- N₁ — 一次绕组匝数，N₁ = 1
- I₂ — 二次绕组中的感应电流
- N₂ — 二次绕组匝数

**变比关系：**

由于 N₁ = 1，N₂ >> N₁，因此：

```
I₂ = I₁ / N₂
```

即二次电流远小于一次电流，实现了大电流到小电流的变换。例如 N₂ = 1000 时，100A 的一次电流在二次侧仅产生 0.1A 的感应电流，方便后续电路处理。

**关键特性：**

1. **只能测量交流**：电磁感应依赖变化的磁场，直流电流无法产生持续的感应电动势
2. **不中断测量**：被测导线穿心而过，无需断开电路
3. **钳口闭合重要性**：铁心必须闭合才能形成完整的磁路，钳口张开时磁阻增大，测量误差显著增加
4. **二次侧不可开路**：CT 工作时二次侧必须接入负载，开路会产生危险高压（本仿真中二次侧连接至整流电路，始终处于带载状态）

### 3.3 铁心与磁路

钳口闭合时，环形铁心形成闭合磁路。被测电流 I₁ 在铁心中产生交变磁通 Φ：

```
Φ = (I₁ × N₁) / Rm
```

其中 Rm 为磁路总磁阻。交变磁通 Φ 在二次绕组中感应出电动势 E₂：

```
E₂ = 4.44 × f × N₂ × Φm
```

其中 f 为电源频率，Φm 为磁通峰值。

## 四、桥式整流电路

### 4.1 作用

CT 二次绕组输出的交流电流 I₂ 需要转换为直流信号，才能被后续的 ADC 和 MCU 处理。桥式整流电路完成 AC → DC 的转换。

### 4.2 电路结构

桥式整流由 4 个二极管（D₁~D₄）接成菱形结构：

```
        ┌──── D₁ ────┐
        │            │
  AC输入┤   D₃  D₄   ├ DC输出(+)
        │            │
        └──── D₂ ────┘
              │
            DC输出(-)
```

### 4.3 工作过程

在交流正半周：
- 电流从二次绕组上端 → D₁（正向偏置）→ 负载 R → D₂（正向偏置）→ 二次绕组下端

在交流负半周：
- 电流从二次绕组下端 → D₃（正向偏置）→ 负载 R → D₄（正向偏置）→ 二次绕组上端

无论正负半周，流过负载 R 的电流方向始终一致，实现了全波整流。

### 4.4 整流波形

- 输入：正弦交流
- 输出：全波脉动直流（频率为输入的两倍）
- 经滤波后：平滑直流

### 4.5 本仿真中的实现

在仿真组件右侧面板中，整流电路之后的"信号调理"模块对脉动直流进行：
- **滤波**：电容平滑脉动纹波
- **真有效值转换**：计算 RMS 值（True RMS），保证非正弦波形的准确测量
- **放大**：调整信号幅度匹配 ADC 输入范围

## 五、信号处理链路（从模拟到数字）

### 5.1 完整信号流程

```
被测电流 I₁
    ↓
CT 铁心 → 二次绕组 I₂ = I₁ / N₂
    ↓
交流电流 I₂
    ↓
桥式整流 → 脉动直流
    ↓
信号调理 → 滤波、放大、真有效值转换
    ↓
ADC（模数转换器）→ 数字量
    ↓
MCU（微控制器）→ 真有效值计算、量程换算
    ↓
LCD 驱动 → 数字显示
```

### 5.2 真有效值测量

数字钳形电流表采用真有效值（True RMS）测量技术。对于任意周期性波形，RMS 值的数学定义为：

```
IRMS = √(1/T × ∫₀ᵀ i²(t) dt)
```

MCU 内部通过高速采样和数值积分计算 RMS 值，支持正弦波、方波、三角波等各种波形的准确测量。

### 5.3 量程切换

量程转换旋钮控制 MCU 内部的增益设置和显示比例：

| 旋钮档位 | 测量范围 | 显示分辨率 |
|---------|---------|-----------|
| 5A 档 | 0~5A | 0.001A（1mA） |
| 50A 档 | 0~50A | 0.01A |
| 100A 档 | 0~100A | 0.1A |
| 250A 档 | 0~250A | 0.1A |

## 六、操作步骤（仿真流程）

1. **连接电路** — 建立交流电源、负载电阻、电容和地的连接
2. **开启电源** — 调节交流电压到指定值
3. **选择合适的量程** — 根据预估电流选择 5A/50A/100A/250A
4. **钳入导线** — 扣动扳机打开钳口，夹入被测导线，松开扳机使钳口闭合
5. **读取数值** — LCD 屏幕显示测量电流值
6. **移出导线** — 再次扣动扳机打开钳口，移出导线
7. **切换量程重新测量** — 根据需要切换档位重复测量
8. **HOLD 功能** — 按下 HOLD 键锁定当前读数，方便记录

## 七、注意事项

1. **钳口必须完全闭合**：钳口油污或未完全闭合会增大磁阻，导致读数偏低
2. **每次只钳一根导线**：同时钳入两根导线（如相线和零线），两电流磁场相互抵消会导致读数为零
3. **先选量程后测量**：从大量程开始，逐步切换到合适档位，避免过载损坏
4. **CT 不能测量直流**：电流互感器原理决定了它只对交变电流有响应
