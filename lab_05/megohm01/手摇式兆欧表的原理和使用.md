# 手摇式兆欧表的原理和使用

## 一、概述

兆欧表（Megohmmeter），俗称摇表，是一种用于测量电气设备绝缘电阻的便携式仪表。它通过向被测设备施加直流高压（通常为 500V、1000V 或 2500V），测量泄漏电流的大小，从而计算出绝缘电阻值。因其测量时需要手摇发电机产生高压，故又称手摇式兆欧表。

兆欧表的最大特点是**刻度反向**——右端为 0（短路），左端为 ∞（开路），这与普通欧姆表恰好相反。

---

## 二、兆欧表的组成

手摇式兆欧表主要由以下三部分组成：

### 2.1 手摇直流发电机

发电机是兆欧表的能源核心。它由：

- **定子**：永久磁铁（N/S 两极）
- **转子（电枢）**：绕有线圈的铁芯，通过摇动手柄驱动旋转
- **换向器**：将电枢产生的交流电整流为直流电

手柄摇动速度约为 120 r/min（每分钟 120 转），经齿轮增速后转子可达约 240 r/min。发出的直流高压通过输出端子供给测量回路。

在仿真中，发电机的输出端子标记为 **Gen-**（左侧负极）和 **Gen+**（右侧正极），正极输出直流高压（默认 500V）。

### 2.2 比率型表头（流比计）

比率型表头是兆欧表的核心测量机构，它**没有游丝**（反作用弹簧），指针的偏转仅取决于两个线圈中电流的比值，与电源电压的波动无关。

表头内部有两个固定在同一转轴上的线圈：

| 线圈 | 颜色 | 串联元件 | 电流 | 作用 |
|------|------|----------|------|------|
| **电压线圈 Uv** | 黄色 | 固定电阻 R0 | I₂ = U / R0（恒定） | 产生与电压成正比的力矩 |
| **电流线圈 Ic** | 红色 | 被测电阻 Rx | I₁ = U / Rx（随 Rx 变化） | 产生与被测电流成正比的力矩 |

两个线圈在空间上交叉 ±45° 安装。当电流流过时，它们在永磁体的气隙磁场中分别产生方向相反的力矩。

### 2.3 接线端子

| 端子 | 名称 | 用途 |
|------|------|------|
| **L** | Line（线路） | 接被测导体 |
| **E** | Earth（接地） | 接地或被测设备外壳 |
| **G** | Guard（屏蔽） | 消除表面泄漏电流的影响（测量电缆绝缘时使用） |

## 三、工作原理

### 3.1 手摇发电机的工作原理

手摇发电机基于**电磁感应原理**工作：

1. 永磁体产生恒定磁场（N → S）
2. 摇动手柄驱动电枢绕组在磁场中旋转
3. 绕组切割磁感线，产生感应电动势
4. 换向器将交流电整流为直流电，输出到测量回路

发电机的输出电压与以下因素有关：
- 磁场的强弱
- 电枢绕组的匝数
- 转子旋转的速度

在额定转速（120 r/min）下，发电机输出稳定的额定电压（如 500V）。由于比率型表头的测量结果与电压无关，因此对手摇速度的要求并不苛刻，只要保持大致稳定的转速即可。

### 3.2 比率计（流比计）的工作原理

比率计的核心公式为：

```
指针偏转角 α ∝ I₁ / I₂
```

其中：

- **I₁ = U / Rx** —— 电流线圈 Ic 中的电流，与被测电阻 Rx 成反比
- **I₂ = U / R0** —— 电压线圈 Uv 中的电流，与固定电阻 R0 成反比，为恒定值

因此：

```
α ∝ I₁ / I₂ = (U / Rx) / (U / R0) = R0 / Rx
```

**结论**：指针偏转角仅取决于 R0/Rx 的比值，与发电机电压 U 无关。这是比率型兆欧表最突出的优点——手摇速度的快慢不会影响测量结果。

具体来说：

| 被测电阻 Rx | Ic 电流 I₁ | 指针位置 |
|------------|-----------|---------|
| 0（短路） | 最大 | 指向 0（右端） |
| 中等阻值 | 适中 | 指向中间刻度 |
| ∞（开路） | 为零 | 指向 ∞（左端） |

### 3.3 刻度特性

兆欧表的刻度为**非线性反向对数刻度**：

- 低阻区（0 ~ 10 MΩ）刻度密集，分辨率高
- 高阻区（100 MΩ ~ ∞）刻度较疏

刻度映射公式（以本仿真为例）：

```
s = 2.4                     // 压缩系数
scale = 1 + 1000 × s        // 量程上限 1000 MΩ
frac = log₁₀(1 + s × R) / log₁₀(scale)    // R 以 MΩ 为单位
angle = 355° - frac × 170°
```

其中：

- 0 MΩ → 355°（表盘右上，指向 0）
- 20 MΩ → 270°（表盘正上，刻度中央）
- 500 MΩ → 200°（极接近 ∞ 位置）
- ≥1000 MΩ → 185°（表盘左上，指向 ∞）

### 3.4 指针的阻尼特性

仿真中指针具有**一阶惯性**（模拟实际仪表的阻尼）：

```
α = 1 - exp(-Δt / τ)
当前角度 += (目标角度 - 当前角度) × α
```

其中 τ（时间常数）默认 1.5 秒，使指针平滑地趋向目标值，避免剧烈摆动。

## 四、兆欧表的使用方法

### 4.1 使用前的检查

#### 开路测试
将兆欧表 L 和 E 端子**悬空**（不接任何对象），摇动手柄至额定转速。指针应指向 **∞**，表示仪表内部正常，无短路故障。

#### 短路测试
将兆欧表 L 和 E 端子**短接**，轻摇手柄。指针应迅速指向 **0**，表示仪表输出正常，无开路故障。

> ⚠️ 注意：短路测试时只能轻摇手柄，以免大电流损坏仪表。

### 4.2 测量线路绝缘电阻

以测量三相电源线路对地绝缘为例：

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 断开被测线路电源，验电确认无电 | 安全操作的前提 |
| 2 | 将兆欧表 L 端接被测相线（如 U 相） | — |
| 3 | 将兆欧表 E 端接地 | — |
| 4 | 摇动手柄至额定转速（120 r/min） | 指针逐渐偏转 |
| 5 | 待指针稳定后读数 | U 相正常绝缘约 5 MΩ（取决于线路情况） |
| 6 | 先取下 L 端连线，再停止摇动 | 防止容性负载反充电 |

依次测量 U、V、W 三相，每相对地绝缘电阻应分别合格。

### 4.3 测量三相异步电动机绝缘电阻

电动机的绝缘测量分为：

#### 绕组的对地绝缘

| 步骤 | 操作 |
|------|------|
| 1 | 断开电动机电源，对绕组进行放电 |
| 2 | 将兆欧表 L 端接电动机 U 相绕组端子（l1） |
| 3 | 将兆欧表 E 端接电动机外壳 PE 端子 |
| 4 | 摇动手柄至额定转速，待指针稳定后读数 |
| 5 | 断开 L 端连线，停止摇动 |
| 6 | 重复步骤 2-5，分别测量 V 相（l2）和 W 相（l3）对地绝缘 |

正常绝缘电阻值：**各相对地 ≥ 20 MΩ**（取决于电机额定电压和绝缘状况）。

#### 绕组相间绝缘

兆欧表 L 端接一相绕组，E 端接另一相绕组，分别测量 U-V、V-W、W-U 之间的绝缘电阻。相间绝缘电阻也应合格（通常要求与对地绝缘同等标准）。

### 4.4 测量注意事项

1. **必须断电**：测量前必须断开被测设备的电源，并进行放电处理
2. **保持转速**：摇动手柄应保持约 120 r/min，不宜过快或过慢
3. **先接后摇**：先接好测量线，再开始摇动；测量结束先取下 L 端线，再停止摇动
4. **避免测量带电设备**：带电测量不仅读数不准，更可能损坏仪表并危及人身安全
5. **L、E 不可接反**：L 端接被测导体，E 端接地或外壳，G 端（如有）用于消除表面泄漏

## 五、常见故障与处理

### 5.1 绝缘电阻过低

**现象**：摇测值明显低于正常范围（如 5 MΩ 线路测得不足 0.5 MΩ）。

**可能原因**：
- 绝缘受潮（最常见）
- 绝缘老化、裂纹
- 表面污垢导致泄漏电流增大

**处理方法**：
- 对设备进行烘干除潮处理
- 清洁绝缘表面
- 若绝缘严重老化，需更换绝缘部件

### 5.2 绝缘电阻为零（短路）

**现象**：摇测值接近 0 MΩ。

**可能原因**：
- 线路或绕组直接接地
- 绝缘击穿
- 导线金属部分触碰外壳

**处理方法**：
- 检查并修复接地故障点
- 更换损坏的绝缘部件

### 5.3 绝缘电阻处理流程

以本仿真项目中的流程为例：

1. **检测**：摇测各相绝缘电阻，确定故障相
2. **判断**：V 相绝缘老化（阻值降至 0.5 MΩ）→ 判断为绝缘下降
3. **修复**：对绝缘下降的相进行烘干、清洁或更换绝缘材料
4. **复测**：修复后重新摇测，确认阻值恢复至正常范围（5 MΩ 或 20 MΩ 以上）
5. **记录**：记录测量数据和维修结果

## 六、总结

手摇式兆欧表是一种经典的绝缘电阻测量仪表，其核心优势在于：

| 特性 | 优势 |
|------|------|
| **自备高压电源** | 无需外接电源，适合现场使用 |
| **比率型表头** | 指针偏转与电压波动无关，转速要求不苛刻 |
| **反向对数刻度** | 低阻区读数精度高，便于判断绝缘状况 |
| **无游丝结构** | 结构简单、可靠性高 |

使用兆欧表进行绝缘测量的关键是：**断电、放电、正确接线、保持转速、安全操作**。对于三相设备，必须分别测量每一相对地的绝缘电阻，以及相间绝缘电阻，任一相不合格都应进行处理后方可投入使用。
