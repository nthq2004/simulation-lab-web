# 数字万用表的使用——测量交流电压、二极管和电容

## 一、数字万用表概述

数字万用表（Digital Multimeter, DMM）是电气测量中最常用的仪表之一，可测量电压、电流、电阻、电容以及检测二极管通断等。本仿真实验使用一款数字万用表，其功能档位包括：

| 档位标识 | 功能 | 量程 |
|---------|------|------|
| OFF | 关机 | — |
| DCVmv / DCV20 / DCV200 | 直流电压 | 200mV / 20V / 200V |
| ACV200 / ACV500 | 交流电压 | 200V / 500V |
| ▶⊦)) | 二极管/蜂鸣 | 正向压降 / 通断 |
| RES200 / RES2k / RES200k | 电阻 | 200Ω / 2kΩ / 200kΩ |
| mA | 直流电流 | 100mA |
| uF | 电容 | 200µF |

**表笔连接说明：**

- **红表笔** —— 接 `VΩ▶⊦` 插孔（电压、电阻、二极管、电容测量）
- **黑表笔** —— 接 `COM` 插孔（公共端）
- **mA 插孔** —— 仅在测量电流时使用红表笔

## 二、测量交流电压

### 2.1 实验电路

本实验使用交流电源（ACPower）连接桥式整流电路（4 只整流二极管 + 滤波电容 + 负载电阻），通过数字万用表依次测量：

- 交流电源输入端的交流电压
- 整流滤波后的直流输出电压

### 2.2 测量步骤

#### 步骤 1：设置交流电源

1. 打开交流电源开关
2. 将电压调节为 **12V**，频率设为 **50Hz**（标准工频）

#### 步骤 2：选择交流电压档

将万用表旋钮旋至 **ACV200** 档（交流 200V 量程）。注意：
- 交流电压档用 `~V` 或 `ACV` 标识
- 选择量程时应大于被测电压的预估最大值
- 12V 有效值的交流电峰值约为 17V，故选 200V 档安全合适

#### 步骤 3：测量交流电源电压

1. 将红表笔接交流电源的 **正极（L）**
2. 黑表笔接交流电源的 **负极（N）**
3. 读取万用表显示值，应为 **12.0V**（交流有效值）

> **交流电压测量不分正负极**，红黑表笔可任意交换，读数相同。

#### 步骤 4：观察电压变化

调节交流电源电压至 **24V**，观察万用表读数随之变化至 **24.0V**。此步骤说明：
- 万用表实时反映被测电压大小
- 交流电压档测量的是 **有效值（RMS）**

#### 步骤 5：搭建桥式整流电路

按照以下拓扑完成桥式整流电路的接线：

```
交流电源 ~ → 四支二极管桥式连接 → 滤波电容 → 负载电阻 → 接地
```

具体接线关系：

| 起点 | 终点 | 说明 |
|------|------|------|
| AC 电源 N 极 | D1 阳极 / D3 阴极 | 交流输入回路 |
| AC 电源 P 极 | D2 阳极 / D4 阴极 | 交流输入回路 |
| D1 阴极 / D2 阴极 | 电容正极（L 端）/ 负载上端 | 直流正极输出 |
| D3 阳极 / D4 阳极 | 电容负极（R 端）/ 负载下端 / 地 | 直流负极输出 |

#### 步骤 6：测量整流输出电压

1. 将万用表切换至 **DCV200** 档（直流 200V 量程）
2. 红表笔接电容正极（直流输出正极）
3. 黑表笔接 **GND（地）**（直流输出负极）
4. 读取显示值，空载状态下约为 **15.6V ~ 17.0V**

> 桥式整流后，脉动直流电压的峰值 = 输入有效值 × √2 ≈ 12 × 1.414 ≈ 17V。考虑二极管正向压降（每支约 0.7V，两个二极管导通）后约为 15.6V。

### 2.3 交流电压测量注意事项

1. **量程选择**：预估被测电压大小，选稍大的量程。未知电压时从最大量程开始，逐渐减小
2. **人身安全**：测量高压（>36V）时注意绝缘防护，严禁湿手操作
3. **禁止错档**：严禁在电阻档或二极管档测量电压，可能损坏仪表
4. **有效值理解**：普通数字万用表交流档测量正弦波的有效值。非正弦波需用真有效值（True RMS）表

## 三、二极管检测

### 3.1 原理说明

二极管具有 **单向导电性**：

- **正向偏置**（阳极电压 > 阴极电压）：导通，硅管压降约 0.6~0.8V
- **反向偏置**（阳极电压 < 阴极电压）：截止，显示 O.L（Overload）

数字万用表的二极管档（▶⊦))）可完成以下两项功能：

1. **测量正向压降**，判断二极管好坏与类型（硅管 / 锗管）
2. **蜂鸣通断检测**，判断线路是否连通（电阻 < 50Ω 时蜂鸣）

### 3.2 测量步骤

#### 步骤 1：选择二极管档

将万用表旋钮旋至 **DIODE（▶⊦))）** 档。此时：
- LCD 显示档位标识 `▶⊦·))`
- 红表笔输出正电压，黑表笔为参考地

#### 步骤 2：识别二极管极性

本电路中使用的整流二极管（实物型）外观特征：

- **黑色圆柱体**，一端带有 **白色环形标记**
- **白色环一端为阴极（负极）**
- 未标记端为阳极（正极）

安装方向：二极管垂直放置，**阴极（白色环）朝上**。

#### 步骤 3：正向测试

1. 红表笔接 **D1 阳极（下方引脚）**
2. 黑表笔接 **D1 阴极（上方引脚，白色环端）**
3. 万用表显示 **0.69V**（硅管典型正向压降）

#### 步骤 4：反向测试

1. 红表笔接 **D1 阴极（上方）**
2. 黑表笔接 **D1 阳极（下方）**
3. 万用表显示 **O.L**（截止状态）

### 3.3 测量结果判断

| 测试情况 | 正向测试 | 反向测试 | 判断结果 |
|---------|---------|---------|---------|
| 正常二极管 | 0.5~0.8V（硅）/ 0.2~0.4V（锗） | O.L | 正常 |
| 短路损坏 | ~0V | ~0V | 击穿短路 |
| 开路损坏 | O.L | O.L | 内部断路 |
| 漏电（软击穿） | 0.5~0.8V | 有读数（非 O.L） | 漏电失效 |

### 3.4 二极管检测注意事项

1. **不可带电测量**：测量前必须断开电路电源，确保二极管两端无电压
2. **极性识别**：实物二极管的阴极（白色环）为正测试时的黑表笔端
3. **在线测试**：在路测量时，其他并联元件可能影响读数，必要时焊下一端测量
4. **硅管 vs 锗管**：硅管正向压降 0.6~0.8V，锗管 0.2~0.4V；现代电力电子中硅管占绝大多数

## 四、电容测量

### 4.1 原理说明

电容是储能元件，其基本参数为 **电容量**（单位：法拉 F）。实际常用：

- µF（微法，10⁻⁶ F）—— 电解电容、薄膜电容
- nF（纳法，10⁻⁹ F）—— 瓷片电容
- pF（皮法，10⁻¹² F）—— 高频电容

数字万用表的电容档通过 **RC 充电时间常数** 或 **交流电桥法** 测量容值。

### 4.2 测量步骤

#### 步骤 1：确保电容已放电

1. 断开电路电源
2. 检查电容两端电压应接近 **0V**
3. 如有残余电荷，用电阻或短接线将电容两端短接放电

> **安全警告**：大容量电解电容可能存储危险电压，放电时需使用合适的放电电阻，不可直接短路大容量高压电容。

#### 步骤 2：选择电容档

将万用表旋钮旋至 **uF（电容）** 档。此时：
- LCD 显示档位标识 `CAP`
- 单位显示 `uF`

#### 步骤 3：测量电容

1. 红表笔接电容 **正极（左长脚）**
2. 黑表笔接电容 **负极（右短脚，有负极标识条）**
3. 等待 1~2 秒，读取稳定的容值

> 本实验电容标称值 100µF，实测应显示约 **100.00µF**。

### 4.3 电解电容极性识别

| 特征 | 正极 | 负极 |
|------|------|------|
| 引脚长度 | **长脚**（长引脚） | 短脚 |
| 壳体标识 | 无特殊标记 | 有 **"-" 号** / 灰色条带 |
| 表笔连接 | **红**表笔 | **黑**表笔 |

### 4.4 电容测量注意事项

1. **必须先放电**：带电测量会损坏万用表，并可能产生电击危险
2. **极性不可反接**：电解电容反接可能爆裂，红表笔接正极、黑表笔接负极
3. **稳态读数**：电容档需要充电时间，等待显示稳定后再记录
4. **在线测量限制**：电路中的其他元件（电阻、电感）会影响测量精度，精确测量应焊下电容
5. **容值偏差**：电解电容的实际容量允许 ±20% 误差，属正常现象

## 五、综合安全规范

| 序号 | 安全要点 |
|------|---------|
| 1 | **测前检查**：确认表笔绝缘完好，无破损裸露 |
| 2 | **档位确认**：测量前确认档位正确，尤其避免用电阻/二极管档测电压 |
| 3 | **量程优先**：未知被测量时，从最大量程开始逐步减小 |
| 4 | **断电操作**：转换测量对象时，应先断开表笔再切换档位 |
| 5 | **电容放电**：测量电容前必须完全放电 |
| 6 | **手位置**：测量高压时单手操作，另一只手不接触任何导体 |
| 7 | **使用后关机**：测量完毕将旋钮旋至 OFF 档，延长电池寿命 |

## 六、习题

### 1. 交流电压测量

单相桥式整流电路中，交流输入有效值为 12V，空载直流输出电压峰值约为？

- A. 12V
- B. **约 17V**（✓）
- C. 约 10.8V
- D. 约 24V

**解析**：桥式整流后脉动直流电压峰值 ≈ 输入有效值 × √2 = 12 × 1.414 ≈ 17V。考虑两支二极管压降（约 1.4V）后约为 15.6V。

### 2. 二极管特性

硅二极管的正向导通压降通常约为？

- A. 0.2V
- B. **0.7V**（✓）
- C. 1.4V
- D. 5V

**解析**：硅二极管的正向导通压降约为 0.6~0.8V，典型值 0.7V。

### 3. 电容测量

用数字万用表电容档测量电解电容时，以下哪项操作正确？

- A. 直接在线测量，无需放电
- B. 红表笔接负极、黑表笔接正极
- C. **将电容短路放电后再测量**（✓）
- D. 电容档可测量带电电容

**解析**：测量前应将电容放电（短路），红表笔接正极、黑表笔接负极。带电测量会损坏仪表。
