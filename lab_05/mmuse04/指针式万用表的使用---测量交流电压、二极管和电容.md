# 指针式万用表的使用 — 测量交流电压、二极管和电容

## 一、MF47 指针式万用表简介

MF47 是一款经典的指针式（模拟）万用表，以表头指针的偏转角度来指示被测量的数值。其主要特点包括：

- **表头刻度盘**：包含多条刻度线，分别用于读取电阻（Ω）、交直流电压（V）、直流电流（mA）等。
- **机械调零螺丝**：位于表盘指针转轴下方，用于在未测量时调整指针归零。
- **量程旋钮**：中央大旋钮切换不同档位，包括 DCV（直流电压）、ACV（交流电压）、DCmA（直流电流）、OHM（电阻）等区域。
- **欧姆调零旋钮**：位于面板右侧，用于电阻/二极管测量前将指针调至 Ω 刻度右端零位。
- **接线柱**：面板底部有三个插孔 — COM（黑表笔）、V（红表笔，测电压/电阻）、mA（红表笔，测电流）。
- **数字辅助读数**：表盘下方有数字显示屏，可直接读出当前测量数值。

> 与数字万用表不同，指针万用表能直观反映被测信号的变化趋势（如电容充电过程、电压波动），是电气维修入门的重要工具。

## 二、测量交流电压

### 2.1 电路背景

本实验采用单相桥式整流电路：

```
交流电源 (AC 12V/50Hz) → 桥式整流（4个二极管）→ 滤波电容 → 负载电阻 → 地
```

### 2.2 测量步骤

1. **开机与设置**：打开交流电源，调至 12V / 50Hz。
2. **机械调零**：观察指针是否对准刻度左端零位。若偏离，用一字螺丝刀旋转机械调零螺丝，使指针对齐。
3. **选择档位**：将量程旋钮旋至 **ACV 区域**，根据被测电压选择大于且最接近的量程。已知约 12V，选择 **ACV 50V** 档（若读数太小再换低档，若超量程则换高档）。
4. **表笔连接**：红表笔插入 **V** 插孔，黑表笔插入 **COM** 插孔。两表笔分别接触交流电源的两端（不分正负）。
5. **读数**：待指针稳定后，读取刻度盘上标有 **~（AC）** 的刻度线。指针满偏对应所选量程值（50V 档满偏为 50V）。
6. **改变电压观察**：调节交流电压至 24V，观察指针随电压升高而偏转角度增大。

### 2.3 测量桥式整流输出电压

桥式整流后输出为脉动直流电压，需用 **DCV 档** 测量：

1. **拆除交流测量接线**，断开表笔。
2. 将 MF47 旋至 **DCV 50V** 档。
3. 红表笔接整流输出正端（滤波电容正极），黑表笔接地（GND）。
4. 读取 **DC** 刻度线。空载时电压峰值约为 1.414 × 交流有效值（12V 输入 ≈ 17V）。

### 2.4 注意事项

| 要点 | 说明 |
|------|------|
| 量程选择 | 始终选择大于被测值的最小量程，指针偏转在 1/3~2/3 刻度范围时读数最准 |
| 表笔安全 | 测量高压（>36V）时务必握持表笔绝缘部分 |
| 交流档限 | MF47 的 ACV 档通常只能测正弦波交流电，非正弦波读数不准确 |
| 测前断电 | 切换档位或改接电路前必须切断电源 |
| 防反接 | 直流档红正黑负，但交流档不分正负 |

## 三、检测二极管

### 3.1 原理

利用指针万用表 **电阻档（OHM）** 的内部电池作为测试电源，通过测量二极管的正、反向电阻来判断其好坏：

- **正向偏置**：内部电池正极经红表笔 → 二极管阳极 → 阴极 → 黑表笔 → 内部负极，二极管导通，指针偏转。
- **反向偏置**：二极管截止，指针几乎不动（阻值 ∞）。

### 3.2 测量步骤

1. **机械调零**：先检查并调整机械零位。
2. **选择档位**：将量程旋钮旋至 **Ω×10** 或 **Ω×100** 档。
   - 小功率二极管用 Ω×100，大功率二极管用 Ω×10。
3. **欧姆调零**：将红黑表笔短接，旋转 **欧姆调零旋钮**，使指针准确指向 Ω 刻度右端的 **0** 位。
   > 每次更换电阻档后都必须重新欧姆调零。
4. **正向测试**：黑表笔接二极管 **阳极（Anode）**，红表笔接 **阴极（Cathode）**。
   - 硅二极管应显示数百至两千欧姆（指针偏转至刻度中部偏左）。
5. **反向测试**：交换表笔，红表笔接阳极，黑表笔接阴极。
   - 指针应几乎不动（指示 ∞）。

### 3.3 结果判断

| 测试结果 | 判断 |
|----------|------|
| 正向电阻几百~几千Ω，反向 ∞ | 二极管正常 |
| 正反向均为 0 | 二极管击穿短路 |
| 正反向均为 ∞ | 二极管断路 |
| 正向电阻偏大（> 5kΩ） | 二极管性能劣化 |

> **注意**：MF47 电阻档红表笔连接内部电池 **负极**，黑表笔连接电池 **正极**。因此正向测试时，黑表笔（正电位）接阳极才能导通。

## 四、检测电容

### 4.1 原理

指针万用表无法直接读取电容值（无电容档），但可利用 **电阻档** 观察电容的 **充电过程** 来定性判断好坏：

```
表笔接通瞬间 → 电容充电（电流大）→ 指针大幅偏转
→ 充电渐满（电流减小）→ 指针缓慢回退
→ 充电完成（电流为 0）→ 指针回到 ∞
```

偏转幅度越大、回退越慢，说明电容量越大。

### 4.2 测量步骤

1. **机械调零**。
2. **选择档位**：根据电容容量选择合适的电阻档：
   - < 1μF：Ω×1K 或 Ω×10K
   - 1~100μF：Ω×100 或 Ω×1K
   - > 100μF：Ω×10 或 Ω×100
3. **欧姆调零**：短接表笔，调零。
4. **放电**：测量前必须将电容两端 **短路放电**，尤其是电解电容。
5. **第一次测量**：红表笔接电容正极（电解）或任意端（无极性），黑表笔接另一端，观察指针摆动。
6. **第二次测量**：交换表笔，指针偏转幅度应比第一次更大（反向充电），说明电容正常。

### 4.3 结果判断

| 现象 | 判断 |
|------|------|
| 指针大幅偏转后缓慢回到 ∞ | 电容正常 |
| 指针不动（始终 ∞） | 电容内部断路 |
| 指针偏转到 0Ω 后不返回 | 电容击穿短路 |
| 指针偏转小且回退快 | 容量明显减小 |
| 指针在中间某位置停住 | 电容漏电严重 |

### 4.4 注意事项

- **必须先放电**：电解电容存储电荷可能造成触电或损坏万用表。
- **大电容观测时间长**：测量几百 μF 以上电容时，指针回退可能需数秒至数十秒。
- **不能在线测量**：应将电容从电路中拆下（或至少断开一端引脚）再测。
- **电解电容极性**：电解电容长脚为正极，短脚为负极，外壳有标记。反向充电时漏电流大，指针回退慢属正常。

## 五、通用安全注意事项

1. **测电压时表笔插 V/COM**，**测电流时表笔插 mA/COM**，切勿插错。
2. **严禁在电阻档或二极管档测量带电电路**，否则内部电池和表头可能损坏。
3. **每次更换电阻档后必须重新欧姆调零**。
4. **长期不用时将档位置于 OFF 或交流电压最高档**。
5. **指针不归零时优先调节机械调零螺丝**，非必要时不要拆动表头。
6. **被测值未知时，始终从最高量程开始向下调整**。

## 六、实训电路原理图

```
        ┌──────────┐
AC 12V──┤  AC源     ├─── D4 ──┐   ┌──────────┐
        │ 12V/50Hz  │   │     │   │          │
        └──────────┘   ┌─┘     │   │   电容   │
                       │ D2    ├───┤   C=10μF │
                       └─┐     │   │          │
        ┌──────────┐     │     │   └────┬─────┘
        │          ├─── D1 ──┘          │
        │   GND    │                    │
        │          │     ┌──────────────┤
        └──────────┘     │   负载        │
                    D3 ──┤   R=1kΩ      │
                         └──────────────┘
                                        │
                                       GND
```

- **D1~D4**：桥式整流二极管（1N4007 或等效），V_F ≈ 0.7V
- **C**：滤波电容 10μF（电解电容）
- **R_load**：负载电阻 1kΩ

## 七、常见故障排查

| 故障现象 | 可能原因 | 解决措施 |
|----------|----------|----------|
| 指针完全不动 | 表笔未接好 / 保险丝熔断 | 检查连接，更换保险丝 |
| 各档位读数均偏大/偏小 | 电池电压不足 | 更换内部电池 |
| 电阻档短接不能归零 | 电池耗尽 / 欧姆调零旋钮故障 | 换电池或检修 |
| 电压档读数明显偏离 | 档位选错 / 表头灵敏度下降 | 确认档位，校准表头 |
