# IGBT 的特性测试

## 一、IGBT 工作原理

### 1.1 基本结构

IGBT（Insulated Gate Bipolar Transistor，绝缘栅双极型晶体管）是一种复合全控型电压驱动式功率半导体器件，它结合了 MOSFET 和 BJT 的优点：

- **输入端（门极 G）**：采用 MOSFET 的绝缘栅结构，输入阻抗极高，电压控制
- **输出端（集电极 C、发射极 E）**：采用 BJT 的双载流子导电结构，导通压降低、电流密度大

IGBT 的三个电极：

- **门极（Gate, G）**：绝缘栅控制端，施加正压时导通沟道
- **集电极（Collector, C）**：功率电流输入端（对应 PNP 管的集电区）
- **发射极（Emitter, E）**：功率电流输出端（对应 PNP 管的发射区）

内部等效结构：

```
   门极 G
      │
   ┌──┴──┐
   │  SiO₂ 绝缘层
   │  P   ← 沟道区（P 阱）
   │  N⁻  ← 漂移区（N⁻ 基区）
   │  N⁺  ← 缓冲层
   │  P⁺  ← 注入区（PNP 发射区）
   └──┬──┘
      │
   集电极 C
```

C-E 之间集成了一个**体二极管（续流二极管）**，方向为 E（阳极）→ C（阴极）。

### 1.2 工作原理

IGBT 是**电压控制型**器件：

| 门极电压 | 状态 | 说明 |
|----------|------|------|
| V(G) > Vth（阈值电压，约 4.5V） | 导通 | 门极正压形成导电沟道，C-E 间导通 |
| V(G) < Vth 或施加负压 | 关断 | 导电沟道消失，C-E 间高阻截止 |

**导通状态**：门极施加高于阈值电压的正压时，绝缘栅下方的 P 区形成 N 型反型层（导电沟道），电子从发射极流入漂移区，同时 P⁺ 注入区向漂移区注入空穴，形成电导调制效应，使导通压降显著降低（典型值 1.5~2.5V）。

**关断状态**：门极电压降至阈值以下或施加负压时，导电沟道消失，C-E 间呈现高阻抗（截止电阻约 1MΩ）。

### 1.3 IGBT 与 SCR、MOSFET 的对比

| 特性 | IGBT | SCR（晶闸管） | MOSFET |
|------|------|-------------|--------|
| 控制方式 | 电压控制 | 电流触发 | 电压控制 |
| 导通机制 | 门极正压导通 | 门极脉冲触发 | 门极正压导通 |
| 关断机制 | 撤除门极电压即关断 | 需主电流降至维持电流以下 | 撤除门极电压即关断 |
| 自锁特性 | **无自锁** | **有自锁**（触发后门极失效） | 无自锁 |
| 导通压降 | 低（1.5~2.5V） | 极低（约 1V） | 较高（与 Ron 相关） |
| 输入阻抗 | 极高（MOS 结构） | 低（PN 结） | 极高（MOS 结构） |
| 适用频率 | 中频（~20kHz） | 低频（工频为主） | 高频（~MHz） |

**关键区别**：SCR 一旦触发导通，即使撤除门极信号，器件仍保持导通（自锁特性），直到主电流降至维持电流以下才能关断。而 IGBT 是电压控制器件，门极正压导通、零压或负压关断，**没有自锁特性**。这一点是 IGBT 和 SCR 最重要的区别。

### 1.4 开关特性

IGBT 用作电子开关时：

- **截止状态**：V(G) < Vth，C-E 间高阻，V(CE) ≈ 电源电压
- **导通状态**：V(G) > Vth，C-E 间低阻，V(CE) ≈ Vce(on)（导通压降）

本仿真电路中：
- 主电路：24V → 1kΩ → IGBT 集电极 → 发射极 → 地
- 门极驱动：+15V → 10kΩ → 门极 G
- IGBT 参数：Vth = 4.5V，Vce(on) = 1.8V，Ron = 0.1Ω，Roff = 1MΩ

## 二、IGBT 开关特性测试方法

### 2.1 测试电路

电路由两部分组成：

**主电路（功率回路）**：
```
24V(+) → 1kΩ → IGBT(C) → IGBT(E) → GND
24V(-) → GND
```

**门极驱动电路**：
```
+15V → 10kΩ → IGBT(G) → IGBT(E) → GND
驱动电源(-) → GND
```

### 2.2 测试步骤

**步骤 1~3：构建电路**

按上述电路连线，将数字万用表拨到 DCV200 档，红表笔接 IGBT 集电极 C，黑表笔接发射极 E，测量 CE 两端电压。

**步骤 4：门极不加电压，接通主电路 24V**

此时门极 G 悬空（V(GE) = 0 < Vth），IGBT 处于截止状态。C-E 间无导电沟道，相当于开路。由于 1kΩ 电阻上无电流流过，CE 两端电压接近电源电压：

- V(CE) ≈ 24V（电源电压）
- I(C) ≈ 0

**步骤 5：接通门极驱动 +15V**

门极施加 +15V 电压，超过阈值电压 Vth（4.5V），IGBT 导通。C-E 间形成导电沟道，电流流过主回路。由于 IGBT 的导通压降 Vce(on) 约为 1.8V，CE 两端电压降至：

- V(CE) ≈ 1.8V（导通压降）
- I(C) = (24 - 1.8) / 1000 ≈ 22.2mA

**步骤 6：切断门极驱动（门极电压降为 0）**

门极电压降至 0V（低于 Vth），导电沟道消失，IGBT 关断。CE 两端电压恢复至：

- V(CE) ≈ 24V（恢复截止）
- I(C) ≈ 0

**重要结论**：IGBT 导通后，撤除门极信号即可关断，无自锁特性。

### 2.3 测试结果汇总

| 门极状态 | V(CE) | IC | IGBT 状态 |
|----------|-------|-----|-----------|
| 悬空/0V（V(G) < Vth） | ≈ 24V | ≈ 0 | 截止（高阻） |
| +15V（V(G) > Vth） | ≈ 1.8V | ≈ 22mA | 导通（低阻） |
| 恢复 0V | ≈ 24V | ≈ 0 | 恢复截止 |

## 三、用数字万用表检测 IGBT

### 3.1 测试原理

数字万用表的**二极管档（▶|-))）** 内部产生一个约 1mA 的恒流源，通过测量被测器件两端的电压降来判断 PN 结或体二极管的好坏。

| 测量结果 | 含义 |
|----------|------|
| 显示 0.4V~0.7V | 体二极管正偏导通 |
| 显示 OL（Over Limit） | 反偏截止或开路 |
| 显示 0V 或接近 0V | 已击穿短路 |

**数字万用表极性**：红表笔（V）为正极（+），黑表笔（COM）为负极（-）。

### 3.2 检测步骤

**准备**：将数字万用表拨到二极管档（▶|-))）。

**① 检测 G-E 之间**

| 测量 | 红表笔(V) | 黑表笔(COM) | 正常结果 |
|------|-----------|------------|---------|
| G-E 正向 | G | E | OL（极高阻抗） |
| G-E 反向 | E | G | OL（极高阻抗） |

G-E 之间是绝缘栅结构（MOS 电容），正反向均显示 OL，表现为极高阻抗。这是 IGBT 的**正常特征**。

**② 检测 C-E 体二极管正向**

| 测量 | 红表笔(V) | 黑表笔(COM) | 正常结果 |
|------|-----------|------------|---------|
| 体二极管正向 | E | C | 约 0.6~0.7V |
| 体二极管反向 | C | E | OL |

IGBT 内部集成有体二极管（续流二极管），方向为发射极 E（阳极）→ 集电极 C（阴极）。因此：

- 红表笔接 E（正极加在体二极管阳极），黑表笔接 C（负极加在体二极管阴极）：体二极管正偏，显示约 0.6~0.7V
- 红表笔接 C，黑表笔接 E：体二极管反偏，显示 OL

**③ 检测 C-E 电阻（电阻档）**

| 操作 | 接线 | 正常结果 |
|------|------|---------|
| 200kΩ 电阻档 | V→C, COM→E | OL（高阻） |

将万用表切换到 200kΩ 电阻档，C-E 间应显示高阻（OL），因为 IGBT 处于截止状态。

### 3.3 故障检测

**CE 击穿故障**：

| 操作 | 接线 | 故障结果 |
|------|------|---------|
| 二极管档 | V→E, COM→C | 约 0V |
| 电阻档 200kΩ | V→C, COM→E | 极小阻值（约 1Ω） |

当触发"CE 击穿故障"时，体二极管短路，C-E 间呈低阻状态，二极管档测不到正常 PN 结压降，电阻档显示极小阻值。

### 3.4 数字万用表检测汇总

| 测量项目 | 正常 IGBT | CE 击穿 | CE 开路 |
|----------|----------|---------|---------|
| G-E 正向 | OL | OL | OL |
| G-E 反向 | OL | OL | OL |
| C-E 体二极管正向（V→E, COM→C） | 0.6~0.7V | 极小 | OL |
| C-E 体二极管反向（V→C, COM→E） | OL | 极小 | OL |
| C-E 电阻 | OL（高阻） | 约 1Ω | OL |

## 四、用指针万用表（MF47）检测 IGBT

### 4.1 测试原理

指针万用表（如 MF47）的**电阻档**内部装有电池，可以向外电路提供测试电流。不同档位的电池电压和内阻不同：

| 档位 | 电池电压 | 内阻 |
|------|---------|------|
| R×10（×10Ω） | 1.5V | 200Ω |
| R×100（×100Ω） | 1.5V | 2kΩ |
| R×1K（×1kΩ） | 1.5V | 20kΩ |
| R×10K（×10kΩ） | 9V | 200kΩ |

**关键区别**：指针万用表在电阻档时，**黑表笔（COM）接内部电池正极（+）**，**红表笔（V）接内部电池负极（-）**。这与数字万用表的极性正好相反。

### 4.2 检测步骤（R×100 档）

**准备**：将 MF47 拨到 R×100 档，短接表笔调零。

**① 测量 C-E 体二极管正向**

| 测量 | 黑表笔(COM/+) | 红表笔(V/-) | 正常结果 |
|------|--------------|-------------|---------|
| 体二极管正向 | E（阳极） | C（阴极） | 指针偏转至较小阻值 |

指针偏转说明体二极管正偏导通。注意此时黑表笔（COM/+）接发射极 E，红表笔（V/-）接集电极 C——与数字万用表的外表笔接法相反。

**② 测量 C-E 体二极管反向**

| 测量 | 黑表笔(COM/+) | 红表笔(V/-) | 正常结果 |
|------|--------------|-------------|---------|
| 体二极管反向 | C | E | 指针不动（∞） |

体二极管反偏截止，显示高阻。

**③ 测量 G-E 阻抗**

| 测量 | 黑表笔(COM/+) | 红表笔(V/-) | 正常结果 |
|------|--------------|-------------|---------|
| G-E | G | E | 指针不动（∞） |
| G-E | E | G | 指针不动（∞） |

G-E 间为绝缘栅结构，正反向均应显示 ∞，表现为极高阻抗。**如果测到低阻或导通，说明门极已击穿损坏**。

### 4.3 指针式与数字式万用表对比

| 对比项 | 数字万用表（二极管档） | 指针万用表（电阻档） |
|--------|---------------------|-------------------|
| 表笔极性 | 红表笔为正（V+） | 黑表笔为正（COM+） |
| 显示方式 | 直接显示体二极管正向压降（V） | 指针偏转指示等效电阻（Ω） |
| 导通判据 | 0.4V~0.7V 表示体二极管正常 | 指针偏转至小阻值表示体二极管正常 |
| 截止判据 | 显示 OL | 指针不动（∞） |
| 优点 | 读数精确、可直接读出压降 | 可直观观察指针偏转幅度 |
| 缺点 | 需要理解 OL 含义 | 极性易混淆（与数字表相反） |

### 4.4 指针万用表操作要点

1. **每次换电阻档后必须调零**：短接两表笔，调节调零旋钮使指针满偏（0Ω）
2. **读数方法**：指针在刻度盘上的读数 × 倍率 = 实际电阻值
3. **极性牢记**：电阻档时黑表笔为（+），红表笔为（-），与数字万用表相反
4. **双手握表笔**：测量时手不要同时接触表笔金属端和被测引脚，以免人体电阻并联影响测量

## 五、数字式和指针式检测 IGBT 的外表笔对应关系

由于两种万用表在电阻/二极管测试时的内部极性不同，检测 IGBT 体二极管时外表笔接法恰好相反：

| 万用表类型 | 测体二极管正向（E→C 导通） |
|-----------|--------------------------|
| 数字式（二极管档） | 红表笔(V) **接 E**，黑表笔(COM) **接 C** |
| 指针式 MF47（电阻档） | 黑表笔(COM/+) **接 E**，红表笔(V/-) **接 C** |

两种接法中，**正表笔（内部正极）都接在发射极 E（体二极管阳极）上**，因此都使体二极管正偏导通。

## 六、常见故障判断

### 6.1 CE 击穿

**现象**：C-E 之间导通（数字表显示约 0V 或极小阻值，指针表显示极小阻值），G-E 仍为高阻。

**仿真操作**：在"故障设置"中触发"CE 击穿故障"，用万用表再次测量 CE 之间验证。

**实际原因**：过压击穿或过热损坏，导致 C-E 间短路。

**数字万用表表现**：二极管档测 E→C 显示约 0V（正常应为 0.6~0.7V），电阻档测 C-E 显示极小阻值。

### 6.2 CE 开路

**现象**：C-E 之间正反向都测不到任何导通特性，体二极管特性消失。

**仿真操作**：在"故障设置"中触发"CE 开路故障"。

**实际原因**：内部开路，芯片烧断或键合线断开。

**数字万用表表现**：二极管档测 E→C 显示 OL，电阻档测 C-E 显示 OL。

### 6.3 GE 击穿

**现象**：G-E 之间测得低阻或导通。

**仿真操作**：可在 IGBT 配置参数中将截止电阻 Roff 设为极小值模拟。

**实际原因**：静电放电（ESD）或过压损坏门极绝缘层。

## 七、测试总结

1. **IGBT 结构本质**：电压控制型复合器件，MOSFET 栅极 + BJT 输出级，内部集成体二极管
2. **开关特性**：门极正压导通、零压/负压关断，**无自锁特性**（区别于 SCR）
3. **体二极管检测**：C-E 间存在体二极管（E→C 正向导通约 0.6~0.7V），这是判断 IGBT 好坏的重要依据
4. **门极检测**：G-E 间正反向均应显示高阻（绝缘栅结构），如测到低阻说明门极已损坏
5. **故障判断**：CE 击穿 → 体二极管短路；CE 开路 → 体二极管消失；GE 击穿 → 门极阻抗降低
6. **表笔极性牢记**：
   - 数字万用表二极管档：红笔正（V+）、黑笔负（COM-）
   - 指针万用表电阻档：黑笔正（COM+）、红笔负（V-）
7. **IGBT 状态判断**：
   - 截止：V(G) < Vth，V(CE) ≈ 电源电压，IC ≈ 0
   - 导通：V(G) > Vth，V(CE) ≈ Vce(on)，IC = (VCC - Vce(on)) / RC
