# 发光二极管的特性测试

## 一、发光二极管的工作原理

### 1.1 PN 结发光原理

发光二极管（Light Emitting Diode，简称 LED）是一种将电能直接转化为光能的半导体器件。其核心是一个由 P 型半导体和 N 型半导体构成的 PN 结。

当 LED 处于**正向偏置**状态（P 端接正极、N 端接负极）且外加电压超过其导通阈值（通常为 1.8~3.3V）时，P 区的空穴和 N 区的电子在正向电场驱动下向对方区域扩散，在 PN 结附近发生复合。复合过程中，电子从高能级跃迁到低能级，释放出能量——该能量以光子的形式辐射，即产生发光现象。

不同半导体材料决定了 LED 发光的颜色：
- 磷化镓（GaP）：红色/绿色
- 氮化镓（GaN）：蓝色/白色
- 砷化镓（GaAs）：红外
- 磷砷化镓（GaAsP）：红/橙/黄

### 1.2 LED 的电气特性

LED 的 I-V 特性曲线具有以下特征：

1. **正向死区**：外加电压低于导通阈值时，电流几乎为零。
2. **正向导通区**：电压超过阈值后，电流随电压呈指数增长。因此，LED 必须**串联限流电阻**，否则微小的电压波动会导致电流急剧增大，烧毁器件。
3. **正向压降**：LED 正常发光时两端的电压降（Vf），不同颜色 LED 的典型值：
   - 红外：1.2~1.5V
   - 红色：1.8~2.2V
   - 黄色：2.0~2.4V
   - 绿色：2.0~3.0V
   - 蓝色/白色：2.8~3.5V
4. **反向截止**：LED 在反向偏置时呈现高阻抗，仅有极小的漏电流。反向电压超过击穿电压（通常 >5V）将造成永久损坏。

### 1.3 限流电阻的计算

限流电阻的阻值由以下公式确定：

```
R = (Vcc - Vf) / If
```

其中 Vcc 为电源电压，Vf 为 LED 正向压降，If 为目标工作电流。

**示例**：电源电压 12V，红色 LED 正向压降 2V，目标电流 20mA：
```
R = (12V - 2V) / 0.02A = 500Ω
```
实际选用标称值 510Ω 或 560Ω。

## 二、LED 基本特性测试（仿真实验）

实验电路：12V 直流电源 → 330Ω 限流电阻 → 红色 LED → GND

### 2.1 正向压降测量

**测试目的**：测量 LED 在正常发光时的正向压降。

**仪器**：数字万用表（DCV20V 档）

**步骤**：
1. 按电路图连接：电源正极→330Ω 电阻→LED 阳极，LED 阴极→GND，电源负极→GND。
2. 将万用表红表笔接 LED 阳极，黑表笔接 GND（即测量 LED 两端电压）。
3. 接通 12V 电源，读取万用表显示值。

**预期结果**：万用表显示约 2.0V（红色 LED 的典型正向压降）。

**原理分析**：LED 导通后，PN 结上的压降基本恒定，与电源电压无关。电源电压减去 LED 压降后剩余电压全部落在限流电阻上，用于产生驱动电流。

### 2.2 工作电流测量（五点步进法）

**测试目的**：通过改变限流电阻，观察 LED 工作电流与亮度的关系。

**仪器**：直流电流表（mA 档）

**步骤**：将电流表串联接入 LED 支路，依次设置限流电阻为以下 5 个值，记录电流和亮度变化：

| 步骤 | 限流电阻 | 理论电流 | 亮度描述 |
|------|---------|---------|---------|
| 1    | 10kΩ    | 1mA     | 微亮，可见微弱红光 |
| 2    | 2kΩ     | 5mA     | 足够亮，清晰可见 |
| 3    | 1kΩ     | 10mA    | 很亮，达到最大亮度 |
| 4    | 330Ω    | 30mA    | 正常驱动电流，亮度充足 |
| 5    | 100Ω    | 100mA   | **过流！LED 烧毁** |

**结果分析**：
- 1mA 时 LED 开始发光（起亮电流阈值）。
- 5mA~10mA 区间亮度随电流增加显著提升。
- 超过 10mA 后亮度趋于饱和。
- 超过额定电流（通常 20~30mA）会导致 PN 结过热，最终烧毁（开路失效，透镜发黑）。

## 三、用数字万用表测试 LED

### 3.1 二极管档测试原理

数字万用表的二极管档（标识为 ▶|·)) 或 DIODE）是专门用于检测 PN 结的档位。其工作原理：

1. 万用表内部输出一个约 2~3V 的恒流源（通常约 1mA）。
2. 红表笔（V/Ω 插孔）输出正电压，黑表笔（COM 插孔）为参考地。
3. 当表笔接至 PN 结两端时，万用表测量 PN 结的正向压降并直接以电压值显示。

### 3.2 数字万用表测试 LED 的方法

**正向测试**：
1. 将万用表拨到二极管档（DIODE）。
2. 红表笔接 LED 阳极（正极、较长引脚）。
3. 黑表笔接 LED 阴极（负极、较短引脚、有切边标记）。
4. 正常时显示 LED 的正向压降值（如红色 LED 显示约 2.02V）。

**反向测试**：
1. 红表笔接 LED 阴极。
2. 黑表笔接 LED 阳极。
3. 正常时显示 "OL"（Over Load）或 "1"，表示截止状态。

**判断标准**：
- 正向显示正常压降值、反向显示 OL：LED 良好。
- 正反向均显示 OL：LED 开路损坏。
- 正反向均显示 0V（或接近 0）：LED 击穿短路。

### 3.3 注意事项

- 数字万用表二极管档的输出电压（约 2~3V）足以使大多数 LED 导通。
- 但若测试蓝色或白色 LED（导通电压 > 3V），部分万用表的二极管档可能因输出电压不足而无法使其导通，此时应使用电阻档或更高电压的测试方法。
- 测试时 LED 可能会微微发光，属正常现象。

## 四、用指针万用表测试 LED

### 4.1 指针万用表电阻档测试原理

指针万用表（如 MF47 型）的电阻档内含电池，不同档位使用的电池电压不同：
- R×1、R×10、R×100、R×1k 档：使用 1.5V 电池
- R×10k 档：使用 9V 或 15V 叠层电池

电阻档测试时，红表笔（正极插孔）连接内部电池的**负极**，黑表笔（COM 插孔）连接内部电池的**正极**——这与数字万用表的极性相反，需特别注意。

### 4.2 MF47 指针万用表测试 LED 的方法

由于普通 LED 的正向压降（1.8~2.2V）高于 1.5V，使用 R×1~R×1k 档（1.5V 电池）可能无法使 LED 导通，因此应当选用 **R×10k 档**（9V 或 15V 电池）。

**正向测试**：
1. 将 MF47 拨到 R×10k 档。
2. 黑表笔（正极）接 LED 阳极（正极）。
3. 红表笔（负极）接 LED 阴极（负极）。
4. 观察指针偏转：应向右偏转指示较小阻值，同时 LED 会微微发光。

**反向测试**：
1. 黑表笔接 LED 阴极。
2. 红表笔接 LED 阳极。
3. 指针应几乎不动（指示 ∞），LED 不发光。

### 4.3 指针万用表测试经验总结

| 测量状态 | 表笔连接 | 指针指示 | LED 状态 |
|---------|---------|---------|---------|
| 正向偏置 | 黑→阳极，红→阴极 | 向右偏转（小阻值） | 微微发光 |
| 反向偏置 | 黑→阴极，红→阳极 | 不动（∞） | 不发光 |

> **注意**：使用 R×10k 档时，由于表内电压较高（9V/15V），切勿用手同时接触两支表笔的金属端，以免触电。

## 五、常见故障与判断

### 5.1 LED 开路故障

**现象**：回路中无电流，LED 不发光。
**万用表检测**：
- 数字表二极管档：正反向均显示 "OL"。
- 指针表 R×10k 档：正反向指针均不动。

**电路分析**：LED 开路后，回路电流为零，限流电阻上无压降，LED 两端（即开路点两端）电压等于电源电压。

### 5.2 LED 击穿短路故障

**现象**：LED 不发光，但回路中有大电流（仅受限于限流电阻），限流电阻可能过热。
**万用表检测**：
- 数字表二极管档：正反向均显示接近 0V。
- 指针表 R×10k 档：正反向指针均大幅偏转（接近 0Ω）。

**电路分析**：LED 短路后，两端压降接近 0V，电源电压全部加在限流电阻上，电流仅由限流电阻决定（I = Vcc / R）。

### 5.3 过流烧毁故障

**现象**：LED 透镜发黑、内部断线，完全不发光。
**原因**：电流超过 LED 额定值（通常 >50mA）导致 PN 结过热烧毁。
**预防**：始终串联合适的限流电阻。

## 六、知识点总结

1. **LED 是电流驱动型器件**：其亮度与正向电流成正比，而非电压。
2. **必须串联限流电阻**：LED 的 I-V 特性呈指数关系，不加限流电阻直接接电源会瞬间烧毁。
3. **正向压降基本恒定**：正常发光时 LED 两端电压稳定在约 2V（以红色为例），与电源电压无关。
4. **单向导电性**：LED 与普通二极管一样具有单向导电性，反向截止。
5. **万用表检测要点**：
   - 数字万用表：二极管档直接测量正向压降（Vf 值）。
   - 指针万用表：使用 R×10k 档（高电压），注意表笔极性相反。
   - 正向导通、反向截止为正常，否则为故障。
