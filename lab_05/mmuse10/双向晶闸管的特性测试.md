# 双向二极管与双向晶闸管的工作原理、特性及测试方法

## 一、引言

双向二极管（DIAC）和双向晶闸管（TRIAC）是交流调光、调压、电机软启动等电力电子电路中的核心器件。本仿真工程以**白炽灯调光电路**为对象，完整实现了从 DIAC 触发到 TRIAC 导通、从波形观察万用表检测的全部教学流程。本文结合仿真引擎的物理模型，详细阐述两器件的工作原理及测试方法。

---

## 二、双向二极管（DIAC）

### 2.1 器件结构与符号

DIAC（Diode for Alternating Current）是一种**双向对称触发的两端半导体器件**，相当于两只背对背串联的肖特基二极管或 NPN 三层结构。其电路符号为两个反向并联的三角形，表示正负方向均可导通。

<div align="center">

```
   ──▶──◀──
```

在本仿真中，DIAC 使用 `DIAC` 组件（简化符号）或 `RealDIAC` 组件（DB3 封装外观），类型标识 `type = 'diac'`。

### 2.2 工作原理

DIAC 具有以下关键特性：

1. **对称转折特性**：无论两端电压极性如何，当电压绝对值超过**转折电压** `vBO`（默认 30V）时，DIAC 进入导通状态。
2. **负阻特性**：导通后端电压立即下降到**维持电压** `vHold`（默认 10V），呈现负阻效应。
3. **电流关断**：当流过器件的电流降至维持电流以下时，DIAC 关断并返回高阻态。

#### 仿真模型

仿真引擎采用 MNA（改进节点分析法）对 DIAC 建模（`tools/DeviceStamps.js:stampDIACs`）：

| 状态 | 等效电路 | 参数 |
|------|---------|------|
| **截止** | 高阻电阻 | `rOff = 1×10⁸Ω` |
| **导通** | `vHold` 电压源 + `rOn` 电阻 | `rOn = 5Ω`, `vHold = 10V` |
| **短路故障** | 小电阻 | `1Ω` |

状态切换逻辑：

```
if |vDiff| > vBO →
    进入导通态，锁定导通方向 sign = ±1
else if 导通态中 →
    检查 (|vDiff| - vHold) / rOn < 0.01 → 关断
```

方向锁定 `_diacSign` 保证导通期间电压极性不会因迭代计算中的数值抖动而反转，这是仿真收敛的关键技术细节。

### 2.3 伏安特性曲线

```
I (mA)
  ↑
  │         ┌──── 导通区 (rOn=5Ω)
  │         │ 斜率 = 1/rOn
  │    vBO  │ vHold
  │ ───◄───┼───────►──── V (V)
  │    │    │
  │    │    │ 截止区 (rOff=1e8Ω)
  │    └────┘
```

正负方向完全对称：`|vBO| = 30V`，导通后降至 `|vHold| = 10V`。

## 三、双向晶闸管（TRIAC）

### 3.1 器件结构与符号

TRIAC（Triode for Alternating Current）是一种**双向可控的三端半导体开关器件**，相当于两只反并联的晶闸管（SCR）共用门极。三个端子为：

- **MT1**（Main Terminal 1）：主端子 1，参考地
- **MT2**（Main Terminal 2）：主端子 2
- **G**（Gate）：门极（触发端）

电路符号为两只反并联二极管中间引出栅极：

```
      MT2
       │
    ───┼───▶───┐
       │       │
       │       │
    ───┼───◀───┘
       │
       G
      MT1
```

在本仿真中，TRIAC 使用 `Triac` 组件（简化符号）或 `RealTriac` 组件（BT136 封装外观），类型标识 `type = 'triac'`。

### 3.2 工作特性

TRIAC 的工作状态可归纳为以下四种：

| MT2 对 MT1 极性 | 门极触发脉冲极性 | 触发结果 |
|:---:|:---:|:---|
| + | + | 触发导通（第一象限工作） |
| + | - | 触发导通（第四象限工作） |
| - | + | 触发导通（第二象限工作） |
| - | - | 触发导通（第三象限工作） |

**关键特性**：

1. **双向导通**：TRIAC 可双向流过大电流，导通后表现为低阻（`rOn = 0.1Ω`）
2. **门极触发**：门极触发电压 `vGt = 1.5V`，正负脉冲均可触发
3. **自锁保持**：一旦触发，撤除门极信号后 TRIAC 继续导通（自锁），直到主回路电流降至维持电流 `holdCurrent = 5mA` 以下
4. **过零关断**：在交流电路中，TRIAC 在电流过零时自然关断

#### 仿真模型

仿真中 TRIAC 的 MNA stamp（`DeviceStamps.js:stampTRIACs`）：

**门极回路**（G → MT1）：
- 截止时：`rGOff = 1×10⁸Ω`
- 导通时：`rG = 10Ω` 串联 `vGt = 1.5V`
- 滞回比较：激活阈值 `vGt`，关断阈值 `vGt × 0.3`

**主回路**（MT2 → MT1）：

- 截止时：`rOff = 1MΩ`
- 导通时：`rOn = 0.1Ω`
- 触发锁存：门极激活上升沿使 `_triggered = true`

### 3.3 伏安特性曲线

```
I (A)
  ↑
  │      ┌─── 导通态 (rOn=0.1Ω)
  │      │ 斜率 = 1/rOn
  │      │
  ───────┼────────► V (V)
  │      │
  │ 截止态 (rOff=1MΩ)
  │
  vGt    ← 门极触发电压 1.5V
```

### 3.4 关断机制 — 维持电流检测

仿真在 `CircuitSolver.js:_updateDeviceCurrents` 中实现自动关断：

```
if |physCurrent| < holdCurrent (5mA) →
    _triggered = false
    _gateActive = false
```

每次求解后检测主回路电流绝对值，低于维持电流则清除触发锁存位。这精确模拟了 TRIAC 的**过零关断**物理特性。

## 四、DIAC 触发 TRIAC 的详细过程

### 4.1 电路拓扑

本仿真项目 `multimeter_triac` 实现了经典 DIAC-TRIAC 调光电路：

```
AC 220V ── 白炽灯 ── TRIAC (MT2─MT1) ── GND
                        │
                  ┌─────┴─────┐
                  │           │
                  R1         DIAC
                (10kΩ)        │
                  │      (门极 G)
                 VR1          │
              (0~400kΩ)      │
                  │           │
                  C1 ──── GND
               (0.1µF)
```

### 4.2 工作过程分阶段分析

#### 阶段 1：RC 充电（DIAC 截止）

交流电源经白炽灯、R1、VR1 对 C1 充电。C1 两端电压：

$$V_{C1}(t) = V_{peak} \sin(\omega t) \times \left(1 - e^{-t / R_{eq}C}\right)$$

其中 `Req = R1 + VR1`，`C = C1 = 0.1µF`。

- VR1 阻值越大，RC 时间常数越大，C1 充电越慢
- VR1 阻值越小，RC 时间常数越小，C1 充电越快

此时 DIAC 处于截止高阻态（`rOff = 1×10⁸Ω`），TRIAC 门极无触发信号，TRIAC 处于截止态。

#### 阶段 2：DIAC 转折导通

当 `|VC1|` 超过 DIAC 转折电压 `vBO = 30V` 时，DIAC 进入导通态：

1. DIAC 端电压从 30V 骤降至 `vHold = 10V`
2. DIAC 导通电阻从 `1×10⁸Ω` 降至 `5Ω`
3. C1 通过 DIAC 向 TRIAC 门极放电

#### 阶段 3：TRIAC 门极触发

DIAC 导通后，C1 上的电荷经 DIAC 注入 TRIAC 门极，门极电流产生门极电压 `vGmt1`：

$$v_{Gmt1} = v_{C1} - v_{DIAC\_drop}$$

当 `|vGmt1| > vGt = 1.5V` 时：

1. TRIAC 的 `_gateActive` 置 `true`
2. 在 `_gateActive` 上升沿，`_triggered = true`（触发锁存）
3. TRIAC 主回路（MT2-MT1）从高阻（1MΩ）变为低阻（0.1Ω）

#### 阶段 4：负载导通

TRIAC 导通后，主回路电流流过白炽灯：

$$I_{load} = \frac{V_{AC} - V_{TRIAC\_drop}}{R_{lamp}}$$

- `rOn = 0.1Ω`，TRIAC 导通压降极小（约 1-2V）
- 白炽灯两端电压 ≈ 电源电压（减去 TRIAC 微小压降）

#### 阶段 5：DIAC 关断

TRIAC 导通后，MT2-MT1 电压被钳位在低电平，C1 无法继续从主回路获得充电电流。同时 DIAC 电流下降：

$$I_{DIAC} = \frac{v_{C1} - v_{Hold}}{r_{On}}$$

当 `|I_{DIAC}| < 0.01A` 时，DIAC 关断，返回高阻态。

#### 阶段 6：过零关断

交流电压过零时，TRIAC 主回路电流下降至维持电流 `5mA` 以下：

$$|I_{load}| < I_{hold} \quad \rightarrow \quad \_triggered = false$$

TRIAC 关断，等待下一个半周期的 RC 充电 → DIAC 触发过程。

### 4.3 调光原理小结

| VR1 阻值 | RC 时间常数 | DIAC 触发相位 | TRIAC 导通角 | 灯亮度 |
|:--------:|:----------:|:------------:|:-----------:|:------:|
| 大（400kΩ） | 长 | 延迟（接近 π/2） | 小 | 暗 |
| 中（200kΩ） | 中 | 中等 | 中 | 中 |
| 小（5kΩ） | 短 | 提前（接近 0） | 大 | 亮 |

#### 导通角

导通角 $\alpha$ 是指在一个周期内 TRIAC 导通的时间比例：

$$\alpha = \pi - \theta_{trigger}$$

其中 $\theta_{trigger}$ 为 DIAC 触发电容电压达到 30V 的相位角。

## 五、用万用表测试双向晶闸管

### 5.1 万用表相关组件

本仿真提供两种万用表：

| 类型 | 组件 | 特性 |
|------|------|------|
| **指针式** | `MF47Multimeter` (`mf47-panel`) | 模拟表头机械偏转，电阻档内置电池 |
| **数字式** | `Multimeter` (`multimeter`) | LCD 数字显示，高输入阻抗 |

### 5.2 数字万用表测试 TRIAC

数字万用表使用电阻档或二极管档可完成基本测试。

**测试原理**：
- 数字万用表电阻档输出恒定测试电流（通常约 0.5-1mA），测量被测元件两端压降
- 二极管档输出约 1mA 测试电流，显示正向压降（mV）

**TRIAC 引脚识别**：

| 测量对象 | 表笔接法 | 预期读数 | 说明 |
|---------|---------|---------|------|
| MT1-MT2 | 任意 | OL（无穷大） | 未触发时两主端子间高阻 |
| G-MT1 | 红(+)接G，黑(-)接MT1 | OL 或 1.5-3V（二极管档） | 门极-主端子间 PN 结特性 |
| G-MT1 | 红(+)接MT1，黑(-)接G | OL | 反向 PN 结截止 |
| G-MT2 | 任意 | OL | G-MT2 间无直接 PN 结 |

#### 模拟接线步骤

1. 将数字万用表拨至 **电阻 200kΩ 档**（`RES200k`）或 **二极管档**（`DIODE`）
2. 红表笔接 TRIAC 门极 G，黑表笔接 MT1
3. 读取门极正向特性
4. 交换表笔读取门极反向特性
5. 将红表笔接 MT2，黑表笔接 MT1，读取主端子间阻值

### 5.3 指针万用表测试 TRIAC

#### 5.3.1 测试原理

指针式万用表（以 MF47 为例）的电阻档具有以下特点：

1. **内部电池**：R×1、R×10、R×100、R×1k 档使用 **1.5V** 电池，R×10k 档使用 **9V** 电池
2. **表笔极性**：黑表笔为内部电池 **正极**（+），红表笔为 **负极**（-）
3. **刻度读数**：指针偏转角度与 Rx 成反比，$\theta \propto R_{mid} / (R_{mid} + R_x)$

#### 5.3.2 偏转公式

电阻档指针偏转量定义为：

$$\text{deflection} = \frac{R_{mid}}{R_{mid} + R_x}$$

其中 $R_{mid}$ 为该量程的中值电阻 = 倍率 × 20Ω，$R_x$ 为被测电阻。

| 档位 | 中值电阻 Rmid | 内部电池 |
|:----:|:------------:|:--------:|
| R×10 | 200Ω | 1.5V |
| R×100 | 2kΩ | 1.5V |
| R×1k | 20kΩ | 1.5V |
| R×10k | 200kΩ | **9V** |

#### 5.3.3 测试流程（仿真工作流 4：`triac-mf47-test`）

**步骤 1：万用表准备**
- 将 MF47 拨至 **R×100 档**
- 短接表笔调零（仿真中自动完成）

**步骤 2：门极正向测量（黑→G，红→MT1）**

| 项目 | 说明 |
|------|------|
| 万用表内部极性 | 黑表笔（COM）= 电池正极（+） |
| 接线 | `COM → G`, `V → MT1` |
| 仿真行为 | 指针偏转 **55%**（硬编码等效） |
| 物理含义 | G-MT1 间的 PN 结在正向偏置下有微小电流导通 |

**为什么是 55% 偏转？**
仿真中 MF47 电阻档的注入模型采用诺顿等效：电导 `1/Rmid` 并联电流源 `Vbat/Rmid`。门极触发电压约 1.5V，与 R×100 档的 1.5V 电池接近，门极微弱导通对应于偏转公式的等效阻值。**偏转 55%** 等效于：

$$R_x = R_{mid} \times \frac{1 - 0.55}{0.55} \approx 2k\Omega \times 0.818 \approx 1.64k\Omega$$

这对应于门极-主端子间的等效正向电阻。

**步骤 3：门极反向测量（交换表笔）**

| 项目 | 说明 |
|------|------|
| 接线 | `COM → MT1`, `V → G` |
| 仿真行为 | 指针不动（∞） |
| 物理含义 | PN 结反偏，仅极小的漏电流通过 |

**步骤 4：测量 MT1-MT2（未触发态）**

| 项目 | 说明 |
|------|------|
| 接线 | `黑→MT2`, `红→MT1` |
| 预期 | 指针不动（∞） |
| 检测条件 | `triac._triggered = false` |

**步骤 5：测量 MT1-MT2（触发后）**

这是检测的关键步骤——需要用外部手段使 TRIAC 触发，然后测量主端子间电阻变化：

| 操作 | 说明 |
|------|------|
| **短接 G-MT2** | 用导线将门极与 MT2 短路 |
| 原理 | MT2 ∼ G 同电位 → 主回路电压通过内部结构给门极提供触发电流 |
| 仿真检测 | `sameCluster(triac1_wire_g, triac1_wire_mt2)` → 设置 `_triggered = true` |
| 结果 | MT1-MT2 阻值从 ∞ 下降到 **较小值**（约几 Ω～几十 Ω） |
| 物理本质 | 触发后 TRIAC 内部导通关断恢复，主端子间呈现低阻 |

**步骤 6：撤除短接**

短接撤除后，若主回路仍有足够维持电流，TRIAC 保持导通态；若电流低于维持电流，TRIAC 关断。在欧姆档测试中，万用表提供的测试电流通常不足以维持导通，因此撤除短接后阻值会恢复到 ∞。

#### 5.3.4 测试原理总结

```
TRIAC 测试核心要点：

1. 门极为高阻输入 → 万用表直接测 G-MT1 正反向均为高阻
   （仿真中 G-MT1 正向有 55% 偏转，模拟微弱 PN 结导通）

2. MT1-MT2 在未触发时为高阻（∞）

3. 短接 G-MT2 可触发 TRIAC → MT1-MT2 间呈现低阻

4. 触发信号撤除后，若测试电流足够大则 TRIAC 保持导通
   （万用表电阻档的电流约 0.1~1mA，通常小于维持电流）
```

### 5.4 数字式 vs 指针式万用表对比

| 对比项目 | 数字万用表 | 指针万用表 |
|---------|-----------|-----------|
| 显示方式 | LCD 数字 | 机械指针偏转 |
| 分辨率 | 高（可达 0.1Ω） | 低（对数刻度） |
| 测试电流 | ~0.5mA | 随档位变化（R×1档可达 100mA） |
| 输入阻抗 | 极高（10MΩ） | 低（中值电阻） |
| 二极管档 | **有**，显示 Vf | 无专用档 |
| TRIAC 触发能力 | 弱（电流小） | 相对较强（R×1 档电流大） |
| PN 结判断 | 直接读 Vf | 观察偏转角度 |

**教学建议**：
- 使用**指针万用表**更适合 TRIAC 触发测试，因其能提供更大的测试电流
- 使用**数字万用表二极管档**可准确读取门极 PN 结正向压降
- 两种仪表配合使用可全面判断 TRIAC 好坏

## 六、示波器波形观察

### 6.1 三路示波器配置

仿真集成 `Oscilloscope_tri` 组件（`type = 'oscilloscope_tri'`），支持三通道波形观察：

| 通道 | 颜色 | 典型接线（工作流3） | 观察波形 |
|:----:|:----:|-------------------|---------|
| CH1 | 黄色 | 白炽灯两端 | 被斩波的正弦波 |
| CH2 | 蓝色 | C1 两端 | RC 充放电锯齿波 |
| CH3 | 红色 | DIAC 两端（可选） | 触发尖峰 |

### 6.2 关键波形分析

#### CH1：负载电压波形（白炽灯两端）

```
V
↑  ┌──┐      ┌──┐
│  │  │      │  │
│  │  │      │  │
│  │  │      │  │
0──┴──┴──────┴──┴──────→ t
│        │         │
触发角    导通角    过零关断
```

- 触发角由 VR1-C1-DIAC 决定
- 前半个周期被"斩"掉的部分对应 DIAC 转折前的 RC 充电时间
- 导通角越大，负载平均功率越大，灯越亮

#### CH2：电容 C1 电压波形

```
V
↑    ╱╲      ╱╲
│   ╱  ╲    ╱  ╲
│  ╱    ╲  ╱    ╲
│ ╱      ╲╱      ╲
0─╱───────╱─────────→ t
│         │
30V       DIAC转折点
（vBO）     C1 经 DIAC 放电
```

- 充电曲线由 VR1×C1 时间常数决定
- 达到 30V 时 DIAC 转折，C1 快速放电至 TRIAC 门极

## 七、故障模拟与排查

### 7.1 故障配置

| 故障 | 设置方式 | 现象 |
|------|---------|------|
| TRIAC 击穿（`_faultMTShort`） | `triac1._faultMTShort = true` | 灯常亮，无法调光 |
| TRIAC 门极开路（`_faultGateOpen`） | `triac1._faultGateOpen = true` | 灯不亮，无法触发 |
| DIAC 击穿（`_faultShort`） | `diac1._faultShort = true` | 灯微亮，无法正常调光 |

### 7.2 排查方法

| 现象 | 可能原因 | 诊断步骤 |
|------|---------|---------|
| 灯完全不亮 | 电源未开、门极开路、DIAC 开路 | 1. 查电源电压<br>2. 查 TRIAC G-MT1 触发电压<br>3. 查 DIAC 两端波形 |
| 灯常亮不可调 | TRIAC 击穿短路 | 万用表测 MT1-MT2 阻值（应为∞或极低） |
| 灯亮度不足 | VR1 过大、C1 失效 | 测 C1 电压波形 |
| 调光不连续 | DIAC 转折电压不稳定 | 查 DIAC 两端电压波形 |
