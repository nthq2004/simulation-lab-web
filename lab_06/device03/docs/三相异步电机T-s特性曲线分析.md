# 三相异步电机 T-s 特性曲线分析

## 实现的功能

通过 **T-s 特性曲线面板**直观展示三相异步电动机的电磁转矩与转差率（转速）之间的关系。观察电机在恒转矩负载和风机型负载下的起动过程和稳定工作点。

## 工作原理

**T-s 曲线**：描述电磁转矩 Te 随转差率 s 变化的曲线。在定子电压 V、频率 f 和转子电阻 R₂ 一定时，电磁转矩：

```
Te = 3V²(R₂/s) / [ω_sync·((R₁+R₂/s)² + X²)]
```

曲线特征：
- **起动点**（s=1）：起动转矩 T_st
- **临界点**（s=s_m）：最大转矩 T_max（也称为颠覆转矩）
- **额定点**：额定负载对应的转矩和转差率
- **同步点**（s=0）：Te=0

**参考曲线**（虚线）：
- 蓝色虚线：220V / 50Hz / R₂=0.46Ω（额定参数基准线）
- 橙色虚线：110V / 25Hz / R₂=0.46Ω
- 绿色虚线：220V / 50Hz / R₂=1.38Ω

**负载特性线**：负载转矩 T_L 随转速的变化曲线。
- 恒转矩负载：水平直线（T_L = 常数）
- 风机型负载：抛物线（T_L ∝ n²）

**稳定工作点**：T-s 曲线与负载特性线的交点，该点 Te = T_L。

## 操作步骤

| 步骤 | 操作说明 | 检测要点 |
|------|---------|---------|
| 1 | Y 形接线，设置恒转矩 30 N·m，T-s 面板显示蓝色虚线（T-s 曲线）和橙色虚线（负载线），均为虚线表示电机未起动 | loadTorque > 25 |
| 2 | 起动电机（220V/50Hz），红色点（工作点）沿曲线移动，蓝色点（负载点）沿负载线移动，最终在交点稳定 | ω_m > 140 rad/s |
| 3 | 断开电源，切换为风机型负载，负载线由水平变为抛物线 | 电源关闭，loadType='fan' |
| 4 | 重新接通电源，观察电机在风机负载下起动，红蓝两点在新的交点处稳定 | 电源开启，ω_m > 140 |
