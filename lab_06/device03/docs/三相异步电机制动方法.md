# 三相异步电机制动方法

## 实现的功能

演示三相异步电动机的三种电气制动方法：**反接制动**、**再生制动**和**能耗制动**，对比其原理、能量流向和制动效果。

## 工作原理

### 反接制动
将三相电源任意两相对调，产生反向旋转磁场，转子受到与旋转方向相反的电磁转矩，转速迅速下降。当转速接近零时需及时切断电源，否则电机将反向起动。

**能量流向**：电机从电网吸收电能，同时转子惯性动能转化为热能消耗在转子电阻中。

### 再生制动
降低电源频率（或电机转速超过同步转速），转差率 s < 0，电机由电动状态转变为发电状态，将机械能回馈至电网。

**能量流向**：机械能 → 电能 → 回馈电网。

### 能耗制动
切断交流电源，向定子绕组通入直流电流，产生静止磁场。转子切割静止磁场产生制动转矩，动能转化为热能消耗在转子回路中。

**能量流向**：机械能 → 热能（转子电阻）。

## 操作步骤

| 步骤 | 操作说明 | 检测要点 |
|------|---------|---------|
| 1 | 接线（正序 UVW），起动电机达到稳定运行状态 | 电源开启，正序 |
| 2 | 将相序切换为负序（UWV），观察转速迅速下降（反接制动） | _phaseSeq = -1 |
| 3 | 恢复正序，将频率降至 30Hz，观察电机进入再生制动（转速降至约 900 rpm） | _phaseSeq=1，频率≈30Hz |
| 4 | 恢复 50Hz，切断交流电源，将 DC 24V 正极接 U1、负极接 V1，打开直流电源，观察能耗制动停车 | AC 关、DC 开，ω_m ≈ 0 |
| 5 | 知识问答：哪种制动方式可将机械能回馈至电网？ | 正确答案：再生制动 |
