# 三相异步电机特性测试

## 实现的功能

通过**堵转试验**、**空载试验**和**负载试验**，系统测量三相异步电动机的关键运行参数，包括堵转电流、堵转转矩、空载电流、额定转速、额定转矩、最大转矩和过载能力。

## 工作原理

**堵转试验**：将转子堵住（s=1），施加额定电压，测量堵转电流和堵转转矩。堵转电流是电机起动性能的重要指标。

**空载试验**：转子不带负载（s≈0），测量空载电流和空载转速，反映电机的励磁特性和机械损耗。

**额定负载试验**：施加额定负载转矩，测量额定电流、额定转速和额定转矩，验证电机的额定性能。

**过载能力**：异步电机最大转矩 T_max 与额定转矩 T_N 的比值，反映电机承受短时过载的能力。

## 操作步骤

| 步骤 | 操作说明 | 检测要点 |
|------|---------|---------|
| 1 | 调出数字功率计，将电流线圈串联接入 U 相，电压线圈 U+ 接 I+、U- 接 U2。V、W 相直连 | 功率计可见，连线正确 |
| 2 | 设置负载 200 N·m（堵转），接通三相电源（220V/50Hz），观察堵转电流和堵转转矩 | loadTorque ≥ 200，电源开启 |
| 3 | 空载实验：将负载调至 0 N·m，记录空载电流和空载转速 | loadTorque ≈ 0 |
| 4 | 额定负载实验：设置负载 67 N·m，记录额定电流、转速和转矩 | loadTorque ≈ 67 |
| 5 | 过载能力测试：设置负载 160 N·m（略小于最大转矩），观察电机仍能稳定运行 | loadTorque ≈ 160 |
| 6 | 加负载至 200 N·m（超过最大转矩），观察电机转速迅速下降直至堵转 | loadTorque ≈ 198 |
| 7 | 知识问答：堵转电流约为额定电流的多少倍？ | 正确答案：4~7 倍 |
