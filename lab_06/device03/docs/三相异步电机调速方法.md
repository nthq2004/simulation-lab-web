# 三相异步电机调速方法

## 实现的功能

演示四种异步电动机调速方法：**调压调速**、**转子串电阻调速**、**变极调速**和**变频调速**（含恒 V/f 和弱磁调速），对比不同调速方式的特点。

## 工作原理

三相异步电机的转速公式：

```
n = 60f/p × (1 - s)
```

调速途径：

| 方法 | 原理 | 特点 |
|------|------|------|
| **调压调速** | 改变定子电压 V → 改变电磁转矩 → 改变转差率 s | 调速范围窄，适用于风机泵类 |
| **转子串电阻调速** | 增大 R₂ → 改变 T-s 曲线 → 改变工作点 s | 有级调速，效率随电阻增大降低 |
| **变极调速** | 改变定子绕组极对数 p → 改变同步转速 | 有级调速，需专用多速电机 |
| **变频调速** | 改变电源频率 f → 改变同步转速 | 无级调速，调速范围宽，效率高 |

V/f 恒定控制保持主磁通不变，是变频调速的基本方式。当频率超过额定频率时，电压无法继续升高，进入弱磁调速区。

## 操作步骤

| 步骤 | 操作说明 | 检测要点 |
|------|---------|---------|
| 1 | 接线（Y 形），设置风机型负载，起动电机（220V/50Hz），观察稳定转速 | 电源开启，loadType='fan' |
| 2 | 将电压降至 160V（保持 50Hz），观察转速下降（调压调速） | vRms ≈ 160 |
| 3 | 恢复 220V，切换为恒转矩（60 N·m），将 R₂ 由 0.46Ω 增大至 1.46Ω，观察转速下降 | loadType='constant'，loadTorque≈60，R2≈1.46 |
| 4 | 恢复 R₂=0.46Ω，极对数由 2 改为 4，观察转速减半（变极调速） | R2≈0.46，polePairs=4 |
| 5 | 恢复极对数 2，频率降至 40Hz，电压同步降至 176V（恒 V/f 变频调速） | polePairs=2，频率≈40Hz，电压≈176V |
| 6 | 频率升至 60Hz，电压恢复 220V（V/f 比减小，弱磁调速） | 频率≈60Hz，电压≈220V |
| 7 | 知识问答：哪种调速方法属于改变同步转速的高效调速方式？ | 正确答案：变频调速 |
