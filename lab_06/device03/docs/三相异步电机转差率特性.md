# 三相异步电机转差率特性

## 实现的功能

通过改变负载转矩、相序和电源频率，系统观察转差率 s 从 0 到 1 再到大于 1 及小于 0 的全范围变化，理解转差率与电磁转矩之间的关系。

## 工作原理

转差率是异步电机的核心参数：

```
s = (n_sync - n) / n_sync
```

不同 s 值对应的运行状态：

| s 范围 | 运行状态 | 说明 |
|--------|---------|------|
| s = 0 | 理想空载 | 转子转速等于同步转速（无转矩） |
| 0 < s < 1 | 电动状态 | 正常电机运行范围 |
| s = 1 | 堵转/起动 | 转子静止，起动电流最大 |
| s > 1 | 反接制动/反向起动 | 转子逆磁场方向旋转 |
| s < 0 | 再生制动/发电状态 | 转子超同步速，能量回馈 |

**T-s 曲线**：当 s 很小时（< 0.05），电磁转矩与 s 近似成正比（T ∝ s），T-s 曲线接近线性。

## 操作步骤

| 步骤 | 操作说明 | 检测要点 |
|------|---------|---------|
| 1 | 接线（Y 形），起动电机（220V/50Hz），观察 s 从 1 逐渐降至接近 0 | ω_m > 140 rad/s |
| 2 | 设置负载 200 N·m，观察转速下降至停转，s 从 0 升至 1 | loadTorque > 190 |
| 3 | 卸除负载，切换为负序（UWV），观察 s > 1 的现象 | _phaseSeq = -1 |
| 4 | 恢复正序，频率降至 30Hz，观察再生制动（s < 0） | _phaseSeq=1，频率≈30Hz |
| 5 | 恢复 50Hz，设置负载 19 N·m，记录 Te 和 s | loadTorque≈19，ω_m>140 |
| 6 | 设置负载 29 N·m，记录 Te 和 s | loadTorque≈29，ω_m>140 |
| 7 | 设置负载 39 N·m，验证 Te ≈ 负载转矩，验证 s 很小时 Te ∝ s | loadTorque≈39，ω_m>140 |
| 8 | 知识问答：s 很小时（<0.06），Te 与 s 呈什么关系？ | 正确答案：Te ∝ s |
