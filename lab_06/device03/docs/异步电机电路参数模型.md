# 三相异步电动机简化电路参数模型

> 基于改进节点分析法（MNA）的电磁暂态仿真实现。
> 对应组件 `InductionMotor` 的 `simpleModel = true` 分支。

---

## 一、概述

本模型不使用完整的 6 变量定转子耦合微分方程，而是将每相绕组等效为 RL 串联电路，电磁转矩由稳态 T 型等效电路公式每帧计算。电路的诺顿等效直接嵌入 MNA 节点矩阵，不占用额外的电流变量方程，因此求解规模更小、数值稳定性更好。

### 仿真循环

```
_preSolve(dt)        ← 机械状态欧拉积分（机电耦合）
  ↓
拓扑 → 求解 MNA      ← _stampIMSimple 注入诺顿等效参数
  ↓
_updateDeviceCurrents ← 从节点电压回算电流、计算电磁转矩
  ↓
tick(dt)             ← 视觉效果更新
```

求解顺序由 `consys.js` 的 20 fps 物理循环驱动：

```
CircuitSolver → PneumaticSolver → DigitalSolver → ... → _tickAll
```

## 二、电路求解（MNA）

### 2.1 诺顿等效嵌入

在 `DeviceStamps._stampIMSimple`（`tools/DeviceStamps.js:2229`）中，每相定子绕组用一转差率依赖的 RL 阻抗表示，通过后向欧拉离散化为诺顿等效电路。

#### 等效阻抗

```
Zeq = R_load + L_total / dt
```

其中：

```
R_load  = R1 + R2 / s          (s = 转差率)
L_total = Lσ1 + Lσ2            (总漏感)
```

#### 诺顿电导与历史电流源

```
Geq = 1 / Zeq
Ih  = (L_total / dt) · Geq · i_prev
```

将诺顿等效（并联电导 Geq + 历史电流源 Ih）跨接在 `u1-u2`、`v1-v2`、`w1-w2` 端子对之间，即完成对 G 矩阵和 B 向量的 stamp。

#### 实现代码（简化）

```js
this._fill(ctx, G, B, cU1, cU2, Geq);       // 跨接电导
this._addI(ctx, B, cU2, cU1, Ih_u);          // 注入历史电流
```

其中 `_fill` 在 G 矩阵的 `(node1,node2)` 位置加 Geq，`_addI` 在 B 向量对应节点注入 Ih。

### 2.2 励磁支路并联

励磁支路 `Rc || (R_damp + Lm)` 也离散为诺顿等效，与转子支路并联：

```
G_Rc   = 1 / Rc                           (铁损电导)
K_Lm   = dt / (2 · Lm)                    (梯形积分系数)
Geq_RL = K_Lm / (1 + R_damp · K_Lm)      (Lm 等效电导)
```

梯形积分历史项：

```js
damp_alpha = (1 - R_damp · K_Lm) / (1 + R_damp · K_Lm);
Ih_mag_u = damp_alpha · Ih_mag_u_prev + Geq_RL · V_u_prev;
```

**总等效**：每相端口并联电导 `G_eq_total = Geq + G_Rc + Geq_RL`，总历史电流 `Ih_total = Ih_rotor + Ih_mag`。

### 2.3 方程规模

| 模型 | 每台电机额外变量数 | 说明 |
|:---|:---:|:---|
| 简化模型 | 0 | 诺顿等效直接嵌入节点矩阵，无额外方程 |
| 全模型 | 6 | 3 定子电流 + 3 转子电流，G 矩阵扩大 6×6 |

### 2.4 自适应跳帧

电路达到稳态（连续 10 帧节点电压变化量 < 1e-6）后隔帧求解，降低 CPU 开销。存在交流源（`_hasACSource = true`）时不跳帧，确保波形精确度。

## 三、相电流计算

### 3.1 从节点电压回算

求解 MNA 后，各相电流从端口电压回算（`CircuitSolver._updateDeviceCurrents`，约第 1280 行）：

```js
const Vu = (vu1 !== undefined && vu2 !== undefined)
           ? Geq * (vu1 - vu2) + Ldt * Geq * iup : 0;
```

展开为三相：

```js
i_u = Geq · (V_u1 − V_u2) + (L_total/dt) · Geq · i_u_prev
i_v = Geq · (V_v1 − V_v2) + (L_total/dt) · Geq · i_v_prev
i_w = Geq · (V_w1 − V_w2) + (L_total/dt) · Geq · i_w_prev
```

式中 `Geq = 1/Zeq`，`Ldt = L_total/dt`，`i_prev` 为上帧电流。

### 3.2 励磁电流

励磁支路电流也从同一端电压回算：

```js
i_mag_u = G_mag · (V_u1 − V_u2) + Ih_mag_u
```

其中 `G_mag = G_Rc + Geq_RL`，`Ih_mag_u` 为梯形积分历史项。

### 3.3 总电流与显示

```js
i_total_u = i_u + i_mag_u
dev._iuDisplayPrev = i_total_u
```

存入显示缓存，供电机面板上的电流表读取。

### 3.4 限幅保护

为防止 MNA 数值发散导致电流爆裂，`_postSolve` 将每相电流钳位在 ±300 A：

```js
const IM_MAX = 300;
const clamp = (v) => Math.max(-IM_MAX, Math.min(IM_MAX, v));
this._iuPrev = clamp(i_u);
```

### 3.5 电机面板显示值

| 显示项 | 数据源 | 单位 |
|:---|:---|:---:|
| 相电流 (U/V/W) | `_iuDisplayPrev` / `_ivDisplayPrev` / `_iwDisplayPrev` | A |
| 相电压 RMS | `_Vrms`（由三相电压平方平均计算） | V |
| 转速 | `_omega_m × 60 / 2π` | rpm |
| 转差率 | `slip = (ω_sync − ω_m) / ω_sync` | — |
| 电磁转矩 | `_Te` | N·m |

## 四、相序检测

在 `InductionMotor._updateDynamic`（每帧 tick 前调用）中，使用**瞬时值代数法**检测相序。

### 4.1 原理

利用三相电压的旋转方向判别。对三相瞬时值 `V_u`、`V_v`、`V_w`，构造判别式：

```
seq = V_u · (V_v' − V_w') + V_v · (V_w' − V_u') + V_w · (V_u' − V_v')
```

其中 `V_u'`、`V_v'`、`V_w'` 为上帧电压瞬时值。该式在几何上等效于计算电压空间矢量的旋转方向：

- **正序（UVW）**：`seq ≥ 0`
- **逆序（UWV）**：`seq < 0`

### 4.2 判断逻辑

```js
if (hasAllPhases) {          // U、V、W 三相电压均 > 15V
    this._phaseSeq = seq ≥ 0 ? 1 : -1;   // 1 = 正序, -1 = 逆序
} else if (!hasVoltage) {    // 三相均 < 15V（电源完全断开）
    this._phaseSeq = 0;                   // 无相序
}
// 零交叉过渡态 → 保持上一次 _phaseSeq 不变
```

**阈值 15V** 用于消除数值噪声导致的误判。三相都满足 `> 15V` 才更新，单相或两相缺失时不更新，避免相序闪烁。

### 4.3 相序的物理作用

| `_phaseSeq` | 同步转速方向 | 转矩方向 | 典型场景 |
|:---:|:---:|:---:|:---|
| 1 | 正转（`+ω_sync`） | 正向驱动 | 正常起动、V/f 调速 |
| −1 | 反转（`−ω_sync`） | 反向驱动 | 反接制动、负序运行 |
| 0 | 无 | 不产生转矩 | 缺相、电源断开 |

相序直接影响机械积分中的同步转速设定：

```js
// _preSolve 中：
this._omega_sync = (2πf / p) · this._phaseSeq;

// 堵转保护：正序下不允许电机反转
if (this._phaseSeq > 0 && this._omega_m < 0) this._omega_m = 0;
```

## 五、电磁转矩计算

### 5.1 简化模型转矩公式

在 `CircuitSolver._updateDeviceCurrents` 中，使用 T 型等效电路的输出转矩公式：

```
T_e =  3 · V_ph² · (R₂ / s)
      ──────────────────────
          ω_sync · Z²
```

#### 各变量含义

| 符号 | 含义 | 计算公式 |
|:---|:---|---:|
| `V_ph` | 相电压 RMS | `√[(V_u² + V_v² + V_w²) / 3]` |
| `ω_sync` | 同步角速度 | `2πf / p` |
| `s` | 转差率 | `(ω_sync − ω_m) / ω_sync` |
| `Z²` | 等效阻抗模平方 | `(R₁ + R₂/s)² + (X₁ + X₂)²` |
| `X₁ + X₂` | 总漏抗 | `2πf · (Lσ₁ + Lσ₂)` |

#### 完整计算流程

```js
// 1. 端电压瞬时值
V_u = V_u1 - V_u2
V_v = V_v1 - V_v2
V_w = V_w1 - V_w2

// 2. 相电压 RMS（三相平方平均）
V_ph² = (V_u² + V_v² + V_w²) / 3

// 3. 等效阻抗
X_total  = 2πf · (Lσ₁ + Lσ₂)
R_load   = R₁ + R₂ / s
Z²       = R_load² + X_total²

// 4. 电磁转矩
T_e = 3 · V_ph² · (R₂ / s) / (ω_sync · Z²)
```

### 5.2 特殊工况处理

#### 缺相起动

三相中任一相电压低于 5V 且电机近静止时，强制转矩为 0：

```js
const hasAllPhaseV = |V_u| > 5 && |V_v| > 5 && |V_w| > 5;
if (!hasAllPhaseV && |ω_m| < 5) te = 0;
```

运行中缺相（`|ω_m| ≥ 5`）则不受此限，电机继续运行但转矩降低、电流增大。

#### 反接制动（|s| > 1.2）

转矩乘以放大因子模拟集肤效应导致的转子等效电阻增大：

```js
if (|s| > 1.2) te *= 2 · (|s| − 0.7);
```

#### 物理限幅

计算最大电磁转矩（对应临界转差率 `s_max = R₂ / √(R₁² + X_total²)`）：

```
T_max = 3 · V_ph² / [2 · ω_sync · (R₁ + √(R₁² + X_total²))]
```

根据该理论极限将转矩钳位在物理可实现范围内：

```js
te = Math.max(-1.2 · T_max, Math.min(1.2 · T_max, te));
```

### 5.3 与全模型的区别

| 特性 | 简化模型 | 全模型（6 变量） |
|:---|:---|:---|
| 电流变量 | 0（诺顿嵌入节点矩阵） | 6/台（定子 3 + 转子 3） |
| 转矩公式 | 稳态 T 型等效电路 | `T_e = p · i_sᵀ · dL_sr/dθ · i_r` |
| 转子动态 | 瞬态电抗近似（`Lσ₂/s`） | 转子绕组微分方程耦合 |
| 励磁电流 | 梯形积分诺顿等效 | 与定转子完全耦合 |
| 剩磁效应 | 断路时注入反电动势电流源 | 转子方程中添加反电动势项 |
| 集肤效应 | 经验放大因子（|s| > 1.2 时） | 隐含在 R₂ 频率响应中 |
| 数值稳定性 | 较好（无微分方程耦合） | 大时间步长下易发散 |
| MNA 方程数 | 0 | 6 × 电机台数 |

### 5.4 缺相仿真验证

以工作流 8（`fault-analysis`）为例：

| 步骤 | 状态 | `hasAllPhaseV` | `ω_m` | `T_e` | 结果 |
|:---|:---|:---:|:---:|:---|:---|
| 1 正常起动 | 三相完整 | true | > 140 | 正转矩 | 正常起动 |
| 2 运行中断 W 相 | W 相缺相 | false | > 100 | 降低 | 继续旋转，电流增大 |
| 3 缺相重起 | W 相缺相 | false | < 1 | 0 | 无法起动 |
| 4 降压运行 | 三相恢复 | true | > 100 | 降低 | 低转速运行 |

## 六、机电耦合（`_preSolve`）

每帧先于电路求解执行，欧拉法积分更新机械状态：

```js
α = (T_e − T_load − B · ω_m) / J
ω_m += α · dt
```

### 负载转矩计算

- **恒转矩模式**（`loadType = 'constant'`）：
  ```
  T_load = loadTorque · sign(ω_m)
  ```

- **风机型模式**（`loadType = 'fan'`）：
  ```
  T_load = fanK · ω_m · |ω_m|
  ```

  其中 `fanK = P_rated / (ω_rated)³`（由额定功率和额定转速计算）。

### 堵转保护

极低转速（`|ω_m| < 0.5`）下，若负载转矩大于电磁转矩，维持停转：

```js
if (|ω_m| < 0.5 && loadTorque > |T_e|) ω_m = 0;
```

### 直流能耗制动

检测 DC24V 电源是否接到 U1/V1 且交流电源关闭：

```js
const brakeT = ω_m;           // 制动转矩 = 转速 × 1
const accel  = (T_e − T_load − brakeT − B·ω_m) / J;
```

制动转矩方向始终与转速相反，电机迅速减速至停转。

### 默认值下的理论计算

```
同步转速      ω_sync = 2π × 50 / 2 = 157.08 rad/s
额定转速      ω_n    = 1440 × 2π / 60 = 150.80 rad/s
额定转差率    s_n    = (1500 − 1440) / 1500 = 0.04
额定转矩      T_n    = 10×10³ / 150.80 = 66.3 N·m
最大转矩      T_max  ≈ 2.0 × T_n ≈ 133 N·m
起动转矩      T_start ≈ 1.2 × T_n ≈ 80 N·m
起动电流      I_start ≈ 5~6 × I_n
```
