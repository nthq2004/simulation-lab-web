# 三相异步电动机三相瞬态模型

> 基于改进节点分析法（MNA）的 6 变量定转子耦合电磁暂态仿真。
> 对应组件 `InductionMotor` 的 `simpleModel = false` 分支。

---

## 一、概述

本模型为 InductionMotor 的全 6 变量版本，不依赖稳态等效电路近似，而是直接求解定子三相绕组和转子三相绕组的瞬态耦合微分方程。定转子通过**随电角度变化的互感矩阵 `Lₛᵣ(θᵣ)`** 耦合，电磁转矩由电流和电感对角度的导数计算。

全模型比简化模型多 6 个 MNA 电流变量（每台电机），能更精确地模拟：

- 转子动态过程（转子时间常数的衰减特性）
- 变频调速时的瞬态响应
- 谐波和 PWM 激励下的电流波形
- 自励发电（剩磁注入）

### 仿真循环

```
_preSolve(dt)           ← 机械状态欧拉积分
  ↓
拓扑 → 求解 MNA          ← _stampIMFull 注入 6×6 伴随模型
  ↓
_updateDeviceCurrents    ← 从 MNA 解中直接读取 6 个电流变量
  ↓                        + 计算电磁转矩 T_e = p · iₛᵀ · dLₛᵣ/dθ · iᵣ
tick(dt)                ← 视觉效果更新
```

## 二、数学模型

### 2.1 定转子电压方程

在三相静止坐标系（ABC 坐标系）下，绕线型异步电机的电压方程为：

```
Vₛ = Rₛ · iₛ + d(Lₛₛ · iₛ + Lₛᵣ · iᵣ) / dt
Vᵣ = Rᵣ · iᵣ + d(Lᵣₛ · iₛ + Lᵣᵣ · iᵣ) / dt
```

展开为 6 维系统：

```
[Vₛ]   [Rₛ  0 ] [iₛ]     d  [ Lₛₛ  Lₛᵣ ] [iₛ]
[  ] = [      ] [  ]  +  -- [          ] [  ]
[Vᵣ]   [ 0  Rᵣ] [iᵣ]     dt [ Lᵣₛ  Lᵣᵣ ] [iᵣ]
```

对于**笼型转子**，转子端部短路：`Vᵣ = [0, 0, 0]ᵀ`。

### 2.2 电感矩阵

#### 定子自感（与转子位置无关）

```
        ┌                         ┐
        │ L₁ₛ + Lₘ    −Lₘ/2  −Lₘ/2 │
Lₛₛ =   │ −Lₘ/2   L₁ₛ + Lₘ    −Lₘ/2 │
        │ −Lₘ/2    −Lₘ/2  L₁ₛ + Lₘ │
        └                         ┘
```

- `L₁ₛ` — 定子漏感（`Lsigma1`）
- `Lₘ` — 励磁电感（`Lm`）
- 互感的 `−Lₘ/2` 来源于三相 120° 对称：`cos(120°) = −1/2`

#### 转子自感（结构对称，与转子位置无关）

```
        ┌                           ┐
        │ L₂ₛ + Lₘ    −Lₘ/2   −Lₘ/2 │
Lᵣᵣ =   │ −Lₘ/2   L₂ₛ + Lₘ    −Lₘ/2 │
        │ −Lₘ/2    −Lₘ/2  L₂ₛ + Lₘ │
        └                           ┘
```

- `L₂ₛ` — 转子漏感（`Lsigma2`）

#### 定转子互感（随电角度 θᵣ 变化）

```
        ┌                                            ┐
        │ Lₘ·cos(θᵣ)  Lₘ·cos(θᵣ−120°)  Lₘ·cos(θᵣ+120°) │
Lₛᵣ =   │ Lₘ·cos(θᵣ+120°)  Lₘ·cos(θᵣ)  Lₘ·cos(θᵣ−120°) │
        │ Lₘ·cos(θᵣ−120°)  Lₘ·cos(θᵣ+120°)  Lₘ·cos(θᵣ) │
        └                                            ┘
```

`Lᵣₛ = Lₛᵣᵀ`。

### 2.3 后向欧拉离散化

采用后向欧拉法（Backward Euler）将微分方程离散为 MNA 兼容的伴随模型：

对一般形式 `V = R·i + d(L·i)/dt`，后向欧拉离散：

```
V(t) = R·i(t) + L·[i(t) − i(t−Δt)] / Δt
```

整理为：

```
V(t) = (R + L/Δt)·i(t) − L/Δt·i(t−Δt)
```

对三相系统扩展为 6×6 矩阵形式，每相的历史项包含所有其他相的耦合。

## 三、电路求解（MNA）

### 3.1 6×6 伴随矩阵构建

在 `DeviceStamps._stampIMFull`（第 1998−2227 行）中，每台电机向 G 矩阵注入 **6 个电流变量**（列）和 **6 个方程**（行）：

| 变量 | 列索引 | 物理含义 |
|:---|:---:|:---|
| `colU` | `idx` | 定子 U 相电流 iᵤ |
| `colV` | `idx+1` | 定子 V 相电流 iᵥ |
| `colW` | `idx+2` | 定子 W 相电流 i_w |
| `colRU` | `idx+3` | 转子 U 相电流 iᵣᵤ |
| `colRV` | `idx+4` | 转子 V 相电流 iᵣᵥ |
| `colRW` | `idx+5` | 转子 W 相电流 iᵣ_w |

#### 3.1.1 伴随电导矩阵

```
G_element = L / Δt
```

其中 L 为 6×6 电感矩阵。按定子/转子分块：

**定子块**（3×3）：

```
Gss_diag = (L₁ₛ + Lₘ) / Δt      (自感伴随电导)
Gss_off  = (−Lₘ/2) / Δt        (互感伴随电导)
```

**转子块**（3×3）：

```
Grr_diag = (L₂ₛ + Lₘ) / Δt
Grr_off  = (−Lₘ/2) / Δt
```

**耦合块**（3×3，随 θᵣ 变化）：

```
Gsr_uu = Lₘ·cos(θᵣ)     / Δt
Gsr_uv = Lₘ·cos(θᵣ−120°) / Δt
Gsr_uw = Lₘ·cos(θᵣ+120°) / Δt
...（对称循环排列）
```

#### 3.1.2 历史电流源

6×1 历史项 B_vector 由**上帧的电流值**和**上帧的 θᵣ** 计算：

```
H = L(θᵣ_prev) / Δt · i_prev
```

展开后，以定子 U 相为例：

```
Hᵤ = Gss_diag·iᵤ⁻  + Gss_off·iᵥ⁻  + Gss_off·i_w⁻
   + Gsr(θᵣ_prev)ᵤᵤ·iᵣᵤ⁻ + Gsr(θᵣ_prev)ᵤᵥ·iᵣᵥ⁻ + Gsr(θᵣ_prev)ᵤ_w·iᵣ_w⁻
```

这些历史项注入 B 向量对应方程的右侧。

#### 3.1.3 方程结构

以定子 U 相为例，完整的 MNA 方程为：

```
V(u1) − V(u2) − (R₁ + Gss_diag)·iᵤ − Gss_off·iᵥ − Gss_off·i_w
    − Gsr_uu·iᵣᵤ − Gsr_uv·iᵣᵥ − Gsr_uw·iᵣ_w = Hᵤ
```

转子的 3 个方程为内部短接形式（端口悬空）：

```
0 − (R₂ + Grr_diag)·iᵣᵤ − Grr_off·iᵣᵥ − Grr_off·iᵣ_w
    − Gsr_uu·iᵤ − Gsr_vu·iᵥ − Gsr_wu·i_w = Hᵣᵤ
```

### 3.2 定子端口的 KCL 注入

对定子三相的 `u1-u2`、`v1-v2`、`w1-w2` 端子对，在节点电压矩阵（G 矩阵的左上角）中进行 KCL 注入：

```js
// 在 u1 节点的行，电流变量 colU 的列：系数 +1
// 在 u2 节点的行，电流变量 colU 的列：系数 −1
kclStamp(cU1, colU,  1);
kclStamp(cU2, colU, -1);
```

这建立了电机端子电流与外部电路的连接。

### 3.3 铁损电阻并联

在各相端子 `u1-u2`、`v1-v2`、`w1-w2` 间并联等效电导：

```
gCore = 1 / (3 · Rc)
```

### 3.4 剩磁注入

起动时（`slip > 0.8`），在转子方程中注入剩磁反电动势，使电机能自励发电：

```
B[colRU] −= Φ_rem · ω_sync · 0.3 · cos(θᵣ)
B[colRV] −= Φ_rem · ω_sync · 0.3 · cos(θᵣ − 120°)
B[colRW] −= Φ_rem · ω_sync · 0.3 · cos(θᵣ + 120°)
```

其中 `Φ_rem` 为剩磁通（默认 0.012 Wb），`ω_sync` 为同步角速度。

### 3.5 方程规模

| 模型 | 每台电机变量数 | G 矩阵扩大 | Stamp 方式 |
|:---|:---:|:---:|:---|
| 全模型 | 6 | 6 列 + 6 行 | `_stampIMFull` |
| 简化模型 | 0 | 无 | `_stampIMSimple` 诺顿嵌入 |

方程总数计算（`CircuitSolver._solve` 第 441−448 行）：

```js
const imFullEq = inductionMotorDevs.filter(d => !d.simpleModel).length * 6;
```

## 四、相电流读取

### 4.1 从 MNA 解中直接提取

全模型的电流是 MNA 变量，求解后从结果向量中直接读取：

```js
// CircuitSolver._updateDeviceCurrents 第 1351−1360 行
const i_u  = results[dev._iUCol];
const i_v  = results[dev._iVCol];
const i_w  = results[dev._iWCol];
const i_ru = results[dev._iRUCol];
const i_rv = results[dev._iRVCol];
const i_rw = results[dev._iRWCol];
dev._postSolve(i_u, i_v, i_w, i_ru, i_rv, i_rw);
```

### 4.2 电流限幅

`_postSolve` 将每相电流钳位在 ±300 A：

```js
const IM_MAX = 300;
const clamp = (v) => Math.max(-IM_MAX, Math.min(IM_MAX, v));
this._iuPrev  = clamp(iu);
this._iruPrev = clamp(iru);
// ...
this.phaseCurrents = { u: iu, v: iv, w: iw };
```

### 4.3 与简化模型的区别

| 特性 | 全模型 | 简化模型 |
|:---|:---|:---|
| 电流来源 | MNA 求解变量（`results[colIdx]`） | 从端口电压回算 |
| 转子电流 | 直接求解 iᵣᵤ、iᵣᵥ、iᵣ_w | 无（等效为 R₂/s） |
| 精度 | 无近似，含转子动态 | 稳态等效电路近似 |

## 五、相序检测

与简化模型完全一致。见 `InductionMotor._updateDynamic`（第 605−617 行）。

### 5.1 检测原理

利用三相电压瞬时值的旋转方向判别：

```
seq = Vᵤ · (Vᵥ⁻ − V_w⁻) + Vᵥ · (V_w⁻ − Vᵤ⁻) + V_w · (Vᵤ⁻ − Vᵥ⁻)
```

其中 `V⁻` 为上帧电压瞬时值。

### 5.2 判断逻辑

```js
if (hasAllPhases) {          // |Vᵤ| > 15 && |Vᵥ| > 15 && |V_w| > 15
    this._phaseSeq = seq ≥ 0 ? 1 : −1;
} else if (!hasVoltage) {    // 三相均 < 15V
    this._phaseSeq = 0;
}
// 零交叉过渡态 → 保持上次值
```

### 5.3 相序的作用

```js
this._omega_sync = (2πf / p) · this._phaseSeq;

// 堵转保护：正序下不允许反转
if (this._phaseSeq > 0 && this._omega_m < 0) this._omega_m = 0;
```

## 六、电磁转矩计算

### 6.1 虚位移法

全模型的转矩基于**磁共能对机械角的虚位移**原理，而非稳态等效电路公式：

```
T_e = p · iₛᵀ · dLₛᵣ/dθᵣ · iᵣ
```

其中 `dLₛᵣ/dθᵣ` 为互感对电角度的导数：

```
dLₛᵣ/dθᵣ = Lₘ · d/dθᵣ [cos矩阵]
```

### 6.2 导数矩阵

```
dLₛᵣ/dθᵣ =
  ┌                                                          ┐
  │ −Lₘ·sin(θᵣ)  −Lₘ·sin(θᵣ−120°)  −Lₘ·sin(θᵣ+120°) │
  │ −Lₘ·sin(θᵣ+120°)  −Lₘ·sin(θᵣ)  −Lₘ·sin(θᵣ−120°) │
  │ −Lₘ·sin(θᵣ−120°)  −Lₘ·sin(θᵣ+120°)  −Lₘ·sin(θᵣ) │
  └                                                          ┘
```

### 6.3 转矩计算代码

```js
// CircuitSolver._updateDeviceCurrents 第 1362−1372 行
const si     = Math.sin(theta_r);
const si120  = Math.sin(theta_r − 120°);
const siM120 = Math.sin(theta_r + 120°);

const te = p · Lₘ · (
    i_u  · (−si · i_ru − si120 · i_rv − siM120 · i_rw) +
    i_v  · (−siM120 · i_ru − si · i_rv − si120 · i_rw) +
    i_w  · (−si120 · i_ru − siM120 · i_rv − si · i_rw)
);
dev._setTorque(te);
```

### 6.4 与简化模型转矩对比

| 特性 | 全模型 | 简化模型 |
|:---|:---|:---|
| 公式 | `T_e = p · iₛᵀ · dLₛᵣ/dθ · iᵣ` | `T_e = 3·V²·R₂/s / (ω_sync·Z²)` |
| 转子动态 | 含（iᵣ 每帧求解） | 无（由 s 瞬时决定） |
| 谐波响应 | 准确 | 近似（基波等效） |
| 集肤效应 | 无（需额外 R₂ 修正） | 有（|s|>1.2 放大因子） |
| 缺相起动 | 自动包含（缺相时 iᵣ 自然为 0） | 需额外逻辑强制 Te=0 |

### 6.5 转矩限幅

与简化模型一致，若 `dev._T_max` 已由 `_computeTorqueSpecs` 预计算：

```
te = clamp(te, −1.2·T_max, 1.2·T_max)
```

## 七、机电耦合（`_preSolve`）

每帧先于电路求解执行，欧拉法积分：

```js
α = (T_e − T_load − B · ω_m) / J
ω_m += α · dt
θ_m += ω_m · dt
θ_r = p · θ_m
```

**关键点**：

1. **θᵣ 在 stamp 中延迟一帧生效**：当前帧 stamp 使用 `θᵣ_prev`（上帧角度）构建耦合矩阵的历史项，当前帧 θᵣ 在下一次 stamp 中才被使用。这符合后向欧拉离散的一致性原则。

2. **负载转矩**：
   - 恒转矩：`T_load = loadTorque · sign(ω_m)`
   - 风机型：`T_load = fanK · ω_m · |ω_m|`

3. **直流能耗制动**：检测 `dc24v_wire_p→im01_wire_u1` 和 `dc24v_wire_n→im01_wire_v1` 连接且 `DC24V.isOn && !AC.isOn`：
   ```js
   brakeT = ω_m;
   ```

4. **堵转保持**：`|ω_m| < 0.5` 时若 `loadTorque > |T_e|` 则 ω_m = 0。

5. **转差率计算**：
   ```js
   slip = (ω_sync − ω_m) / ω_sync
   if (|slip| < 0.0001) slip = sign(slip) · 0.0001
   ```

## 八、系统频率检测

`CircuitSolver._solve` 第 251−260 行从活跃的三相电源获取系统频率：

```js
this._systemFreq = 50;
for (const src of power3Devs) {
    if (src.isOn) { this._systemFreq = src.freq || 50; break; }
}
```

该频率通过 `ctx.systemFreq` 传递给 `DeviceStamps`，用于：

- 剩磁注入时计算 `ω_sync`
- `_preSolve` 中更新 `ω_sync`
- `_computeTorqueSpecs` 中计算漏抗和额定参数

## 九、与简化模型的对比总结

| 特性 | 全模型（6 变量） | 简化模型（诺顿等效） |
|:---|:---|:---|
| 理论依据 | 三相瞬态 dq 变换等效 | 稳态 T 型等效电路 |
| 方程数 | 每台 +6 | 不变 |
| 电流获取 | 直接读 MNA 解 | 回算 |
| 转子动态 | 精确（Lᵣᵣ - R₂） | 近似（R₂/s） |
| 转矩公式 | 虚位移 `p·iᵀ·dL/dθ·iᵣ` | 稳态公式 `3V²R₂/s / (ωZ²)` |
| 角度相关 | 是（Lₛᵣ 随 θᵣ 变化） | 否 |
| 剩磁自励 | 转子方程注入 | 断路时电流源注入 |
| 收敛性 | 大 Δt 易发散 | 较稳定 |
| 适用场景 | 瞬态、谐波、PWM、V/f 变频起动 | 稳态运行、教学演示 |
