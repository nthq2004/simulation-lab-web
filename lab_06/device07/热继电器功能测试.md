# 热继电器功能测试

## 1. 热继电器的结构和工作原理

### 1.1 概述

热继电器（Thermal Overload Relay，简称热继）是一种利用电流热效应原理工作的过载保护电器。它主要用于电动机的长期过载保护，具有反时限特性——过载倍数越大，动作时间越短。

本仿真工程完整模拟了一台三相热继电器的内部结构和电气特性，包含双金属片热弯曲、挡板-推杆机械传动、触点切换等核心机构。

### 1.2 物理结构

热继电器由以下主要部件组成（从左到右排列）：

| 部件 | 功能 | 仿真实现 |
|------|------|----------|
| **热元件**（3 相） | 每相一个 0.01Ω 小电阻，串联在主电路中，流过电流时产生焦耳热 | `DeviceStamps.stampThermalRelays()` 注入 MNA 矩阵 |
| **双金属片**（3 片） | 两种热膨胀系数不同的金属片复合而成，受热后向低膨胀层一侧弯曲 | `_createBimetals()` 绘制，`_poleBend[i]` 控制弯曲量 |
| **加热线圈** | 缠绕在双金属片上的电阻丝，通电后加热双金属片 | 10 匝斜绕铜色线，奇数匝可见 |
| **挡板 + 挡片** | 双金属片弯曲时推动挡板，挡片将位移传给推杆 | `_getDeflectorDx()` 计算位移量 |
| **推杆 + 曲柄连杆** | 将挡板的水平位移传递到右侧触点机构 | `_pushRod` + `_linkLine` 动态绘制 |
| **触点臂** | 绕支点旋转的刚性臂，正常 0°，跳脱约 20° | `_armGroup.rotation()` 控制 |
| **NC 触头**（95-96） | 常闭触头，正常闭合，跳脱断开 | `internalUnion` 并查集实现 |
| **NO 触头**（97-98） | 常开触头，正常断开，跳脱闭合 | `internalUnion` 并查集实现 |
| **整定旋钮** | 调节整定电流值，带刻度盘和红色指针 | `_createKnobPointer()` 绘制 |
| **RESET 按钮** | 红色按钮，跳脱后手动复位 | `reset()` 方法 + 虚线联动 |
| **TEST 按钮** | 蓝色按钮，按下模拟机械脱扣测试 | `_testPressed` 状态 |
| **TRIP 指示灯** | 红色 LED，跳脱后点亮 | `_tripLed` 呼吸动画 |

### 1.3 机械传动路径

```
双金属片受热弯曲
       ↓
挡板水平右移（位移量 = bendRatio × bmsMaxBend）
       ↓
挡片推动推杆右移
       ↓
曲柄连杆传递位移到支点
       ↓
触点臂绕支点旋转（~20°）
       ↓
NC 断开 / NO 闭合
```

### 1.4 工作原理（电气-热-机械耦合）

1. **电气检测**：每相主电路串联 0.01Ω 小电阻，`CircuitSolver` 通过 MNA 求解节点电压差，计算每相瞬时电流
2. **RMS 计算**：40 点滑动窗口（20fps × 2 秒），每相独立平方和 → 开方 → `_iRms[i]`
3. **热积累**：`_poleLoadRatio[i] = _iRms[i] / ratedCurrent`，根据负载比查表得到 tripRate/bendRate，逐相独立累加 `_poleHeat[i]`
4. **机械弯曲**：`_poleBend[i]` 控制双金属片自由端偏移量，偏移量= `_poleBend[i] × _bmsMaxBend`
5. **状态切换**：`_heatLevel ≥ 1.0` → 跳脱，NC 断开、NO 闭合

### 1.5 反时限特性

过载倍数（负载比）与动作时间的关系：

| 负载比 r | 升温速率 tripRate | 大致动作时间（从冷态） |
|----------|------------------|----------------------|
| r ≤ 1.0 | -0.4（冷却） | 不动作 |
| 1.0~1.1 | 0.001~0.026/s | 40~1000 秒 |
| 1.1~1.2 | 0.026~0.05/s | 20~40 秒 |
| 1.2~1.5 | 0.05~0.2/s | 5~20 秒 |
| ≥ 1.5 | 0.2/s | ~5 秒 |

## 2. 热继电器的功能测试

### 2.1 仿真环境准备

本工程对应的操作项目为"过载保护操作"，工作流 ID：`overload-test`。

**组件布局**：

| 组件 | ID | 位置 | 初始参数 |
|------|----|------|----------|
| 三相电源 | `ac` | (100, 60) | vRms=50V, 50Hz, isOn=true |
| 热继电器 | `fr` | (100, 300) | ratedCurrent=10A, tripClass=10 |
| 负载电阻 R1 | `r1` | (160, 810) | 10Ω, 星形连接 |
| 负载电阻 R2 | `r2` | (260, 810) | 10Ω, 星形连接 |
| 负载电阻 R3 | `r3` | (360, 810) | 10Ω, 星形连接 |

**主电路接线**：

```
ACPower3P(U/V/W) ──→ fr(L1/L2/L3) ──→ fr(T1/T2/T3) ──→ R1/R2/R3(10Ω/星形)
```

### 2.2 正常状态观察

电源电压 50V，相电流 = 50V / 10Ω = 5A，负载比 = 5A / 10A = 0.5 倍。

- 双金属片微弯（约 0.5 × 0.85 = 0.425 比例）
- 推杆轻微右移，挡板基本居中
- 触点臂垂直（~0°），NC 闭合，NO 断开
- 底部状态显示：`● 运行 50%`
- TRIP 指示灯不亮

### 2.3 过载跳脱测试

**操作**：调节三相电源输出电压到 135V（过载系数 ≈ 1.35 倍）

**预期现象**：

1. **升温阶段**（0~8 秒）：相电流 = 135V / 10Ω = 13.5A，负载比 = 1.35
2. 双金属片逐渐弯曲，挡板和推杆匀速右移
3. 触点臂随 `_heatLevel` 缓慢旋转（`armAngleCur = heatLevel × 20°`）
4. NC 触头逐渐分离（出现橙色间隙光晕）
5. 底部状态：`▲ 升温中 XX%`
6. **跳脱时刻**（~8 秒）：
   - `_heatLevel ≥ 1.0`，状态切换为 `tripped`
   - TRIP 指示灯亮红色
   - 推杆推至最右端
   - 触点臂完全旋转至 20°
   - NC 完全断开（万用表测 95-96 显示 O.L）
   - NO 闭合
   - 底部状态：`⚡ 过载跳脱`

### 2.4 电流整定（刻度中心线调整）

**操作**：打开热继电器配置对话框，修改"刻度中心线值"参数。

**效果**：
- 刻度盘所有标签按新中心值重新计算（范围：中心值 × 0.5 ~ 中心值 × 1.5）
- 数字输入框的 min/max/step 自动适配（step = center × 0.05）
- 整定指针重新指向中心（12 点钟方向）
- `_defaultRated` 更新，过载检测使用新整定值

**示例**：默认刻度中心线 = 10A
- 标签：5.0 / 7.5 / 10.0 / 12.5 / 15.0
- 数字输入 step = 0.5

**示例**：修改为 8A
- 标签：4.0 / 6.0 / 8.0 / 10.0 / 12.0
- 数字输入 step = 0.4
- 旋钮指针重新指向 12 点钟

### 2.5 复位操作

**前提条件**：热继电器处于 `tripped` 状态。

**操作 1 —— 热态锁定**：
如果跳脱后双金属片仍处于高温状态（`_getMaxActiveBend() > 0.3`），按下 RESET 按钮无效。需要等待双金属片冷却（散热速率 0.4/s，约需 1.75 秒）。

**操作 2 —— 正常复位**：
双金属片冷却后（`bendRatio < 0.3`），按下 RESET 按钮：
- 启动 1 秒 `easeOutSine` 缓出动画
- 双金属片回直（`poleBend` → 0）
- 推杆/挡板归零
- 触点臂旋转回 0°，NC 重新闭合，NO 断开
- TRIP 指示灯熄灭
- 状态：`○ 空载`
- 操作计数 +1

### 2.6 TEST 按钮测试

**操作**：按住蓝色 TEST 按钮（位于左侧推杆上方）

**效果**（机械模拟，不影响热状态）：
- 推杆直接右移至满行程（`_testPushDx = bmsMaxBend`）
- 触点臂旋转至跳脱角度（20°）
- NC 断开、NO 闭合
- TRIP 指示灯保持原状态（TEST 不触发 TRIP 灯）

**释放 TEST**：
- 推杆弹回原位
- 触点臂恢复
- NC 重新闭合

> **注意**：TEST 按钮与过载跳脱的区别：TEST 只推动机械机构，不影响双金属片的热状态，不会累加操作计数。

## 3. 热继电器用万用表测试

### 3.1 万用表档位设置

本工程使用数字万用表（Multimeter），电阻测量采用恒流源法（R = V / I）：

| 档位 | 量程 | 恒流源 | 分辨率 |
|------|------|--------|--------|
| 200Ω | 0~200Ω | 1 mA | 0.01Ω |
| 2kΩ | 0~2kΩ | 100 μA | 0.001kΩ |
| 200kΩ | 0~200kΩ | 1 μA | 0.1kΩ |

### 3.2 测量热元件电阻（第 1 步）

**接线**：
- 红表笔（VΩ 插孔）→ 热继电器 L1 端子
- 黑表笔（COM 插孔）→ 热继电器 T1 端子

**档位**：200Ω

**预期结果**：约 0.01Ω

**原理**：发热元件是串联在主电路中的一个 0.01Ω 小电阻（`_phaseResistance`）。万用表内部 1mA 恒流源经 VΩ → L1 → 0.01Ω → T1 → COM 形成回路，测得电压 V = 0.001A × 0.01Ω = 10μV → 显示 0.01Ω。

### 3.3 测量常闭触头电阻（第 2 步）

**接线**：
- 红表笔 → 热继电器 NC 端子 95（`fr_wire_nc_a`）
- 黑表笔 → 热继电器 NC 端子 96（`fr_wire_nc_b`）

**档位**：200Ω

**预期结果**：0Ω（闭合）

**原理**：热继电器正常状态下，NC 触头通过 `internalUnion` 在电路拓扑中等效短接。万用表 1mA 恒流源经 VΩ → 95 → 闭合触点 → 96 → COM，形成低阻回路。

### 3.4 测量跳脱后的 NC 触头（第 3 步）

**操作**：保持万用表接线在 NC 触头两端，同时接通主电路（三相电源 → 热继电器 → 负载），调节电压到 135V，等待热继电器跳脱。

**预期结果**：万用表显示 **O.L**（溢出）

**原理**：跳脱后 NC 断开，VΩ 和 COM 之间开路。万用表内部 1mA 恒流源无法形成回路，端子电压上升至超过 0.2V 阈值 → 触发 O.L 显示（电阻无穷大）。

### 3.5 测量要点

| 测量对象 | 万用表模式 | 探针连接 | 预期值 | 说明 |
|----------|-----------|----------|--------|------|
| 发热元件（A 相） | 200Ω | VΩ→L1, COM→T1 | ~0.01Ω | 检测热元件是否完好 |
| 发热元件（B 相） | 200Ω | VΩ→L2, COM→T2 | ~0.01Ω | 检测热元件是否完好 |
| 发热元件（C 相） | 200Ω | VΩ→L3, COM→T3 | ~0.01Ω | 检测热元件是否完好 |
| NC 触头（正常） | 200Ω | VΩ→95, COM→96 | ~0Ω | 检测常闭触点通断 |
| NC 触头（跳脱） | 200Ω | VΩ→95, COM→96 | O.L | 确认触点已可靠断开 |
| NO 触头（正常） | 200Ω | VΩ→97, COM→98 | O.L | 正常应为断开 |
| NO 触头（跳脱） | 200Ω | VΩ→97, COM→98 | ~0Ω | 跳脱后闭合 |

## 4. 热继电器的应用

### 4.1 典型应用场景

#### 电动机过载保护

热继电器最广泛的应用是与交流接触器配合，构成电动机磁力起动器：

```
三相电源 → 断路器 → 接触器主触点 → 热继电器 → 电动机
                                ↑
                    控制回路：起动/停止按钮 → 接触器线圈
                                       ↑
                              热继电器 NC 触头（95-96）
```

当电动机长期过载时，热继电器双金属片弯曲，推动机械机构使 NC 触头（95-96）断开，切断接触器线圈电源，接触器主触点释放，电动机停机。

#### 过载与短路的区别

| 故障类型 | 保护器件 | 特点 |
|----------|----------|------|
| 过载 | 热继电器 | 电流 1.0~8 倍额定值，反时限特性，允许短暂过载 |
| 短路 | 熔断器/断路器 | 电流数十倍额定值，要求瞬时切断 |

热继电器不能代替短路保护。短路电流会产生巨大冲击力，可能损坏热继电器的双金属片和机械机构。

### 4.2 仿真工程中的典型电路

本工程模拟了一个简化的过载保护系统：

```
三相电源（ACPower3P）
    │ U/V/W
    ↓
热继电器主电路（L1/L2/L3 → T1/T2/T3）
    │ T1/T2/T3
    ↓
星形负载（R1/R2/R3 = 10Ω，中性点短接）
```

控制回路（NC 触头 95-96）在跳脱时断开，切断控制信号。在此仿真中，NC 变化通过 `CircuitTopology` 的 `internalUnion` 实现，可被万用表检测。

### 4.3 热元件数目选择

| 极数 | 适用场景 | 仿真配置 |
|------|----------|----------|
| **1 极** | 单相过载保护 | `poles: 1`，仅中间相有双金属片 |
| **2 极** | 两相保护（如两相运行的设备） | `poles: 2`，两侧相有双金属片 |
| **3 极** | 三相电动机标准保护 | `poles: 3`，三相全部有双金属片 |

### 4.4 脱扣等级选择

脱扣等级（tripClass）决定了在 7.2 倍额定电流下的最大动作时间。本仿真使用 10 级（标准电动机保护），对应 7.2× 时动作时间 ≤ 10 秒。

### 4.5 整定电流设置原则

整定电流（刻度中心线值）应等于电动机的额定电流。选择公式：

```
整定电流 = 电动机额定电流 × 0.95~1.05
```

示例：10kW / 380V 电动机，额定电流约 19A → 整定电流选 18~20A。

## 5. 热继电器常见故障处理

### 5.1 故障分类与检查方法

| 故障现象 | 可能原因 | 检查方法 |
|----------|----------|----------|
| 电动机频繁停机 | 整定电流过小 | 用钳形电流表测量实际电流，与整定值对比 |
| 过载不跳脱 | 双金属片失效 / 机械卡涩 | 万用表 200Ω 档测量热元件电阻（应 ~0.01Ω） |
| NC 触头不通 | 触头烧蚀 / 已跳脱未复位 | 万用表测 95-96，正常闭合应为 0Ω |
| 缺相不动作 | 仅部分相有热元件 | 逐相检测各相电流和热元件电阻 |
| 复位后仍跳脱 | 双金属片未冷却（热态锁定） | 等待 2~3 秒后再按 RESET |

### 5.2 热态锁定

**现象**：跳脱后立即按下 RESET 按钮，复位无效。

**原理**：双金属片在跳脱后仍处于高温状态（`poleHeat ≈ 1.0`），弯曲量超过阈值（`bendRatio > 0.3`）。复位被锁定，需等待双金属片冷却。

**冷却时间计算**：

```
散热速率 = 0.4 / 秒
从 bendRatio = 1.0 冷却到 0.3：
  需要时间 = (1.0 - 0.3) / 0.4 ≈ 1.75 秒
```

在实际操作中，建议断开电源后等待 **2~3 秒**再按 RESET。

### 5.3 缺相检测

**现象**：三相电源中某一相断开，但热继电器仍可能不跳脱或延迟跳脱。

**仿真验证**：
1. 正常状态（三相平衡，负载 = 0.5 倍）→ 无过载
2. 断开 W 相（仅 U、V 两相通电）→ 每相电流不变，无过载信号
3. 若某相负载过大（如缺相导致其余相电流增大）→ 相应相单独累积热量

**结论**：热继电器主要提供过载保护，对缺相故障的响应取决于缺相后剩余相的电流是否超过整定值。

### 5.4 万用表检测故障流程

```
[故障现象] 电动机过热停机，热继电器已跳脱
                     ↓
  1. 检测热元件是否完好
     万用表 200Ω → L1-T1 / L2-T2 / L3-T3
     预期：~0.01Ω / 若 O.L → 热元件烧断
                     ↓
  2. 检测 NC 触头状态
     万用表 200Ω → 95-96
     正常闭合：~0Ω
     跳脱/故障：O.L
                     ↓
  3. 检查整定值
     查看热继电器面板刻度，确认整定值与电动机匹配
                     ↓
  4. 检查 RESET 功能
     等待冷却后按 RESET，确认复位动作
     若无法复位：检查机械机构是否卡涩
```

### 5.5 仿真常见问题排查

| 问题 | 检查项 |
|------|--------|
| 万用表显示 0 或无变化 | 检查档位是否为 `200Ω`，探针是否插紧 |
| 热继电器长时间不跳脱 | 检查负载比是否 > 1.0（电压是否 > 100V） |
| RESET 无效 | 检查是否为 `tripped` 状态，是否还在冷却锁定中 |
| 连线后无电流 | 检查电源是否 `isOn=true`，连线是否完整 |
| 刻度标签不更新 | 确认 `getConfigFields()` 返回的 `_defaultRated` 已更新 |
| TEST 按钮无反应 | 检查鼠标事件是否被其他图层遮挡（`_interactGroup` 在最上层） |
