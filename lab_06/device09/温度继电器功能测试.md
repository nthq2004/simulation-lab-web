# 温度继电器功能测试 

---

## 一、压力式温度继电器的结构和工作原理

### 1.1 概述

本仿真平台中的 **WT1226 温度继电器**（型号 WTZK-50-C）属于**压力式温度继电器**，又称为**充注式温度控制器**。它利用感温包内工质的压力随温度变化的物理特性，通过毛细管-波纹管-杠杆机构驱动微动开关，实现双位（滞回）通断控制。此类继电器广泛应用于工业制冷、暖通空调、冷库、烘干设备等温度控制场景。

### 1.2 核心部件结构

| 部件 | 功能 |
|------|------|
| **感温包（Bulb）** | 内部充注感温工质（气体或液体），安装在被控温度场中。温度升高时工质膨胀，温度降低时工质收缩。 |
| **毛细管（Capillary Tube）** | 连接感温包与波纹管的细长铜管，将感温包内的压力变化传递至波纹管，无相变损失。 |
| **波纹管（Bellows）** | 弹性金属波纹管，内部压力变化使其产生伸缩位移（Δy ∝ ΔP）。 |
| **传动杆（Connecting Rod）** | 连接波纹管顶部与杠杆右端的刚性连杆，将波纹管的位移传递给杠杆。 |
| **主杠杆（Lever Bar）** | 核心力臂，绕支点（Pivot）旋转，将波纹管位移放大后作用于弹性片。 |
| **主弹簧（设定弹簧）** | 连接设定螺钉与杠杆左端，提供弹性反力，决定温度设定值（下限）。 |
| **设定螺钉（Set Screw）** | 调节主弹簧预紧力，改变温度动作下限（lowSet）。 |
| **幅差弹簧（Diff Spring）** | 提供切换差（滞回带宽度）的弹性力，决定动作上限与下限之差。 |
| **幅差调节螺钉（Diff Screw）** | 调节幅差弹簧预紧力，改变切换差（highSet − lowSet）。 |
| **弹性片（Elastic Plate）** | 与杠杆联动，累积弹性势能后通过跳簧实现触点的快速跳变。 |
| **跳簧（Toggle Spring）** | 二次贝塞尔曲线模拟的快速跳变机构，提供触点切换的瞬时动作力，防止触点缓慢接触产生电弧。 |
| **触点系统（NC / NO / COM）** | 微动开关的三个接线端：NC（常闭）、NO（常开）、COM（公共端）。 |

### 1.3 工作原理

**信号传递链：**

```
温度变化（外部输入）
    ↓
感温包内工质压力变化（P ∝ T）
    ↓
毛细管传递压力
    ↓
波纹管顶部位移（Δy ∝ ΔP）
    ↓
传动杆 → 杠杆绕支点旋转
    ↓
弹性片联动 → 跳簧快速跳变
    ↓
动触点摆向 NC 或 NO
    ↓
电路通断状态改变
```

**关键公式：**

- **温度 → 模拟压力**（归一化）：`pressureSim = (T − tempMin) / (tempMax − tempMin)`，线性映射到 [0, 1]
- **波纹管压缩量**：`bScaleY = 2.0 − pressureSim × 0.8`，温度最低时波纹管最长（伸展），最高时最短（压缩）
- **感温包膨胀量**：`bulbScale = 0.8 + pressureSim × 0.4`，与波纹管反向同步动作
- **杠杆旋转角**：`forceEffect = (pressureSim − 0.5) × 8`，限制在 ±10°

### 1.4 触点状态与温度的关系

| 温度条件 | `isEnergized` | 触点连接 | 色彩指示 |
|----------|:------------:|---------|---------|
| T < lowSet（低于下限） | **true**（得电） | **COM ↔ NC** 导通 | 绿色高亮 |
| lowSet ≤ T ≤ highSet | 保持之前状态 | 不变（滞回区） | 不变 |
| T > highSet（高于上限） | **false**（失电） | **COM ↔ NO** 导通 | 红色高亮 |

**滞回特性**：温度在 lowSet 和 highSet 之间变化时，继电器状态保持不变，形成一个"死区"（滞回带）。这是防止继电器在设定点附近因微小温度波动而频繁通断的关键设计。

### 1.5 模拟仿真中的视觉呈现

- **设定值调节**：点击绿色螺钉，上半部分增大设定值（lowSet 升高），下半部分减小
- **幅差调节**：点击墨绿色螺钉，右半增大幅差（滞回带变宽），左半减小
- **红色指针**：在刻度盘上指示当前设定值位置
- **幅差刻度盘**：显示 0~10 档的当前幅差值
- **毛细管三圈绕线**：感温包右上角至波纹管底部之间，铜色多圈曲线
- **状态色彩**：绿色表示 COM-NC 导通（得电态），红色表示 COM-NO 导通（失电态）

## 二、PT100 电子式温度继电器的结构和工作原理

### 2.1 概述

**PT100 铂电阻温度传感器**是利用铂金属的电阻随温度变化而变化的物理特性实现温度测量的传感器。与压力式温度继电器不同，**PT100 电子式温度继电器**采用电子电路测量 PT100 的电阻值，将其转换为电信号，经比较器或微处理器处理后驱动继电器输出。它具有精度高、响应快、便于远程传输和数字化处理等优点。

### 2.2 PT100 铂电阻传感器结构

本仿真平台提供了两种 PT100 组件：

**简化版（PT100.js）：**
- 探棒形状（尖端圆形、尾部扁平的不锈钢外壳）
- 内部封装铂电阻元件
- 两线制引出（左右各一个接线端口）

**实物风格版（RealPT100.js）：**
- 不锈钢探棒（前端圆角、金属质感渐变填充）
- 六角安装螺母与螺纹
- 柔性金属屏蔽线
- **三线制引出**：三根彩色引线（红色 L 线、蓝色 R 线、蓝色 T 补偿线），末端带冷压端子
- 支持 PT1000 扩展（通过 `r0` 参数配置）

### 2.3 PT100 测温原理

铂电阻的阻值与温度之间存在近似的线性关系。本仿真使用经验系数：

```
R = R₀ + α × T
```

其中：
- **R₀** = 100Ω（PT100 在 0°C 时的标称阻值；PT1000 为 1000Ω）
- **α** = 0.3851 Ω/°C（项目使用的经验温度系数）
- **T** = 被测温度（°C）

典型阻值对应关系：

| 温度（°C） | PT100 阻值（Ω） |
|:---------:|:--------------:|
| −50 | 80.75 |
| 0 | 100.00 |
| 50 | 119.26 |
| 100 | 138.51 |
| 200 | 177.02 |

### 2.4 三线制接法

RealPT100 采用**三线制**连接方式，这是工业中消除引线电阻影响的常用方法：

- **L 线（Line）**：红色，信号正极
- **R 线（Return）**：蓝色，信号负极
- **T 线（Third/Compensation）**：蓝色，补偿线

三线制的原理：在 PT100 的 R 端和 T 端之间并联接入，通过电路测量两端的电压差来消除引线电阻引入的测量误差。

### 2.5 故障模拟

PT100 组件支持两种故障模式：

| 故障类型 | 阻值变化 | 模拟方法 |
|---------|---------|---------|
| **开路（Open）** | R → 1e9Ω（极大值） | 传感器断路，检测电路读到极高阻值 |
| **短路（Short）** | R → 0.01Ω（近似 0） | 传感器短路，检测电路读到接近零阻值 |

双击组件可清除故障标志，恢复正常测量。

### 2.6 电子式温度继电器的完整系统

在工业应用中，PT100 电子式温度继电器的典型系统架构为：

```
PT100 传感器 → 温度变送器 → 比较器/微处理器 → 继电器输出
```

1. **PT100** 检测温度，输出对应的电阻值
2. **温度变送器** 将电阻信号转换为标准电信号（4~20mA 或 0~10V），或直接通过 ADC 采样
3. **比较器/微处理器** 进行滞回比较逻辑：
   - T > highSet → 继电器断开（或闭合，取决于接线方式）
   - T < lowSet → 继电器复位
4. **继电器输出** 驱动外部负载（如接触器、电磁阀、压缩机等）

**电子式与压力式的对比：**

| 特性 | 压力式（WT1226） | 电子式（PT100+继电器） |
|------|:--------------:|:-------------------:|
| 感温元件 | 充注工质的感温包 | 铂电阻元件 |
| 信号传递 | 毛细管机械压力传递 | 电信号传输 |
| 调节方式 | 螺钉机械调节 | 电位器/数字设定 |
| 精度 | 较低（±2~3°C） | 较高（±0.1~0.5°C） |
| 响应速度 | 较慢（热惯性大） | 较快 |
| 远程能力 | 受限于毛细管长度 | 可长距离传输 |
| 适用场景 | 制冷、空调等传统工业 | 精密温控、工业自动化 |

## 三、温度继电器上下限的测试和整定过程

### 3.1 初始参数

WT1226 温度继电器的默认参数（本仿真项目）：

| 参数 | 值 | 含义 |
|------|:--:|------|
| 全量程 | −40°C ~ +40°C | 温度刻度范围 |
| 设定值（setPoint） | 50% | 决定低动作点在量程中的百分比位置 |
| 幅差（differential） | 50% | 决定切换差在 1~6°C 中的百分比位置 |

**计算结果：**

```
低动作点 lowSet  = −40 + 80 × (50/100) = 0°C
高动作点 highSet = 0 + 1 + 5 × (50/100) = 3.5°C
```

即：温度低于 0°C 时 COM-NC 导通（得电），温度高于 3.5°C 时 COM-NO 导通（失电），0°C ~ 3.5°C 为滞回区。

### 3.2 测试流程（7 步）

#### 步骤 1：查看当前设定并打开温控器测试开关

打开工具栏上的**温控器测试**开关，弹出温度滑块。通过参数配置对话框查看当前 lowSet = 0°C、highSet = 3.5°C。

#### 步骤 2：测试高于上限

将滑块拖动至 **> 3.5°C**（如 5°C），观察：
- 温控器状态切换为 **失电**（NO 导通，NC 断开）
- 触点色彩变为**红色**
- 动触点摆向 NO 侧

#### 步骤 3：测试低于下限

将滑块拖动至 **< 0°C**（如 −5°C），观察：
- 温控器状态切换为 **得电**（NC 导通，NO 断开）
- 触点色彩变为**绿色**
- 动触点摆向 NC 侧

#### 步骤 4：整定下限值到 −8°C

点击设定螺钉（绿色），将 `setPoint` 调节至 40%：

```
lowSet = −40 + 80 × (40/100) = −8°C
```

**视觉反馈**：设定螺钉上下移动、主弹簧伸缩、刻度盘红色指针指示新位置。

#### 步骤 5：整定幅差为 3°C

点击幅差调节螺钉（墨绿色），将 `differential` 调节至 40%，使得切换差为 3°C：

```
highSet = −8 + 1 + 5 × (40/100) = −5°C
```

**视觉反馈**：幅差螺钉移动、幅差弹簧伸缩、幅差刻度盘数字滚动高亮。

此时温度为 −8°C ~ −5°C 之间为滞回区。

#### 步骤 6：自动双位控制演示

将 WT1226 的 NO 和 COM 端口分别连接至冷却系统（CoolingSys）的控制端 L 和 R，将控制模式开关拨至 REMOTE，观察自动控制过程：

```
温度上升至 −5°C → 温控器失电 → NO-COM 断开 → 制冷停止
     ↓                                              |
温度下降至 −8°C ← 温控器得电 ← NC-COM 导通 ← 制冷开始
     ↓                                              |
                    ← 重复循环 →
```

温度始终保持在 **−8°C ~ −5°C** 区间内振荡。

#### 步骤 7：测验

完成选择题测试，巩固滞回控制的核心理念。

### 3.3 整定要点

| 操作 | 方法 | 影响 |
|------|------|------|
| 增大设定值 | 点击设定螺钉上半部分（`setPoint += 2`） | lowSet 升高，highSet 随动升高 |
| 减小设定值 | 点击设定螺钉下半部分（`setPoint -= 2`） | lowSet 降低，highSet 随动降低 |
| 增大幅差 | 点击幅差螺钉右半部分（`differential += 2`） | 滞回带变宽，highSet 升高 |
| 减小幅差 | 点击幅差螺钉左半部分（`differential -= 2`） | 滞回带变窄，highSet 降低 |

## 四、温度双位控制原理

### 4.1 基本概念

**双位控制（Two‑Position Control）** 是最简单的反馈控制方式，控制器的输出只有两个状态——"开"或"关"（ON/OFF）。在温度控制中，即：

- **温度超过上限** → 关闭制冷设备（或开启加热设备）
- **温度低于下限** → 开启制冷设备（或关闭加热设备）
- **温度在上下限之间** → 保持之前状态（滞回区，防止频繁切换）

### 4.2 本仿真的双位控制回路

仿真平台中的完整双位控制回路由以下组件构成：

```
┌─────────────────────────────────────────────────────────────┐
│                    双位温度控制回路                            │
│                                                              │
│  ┌────────────────────────────────────────────────────┐      │
│  │               WT1226 温度继电器                       │     │
│  │  输入：温度值         输出：isEnergized 状态          │     │
│  │                                                      │     │
│  │  T < lowSet  → isEnergized = true  → COM-NC 导通    │     │
│  │  T > highSet → isEnergized = false → COM-NO 导通    │     │
│  │  lowSet ≤ T ≤ highSet → 保持原状态（滞回区）          │     │
│  └───────────────┬──────────────────────────┬──────────┘      │
│                  │ NO/COM 接线              │ 温度输入         │
│                  ▼                          ▼                  │
│  ┌──────────────────────────┐   ┌──────────────────────┐      │
│  │     CoolingSys 制冷系统    │   │  温度场/滑块输入       │      │
│  │                          │   │                      │      │
│  │  接通 → 压缩机运行        │   │  手动：滑块控制温度    │      │
│  │       → 温度以 0.2°C/tick│   │  自动：CoolingSys     │      │
│  │         下降             │   │       内部温度变化     │      │
│  │  断开 → 压缩机停止        │   │                      │      │
│  │       → 温度以 0.1°C/tick│   │                      │      │
│  │         上升             │   │                      │      │
│  └──────────────────────────┘   └──────────────────────┘      │
└─────────────────────────────────────────────────────────────┘
```

### 4.3 控制逻辑的两种模式

#### 本地模式（LOCAL）

- 通过控制面板上的**起动/停止**按钮手动控制压缩机
- 与温度继电器无关，用于独立测试制冷系统

#### 远程模式（REMOTE）

- 模式旋钮旋转至 REM 位置
- 压缩机运行状态由外部连线控制：
  - `wt_wire_NO` ↔ `cs_wire_l`（控制端 L）
  - `wt_wire_COM` ↔ `cs_wire_r`（控制端 R）
- 当电路导通时（NO-COM 连通），制冷系统启动
- 当电路断开时（NC-COM 连通），制冷系统停止

### 4.4 动态响应过程

**制冷系统温度变化规律：**

| 状态 | 温度变化 | 限制 |
|:----:|:-------:|:----:|
| 运行中（running） | −0.2°C/tick | 最低 −18°C |
| 停止中（stopped） | +0.1°C/tick | 最高 20°C |

**完整的自动控制循环（以整定后的参数为例）：**

```
初始温度 0°C
    ↓
NO-COM 导通 → 制冷系统运行 → 温度下降
    ↓
温度降至 −8°C（达到 lowSet）
    ↓
isEnergized = true → NC-COM 导通 → NO-COM 断开
    ↓
制冷系统停止 → 温度回升
    ↓
温度升至 −5°C（达到 highSet）
    ↓
isEnergized = false → NO-COM 导通 → NC-COM 断开
    ↓
制冷系统运行 → 温度下降
    ↓
                ← 循环 →
```

### 4.5 滞回带的作用

若没有滞回带（即 lowSet = highSet = 设定点），温度一旦达到设定点就会立即切换，由于系统惯性和测量噪声，会导致：

- **频繁通断**：继电器每分钟切换数十次
- **触点烧毁**：微动开关在负载电流下频繁通断产生电弧，加速触点损坏
- **压缩机损伤**：压缩机频繁启停，电机绕组过热，寿命缩短
- **温度波动加剧**：系统来不及响应就被迫切换

**滞回带的宽度**（切换差）应根据被控对象的特性和工艺要求来整定：
- **窄滞回**（如 0.5°C）：控温精度高，但切换频率也高，适用于精密控温
- **宽滞回**（如 3°C）：控温精度低，但切换频率低，适用于大惯性系统（如冷库、中央空调）

本仿真中的滞回带宽度由幅差旋钮调节，范围为 1°C ~ 6°C。

### 4.6 仿真中的教学意义

通过本仿真平台，学生可以直观地观察到：

1. **机械结构的可视化**：感温包膨胀/收缩、波纹管压缩/伸展、杠杆旋转、触点跳变等机械动作与温度变化实时联动
2. **设定点整定的影响**：调整设定螺钉和幅差螺钉后，lowSet 和 highSet 的实时变化及其对控制区间的直接影响
3. **滞回带的效果**：通过温度滑块缓慢扫过设定区间，观察继电器不会在临界点频繁抖动
4. **闭环控制全过程**：从温度检测→继电器判断→制冷控制→温度变化→再检测的完整闭环，理解反馈控制的基本原理
5. **教学模式切换**：支持自动演示（show）、单步教学（step）、学生演练（train）、评估考试（eval）四种模式
