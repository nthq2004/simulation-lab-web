# 铅酸蓄电池充电及测试

## 一、铅酸蓄电池的结构、重要概念和工作原理

### 1.1 基本结构

铅酸蓄电池由以下主要部件组成：

- **正极板（阳极）**：活性物质为二氧化铅（PbO₂），呈深棕色
- **负极板（阴极）**：活性物质为海绵状纯铅（Pb），呈深灰色
- **电解液**：稀硫酸溶液（H₂SO₄），浓度约 1.20～1.30（比重）
- **隔板**：用于隔离正负极板，防止短路，同时允许离子通过
- **电池壳**：容纳极板和电解液
- **极柱**：正负极引线出口

单格电池标称电压为 2V。常用的 12V 蓄电池由 6 个单格串联组成。

### 1.2 重要概念

| 概念 | 定义 |
|------|------|
| **容量（Ah）** | 电池在放电条件下能够输出的电荷量，通常以 20 小时放电率的安时数表示 |
| **比重（Specific Gravity）** | 电解液密度与 4℃ 纯水密度的比值，反映电解液硫酸浓度 |
| **SOC（State of Charge）** | 荷电状态，表示电池当前剩余电量占额定容量的百分比 |
| **开路电压（OCV）** | 电池未接负载时正负极之间的电压 |
| **内阻** | 电池内部对电流的阻碍，包括欧姆内阻和极化内阻 |
| **浮充电压** | 电池充满后维持满电状态的均衡充电电压 |

### 1.3 工作原理

铅酸蓄电池的工作原理基于可逆的化学反应：

**放电过程：**

- 正极：PbO₂ + H₂SO₄ + 2H⁺ + 2e⁻ → PbSO₄ + 2H₂O
- 负极：Pb + H₂SO₄ → PbSO₄ + 2H⁺ + 2e⁻
- 总反应：PbO₂ + Pb + 2H₂SO₄ → 2PbSO₄ + 2H₂O

**充电过程（上述反应逆向进行）：**

- 正极：PbSO₄ + 2H₂O → PbO₂ + H₂SO₄ + 2H⁺ + 2e⁻
- 负极：PbSO₄ + 2H⁺ + 2e⁻ → Pb + H₂SO₄

**关键规律：**

- 放电时正极和负极均生成 PbSO₄，电解液中的 H₂SO₄ 被消耗，比重下降
- 充电时 PbSO₄ 被还原为 Pb 和 PbO₂，H₂SO₄ 浓度恢复，比重上升
- 电解液比重与 SOC 呈近似线性关系：满电时约 1.28～1.30，亏电时约 1.10～1.15

## 二、蓄电池的充电方法

### 2.1 浮充（Float Charging）

浮充是最常用的维持充电方式。充电电压略高于电池开路电压，通常为 2.20～2.27V/单格（12V 电池约 13.2～13.6V）。

**特点：**
- 电池始终连接在充电电源上，持续接收微小充电电流
- 用于补偿自放电，保持电池始终处于满电状态
- 适用于不停电 UPS、通信基站等需要长期备用的场景
- 充电电流极小（通常为 C/100 到 C/200），不会引起过充

### 2.2 均充（Equalization Charging）

均充是在浮充基础上提高充电电压，使所有单体电池电压趋于一致的过程。通常充电电压提高到 2.35～2.40V/单格（12V 电池约 14.1～14.4V）。

**特点：**
- 用于纠正电池组中各单体电池之间的电压不均衡
- 定期进行（如每月一次），每次持续数小时
- 可能伴随少量电解液产气（水的电解），密封电池需注意通风
- 深度放电后的电池恢复也常使用均充

### 2.3 分段恒流充电（Segmented Constant Current Charging）

分段恒流充电将充电过程分为多个阶段，每个阶段采用不同的恒定电流：

1. **第一阶段（大电流恒流）**：以较大电流（如 C/3 或 C/5）充电，快速补充大部分电量，电压逐渐上升
2. **第二阶段（小电流恒流）**：当电压达到一定值后，切换为较小电流（如 C/10 或 C/20），避免过充
3. **第三阶段（涓流/稳压）**：电压达到终值后转为恒压或涓流充电，完成最后补充

**特点：**
- 充电效率高，充电时间适中
- 可根据电池状态灵活调整各段参数
- 常用于需要较快恢复电池容量的场景

### 2.4 过充电（Overcharging）

过充电指充电电压或充电时间超过电池允许的范围。

**危害：**
- 电解液剧烈分解，产生大量氢气和氧气，造成电解液干涸
- 正极板活性物质软化脱落，缩短电池寿命
- 电池温度急剧升高，可能引发热失控（尤其在密封电池中）
- 安全阀频繁开启，严重的可能导致电池鼓胀或爆裂

**仿真项目中的体现：**
- 本项目中过充电未被纳入正常流程，因为会加速电池老化
- 在实际操作中应避免过充电，充电完成时应及时停止或转为浮充

## 三、蓄电池状态的判断

### 3.1 用万用表测电压

使用数字式万用表直流电压档（DCV）测量电池开路电压，可以粗略判断电池 SOC：

| 开路电压（12V 单体） | 对应 SOC | 状态 |
|----------------------|---------|------|
| ≥ 12.60V | ≈ 100% | 完全充满 |
| 12.30～12.60V | 80～100% | 良好 |
| 12.00～12.30V | 60～80% | 中等 |
| 11.60～12.00V | 40～60% | 较低 |
| 11.20～11.60V | 20～40% | 亏电 |
| ≤ 11.20V | < 20% | 严重亏电 |

**注意事项：**
- 测量应在电池静置 2 小时以上（无负载、无充电）进行
- 负载状态下的电压会低于开路电压，测量值偏低
- 串联电池组应分别测量各单体，避免仅测总压而掩盖单体问题

### 3.2 用比重计测比重

比重计测量电解液比重是判断铅酸蓄电池 SOC 最直接、最准确的方法之一：

| 比重 | 对应 SOC（近似） | 状态 |
|------|----------------|------|
| 1.30 | ≈ 100% | 完全充满 |
| 1.28 | 90～100% | 良好 |
| 1.25 | 70～80% | 中等 |
| 1.20 | 50～60% | 较低 |
| 1.15 | 25～40% | 亏电 |
| ≤ 1.10 | < 25% | 严重亏电 |

**注意事项：**
- 测量时应从电池注液孔吸取电解液，避免从底部吸取沉淀物
- 比重计使用后应清洗干净，避免交叉污染
- 如果电池没有注液孔（密封电池），则无法使用比重计测量

### 3.3 电压与比重的对比判断

在实际测试中，电压和比重应结合使用、相互验证：

- **电压低 + 比重低** → 电池亏电（SOC 低）
- **电压低 + 比重正常** → 可能有单格短路或极板硫化
- **电压正常 + 比重低** → 电解液可能混入水分（稀释）
- **电压高 + 比重高** → 电池正常满电或刚过充

本仿真项目通过第 5、6 步分别测量电池的电压和比重，让学习者直观理解两者的变化规律。

## 四、铅酸蓄电池常见故障和维护保养

### 4.1 常见故障

1. **硫化（Sulfation）**
   - 表现：电池容量显著下降，内阻增大，充电时电压迅速上升
   - 原因：长期亏电存放、充电不足、硫酸铅晶体粗化
   - 预防：避免长期亏电，及时充足电

2. **极板软化（Paste Shedding）**
   - 表现：电池容量不可逆下降，电解液浑浊
   - 原因：过充电、大电流放电、高温运行、老化
   - 预防：避免过充和深度放电，控制充电电流和温度

3. **单格短路**
   - 表现：电池电压异常低（低于正常值很多），充电时该格电压不上升
   - 原因：隔板损坏、正负极板接触、活性物质脱落堆积
   - 处理：通常无法修复，需更换电池

4. **电解液干涸**
   - 表现：比重异常偏高，电池容量急剧下降
   - 原因：过充电失水、密封不良、气温过高
   - 预防：避免长时间过充，添加蒸馏水补充（富液式电池）

5. **自放电过快**
   - 表现：充满电的电池放置一段时间后电压明显下降
   - 原因：极板杂质、电解液不纯、内部微短路
   - 处理：更换电解液或更换电池

### 4.2 维护保养要点

1. **保持适当充电状态**：避免长期亏电存放，定期充电维护
2. **控制充电电压和电流**：按规范充电，避免过充和欠充
3. **监控电解液液位**（富液式电池）：液面应高出极板上缘 10～15mm，不足时添加蒸馏水
4. **保持清洁干燥**：清除极柱和表面的腐蚀物和电解液残渣
5. **控制温度**：避免高温环境（加速老化和失水），避免极低温（降低容量和充电效率）
6. **定期检测**：使用万用表和比重计定期检查电压和比重，及早发现异常
7. **均衡充电**：对电池组定期进行均充，确保各单体一致性
8. **使用专用充电器**：匹配的充电器充电曲线，避免使用不合适的充电设备

## 五、拓展：阀控式免维护蓄电池（VRLA/AGM）

### 5.1 基本原理

阀控式密封铅酸蓄电池（Valve Regulated Lead Acid, VRLA）在传统铅酸电池基础上做了重大改进：

- **密封结构**：电池壳体密封，电解液被吸附在隔板或凝胶中（AGM 玻璃纤维隔板或 GEL 硅胶凝胶），无自由流动的电解液
- **氧循环复合**：充电后期正极产生的氧气通过隔板扩散到负极，在负极被还原为水（Pb + O₂ + H₂SO₄ → PbSO₄ + H₂O），实现" internally recombination "，基本无电解液损失
- **安全阀**：设有单向安全阀，在内部压力异常升高时开启释放气体，恢复正常后自动关闭
- **免维护**：密封设计和氧循环使其无需加水补液，也无需均充维护

### 5.2 与传统富液式铅酸电池的对比

| 对比项目 | 传统富液式（富液） | VRLA（AGM） |
|----------|-------------------|-------------|
| **寿命** | 5～8 年（正常使用），循环寿命约 300～500 次 | 5～10 年，循环寿命约 500～1000 次（取决于温度和放电深度） |
| **容量** | 容量密度适中，大容量成本低 | 容量密度较高，但大容量成本更高；高温下容量下降较快 |
| **温度适应性** | 较宽，可在 -40～+60℃ 环境工作，容量随温度降低而下降 | 温度适应范围窄，对高温敏感（>25℃ 寿命急剧缩短）；低温容量下降明显 |
| **可靠性** | 结构简单，可靠性高，故障模式主要为极板硫化和容量衰减 | 密封结构一旦失效（如安全阀堵塞、隔板干涸）难以修复，突发失效风险较高 |
| **应用场合** | 汽车启动电池、储能电站、通信基站固定安装、工业备用电源 | UPS 不间断电源、EPS 应急电源、便携设备、医疗设备、航空备用电源 |
| **维护要求** | 需定期检查电解液液位、比重和电压，必要时加水 | 免加水维护，但仍需定期电压检测和外观检查 |
| **安装位置** | 可任意位置安装 | 必须直立安装（AGM），避免倒置 |
| **成本** | 单位容量成本较低 | 单位容量成本较高 |
| **环境友好** | 含自由硫酸电解液，泄漏有腐蚀性风险 | 密封设计，泄漏风险低，环保性更好 |

### 5.3 AGM 与 GEL 的区别

VRLA 电池通常分为两种内部结构：

- **AGM（Absorbent Glass Mat）**：电解液被玻璃纤维隔板完全吸附，无流动。响应速度快，深放电恢复能力好，成本较低，应用最广泛。但在高温或过充时隔板易干涸。
- **GEL（胶体）**：电解液被硅胶凝胶化，固定性更强。耐高温和过充性能优于 AGM，但低温性能较差，成本更高，放电容量略低。

### 5.4 在仿真项目中的应用

在本仿真项目中使用的铅酸蓄电池模型基于传统富液式电池模型，支持 SOC、比重、电压等参数的动态模拟，可直观展示：

- 充电和放电过程中电压和比重的变化规律
- 亏电与满电状态的电气特性差异
- 电压与比重作为状态判断依据的对应关系

对于 VRLA 电池，其核心化学原理（Pb/PbO₂/H₂SO₄ 三相反应）完全相同，仅在结构和密封方式上有差异。仿真中的电路模型和求解器同样适用于 VRLA 电池的电气特性模拟。
