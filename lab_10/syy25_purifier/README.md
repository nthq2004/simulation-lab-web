# 船舶分油机（S 型 / EPC-60）自动控制仿真

基于 Konva.js 的船舶分油机自动控制教学仿真，以 Alfa Laval S 936 型分油机与 EPC-60 控制器为原型，覆盖燃油分油机的起动、水封、进油、分油、自动排渣、停机、参数设置与常见故障处理。

## 页面

| 页面 | 内容 |
|---|---|
| 页 1 | 分油机运行状态仪（转速、TT1、PT1、PT4、PT5、MT、流量、油柜液位、报警、下次排渣倒计时） |
| 页 2 | S 型分油机系统流程（沉淀柜、进油泵、滤器、加热器、转换阀 V1、分油机半剖、净油柜、排渣柜、工作水模块 SV10/SV15/SV16、控制空气）；机旁控制箱（主电源、起动/停止、应急停止、机旁/遥控、进油泵、加热器、压力表、振动、报警） |
| 页 3 | 左侧：EPC-60 控制面板（LCD、数字键盘、功能图标键、电源开关、应急停止、电流表）；右侧：EPC-60 系统模拟图（管线、SV4/SV1/SV10/SV15/SV16/SV5、传感器、分油机、加热器、温度控制器、冷却水） |

## 主要操作

- 工具栏「自动投用」：打开工作水/控制空气，合上主电源，置遥控与 AUTO。
- 工具栏「起动系统」：快速进入正常分油状态（教学快捷）。
- 工具栏「5 点状态」：停止 → 升速 → 水封 → 分油 → 排渣。
- EPC-60 参数菜单：排渣间隔、最短排渣间隔、分离温度、进油流量、水封时间、置换水时间、排水阀时间、水分触发值、仿真时间倍率。
- 页 3 系统模拟图当前以监视为主；调试模式的阀门/电机控制接口已预留。
- 故障设置：振动高、跑油、排渣失败、油温低、工作水压低、水分传感器故障、电机过载。

## 仿真说明

- 过程量（转速、温度、液位、排渣倒计时）默认 **1× 实时** 运行；可在 EPC-60 参数菜单「仿真时间倍率」改为 1～20× 用于快速演示。
- 教学默认排渣间隔 5 min，可在 EPC-60 参数菜单中调整（2～240 min）。
- 水封/置换水 `SV10`、开启水 `SV15`、关闭水 `SV16`；进油阀 `V1`、排水阀 `V5`。
- 报警代码参考 Alfa Laval S 型报警文本（A01 振动高停机、A03 跑油、A04 排渣失败、A05 油温低、A08 工作水压低、A09 控制空气低、A10 排渣柜高、A11 水分传感器故障、A12 电机故障、A14 应急停止）。

```bash
pnpm run one      # 单文件 HTML → dist-one/
pnpm run preview  # 预览构建产物
```
