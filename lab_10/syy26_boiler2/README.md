# 辅锅炉 PLC 控制系统仿真（安全保护操作程序及故障处理）

基于 Konva.js 的船用辅锅炉（蒸发量 1500 kg/h、工作压力 0.7 MPa）PLC 控制仿真，
以教材「第六章 船舶辅助设备的自动控制」的 **S7-200 SMART + 图 6-3-18~6-3-23** 为原型，
覆盖锅炉的自动/手动起动、预扫风、点火、小火稳定、大火运行、蒸汽压力自动控制、
停炉后扫风，以及 7 类安全保护与常见故障处理。

## 上位机（STEP 7-Micro/WIN SMART）

双击第 2 页的上位机（或右键「打开 STEP7 编程软件」）打开编程界面：

| 功能 | 说明 |
|---|---|
| 🔍 查找设备 | 经以太网搜索同网段 PLC（本机 192.168.0.2 ↔ CPU 192.168.0.1），直连或经交换机均可 |
| 🔗 连接 / ✖ 断开 | 建立/断开与 CPU SR40 的在线连接，项目树显示 CPU 与槽 0 的 EM DQ08 |
| ⬆ 上传 | 把 PLC 中正在运行的程序读回，反编译成可编辑梯形图 |
| ⬇ 下载 | 把编辑好的梯形图编译成语句表写入 PLC 并立即运行 |
| ✎ 程序编辑器 | 按网络增删触点/并联/线圈/定时器/计数器/指令，改地址（I/Q/M/T），可「编译检查」 |
| 👁 监控 | 在线监控 I/Q/M/T 过程映像，梯形图触点与线圈按实时状态着色（监控中只读，须先停止监控才能下载） |

> 上位机与 CPU 之间的以太网线在组态时自动接通（属编程链路，非电气预接线）；
> 若被删除，点工具栏「自动接线」即可恢复。「下载」采用"梯形图 ⇄ 语句表"往返编译，
> 下载后锅炉时序仍按教材逻辑运行（已实测跑通自动起动全过程）。

## 操作

- **起动系统**（工具栏）：合电源、选 1# 油泵、按燃烧准备、旋钮自动，并临时提高仿真倍率，
  待点火成功/大火后自动恢复 1×。
- **5 点步进**：停炉 → 预扫风 → 点火 → 小火 → 大火。
- **手动操作**：燃烧控制旋钮依次转到「扫风」→「点火」→「小火」→「大火」；
  「燃烧停止」后风机自动后扫风 40 s。
- **参数调整**：右键系统图 → 参数配置 → 「仿真时间倍率」（1~20），默认 1×（预扫风 60 s 实时）。
- **故障设置**（工具栏）：风压继电器失灵、点火失败、运行中熄火、光电管脏污、
  危险低水位、超高水位、自动起停继电器失灵（超压）、重油加热器故障、给水泵不出水。
- **操作项目**（任务下拉框）：① 自动起动与运行；② 手动点火、大小火切换与停炉；
  ③ 安全保护试验；④ 上位机（STEP 7）连接、上传下载、监控与编程。

## 仿真时序（与教材一致）

| 定时器 | 作用 | 设定 |
|---|---|---|
| T101 | 预扫风 | 60 s |
| T102 | 自动点火 | 3 s |
| T103 | 小火稳定 | 20 s |
| T104 | 停炉后扫风（TOF） | 40 s |
| T105 | 手动点火失败 | 5 s |
| T106 | 点火监视 | 8 s |
| T107 | 手动点火变压器 | 3 s |
| T108 | 风压检测 | 20 s |

压力整定：大小火转换 0.62 MPa（回落 0.50）、自动起停 0.70 MPa（回落 0.60）、蒸汽超压 0.78 MPa。
水位：正常水位 50~62 %、超高 85 %、危险低 25 %；重油油温低于 90 ℃ 报警。

## 实现要点

- `tools/BoilerSolver.js`：锅炉过程模型（汽压/水位/油温/风压/火焰）+ **虚拟 I/O 桥**。
  两页之间无法拉真实导线，故每扫描周期把面板与过程开关量写入 PLC 的 I 过程映像，
  再读回 Q 输出（`S7200Solver` 中预留 `sys.ioBridge` 钩子）。
- `tools/S7200Solver.js`：定时器改为按实际时间带小数累计（修复 20 fps 下定时器快一倍），
  新增 `getProcessImage()` 供过程模型读取 Q/M/T。
- 组件：`BoilerSystemDiagram`（系统图）、`BoilerLocalPanel`（机旁操纵台）、
  `BoilerWiringDiagram`（外部接线图，实时 I/O 监视：输入触点/指示灯、输出触点/线圈/指示灯）、
  `STEP7PC`（上位机，复用平台 `lib/Step7UI.js` 的编程/监控界面与 `tools/NetworkSim.js` 的以太网发现）。
