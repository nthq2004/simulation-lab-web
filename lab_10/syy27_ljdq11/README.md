# 电气线路图和控制箱识别

基于 Konva.js 的船舶电机控制线路仿真，用于教学中的**电气控制线路图识读**与**电机起动控制箱实物识别**。
主电路为三相笼型异步电动机连续（自锁）控制线路，控制回路经控制变压器降压，
配合右侧控制箱实物图完成部件识别与线圈电压测量。

## 页面（单页工程）

本工程为**单页工程**：所有元件同屏显示，不使用页面索引与翻页（无 `PROJECT_PAGES` / `PageManager`）。

| 区域 | 内容 |
|---|---|
| 左侧 | **电机控制线路图**：三相电源、断路器 QF、接触器主触头 KM1、热继电器 FR、电动机 M；控制回路 FU4、控制变压器 TC、停止按钮 SB1、起动按钮 SB2、常开辅助触头 KM1（自锁）、线圈 KM1、热继电器常闭触头 FR、FU5；另有接触器常闭辅助触头 KM1、时间继电器 KT1 及其延时触点。 |
| 右侧 | **电机起动控制箱实物图**：可点击识别箱内空气开关、接触器、热继电器、起动/停止按钮、熔断器、时间继电器。 |

## 操作

- **自动接线**（工具栏）：按线路图自动完成主回路与控制回路接线。
- **起动系统**：自动接线并合上断路器 QF。
- **5 点步进**：自动接线 → 合闸 → 按 SB2 起动（KM1 自锁）→ 按 SB1 停止 → 分闸。
- **手动操作**：合上 QF，按 SB2 起动、按 SB1 停止；接触器线圈失电后主触头与自锁触头同时断开。
- **仪表**（工具栏「选择仪表」）：数字万用表、指针万用表、三路示波器、信号发生器、
  过程校验仪、数字功率计、手摇兆欧表（默认隐藏，勾选后显示）。
- **参数调整**：右键组件 → 参数配置，可改电源电压/频率、断路器整定值、热继电器额定电流等。
- **故障设置**（工具栏）：接触器线圈 A1 端子接触不良、辅助常开 COM 端子接触不良。

## 操作项目（任务下拉框）

| 项目 | 内容 |
|---|---|
| 1. 读懂电气控制图 | 自动接线后，逐项识别线圈、主触头、辅助触头、断路器、熔断器、热继电器、时间继电器、按钮、控制变压器 |
| 2. 解释控制逻辑关系 | 接线合闸 → 按 SB2 观察线圈得电、主触头闭合、常开触头自锁 → 按 SB1 观察全部复位；含主/控电路逻辑关系测试题 |
| 3. 电机控制箱实物识别 | 在控制箱实物图上识别各元器件，并用万用表 ACV 档测量接触器线圈电压（约 220 V） |

## 实现要点

- `project/sys_ljdq1-1.js`：组件布局、工作流（最新范式：`op` 数组逐个“指示 → 执行”＋`check()`）、
  故障配置、接线预设。**单页工程**：不导出 `PROJECT_PAGES`，`consys.js` 不创建 `PageManager`。
  系统初始化时**不做预接线**（`applyAllPresets({ init: true })` 直接返回），
  只有工具栏「自动接线」「起动系统」与工作流才接线。
- `project/sys_ljdq1-1.js` 的 `_autoWire()`：主回路 14 根 + 控制回路 9 根固定接线，
  与线路图端口一一对应。
- 组件复用平台器件：`DiagramACPower3P`、`DiagramThreePhaseACB`、`MainContact`、
  `ThermalHeatElement`、`InductionMotor2`、`ControlTransformer`、`SinglePhaseFuse`、
  `DiagramStartButton` / `DiagramStopButton`、`ContactorCoil`、`AuxNOContact` / `AuxNCContact`、
  `ThermalNCContact`、`TimeRelayCoil`、`TimeDelayNOContact` / `TimeDelayNCContact`、
  `MotorStarterPanel`（控制箱实物识别）。
