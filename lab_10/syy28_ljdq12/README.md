# 电气控制箱故障判断、排查

基于 Konva.js 的船舶电机控制线路仿真，用于教学中的**电气控制箱故障判断与排查**（故障诊断）训练。
主电路为三相笼型异步电动机连续（自锁）控制线路，控制回路经控制变压器降压；
右侧配控制箱实物图。故障设置后，学员用万用表（电阻档 / 交流电压档）按**二分法**逐段测量，
定位断点并修复，最后让电动机恢复正常运行。

## 页面（单页工程）

本工程为**单页工程**：所有元件同屏显示，不使用页面索引与翻页（无 `PROJECT_PAGES` / `PageManager`）。

| 区域 | 内容 |
|---|---|
| 左侧 | **电机控制线路图**：三相电源、断路器 QF、接触器主触头 KM1、热继电器 FR、电动机 M；控制回路 FU4、控制变压器 TC、停止按钮 SB1、起动按钮 SB2、常开辅助触头 KM1（自锁）、线圈 KM1、热继电器常闭触头 FR、FU5。 |
| 右侧 | **电机起动控制箱实物图**：可点击识别箱内空气开关、接触器、热继电器、起动/停止按钮、熔断器、时间继电器。 |

## 三类故障（工具栏「故障设置」）

| 故障 | 现象 | 排查方法 |
|---|---|---|
| 主电路缺相 | 电机不能正常起动或运转异常 | **断电测阻法**：断开电源 → 强制闭合 KM1 → 万用表 200Ω 档二分法分段测通断 |
| 控制电路断路 | 按 SB2 无任何反应，接触器不吸合 | **带电测压法**：按住 SB2 → 万用表 ~500V 档测各元件两端电压，电压≈电源电压处即断点 |
| 点动运行故障 | 按住 SB2 电机转，松开即停（自锁失效） | **断电测阻法**：断开 QF → 强制闭合 KM1 → 200Ω 档测自锁常开触头 COM-NO，O.L 即断点 |

每个故障有 3 种可能原因（随机选 1），学员必须靠测量判断，不能凭"应该是哪里"下结论。

## 操作

- **自动接线**（工具栏）：按线路图自动完成主回路与控制回路接线（25 根）。
- **起动系统**：自动接线并合上断路器 QF。
- **5 点步进**：自动接线 → 合闸 → 按 SB2 起动 → 按 SB1 停止 → 分闸。
- **手动操作**：合上 QF，按 SB2 起动、按 SB1 停止；右键组件可「模拟闭合 / 模拟分闸」「参数配置」。
- **仪表**（工具栏「选择仪表」）：数字万用表、指针万用表、三路示波器、信号发生器、
  过程校验仪、数字功率计、手摇兆欧表（默认隐藏，勾选后显示）。
- **参数调整**：右键组件 → 参数配置，可改电源电压/频率、电源开关、断路器整定值等。

## 操作项目（任务下拉框）

| 项目 | 内容 |
|---|---|
| 1. 主电路缺相—断电查找法 | 设置缺相故障 → 起动观察异常 → 断电并强制闭合 KM1 → 200Ω 档先定断线相 → 二分法定位断点 → 修复 → 复位通电正常起动 |
| 2. 控制电路断线—带电查找法 | 设置控制回路断路 → 起动无反应 → 按住 SB2 → ~500V 档测量各元件两端电压 → 电压≈220V 处即断点 → 修复 → 正常起动 |
| 3. 电动机点动—断电查找法 | 设置点动故障 → 起动松开即停 → 断开 QF、强制闭合 KM1 → 测自锁触头 COM-NO 为 O.L → 修复 → 自锁运行 |

## 实现要点

- `project/sys_ljdq1-2.js`：组件布局（`componentConfigs`）、工作流（`PROJECT_WORKFLOWS`）、
  故障配置（`FAULT_CONFIGS`）、接线预设（`_autoWire`）。
  工作流采用最新范式：`find` 识别步骤 + `check`（`op` 数组逐个"指示 → 执行"＋`check()` 验收）
  + `quiz` 测试题；**单页工程**：不导出 `PROJECT_PAGES`，`consys.js` 不创建 `PageManager`。
- **默认不预接线**：`applyAllPresets({ init: true })` 直接返回，只有工具栏「自动接线」「起动系统」
  与工作流 `op.act` 才接线。
- 演示动作一律走界面/模拟交互：故障设置走「故障设置」界面（`op.type='fault'`），
  仪表调出走「选择仪表」界面（`op.type='instrument'`），电源开关走参数配置界面（`_demoSetCfg`），
  表笔接线用动画接线（`_probeAnimated`，约 3s/根）。
- 断点端口按**当前故障变体**动态计算（`_phaseWholeSpan` / `_phaseBreakSpan` / `_ctrlBreakSpan`），
  三种可能原因都能正确测量，不会指错表笔位置。
- 组件复用平台器件：`DiagramACPower3P`、`DiagramThreePhaseACB`、`MainContact`、
  `ThermalHeatElement`、`InductionMotor2`、`ControlTransformer`、`SinglePhaseFuse`、
  `DiagramStartButton` / `DiagramStopButton`、`ContactorCoil`、`AuxNOContact`、`ThermalNCContact`、
  `MotorStarterPanel`（控制箱实物识别）。
