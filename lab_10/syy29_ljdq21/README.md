# 电子元器件识别与测试仿真

基于 Konva.js 的电工电子基础仿真，用于教学中的**电子元器件识别与万用表检测**训练。
画布左侧是 5 只真实外形的元件（电阻 R1、电容 C1、二极管 D1、三极管 T1、晶闸管 SCR1），
右侧是电子元器件面板（6 格实物照片）；工具栏「选择仪表」可调出数字万用表、指针式万用表、
手摇兆欧表、三路示波器、信号发生器、过程校验仪、数字功率计。

元件上的数值标签默认隐藏（`testFlag: true`），学员必须**用仪表实测**才能得到参数。

## 页面（单页工程）

本工程为**单页工程**：所有元件同屏显示，不使用页面索引与翻页（无 `PROJECT_PAGES` / `PageManager`）。

| 区域 | 内容 |
|---|---|
| 左侧 | 5 只真实风格元件（原始尺寸），按五边形分布：电阻 R1（1kΩ）、电容 C1（100μF）、二极管 D1（0.68V）、三极管 T1（9013，NPN，β=100）、晶闸管 SCR1（BT151）。 |
| 中部 | 电子元器件面板（800×720，缩放 0.72）：电阻、电容 / 二极管、三极管 / 晶闸管、电感 6 格实物照片，每格可点击识别。 |
| 右部（约 1200~1550） | 7 种仪表停靠区（默认隐藏）：既不被识别面板遮挡，也不被右侧「操作流程」面板遮挡，保证演示时仪表与读数全程可见。 |

## 操作项目（工具栏任务下拉框）

| 项目 | 内容 |
|---|---|
| 1. 电子元器件的识别 | 在面板上依次点出电阻、三极管、晶闸管、电容、二极管 → 测试题（电阻与电容的用途） |
| 2. 用数字式万用表检测元件 | 12 步：选择仪表 → 拨 2kΩ 档 → 测 R1(1.000 kΩ) → 填值 → 换 uF 档测 C1(100 μF) → 填值 → 换二极管档测 D1(0.68 V / O.L) → 填值 → 测 T1(B-C 0.62 V、B-E 0.70 V) → 填值 → 测 SCR1(G–K 0.68 V、A–K 两向 O.L) → 填值 → 测试题 |
| 3. 用指针式万用表测试元件 | 13 步：选表 → ×1K 档 → **两表笔短接调零** → 测 R1 → 填值 → 说明"指针表无电容档"→ 填值 → 换 ×100 档**重新调零**测 D1(≈1.66 kΩ，反向 ∞) → 填值 → 测 T1(B 为公共端) → 填值 → 换 ×10 档调零测 SCR1(G–K ≈500 Ω) → 填值 → 测试题 |

> 两个检测项目的 `check` 步骤都是"**指示 → 操作 → 停留观察**"的逐 op 演示：
> 选择仪表走「选择仪表」界面（`op.type='instrument'`）、表笔接线逐根动画（约 3 s/根）、
> 档位用组件公开 API（`Multimeter.setMode()` / `MF47Multimeter.setRange()`）切换并指向旋钮。
> 演练/评估模式下由学员自己完成同样的操作，`check()` 校验仪表已显示、档位正确、表笔已接到目标引脚。

## 操作

- **手动测量**：工具栏「选择仪表」勾选数字万用表 / 指针式万用表 → 转动档位旋钮 → 把表笔接到元件引脚
  （点击端口连线，或拖动元件）→ 读数。表笔线只在测量时需要，换元件前先撤掉。
- **工具栏**：与其它工程保持一致（撤销 / 恢复 / 自动接线 / 起动系统 / 5点步进 / 故障设置 / 重置系统 /
  任务选择 / 自动演示 / 单步演示 / 演练 / 评估 / 选择仪表）。本工程无接线图、无电源、无故障项，
  「自动接线 / 起动系统 / 5点步进 / 故障设置」为平台通用按钮，在本工程中不产生动作。
- **参数调整**：右键元件 → 参数配置，可改阻值、容量、管压降、类型、报数、是否隐藏数值标签等。

## 实现要点

- `project/sys_ljdq2-1.js`：组件布局（`componentConfigs`）、工作流（`PROJECT_WORKFLOWS`）。
  `FAULT_CONFIGS` 为空；`initSlider` / `applyAllPresets` / `applyStartSystem` / `fiveStep` 均为空实现
  （本工程没有接线与起车流程）。
- 工作流通用辅助：`_wire()`（动画接线 3 s/根）、`_clearWires()`（换元件前收表笔）、
  `_wired()`（`check()` 判端口是否已连）、`_dmmSet()`（数字表切档）、`_mf47Set()` / `_mf47Zero()`
  （指针表换档与欧姆调零）。表笔端口：`multimeter_wire_v` / `_com`，`mf47-panel_wire_v` / `_COM`。
- **默认不预接线**：`applyAllPresets({ init: true })` 直接返回；只有学员手动连线才会出现导线。
- `components/ElectronicsPanel.js`：6 格图片**异步加载**，加载完成后必须
  `_forceCacheFlush(true)` 强制重建静态位图缓存，否则 `cache='fixed'` 的静态层会一直停在
  "图片尚未加载"的那一帧，面板显示为空白格子（本工程已修）。
- 7 种保留仪表：`Multimeter`（`multimeter`）、`MF47Multimeter`（`mf47-panel`）、
  `RealMegohmMeter`（`megohm`）、`Oscilloscope_tri`（`osc`）、`SignalGenerator`（`sg`）、
  `ProcessCalibrator`（`cali`）、`ElecMeter`（`elecmeter`），全部 `visible: false`。
