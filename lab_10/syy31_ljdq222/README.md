# 电池充电回路仿真

基于 Konva.js 的**镍氢电池恒流充电回路**仿真，用于教学中的**"整流滤波 → 稳压基准 → 三极管恒流 → 电池充电"认知与仪表检测**训练。
画布上是一条完整的充电回路：交流电源 AC 220 V、控制变压器 T（220 V/12 V）、整流二极管 D1（半波整流）、
滤波电容 C1（2200 µF）、稳压基准 R1（470 Ω）+ DZ（6 V）、恒流三极管 Q1、镍氢电池 BT、
充电指示支路 R2（2 kΩ）+ LED、档位开关 SA 与发射极电阻 R3（53 Ω）/ R4（106 Ω）。
工具栏「选择仪表」可调出数字万用表、三路示波器、指针式万用表、手摇兆欧表等 7 种仪表。

## 页面（单页工程）

本工程为**单页工程**：全部元件同屏显示，不使用页面索引与翻页（无 `PROJECT_PAGES` / `PageManager`）。

| 区域 | 内容 |
|---|---|
| 上部（y 110~620） | 主电路：`ac` → `tr` → `d1` → `c1` → 基准 `r1`+`zd` → 电池 `bt` → 三极管 `q1` → `r2`+`led` 指示支路、`sw`+`r3`/`r4` 档位支路，六处接地 `gnd1`~`gnd6` |
| 下部（y 650~1080） | 7 种仪表停靠区（默认隐藏）：示波器 / 数字万用表 / 指针表互不遮挡，也不被右侧「操作流程」面板挡住 |

## 操作项目（工具栏任务下拉框）

| 项目 | 内容 |
|---|---|
| 1. 识别电池充电回路的元器件 | 7 个 `find` 步骤：变压器 → 整流二极管 → 滤波电容 → 稳压二极管 → 三极管 → 充电指示灯 → 镍氢电池，另加 2 道测试题（稳压管工作状态、充电电流由什么决定） |
| 2. 电池恒流充电电路分析 | 10 步：自动接线并合闸 → 万用表 DCV 20 测滤波电容 → 表笔移到稳压管两端 → 填 6 V → 表笔移到发射极与地 → 填 Ve 与 100 mA → SA 拨到 T2 → 填 50 mA → 电池 SOC 改 0.95 看电流不变 → 测试题 |

> 第 2 个项目全部按最新范式编写：`mode:'check'` 的每步都用 `op` 数组、每个子操作自带 `act()`，
> 演示引擎逐个子操作执行"**闪烁箭头指向目标 → 立即执行 → 停留观察**"：
> 选择仪表走「选择仪表」界面（`op.type='instrument'`）、表笔逐根动画接线（约 3 s/根）、
> 换测点前先"拔表笔"（`_removeProbes`）、参数修改走**参数配置界面**（弹框 → 填值 → 真正点击「保存」）。

## 操作

- **手动操作**：工具栏「自动接线」接好充电回路 → 点交流电源面板上的「电源」键合闸 →「选择仪表」调出仪表 →
  转动万用表旋钮选档 → 点击端口接表笔 → 读数。点击开关 SA 可在 T1（100 mA）/ T2（50 mA）之间换档。
  右键任意元件 →「参数设置」可改电压、频率、容量、初始 SOC、阻值等。
- **工具栏**：撤销 / 恢复 / 自动接线 / 起动系统 / 5点步进 / 故障设置 / 重置系统 / 任务选择 /
  自动演示 / 单步演示 / 演练 / 评估 / 选择仪表。本工程 `FAULT_CONFIGS` 为空，故障列表为空白；
  `fiveStep` 为空实现，点「5点步进」不产生动作。
- **默认不接线**：`applyAllPresets({ init: true })` 直接返回，初始化后画布无任何预接线；
  只有「自动接线」「起动系统」或工作流才会接线（本电路 21 根导线，> 8 根，允许瞬时接线）。

## 实现要点

- `project/sys_ljdq2-2-2.js`：组件布局（`componentConfigs`）、工作流（`PROJECT_WORKFLOWS`）、
  接线与演示辅助函数。
- 工作流辅助：`_wire()` 动画接线、`_wired()` / `_touches()` 判线、`_powerOn()` 模拟按电源键、
  `_removeProbes()` 拔表笔、`_mmReading()` 读万用表数值、`_demoSetCfg()` 走配置界面改参数
  （含"保存后仍不生效"兜底）、`_waitFor()` 条件轮询。
- 动作一律**模拟真实交互**：电源键用 `ACPower.getClickablePartNode('power').fire('mousedown')`，
  开关换档用组件公开方法 `toggle()`（`DiagramSPDT` 未注册命中部件），不直接改内部字段。
- 电路数值：C1 滤波后 ≈ 15 V，DZ 基准 6.00 V，Ve ≈ 5.31 V；R3 = 53 Ω → 充电电流 ≈ 100 mA，
  R4 = 106 Ω → ≈ 50 mA；电池电压由 1.20 V 升到 1.25 V 时充电电流基本不变（恒流）。
- 7 种保留仪表：`Multimeter`（`multimeter`）、`MF47Multimeter`（`mf47-panel`）、`RealMegohmMeter`（`megohm`）、
  `Oscilloscope_tri`（`osc`）、`SignalGenerator`（`sg`）、`ProcessCalibrator`（`cali`）、`ElecMeter`（`elecmeter`），全部 `visible: false`。
