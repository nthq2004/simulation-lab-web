# 船舶发电机主开关仿真

基于 Konva.js 的**船用框架式空气断路器（主开关）**仿真，用于教学中的
**"部件认知 → 储能/合闸/分闸操作 → 不能合闸故障判断与排除 → 可抽拉式开关操作"**训练。

画布上是一套完整的船舶发电机主配电装置：同步发电机 `gen1`（400 kW / 400 V）经主开关 `qf1`
（船用框架式空气断路器，含储能弹簧、合闸线圈、失压脱扣器、分励线圈、主/辅触头、分闸弹簧）
送入汇流排 `bus1`；汇流排两路馈出：`QF2` → 三相异步电机 `im01`、`QF3` → 三盏白炽灯。
控制回路为 DC 24 V（`dc_uv`）：合闸按钮 `sc` → 合闸线圈、分闸按钮 `ss` → 分励线圈、
「模拟失压」按钮 `sb`（常闭）→ 失压线圈、储能电机 `m1/m2`；电子脱扣器 `et1` 负责电流采样与保护。
工具栏「选择仪表」可调出数字万用表、指针式万用表、手摇兆欧表、示波器等 7 种仪表。

## 页面（单页工程）

本工程为**单页工程**：全部元件同屏显示，不使用页面索引与翻页（无 `PROJECT_PAGES` / `PageManager`）。

| 区域 | 内容 |
|---|---|
| 主回路 | `gen1`（x 90, y 700）→ 主开关 `qf1`（x -100, y 220）→ 汇流排 `bus1`（x 220, y 30） |
| 控制回路 | 按钮 `sc`/`ss`/`sb`（x 700~860, y 280~440）、DC 24 V 电源 `dc_uv`（x 1100, y 150）、公共地 `gnd_qf`/`gnd_et`/`gnd_dc` |
| 检测/馈出 | 电子脱扣器 `et1`（x 700, y 650）、`QF2`+电机、`QF3`+三灯、`gnd_l` |
| 仪表停靠 | 7 种仪表默认隐藏，位置互不重叠，可拖动 |

## 操作项目（工具栏任务下拉框）

| 项目 | 内容 |
|---|---|
| 1. 空气断路器的部件及其功能 | 7 个 `find` 步骤（储能弹簧 → 合闸线圈 → 失压脱扣器 → 分励线圈 → 电子脱扣器 → 主触头 → 辅助触头 → 分闸弹簧）+ 5 道测试题 |
| 2. 主开关储能、合闸、分闸 | 9 步：手动储能（按压手柄 5 次）→ 自动接线并起动发电机组 → 手动合闸 → 储能电机自动重新储能 → 手动分闸 → 遥控合闸（合闸线圈）→ 遥控分闸（分励线圈）→ 模拟失压（常闭按钮断开）→ 测试题 |
| 3. 主开关不能合闸故障判断和排除 | 11 步：故障界面设置「合不上闸」→ 接线起动并试合闸 → 看储能指示/手动储能 → 手动合闸区分合闸回路故障 → 电子脱扣器正常 → 万用表 2 kΩ 档测失压线圈电阻（拆线断电测量，O.L 即断线）→ 手动按压动衔铁 → 卡死判定 → 故障界面取消故障并重新合闸 → 测试题 |
| 4. 可抽拉式主开关的操作 | 7 步：连接位 →（顺时针 3 次）试验位 →（再 3 次）断开位 →（逆时针 3 次）试验位 →（再 3 次）连接位，每段配测试题 |

> 全部按最新范式编写：`mode:'check'` 的每步都用 `op` 数组、每个子操作自带 `act()`，
> 演示引擎逐个子操作执行「**闪烁箭头指向目标 → 立即执行 → 停留观察**」；
> 故障走「故障设置」界面（`op.type='fault'`）、仪表走「选择仪表」界面（`op.type='instrument'`）、
> 表笔用动画接线（约 3 s/根）、接线指向端口（`op.ports`）、按钮/手柄/圆盘一律**模拟真实点击**
> （`getClickablePartNode(partId).fire('mousedown'/'click')`）。

## 操作

- **手动操作**：工具栏「自动接线」→ 按发电机机旁「起动」按钮建压 → 按储能手柄手动储能（或等储能电机自动储能）
  → 点主开关面板「合闸」/「分闸」按钮，或按控制面板的「合闸」`sc` /「分闸」`ss` /「模拟失压」`sb` 按钮。
  - 主开关左侧手摇圆盘：**点右半区顺时针、点左半区逆时针**，每 3 次切换一档（连接 → 试验 → 断开，到端点不循环）。
  - 失压脱扣器动衔铁可按下（诊断反作用弹簧/衔铁卡死）。
- **工具栏**：撤销 / 恢复 / 自动接线 / 起动系统 / 5点步进 / 故障设置 / 重置系统 / 任务选择 /
  自动演示 / 单步演示 / 演练 / 评估 / 选择仪表。`fiveStep` 为空实现，点「5点步进」不产生动作。
- **故障设置**：3 类（主开关合不上闸、无法脱扣、误跳闸），每类内部随机触发 12 个具体故障中的 1 个。
- **默认不接线**：`applyAllPresets({ init: true })` 直接返回，初始化后画布无任何预接线；
  只有「自动接线」「起动系统」或工作流才会接线（本电路 43 根导线，> 8 根，允许瞬时接线）。

## 实现要点

- `project/sys_ljdq3-1.js`：组件布局（`componentConfigs`）、故障（`FAULT_CONFIGS`）、
  工作流（`PROJECT_WORKFLOWS`）、接线与演示辅助函数。
- 演示辅助：`_pressPart()`（按—保持—松开）、`_chargeByHandle()`（按压储能手柄）、
  `_dialClicks()`（点击圆盘左右半区）、`_dcSet()`（点直流电源「电源键」）、`_genStart()`（按机旁起动按钮）、
  `_removeProbes()` / `_wire()`（动画接线）、`_waitFor()`（条件轮询）、`_removeWire()` / `_addWire()`（拆/接一根线）。
- 组件侧配套（可点击部件注册）：`MarineMainsSwitch` 的 `handle` / `dial` / `dial-left` / `btn-close` /
  `btn-open` / `uv-armature`；`SyncGenerator3P` 的 `start` / `stop`；`DCPower` 的 `power`（电源键真实开关机）。
- 电路数值：控制电源 DC 24 V；失压线圈 2000 Ω（吸合电流约 10 mA），合闸/储能/电子脱扣线圈 200 Ω，
  分励线圈 50 Ω；拆开失压线圈后 2 kΩ 档读「2.000 kΩ」，线圈断线时显示「O.L」。
- 7 种保留仪表：`Multimeter`（`multimeter`）、`MF47Multimeter`（`mf47-panel`）、`RealMegohmMeter`（`megohm`）、
  `Oscilloscope_tri`（`osc`）、`SignalGenerator`（`sg`）、`ProcessCalibrator`（`cali`）、`ElecMeter`（`elecmeter`），全部 `visible: false`。
