# 船舶发电机主开关保护仿真

基于 Konva.js 的**船舶发电机主开关（框架式空气断路器）保护**仿真，用于教学中
**"短路保护 → 过载保护（自动分级卸载）→ 失压（欠压）保护"** 的判断与处理训练。

画布上是一套完整的船舶发电机主配电装置：同步发电机 `gen1`（80 kW / 400 V）经主开关 `qf1`
（船用框架式空气断路器：储能弹簧、合闸线圈、失压脱扣器、分励线圈、主/辅触头、分闸弹簧）
送入汇流排 `bus1`；汇流排经**低压配电箱 `pdb1`** 三路馈出：`sw1` → 三相异步电机 `im01`、
`sw2` → 三盏白炽灯、`sw3` → 三相可调负载 `tload`。
电子脱扣器 `et1`（In = 100 A）负责电流/电压采样与保护：短路瞬时/定时脱扣、过载反时限脱扣、
过载 5 s / 10 s 两路分励输出（自动分级卸载）、欠压脱扣。控制回路为 DC 24 V（`dc_uv`）。
工具栏「选择仪表」可调出数字万用表、指针式万用表、手摇兆欧表、示波器等 7 种仪表。

## 页面（单页工程）

本工程为**单页工程**：全部元件同屏显示，不使用页面索引与翻页（无 `PROJECT_PAGES` / `PageManager`）。

| 区域 | 内容 |
|---|---|
| 主回路 | `gen1`（x -10, y 700）→ 主开关 `qf1`（x -150, y 220）→ 汇流排 `bus1`（x 220, y 30） |
| 保护 | 电子脱扣器 `et1`（x 600, y 600）：电流采样串在第 3 相，电压采样 W-N，脱扣输出 t1/t2 → `qf1` 的 et 线圈 |
| 馈出 | 低压配电箱 `pdb1`（x 1200, y 190）三路塑壳开关 → 电机 / 照明 / 可调负载 |
| 控制回路 | 按钮 `sc`/`ss`/`sb`、DC 24 V 电源 `dc_uv`（x 900, y 150）、公共地 `gnd_qf`/`gnd_et`/`gnd_dc` |
| 仪表停靠 | 7 种仪表默认隐藏，位于画布下方（y ≈ 1000），位置互不重叠，可拖动 |

## 操作项目（工具栏任务下拉框）

| 项目 | 内容 |
|---|---|
| 1. 发电机短路故障的判断和排除 | 13 步：接线起动合闸带载 → 故障界面设置「主汇流排短路」（0.7 s 内短路脱扣）→ 断开三路负载 → 兆欧表测干线绝缘（0）→ 修复、复位、合闸恢复 → 故障界面设置「重要负载短路」→ 再次跳闸 → 再测绝缘（0）→ 逐路拉开关，读数恢复 ∞ 的一路即短路支路 → 修复恢复送电 → 2 道测试题 |
| 2. 发电机过载故障的判断和处理 | 6 步：带 20 kW 运行 → 调到 95 kW（约 186 A）→ 过载 5 s 分励脱扣 `sw1`、10 s 脱扣 `sw2`（自动分级卸载），负荷回落到 135 A，主开关保持合闸 → 调到 125 kW，过载 15 s 反时限跳闸 → 3 道测试题 |
| 3. 发电机失压（欠压）故障的判断和处理 | 9 步：故障界面设置「调速器故障」（f = 25 Hz、U ≈ 280 V）→ 欠压延时跳闸 → 点击脱扣器看记录 → 修复复位合闸 → 设置「调压器故障」（f ≈ 50 Hz、U ≈ 200 V）→ 欠压跳闸 → 修复复位合闸 → 测试题 |

> 全部按最新范式编写：`mode:'check'` 的每步都用 `op` 数组、每个子操作自带 `act()`，
> 演示引擎逐个执行「**闪烁箭头指向目标 → 立即执行 → 停留观察**」；
> 故障走「故障设置」界面（`op.type='fault'`）、仪表走「选择仪表」界面（`op.type='instrument'`）、
> 表笔用动画接线（约 3 s/根，指向端口 `op.ports`）、可调负载功率与加载状态走**参数配置界面**
> （高亮输入框 + 高亮并点击「保存」）、按钮/手柄/塑壳开关一律**模拟真实点击**
> （`getClickablePartNode(partId).fire('mousedown'/'click')`）。

## 操作

- **手动操作**：工具栏「自动接线」→ 按发电机机旁「起动」按钮建压 → 按储能手柄手动储能
  （或等储能电机自动储能）→ 点主开关面板「合闸」/「分闸」按钮，或按控制面板的
  「合闸」`sc` /「分闸」`ss` /「模拟失压」`sb` 按钮；配电箱三路开关点击手柄切换（TRIP → 点一次复位，再点一次合闸）。
- **参数界面**：右键组件 →「参数设置」（或工作流自动弹出）可改可调负载功率/加载状态、
  脱扣器整定值、配电箱额定电流等；改完必须点「保存」。
- **工具栏**：撤销 / 恢复 / 自动接线 / 起动系统 / 5点步进 / 故障设置 / 重置系统 / 任务选择 /
  自动演示 / 单步演示 / 演练 / 评估 / 选择仪表。`fiveStep` 为空实现，点「5点步进」不产生动作。
- **故障设置**：4 类故障（主汇流排短路、重要负载短路、调速器故障、调压器故障），
  由故障界面勾选后「应用设置」生效。
- **默认不接线**：`applyAllPresets({ init: true })` 直接返回，初始化后画布无任何预接线；
  只有「自动接线」「起动系统」或工作流才会接线（本电路 48 根导线，> 8 根，允许瞬时接线）。

## 实现要点

- `project/sys_ljdq3-2.js`：组件布局（`componentConfigs`）、故障（`FAULT_CONFIGS`）、
  工作流（`PROJECT_WORKFLOWS`）、接线与演示辅助函数。
- 演示辅助：`_genStart()`（机旁起动按钮）、`_ensureCharged()`（按压储能手柄）、`_closeQF()`（合闸）、
  `_pdbSet()`（配电箱开关切档，含 TRIP 复位）、`_etReset()`（脱扣器复位）、
  `_setTload()`（参数配置界面改功率/加载）、`_wire()`（动画接线）、`_mgCrank()`（摇表并等读数）、
  `_putAwayInstrument()`（收表）、`_waitFor()`（条件轮询）。
- 组件侧配套（可点击部件注册）：`MarineMainsSwitch` 的 `handle`/`btn-close`/`btn-open`/`uv-armature`；
  `SyncGenerator3P` 的 `start`/`stop`；`DistributionBox` 的 `sw1`/`sw2`/`sw3`（含命中节点）；
  `MarineElectronicTrip` 的 `lcd`/`reset`；`RealMegohmMeter` 的 `crank`；`ThreePhaseLoad` 的 `power`。
- 电路数值：控制电源 DC 24 V；电子脱扣器 In = 100 A、Un = 380 V，短路 4×In（0.2 s）、
  过载 1.5×In（15 s）、欠压 80%Un（3 s）、过载分流输出 5 s / 10 s；可调负载 20 kW 起、
  cosφ = 1、星形中性点接地。
- 7 种保留仪表：`Multimeter`（`multimeter`）、`MF47Multimeter`（`mf47-panel`）、
  `RealMegohmMeter`（`megohm`）、`Oscilloscope_tri`（`osc`）、`SignalGenerator`（`sg`）、
  `ProcessCalibrator`（`cali`）、`ElecMeter`（`elecmeter`），全部 `visible: false`。
