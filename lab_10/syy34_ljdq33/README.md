# 船舶电网绝缘监视与故障排查仿真

基于 Konva.js 的**船舶动力电网绝缘监视**仿真，用于教学中
**"绝缘低报警 → 三灯判断故障相 → 拉电查找法定位支路 → 兆欧表复核"** 的判断与处理训练。

画布上是一套完整的船舶动力配电装置：同步发电机 `gen1`（80 kW）经主开关 `qf1`
（船用框架式空气断路器：储能弹簧、合闸/分励/失压线圈）送入汇流排 `bus1`；汇流排经
**低压配电箱 `pdb1`** 三路馈出：`sw1` → 三相异步电机 `im01`、`sw2` → 三盏白炽灯、
`sw3` → 三相可调负载 `tload`。母线下缘同一个抽头上并接两台绝缘检测装置：

- **三灯绝缘指示灯 `insul`**：三相各经一灯、星点经面板常开「测试」按钮接船体地。
  按住测试按钮后，某相对地绝缘下降（或接地）则该相灯变暗（或熄灭），据此判断故障相。
- **绝缘监视仪 `insulmon`**：读取三相最小绝缘电阻，低于 0.1 MΩ 声光报警
  （红灯快闪 + 蜂鸣），面板有「消音 / 消闪 / 复位」三键。

控制回路为 DC 24 V（`dc_uv`）。工具栏「选择仪表」可调出数字万用表、指针式万用表、
手摇兆欧表、示波器等 7 种仪表。

## 页面（单页工程）

本工程为**单页工程**：全部元件同屏显示，不使用页面索引与翻页（无 `PROJECT_PAGES` / `PageManager`）。

| 区域 | 内容 |
|---|---|
| 主回路 | `gen1`（x -60, y 700）→ 主开关 `qf1`（x -150, y 220）→ 汇流排 `bus1`（x 220, y 30） |
| 绝缘检测 | 三灯绝缘指示灯 `insul`（x 400, y 620）；绝缘监视仪 `insulmon`（x 720, y 580） |
| 馈出 | 低压配电箱 `pdb1`（x 1200, y 190）三路塑壳开关 → 电机 / 照明 / 可调负载 |
| 控制回路 | 按钮 `sc`/`ss`/`sb`、DC 24 V 电源 `dc_uv`（x 980, y 150）、公共地 `gnd_qf`/`gnd_dc`/`gnd_l` |
| 仪表停靠 | 7 种仪表默认隐藏，位于画布下方（y ≈ 500~1000），位置互不重叠，可拖动 |

## 操作项目（工具栏任务下拉框）

| 项目 | 内容 |
|---|---|
| 1. 用仪表确认动力电网绝缘故障 | 10 步：接线起动合闸带载 → 故障界面设置「动力电网绝缘低」（0.05 MΩ）→ 读数下降、声光报警 → 消音、消闪 → 按住测试按钮（三灯亮度不变）→ 修复、复位 → 设置「动力电网接地」（0 MΩ）→ 消音消闪 → 再按测试按钮（接地相熄灭，其余两相仍亮）→ 修复复位 → 2 道测试题 |
| 2. 电网绝缘故障的查找 | 8 步：带载运行 → 设置绝缘低 → 消音消闪 → **拉电查找法**逐路拉开关，读数恢复的那一路即故障支路 → 挂牌、调出兆欧表（L 接故障相端子、E 接船体地、动画接线）摇测约 0.05 MΩ → 取消故障、合回开关、复位 → 2 道测试题 |

> 全部按最新范式编写：`mode:'check'` 的每步都用 `op` 数组、每个子操作自带 `act()`，
> 演示引擎逐个执行「**闪烁箭头指向目标 → 立即执行 → 停留观察**」；
> 故障走「故障设置」界面（`op.type='fault'`）、仪表走「选择仪表」界面（`op.type='instrument'`）、
> 表笔用动画接线（约 3 s/根，指向端口 `op.ports`）、按钮/手柄/测试按钮/塑壳开关一律**模拟真实点击**
> （`getClickablePartNode(partId).fire('click'/'mousedown'/'mouseup')`）。

## 操作

- **手动操作**：工具栏「自动接线」→ 按发电机机旁「起动」按钮建压 → 按储能手柄手动储能
  （或等储能电机自动储能）→ 点主开关面板「合闸」/「分闸」按钮，或按控制面板的
  「合闸」`sc` /「分闸」`ss` /「模拟失压」`sb` 按钮；配电箱三路开关点击手柄切换
  （TRIP → 点一次复位，再点一次合闸）；绝缘指示灯**按住**「测试」按钮观察三灯。
- **参数界面**：右键组件 →「参数设置」可改可调负载功率/加载状态、绝缘指示灯各负载各相绝缘
  电阻、绝缘监视仪报警阈值等；改完必须点「保存」。
- **工具栏**：撤销 / 恢复 / 自动接线 / 起动系统 / 5点步进 / 故障设置 / 重置系统 / 任务选择 /
  自动演示 / 单步演示 / 演练 / 评估 / 选择仪表。`fiveStep` 为空实现，点「5点步进」不产生动作。
- **故障设置**：2 类故障（动力电网绝缘低 0.05 MΩ、动力电网接地 0 MΩ），随机选取一路负载的一相，
  由故障界面勾选后「应用设置」生效。
- **默认不接线**：初始化后画布无任何预接线；只有「自动接线」「起动系统」或工作流才会接线
  （本电路 42 根导线，> 8 根，允许瞬时接线）。

## 实现要点

- `project/sys_ljdq3-3.js`：组件布局（`componentConfigs`）、故障（`FAULT_CONFIGS`）、
  工作流（`PROJECT_WORKFLOWS`）、接线与演示辅助函数。
- 演示辅助：`_genStart()`（机旁起动按钮）、`_ensureCharged()`（按压储能手柄）、`_closeQF()`（合闸）、
  `_pdbSet()`（配电箱开关切档，含 TRIP 复位）、`_imPress()`（绝缘监视仪按键）、
  `_insulTestHold()`（按住测试按钮观察后松开）、`_wire()`（动画接线）、`_mgCrank()`（摇表并等读数）、
  `_faultLoadPort()`（按故障所选项取 L 端端口）、`_insulRecovered()`（读数是否恢复）、
  `_putAwayInstrument()`（收表）、`_waitFor()`（条件轮询）。
- 组件侧配套（可点击部件注册）：`MarineMainsSwitch` 的 `handle`/`btn-close`/`btn-open`；
  `SyncGenerator3P` 的 `start`/`stop`；`DistributionBox` 的 `sw1`/`sw2`/`sw3`（含命中节点）；
  `InsulationMonitor` 的 `lcd`/`btn-mute`/`btn-flash`/`btn-reset`；
  `InsulationIndicator` 的 `btn`（测试按钮，按住闭合）；
  `RealMegohmMeter` 的 `l`/`e`/`crank`。部件/端口定位一律按组件**绝对变换**换算（计入旋转/缩放）。
- 电路数值：控制电源 DC 24 V；绝缘监视仪报警阈值 0.1 MΩ；绝缘低 0.05 MΩ、接地 0 MΩ；
  三路负载初始绝缘 100 MΩ；可调负载 20 kW 起、cosφ = 1。
- 7 种保留仪表：`Multimeter`（`multimeter`）、`MF47Multimeter`（`mf47-panel`）、
  `RealMegohmMeter`（`megohm`）、`Oscilloscope_tri`（`osc`）、`SignalGenerator`（`sg`）、
  `ProcessCalibrator`（`cali`）、`ElecMeter`（`elecmeter`），全部 `visible: false`。
