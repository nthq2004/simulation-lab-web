# 船舶发电机组并车操作仿真

基于 Konva.js 的**船舶发电机组并车（并联运行）**仿真，用于教学中
**"遥控起动 → 同期条件判断 → 准同步并车 → 负荷转移 → 解列停机"** 的操作与判断训练，
并演示**并车保护（频差 / 非同期跳闸）**与**逆功率保护**的动作过程。

画布上是一套双机双主开关的船舶电站：1# 机组 `gen1`（80 kW）经主开关 `qf1`
（船用框架式空气断路器：储能弹簧、合闸/分励/失压线圈）送入汇流排 `bus1`；
2# 机组 `gen2` 经 `qf2` 送入同一汇流排。汇流排经 QF3 `acb_l` 带三盏白炽灯，
并接三相可调负载 `load3`（20 kW）。

- **数字同步表 `sync1`**：24 个 LED 组成圆环，显示待并机与汇流排 A 相的相位差；
  中央显示频差 Δf 与相位差 Δφ，准同步时顶部灯变绿。
- **同步表选择开关 `sync_sel`**：单刀四掷，1=OFF、2=1# 机、3=2# 机、4=预留。
- **发电机组遥控面板 `genpanel` / `genpanel2`**：遥控起动/停止、调速旋钮、
  合闸/分闸带灯按钮、LCD（电压/频率、电流/有功、功率因数）、READY FOR START 灯。
  **合闸联锁**：电网无电时直接放行；电网有电时必须把选择开关转到本机档位。

## 页面（单页工程）

本工程为**单页工程**：全部元件同屏显示，不使用页面索引与翻页（无 `PROJECT_PAGES` / `PageManager`）。

| 区域 | 内容 |
|---|---|
| 1# 机组 | `gen1`（x -100, y 700）→ `qf1`（x -180, y 180）→ 汇流排第 1 列 |
| 2# 机组 | `gen2`（x 850, y 700）→ `qf2`（x 1100, y 180）→ 汇流排第 7 列 |
| 测量 | 数字同步表 `sync1`（x 600, y 170）；选择开关 `sync_sel`（x 650, y 530） |
| 馈出 | QF3 `acb_l`（x 1826, y 80）→ 三盏白炽灯；可调负载 `load3`（x 950, y 180） |
| 控制电源 | `dc_uv`（x 600, y 750，1# 机组）、`dc_uv2`（x 1580, y 750，2# 机组），DC 24 V |
| 仪表停靠 | 7 种仪表默认隐藏，由工具栏「选择仪表」调出 |

## 操作项目（工具栏任务下拉框）

| 项目 | 内容 |
|---|---|
| 1. 认识船舶主配电装置 | 12 步识别：两台同步发电机、两只主开关（储能弹簧/合闸线圈/失压脱扣器）、两块遥控面板、数字同步表、选择开关手柄、汇流排、可调负载加载按钮 |
| 2. 遥控合闸与并车联锁操作 | 11 步：自动接线 → 复位 → 起动 1# 机 → 电网无电直接合闸 → 起动 2# 机 → 选择开关未到位时合闸被封锁 → 转 2# 档、调频、看相位窗口合闸并车 → 2 道测试题 |
| 3. 并车保护（非同期与频差跳闸） | 12 步：1# 机供电、2# 机待并 → 演示一：频差调至 > 0.5 Hz 时合闸 → 并车保护全船跳闸 → 复位重建 → 演示二：微频差使相位缓慢转动，非同期区间合闸 → 全船跳闸 → 2 道测试题 |
| 4. 并联功率分配与逆功率保护 | 9 步：并车后两台机均分负载 → 减小/增大 2# 机油门看功率转移 → 投入 20 kW 负载并微调至 5 kW → 故障界面设置「2# 发电机冷却水温度高」→ 原动机停机、机组被拖动出现逆功率 → 逆功率达 8 kW 延时 5 s 后 2# 主开关跳闸 → 1 道测试题 |
| 5. 发电机准同步并车、并联负荷转移、解列 | 10 步：1# 机供电 → 填空（准同步三条件）→ 起动 2#、转 2# 档、调频 +0.2 Hz → 观察同步表 → 指针到 11 点位置合闸、选择开关回 OFF → 观察功率均分 → 突加 20 kW → 调节两机调速器把 2# 压到 3 kW、电网回 50 Hz → 2# 分闸解列、停机 |

> 全部按最新范式编写：`mode:'check'` 的每步都用 `op` 数组、每个子操作自带 `act()`，
> 演示引擎逐个执行「**闪烁箭头指向目标 → 立即执行 → 停留观察**」；
> 故障走「故障设置」界面（`op.type='fault'`），按钮/旋钮/手柄一律**模拟真实操作**
> （`getClickablePartNode(partId).fire('mousedown'/'mouseup'/'click')`），
> 调速一律**按住遥控面板调速旋钮**（`knob-inc` / `knob-dec`）直到判据满足，
> 等待一律用条件轮询 `_waitFor`。

## 操作

- **手动操作**：工具栏「自动接线」→ 遥控面板「起动」→ 等储能电机把合闸弹簧储满 →
  按「合闸」/「分闸」；调速旋钮点右半区升速、点左半区降速（按住连续调节）；
  主开关本体还有工作位圆盘（左半区逆/右半区顺）与手动合闸/分闸按钮。
- **参数界面**：右键组件 →「参数设置」可改发电机额定参数/调差率、可调负载功率与投切状态、
  主开关保护定值（频差允许值、逆功率定值、延时）等；改完必须点「保存」。
- **工具栏**：撤销 / 恢复 / 自动接线 / 起动系统 / 5点步进 / 故障设置 / 重置系统 / 任务选择 /
  自动演示 / 单步演示 / 演练 / 评估 / 选择仪表。`fiveStep` 为空实现，点「5点步进」不产生动作。
- **故障设置**：1 类故障（2# 发电机冷却水温度高），由故障界面勾选后「应用设置」生效；
  复位流程会自动取消界面中已勾选的故障（避免上一任务残留导致机组起不来）。
- **默认不接线**：初始化后画布无任何预接线；只有「自动接线」「起动系统」或工作流才会接线
  （本电路 68 根导线，> 8 根，允许瞬时接线）。

## 实现要点

- `project/sys_ljdq4-1.js`：组件布局（`componentConfigs`）、故障（`FAULT_CONFIGS`）、
  工作流（`PROJECT_WORKFLOWS`）、接线与演示辅助函数。
- 演示辅助：`_panelPress()`（面板按钮真实按压）、`_setFreqTo()` / `_setFreqRelTo()`（调速旋钮闭环调频）、
  `_selTo()`（选择开关扳档）、`_startGen()` / `_stopGen()`（遥控起停）、
  `_closeViaPanel()` / `_openViaPanel()`（遥控合分闸）、`_tripByHandle()`（本体分闸）、
  `_sharePowerTo()`（并联负荷转移）、`_trimGridFreq()`（并联调频）、`_loadSet()`（负载投切）、
  `_waitPhaseOK()` / `_waitPhaseIn()` / `_waitLed()`（同步表相位窗口）、`_resetRig()`（完整复位）、
  `_waitFor()`（条件轮询）。
- 组件侧配套（可点击部件登记 + 绝对变换定位）：`GeneratorRemotePanel` 的
  `btn-close`/`btn-open`/`btn-start`/`btn-stop`/`knob`/`knob-inc`/`knob-dec`/`ready-led`；
  `SP4TSwitch` 的 `sel-knob`（整体）/`sel-knob-next`/`sel-knob-prev`（左右半区，合成点击有确定转向）；
  `ThreePhaseLoad` 的 `btn-load`/`btn-unload`/`power`；`MarineMainsSwitch` 的
  `handle`/`dial`/`btn-close`/`btn-open` 与线圈/触头部件。
- 电路数值：控制电源 DC 24 V；两台机 80 kW / 400 V / cosφ 0.8，调差 2 Hz（4%）；
  并车保护相位差窗口 60°~270°、频差允许 ±0.5 Hz；逆功率定值 8 kW、延时 5 s；可调负载 20 kW。
- 7 种保留仪表：`Multimeter`（`multimeter`）、`MF47Multimeter`（`mf47-panel`）、
  `RealMegohmMeter`（`megohm`）、`Oscilloscope_tri`（`osc`）、`SignalGenerator`（`sg`）、
  `ProcessCalibrator`（`cali`）、`ElecMeter`（`elecmeter`），全部 `visible: false`。
