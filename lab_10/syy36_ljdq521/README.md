# 主开关跳闸的应急处理

基于 Konva.js 的**船舶发电机主开关跳闸与应急处理**仿真，用于教学中训练
**"判断跳闸原因 → 应急恢复供电 → 排除故障后复位"** 的处置过程，
覆盖**机械故障、过载、逆功率、欠压、干线短路**五类典型跳闸：

画布上是一套双机双主开关的船舶电站：1# 机组 `gen1`（80 kW）经主开关 `qf1`
（船用框架式空气断路器：储能弹簧、合闸/分励/失压线圈）送入汇流排 `bus1`；
2# 机组 `gen2` 经 `qf2` 送入同一汇流排。汇流排经 QF3 `acb_l` 带三盏白炽灯，
并接三相可调负载 `load3`（默认 20 kW，可在参数界面修改）。

- **数字同步表 `sync1`**：24 个 LED 组成圆环，显示待并机与汇流排 A 相的相位差；
  中央显示频差 Δf 与相位差 Δφ，准同步时顶部灯变绿。
- **同步表选择开关 `sync_sel`**：单刀四掷，1=OFF、2=1# 机、3=2# 机、4=预留。
- **发电机组遥控面板 `genpanel` / `genpanel2`**：遥控起动/停止、调速旋钮、
  合闸/分闸带灯按钮、LCD（电压/频率、电流/有功、功率因数）、READY FOR START 灯。
  **合闸联锁**：母线无电时直接放行；母线带电时必须把选择开关转到本机档位。

## 主开关保护（qf1 / qf2 内置）

| 保护 | 判据 | 动作 |
|---|---|---|
| 过载 | 本机输出 > 额定 ×120%（96 kW）持续 15 s | 延时跳闸，发电机不停机 |
| 欠压 | 端子电压 < 额定 ×85% 持续 2 s | 延时跳闸，发电机可仍在运行 |
| 干线短路 | 汇流排存在短路标记 | 瞬时跳闸 |
| 逆功率 | 原动机故障拖转，逆功率 > 8 kW 持续 5 s | 延时跳闸 |
| 频差/非同期 | 并车时频差 > ±0.5 Hz 或相位落在 60°~270° | 跳闸（仅母线带电时判据有效） |

## 操作项目（工具栏任务下拉框）

| 项目 | 内容 |
|---|---|
| 1. 机械故障导致主开关跳闸的应急处理 | 7 步：识别主触头 → 自动接线复位 → 起 1# 机供电 → 故障界面设置「1#机冷却水温高」→ 原动机停机、母线失压、主开关欠压跳闸 → 2 道测试题 → 起 2# 机合闸恢复供电 |
| 2. 过载故障导致主开关跳闸的应急处理 | 6 步：自动接线复位起机 → 参数界面把负载改 110 kW → 加载后过载 15 s 跳闸（发电机不停机）→ 直接合闸恢复、减载重新投入 → 2# 机并车分担 → 1 道测试题 |
| 3. 逆功率故障导致主开关跳闸的应急处理 | 6 步：起 1# 机 → 起 2# 机并车 → 加载 100 kW 两机均分 → 设置 1# 机冷却水温高：逆功率 5 s 跳 qf1，2# 机独自承担全部负载过载跳 qf2 → 减载 20 kW、合 qf2 恢复供电 → 1 道测试题 |
| 4. 欠压故障导致主开关跳闸的应急处理 | 5 步：起 1# 机 → 设置「1#机欠压故障」：电压跌至 200 V、2 s 后 qf1 跳闸（发电机仍运行）→ 起 2# 机合闸恢复供电 → 取消故障、电压恢复 → 1 道测试题 |
| 5. 短路故障导致主开关跳闸的应急处理 | 5 步：起 1# 机 → 设置「汇流排干线短路故障」：短路保护瞬时跳闸 → 测试题（严禁强合）→ 排除故障后合闸恢复 → 测试题（保护选择性） |

> 全部按最新范式编写：`mode:'check'` 的每步都用 `op` 数组、每个子操作自带 `act()`，
> 演示引擎逐个执行「**闪烁箭头指向目标 → 立即执行 → 停留观察**」；
> 故障走「故障设置」界面（`op.type='fault'`），参数走「参数配置界面」（`_demoSetCfg`），
> 按钮/旋钮/手柄一律**模拟真实操作**（`getClickablePartNode(partId).fire('mousedown'/'mouseup'/'click')`），
> 等待一律用条件轮询 `_waitFor`。

## 操作

- **手动操作**：工具栏「自动接线」→ 遥控面板「起动」→ 等储能电机把合闸弹簧储满 →
  按「合闸」/「分闸」；调速旋钮点右半区升速、点左半区降速（按住连续调节）；
  主开关本体还有工作位圆盘（左半区逆/右半区顺）与手动合闸/分闸按钮。
- **参数界面**：右键组件 →「参数设置」可改发电机额定参数/调差率、可调负载功率与投切状态、
  主开关保护定值等；改完必须点「保存」。
- **工具栏**：撤销 / 恢复 / 自动接线 / 起动系统 / 5点步进 / 故障设置 / 重置系统 / 任务选择 /
  自动演示 / 单步演示 / 演练 / 评估 / 选择仪表。`fiveStep` 为空实现，点「5点步进」不产生动作。
- **故障设置**：5 类故障由故障界面勾选后「应用设置」生效；复位流程会自动取消界面中已勾选的故障。
- **默认不接线**：初始化后画布无任何预接线；只有「自动接线」「起动系统」或工作流才会接线
  （本电路 68 根导线，> 8 根，允许瞬时接线）。

## 实现要点

- `project/sys_ljdq5-2-1.js`：组件布局（`componentConfigs`）、故障（`FAULT_CONFIGS`）、
  工作流（`PROJECT_WORKFLOWS`）、接线与演示辅助函数。
- 演示辅助：`_panelPress()`（面板按钮真实按压）、`_setFreqTo()` / `_setFreqRelTo()`（调速旋钮闭环调频）、
  `_selTo()`（选择开关扳档）、`_startGen()` / `_stopGen()`（遥控起停）、
  `_closeViaPanel()` / `_openViaPanel()`（遥控合分闸）、`_tripByHandle()`（本体分闸）、
  `_loadSet()`（负载投切）、`_demoSetCfg()`（参数配置界面改参数）、`_waitPhaseOK()`（相位窗口）、
  `_resetRig()`（完整复位）、`_waitFor()`（条件轮询）。
- 组件侧配套（可点击部件登记 + 绝对变换定位）：`GeneratorRemotePanel` 的
  `btn-close`/`btn-open`/`btn-start`/`btn-stop`/`knob-inc`/`knob-dec`/`run-led`；
  `SP4TSwitch` 的 `sel-knob`/`sel-knob-next`/`sel-knob-prev`；
  `ThreePhaseLoad` 的 `btn-load`/`btn-unload`/`power`；
  `MarineMainsSwitch` 的 `handle`/`dial`/`btn-close`/`btn-open` 与线圈/触头部件。
- `MarineMainsSwitch._leaderOnline()`：**只有主开关已合闸的在网机组**才算并车对象；
  母线无电（另一台机虽在运行但已跳闸）时不再误判为非同期并车，也不会把本机电压
  错误对齐到故障机（如 AVR 故障时的 200 V）。
- 电路数值：控制电源 DC 24 V；两台机 80 kW / 400 V / cosφ 0.8，调差 2 Hz（4%）；
  并车相位窗口 60°~270°、频差允许 ±0.5 Hz；逆功率 8 kW / 5 s；过载 120% / 15 s；
  欠压 85% / 2 s；可调负载默认 20 kW。
- 7 种保留仪表：`Multimeter`（`multimeter`）、`MF47Multimeter`（`mf47-panel`）、
  `RealMegohmMeter`（`megohm`）、`Oscilloscope_tri`（`osc`）、`SignalGenerator`（`sg`）、
  `ProcessCalibrator`（`cali`）、`ElecMeter`（`elecmeter`），全部 `visible: false`。
