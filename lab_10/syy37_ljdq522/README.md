# 自动化电站主开关跳闸的应急处理

基于 Konva.js 的**船舶自动化电站主开关跳闸与自动恢复**仿真，用于教学中训练
"**判断跳闸原因 → 自动电站换机恢复 → 排除故障后复位**"的处置过程，
覆盖**机械故障、欠压、干线短路**三类典型跳闸。

画布上是一套双机双主开关的船舶电站：1# 机组 `gen1`（80 kW）经主开关 `qf1`
（船用框架式空气断路器：储能弹簧、合闸/分励/失压线圈）送入汇流排 `bus1`；
2# 机组 `gen2` 经 `qf2` 送入同一汇流排。汇流排经 QF3 `acb_l` 带三盏白炽灯，
并接三相可调负载 `load3`（默认 20 kW，可在参数界面修改）。

台架的核心是**电站自动控制模块 `auto_ctl`**：

- **手动/自动转换旋钮**：左=手动、右=自动（点击旋钮换档）。
- **备用机组顺序旋钮**：1-2-3 / 2-1-3（点击换档）。
- **母线采集口**（bus_a / bus_b）：监视汇流排是否带电。
- **通信口**（comm1 / comm2）：向两块遥控面板下发起动、停止、合闸、分闸、调速命令。
- 指示灯：电源、自动、各机组运行；LCD 显示在网机组、总功率、母线电压与频率。

**发电机组遥控面板** `genpanel` / `genpanel2`：遥控起动/停止、调速旋钮、合闸/分闸带灯按钮、
LCD（电压/频率、电流/有功、功率因数）、READY FOR START 灯。

## 自动控制模块的处置逻辑

| 环节 | 判据 | 动作 |
|---|---|---|
| 失电检测 | 母线无在网机组持续 3 s | 判定全船失电，进入自动起机流程 |
| 机组可用性 | AVR 欠压故障，或超速 / 滑油低压 / 冷却水温高 | 标记为"不可用"，选机时跳过 |
| 自动起动 | 按备用顺序取首台可用且未运行的机组 | 经通信口向遥控面板发起动命令 |
| 自动合闸 | 机组运行、电压/频率合格、合闸弹簧储能完成 + 3 s 延时 | 经通信口发合闸命令 |
| 短路闭锁 | 系统中存在短路标记 | 闭锁自动模式（自动灯熄灭），不发起动/合闸 |
| 常规自动 | 单机负载 > 额定 80% 并车；< 30% 解列；频率偏差调频 | 自动并车 / 解列 / 均分负荷 |

## 主开关保护（qf1 / qf2 内置，faultSimpleProtect=true）

| 保护 | 判据 | 动作 |
|---|---|---|
| 欠压 | 机端电压 < 额定 ×85% 持续 2 s | 延时跳闸（发电机可仍在运行） |
| 干线短路 | 汇流排存在短路标记 | 瞬时跳闸 |
| 过载 / 逆功率 / 频差非同期 | 组件内保留定值 | 本工程教学主线未使用 |

## 操作项目（工具栏任务下拉框）

| 项目 | 内容 |
|---|---|
| 1. 机械故障导致主开关跳闸（自动电站自动恢复） | 6 步：识别转换旋钮 → 自动接线复位起 1# 机供电 → 转自动 → 设置「1#机冷却水温高」：原动机停机、主开关欠压跳闸 → 观察自动电站跳过 1# 机、起动 2# 机自动合闸 → 1 道测试题 |
| 2. 欠压故障导致主开关跳闸（自动电站自动恢复） | 6 步：识别主开关主触头 → 接线起机供电 → 转自动 → 设置「1#机欠压故障」：电压跌至 200 V、2 s 后跳闸（机组仍运行）→ 自动电站跳过带故障的 1# 机、起动 2# 机恢复 → 1 道测试题 |
| 3. 短路故障导致主开关跳闸（自动模式闭锁） | 7 步：识别自动模式指示灯 → 接线起机供电 → 转自动 → 设置「汇流排干线短路」：主开关瞬时跳闸 → 观察自动模式闭锁、自动灯熄灭并拨回手动 → 排除短路后手动合闸恢复 → 1 道测试题 |

> 全部按最新范式编写：`mode:'check'` 的每步都用 `op` 数组、每个子操作自带 `act()`，
> 演示引擎逐个执行「**闪烁箭头指向目标 → 立即执行 → 停留观察**」；
> 故障走「故障设置」界面（`op.type='fault'`），按钮/旋钮一律**模拟真实操作**
> （`getClickablePartNode(partId).fire('mousedown'/'mouseup'/'click')`），
> 等待一律用条件轮询 `_waitFor`。

## 操作

- **手动操作**：工具栏「自动接线」→ 遥控面板「起动」→ 等储能电机把合闸弹簧储满 →
  按「合闸」/「分闸」；调速旋钮点右半区升速、点左半区降速；自动控制模块的两个旋钮点击换档。
- **参数界面**：右键组件 →「参数设置」可改发电机额定参数、可调负载功率、主开关保护定值、
  自动模块的机组/开关/面板 ID 与并车、解列阈值；改完必须点「保存」。
- **工具栏**：撤销 / 恢复 / 自动接线 / 起动系统 / 5点步进 / 故障设置 / 重置系统 / 任务选择 /
  自动演示 / 单步演示 / 演练 / 评估 / 选择仪表。`fiveStep` 为空实现，点「5点步进」不产生动作。
- **故障设置**：5 类故障由故障界面勾选后「应用设置」生效；复位流程会自动取消界面中已勾选的故障。
- **默认不接线**：初始化后画布无任何预接线；只有「自动接线」「起动系统」或工作流才会接线
  （本电路 71 根导线，> 8 根，允许瞬时接线）。

## 实现要点

- `project/sys_ljdq5-2-2.js`：组件布局（`componentConfigs`）、故障（`FAULT_CONFIGS`）、
  工作流（`PROJECT_WORKFLOWS`）、接线与演示辅助函数。
- 演示辅助：`_panelPress()`（面板按钮真实按压）、`_startGen()` / `_stopGen()`（遥控起停）、
  `_closeViaPanel()` / `_openViaPanel()`（遥控合分闸）、`_tripByHandle()`（本体分闸）、
  `_autoModeTo()`（点旋钮换档，循环开关反复点击到目标位）、`_waitAutoRecover()`（等自动恢复完成）、
  `_clearFaultsViaUI()` / `_resetRig()`（复位）、`_waitFor()`（条件轮询）。
- 组件侧配套：`ShipAutoControl` 在 `_createDynamicNodes()` 中登记可定位部件
  （`knob-mode` / `knob-seq` / `lcd` / `led-auto` 等，几何 + 命中节点），
  `getClickablePartCenter()` 统一用 `group.getAbsoluteTransform()` 换算绝对坐标；
  `GeneratorRemotePanel` 已在 `_parts` 中登记 `btn-start` / `btn-stop` / `btn-close` / `btn-open` /
  `knob-inc` / `knob-dec` / `run-led`，可直接 `fire('mousedown'/'mouseup')` 模拟真实按压。
- 工具栏「起动系统」= 自动接线 + 复位 + 遥控起动 1# 机 + 合闸供电。
