# 船舶应急发电机系统仿真

基于 Konva.js 的**船舶应急电网与应急发电机**仿真，用于教学中训练
"**认识应急电网 → 手动起动试验 → 自动起动（试验）试验**" 的完整操作过程：

画布上是一套"主电网 + 应急电网"双电网系统：主电网由 1# 同步发电机 `gen1`（80 kW）
经主开关 `qf1`（船用框架式空气断路器：储能弹簧、合闸/分励/失压线圈）送入主汇流排
`bus1`；主汇流排经低压配电箱 `pdb1` 第 3 路（应急配电开关 `sw3`）→ 联络开关 `tie1`
→ 应急汇流排 `bus2`。应急电源为应急发电机 `egen1`（50 kW），经应急主开关 `eqf1`
接入应急汇流排；应急负载为 `el1`/`el2`/`el3` 三盏星形连接的白炽灯，平时由主电网经
联络开关供电，主电网失电后由应急发电机供电。

台架的核心是**应急配电板 `ep1`**：

- **控制模式开关**：手动 / 自动（点击旋钮换档）。
- **联络开关模式开关**：试验 / 正常（点击换档）。打在**试验**位即强制联络开关断开，
  在不拉停主电网的情况下模拟"主电网失电"，用于做应急发电机自动起动试验。
- **检测口**（det_a / det_b）：接配电箱第 3 路出口，监视主电是否带电。
- **输出口**：联络开关合/分励、应急主开关合/分励、应急机组起动/停止/调频。
- **指示灯**：主电有电、应急备用、应急运行；LCD 显示主电电压、应急机组频率/电压、模式与阶段。

**发电机组遥控面板 `genpanel`**（1# 机组）：遥控起动/停止、调速旋钮、合闸/分闸带灯按钮、
LCD（电压/频率、电流/有功、功率因数）、READY FOR START 灯。

## 应急配电板的自动转换逻辑

| 环节 | 判据 | 动作 |
|---|---|---|
| 主电有电 | 检测口峰值 > 120 V | 待机：联络开关合闸、应急主开关分闸、应急机组停机 |
| 主电失电 | 检测口失压 | 联络开关立即断开 |
| 自动起动 | 失电后 10 s | 经起动线发起动命令（应急机组须在「自动」位） |
| 自动合闸 | 机组运行后 8 s | 发应急主开关合闸命令，信号保持 2 s |
| 应急运行 | 应急主开关合闸 | 应急汇流排由应急发电机供电 |
| 自动退出 | 主电恢复 | 3 s 后应急主开关分闸 → 合上联络开关 → 延时后应急机组停机 |

## 应急主开关 / 主开关保护（qf1、eqf1 内置，faultSimpleProtect）

| 保护 | 判据 | 动作 |
|---|---|---|
| 欠压 | 机端电压 < 额定 ×85% 持续 2 s | 延时跳闸（发电机可仍在运行） |
| 过载 | 输出 > 额定 × 过载系数持续设定时间 | 延时跳闸 |
| 干线短路 | 汇流排存在短路标记 | 瞬时跳闸 |

另有过载 / 逆功率 / 频差非同期定值保留在组件内，本工程教学主线未使用。

本工程为**单页工程**：全部元件同屏显示，不使用页面索引与翻页（无 `PROJECT_PAGES` / `PageManager`）。

| 区域 | 内容 |

| 主配电 | `pdb1` 低压配电箱（x 700, y 220），第 3 路 `sw3` 出线接联络开关 |
| 联络 | `tie1`（x 1490, y 220，竖放）→ 应急汇流排第 2 口 |
| 应急电源 | `egen1`（x 1650, y 650）→ `eqf1`（x 1550, y 180）→ 应急汇流排第 3 口 |
| 应急负载 | 应急汇流排第 1 口 → 三盏应急灯 `el1`/`el2`/`el3`（星形） |

## 操作项目（工具栏任务下拉框）

| 项目 | 内容 |
|---|---|
| 0. 应急电网组件认识 | 9 步：识别应急汇流排等主要部件 → 应急配电开关 `sw3` → 联络开关 → 应急配电板 → 控制模式开关 → 联络开关模式开关 → 应急发电机机旁面板 → 应急主开关 → 1 道测试题 |
| 1. 应急发电机手动起动测试 | 6 步：起动系统供主电 → 控制方式开关拨「手动」→ 机旁「起动」建压 → 机旁「停止」→ 拨回「自动」→ 1 道测试题 |
| 2. 应急发电机自动起动测试 | 5 步：起动系统供主电 → 确认自动、联络开关转「试验」→ 观察联络断开、约 10 s 自动起动、约 18 s 自动合闸、应急灯亮 → 转回「正常」观察自动退出 → 1 道测试题 |

> 全部按最新范式编写：`mode:'check'` 的每步都用 `op` 数组、每个子操作自带 `act()`，
> 演示引擎逐个执行「**闪烁箭头指向目标 → 立即执行 → 停留观察**」；
> 按钮/旋钮/开关一律**模拟真实操作**（`getClickablePartNode(partId).fire('mousedown'/'mouseup'/'click')`），
> 等待一律用条件轮询 `_waitFor`。

## 故障（工具栏「故障设置」）

| 故障 | 现象 |
|---|---|
| 应急发电机超速故障 | 原动机保护停机，故障未清除前起动即停 |
| 应急发电机调压器故障（建压不足） | 线电压跌至约 200 V，应急主开关欠压保护 2 s 后跳闸 |
| 应急主开关储能弹簧失效 | 合闸弹簧储不满，应急主开关无法合闸 |
| 应急主开关脱扣轴卡死 | 合闸后任何脱扣原因都不能分闸，自动退出时无法断开应急供电 |

复位流程会自动取消界面中已勾选的故障。

## 操作

- **手动操作**：工具栏「起动系统」→ 1# 遥控面板储能后「合闸」供电；
  应急发电机控制方式开关选「手动」后可按机旁「起动」/「停止」；控制方式在「自动」位时
  才接受应急配电板的遥控起动/停止命令。
- **应急配电板**：控制模式开关（手动/自动）、联络开关模式开关（试验/正常）点击换档；
  手动位时可用「合闸」/「分闸」按钮直接操作应急主开关。
- **参数界面**：右键组件 →「参数设置」可改发电机额定参数、应急配电板各设备 ID 等；改完必须点「保存」。
- **工具栏**：撤销 / 恢复 / 自动接线 / 起动系统 / 5点步进 / 故障设置 / 重置系统 / 任务选择 /
  自动演示 / 单步演示 / 演练 / 评估 / 选择仪表。`fiveStep` 为空实现，点「5点步进」不产生动作。
- **默认不接线**：初始化后画布无任何预接线；只有「自动接线」「起动系统」或工作流才会接线
  （本电路 72 根导线，> 8 根，允许瞬时接线）。
