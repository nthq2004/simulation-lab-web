# 船舶岸电接入仿真

基于 Konva.js 的**船舶岸电接入（船电 ⇄ 岸电双电源）**仿真，用于教学中训练
"**认识岸电接入系统 → 船电切换为岸电 → 岸电切换为船电**" 的完整操作过程：

画布上是一套"船电 + 岸电"双电源系统。船电由 1# 同步发电机 `gen1`（80 kW / 400 V / 50 Hz）
经船电主开关 `qf1`（船用框架式空气断路器：储能弹簧、合闸/分励/失压线圈）送入汇流排 `bus1`；
岸电由三相四线电源 `shore_in`（220 V）经**岸电箱 `shorebox1`**（相序检测 + 相序转换开关
「相序1 / OFF / 相序2」+ 出口空气开关）送入**岸电主开关 `pdb1`**（塑壳断路器），再上汇流排。
汇流排第 10 口带三盏星形连接的白炽灯 `bl1`/`bl2`/`bl3`（冷态 48.4 Ω）作为负载。
**负序继电器 `neg1`** 的进线接岸电箱输出 t1/t2/t3，常闭触点串入岸电主开关失压线圈回路。

## 电气联锁（本工程核心）

| 回路 | 路径 |
|---|---|
| 船电主开关失压线圈 | `dc_uv`+ → 岸电主开关常闭触头 `nc2→nc1` → `qf1 uv1→uv2` → 接地 |
| 岸电主开关失压线圈 | `dc_uv`+ → 负序继电器常闭 `nc2→nc1` → 船电主开关常闭触头 `nc1→nc2` → `pdb1 sw1_uv1→uv2` → 接地 |

- 任一台主开关**合闸到位** → 其常闭辅助触头断开 → 对方失压线圈失电 → 对方失压脱扣，不能合闸；
- 岸电**相序为负序或缺相** → 负序继电器常闭触点断开 → 岸电主开关同样无法合闸；
- 结论：岸电与船电**只能有一台合闸**，且必须先确认岸电相序正确，才能把岸电投入电网。

## 操作项目（工具栏任务下拉框）

| 项目 | 内容 |
|---|---|
| 0. 船舶岸电接入系统认识 | 7 步部件识别（岸电箱 → 相序指示灯 → 空气开关 → 负序继电器 → 岸电主开关 → 岸电电源 → 汇流排/负载灯）+ 2 道测试题 |
| 1. 船电转换为岸电供电 | 6 步：起动系统供船电 → 接岸电四线并合电源 → 相序开关「相序1」+ 确认正序 + 合空开 → 测试题 → 断船电主开关、合岸电主开关 → 测试题 |
| 2. 岸电切换为船电供电 | 5 步：自动接线 + 接通岸电 → 相序开关 + 合空开 + 合岸电主开关 → 起动机组、试合船电主开关（互锁拒动）→ 测试题 → 分岸电、合船电恢复供电 |

> 全部按最新范式编写：`mode:'check'` 的每步都用 `op` 数组、每个子操作自带 `act()`，
> 演示引擎逐个执行「**闪烁箭头指向目标 → 立即执行 → 停留观察**」；
> 按钮/旋钮/开关**一律模拟真实操作**（`getClickablePartNode(partId).fire('click'/'mousedown'/'mouseup')`），
> 等待一律用条件轮询 `_waitFor`，4 根岸电输入线用**动画接线**（`addConnectionAnimated`，约 3 s/根）。

## 操作

- **手动操作**：工具栏「起动系统」→ 1# 遥控面板储能后「合闸」供电；岸电侧需先把
  U/V/W/N 四根线接到岸电箱 in1/in2/in3 与船体接线柱 N，再合电源、把相序开关打到「相序1」、
  合出口空开，最后 **先分船电主开关、再合岸电主开关**。
- **参数界面**：右键组件 →「参数设置」可改岸电电源相序（pos/neg）、电压幅值、岸电箱进线相序等；
  改完必须点「保存」。
- **工具栏**：撤销 / 恢复 / 自动接线 / 起动系统 / 5点步进 / 故障设置 / 重置系统 / 任务选择 /
  自动演示 / 单步演示 / 演练 / 评估 / 选择仪表。`fiveStep` 为空实现，点「5点步进」不产生动作。
- **默认不接线**：初始化后画布无任何预接线（`applyAllPresets({init:true})` 直接返回）；
  只有「自动接线」「起动系统」或工作流 op 才会接线（本电路 40+ 根，> 8 根，允许瞬时接线；
  岸电输入 4 根单独用动画接线）。

## 故障

本工程 `FAULT_CONFIGS` 为空（教学重点是双电源切换与联锁），工具栏「故障设置」界面无条目。
需要做故障练习时，可用两种方式手动构造：

- **岸电相序接反**：右键岸电电源 → 参数设置 → 相序改为 `neg` → 观察岸电箱负序灯亮、
  负序继电器常闭触点断开、岸电主开关合不上；改回 `pos` 即恢复。
- **失压线圈断线**：删除岸电主开关 `sw1_uv1` 与控制电源之间的连线 → 岸电主开关合上即跳。
