# 船舶自动化电站仿真

基于 Konva.js 的**船舶自动化电站（两台机组 + 自动化电站 + 重载询问）**仿真，用于教学中训练
"**认识自动化电站 → 自动并车/自动解列 → Ⅰ级故障带电换机 → Ⅱ级故障断电切换 → 重载询问**"：

画布上是一套"双机并联"的船用电站。1#/2# 同步发电机组 `gen1`/`gen2`（各 80 kW / 400 V / 50 Hz）
分别经船用框架式空气断路器 `qf1`/`qf2`（储能弹簧、合闸/分励/失压线圈、常闭辅助触头）送入
汇流排 `bus1`；两台机组各配一块**遥控面板** `genpanel`/`genpanel2`（起/停、合/分闸、调速、通信口）。
**船舶电站自动控制模块 `auto_ctl`** 采集母线电压，通过 comm1/comm2 与面板通信，实现手动/自动两种
运行方式；自动方式下按"负荷—容量"判据自动并车/解列，按"母线失电"判据自动起动合闸，并按故障
等级执行带电换机或断电切换。汇流排第 6 口接三相可调负载 `load3`，第 5 口接
**重载询问---侧推器 `heavyload`**（默认隐藏，由工具栏「重载询问面板」复选框调出），
第 8 口经 QF3 `acb_l` 带三盏白炽灯 `lamp1~3` 作馈出支路。

## 自动化电站核心逻辑

| 功能 | 判据 | 动作 |
|---|---|---|
| 失电自动起动 | 自动位 + 母线无压 | 延时 3 s 起动首台机组 → 建压储能 → 自动合闸 |
| 自动并车 | 总负荷 > 并车阈值（`parallelKw` = 单机额定 60%，即 48 kW） | 起动备用机组 → 调频 → 同期合闸 |
| 自动均分负荷 | 两机并联 | 调调速器使两机有功趋于相等 |
| 自动解列 | 总负荷 < 解列阈值（`decoupleKw` = 28%）延时 20 s | 转移负荷 → 分闸 → 延时 30 s 停机 |
| Ⅰ级故障带电换机 | 机组Ⅰ级故障（滑油压力下降 / 冷却水温异常，机组不停机） | 并车备用机 → 转移全部负荷 → 解列 → 故障机停机，**全船不断电** |
| Ⅱ级故障断电切换 | 机组Ⅱ级故障（欠压 / 超速 / 滑油低压 / 冷却水温高，跳闸或停机） | 母线失电 → 延时起动备用机 → 自动合闸恢复供电 |
| 重载询问 | 大功率负载起动前发询问 | 并联 → 直接应答"允许"；单机 → 应答"等待"并强制并车，成功后改答"允许" |

## 操作项目（工具栏任务下拉框）

| 项目 | 内容 |
|---|---|
| 0. 船舶自动化电站系统认识 | 7 步部件识别（机组 → 主开关 → 遥控面板 → 汇流排 → 自动化电站 → 负载 → 馈出灯）+ 1 道测试题 |
| 1. 发电机组的自动并车、自动解列 | 4 步：起动系统供电 → 切自动 → 负载加到 50 kW 观察 2# 自动并车与均分 → 卸载观察自动解列停机 + 测试题 |
| 2. Ⅰ级故障自动化电站带电换机 | 3 步：供电 → 切自动 → 故障界面设置「1#机组Ⅰ级故障」观察换机 + 测试题 |
| 3. Ⅱ级故障自动化电站断电切换 | 3 步：供电 → 切自动 → 故障界面设置「1#机欠压故障」观察跳闸与备用机恢复 + 测试题 |
| 4. 重载询问功能实操 | 6 步：自动接线转自动 → 勾选「重载询问面板」并切询问档 → 按询问（回应黄→绿、2# 并车）→ 再按负载起动、观察均分 → 按停止观察解列停机 + 测试题 |

> 全部按最新范式编写：`mode:'check'` 的每步都用 `op` 数组、每个子操作自带 `act()`，
> 演示引擎逐个执行「**闪烁箭头指向目标 → 立即执行 → 停留观察**」；
> 按钮/旋钮/开关**一律模拟真实操作**（`getClickablePartNode(partId).fire('click'/'mousedown'/'mouseup')`），
> 负载功率修改走**参数配置界面**（弹框 → 改值 → 点「保存」），故障走**故障设置界面**，
> 重载询问面板走**工具栏复选框**，等待一律用条件轮询 `_waitFor`。

| 区域 | 内容 |

## 操作

- **手动操作**：工具栏「起动系统」→ 1# 遥控面板储能后按「合闸」供电；2# 机组可手动起动后
  人工并车/解列。停电顺序为「分闸 → 停机」。
- **自动运行**：点击自动化电站的「手动/自动」旋钮到自动位（`led-auto` 点亮），此后起动、并车、
  均分、解列、停机以及故障换机全部自动完成。
- **重载询问**：勾选工具栏「重载询问面板」调出侧推器面板（自动接 6 根线），选择开关切到
  「重载询问」，按「起动/询问」——回应灯黄（等待，电站强制并车）→ 绿（允许）→ 再按按钮负载起动。
- **参数界面**：右键组件 →「参数设置」可改负载功率、侧推功率、`parallelKw`/`decoupleKw` 阈值等；
  改完必须点「保存」。
- **工具栏**：撤销 / 恢复 / 自动接线 / 起动系统 / 5点步进 / 故障设置 / 重置系统 / 任务选择 /
  自动演示 / 单步演示 / 演练 / 评估 / 选择仪表 / 重载询问面板。`fiveStep` 为空实现。
- **默认不接线**：初始化后画布无任何预接线（`applyAllPresets({init:true})` 直接返回）；
  只有「自动接线」「起动系统」或工作流 op 才会接线（本电路 60+ 根，> 8 根，允许瞬时接线）。

## 故障

| 故障项 | 性质 | 现象 |
|---|---|---|
| 1#机组Ⅰ级故障 | 报警级（不停机、不跳闸） | 自动模式下自动换机：2# 并车 → 转移负荷 → 1# 解列停机 |
| 1#机欠压故障 | Ⅱ级 | 电压跌至约 50% 额定，主开关欠压保护 2 s 延时跳闸，2# 自动恢复供电 |
| 1#机超速 / 滑油低压 / 冷却水温高 | Ⅱ级 | 原动机保护停机（并网时经逆功率跳闸），2# 自动恢复供电 |
| 汇流排干线短路 | 严重 | 两台主开关短路保护同时跳闸，全船失电 |

全部故障通过工具栏「故障设置」界面勾选并「应用设置」生效，取消勾选可修复；
故障未清除前，故障机组无法重新起动。
