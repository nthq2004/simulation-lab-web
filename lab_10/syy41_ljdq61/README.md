# 船舶高压系统操作和绝缘监测

基于 Konva.js 的**船舶高压系统（6.6 kV）操作与绝缘监测**仿真，用于教学中训练
"**认识高压配电装置 → 差动保护切除发电机内部故障 → 变压器高温跳闸与切换 → 汇流排单相接地判别 → 真空断路器隔离操作（五防）**"。

画布上是一套单页高压配电装置：**1# 高压发电机 `gen_hv`**（6600 V / 50 Hz / 2000 kW，中性点经 500 Ω 电阻接地）
三相出线 U/V/W 接 **10 kV 真空断路器 `qf1`** 的 T1~T3 端子，L1~L3 出线送 **汇流排 `bus1`**；
断路器带储能电机、合闸/分励/失压线圈、常闭辅助触头与手动操作面板（储能手柄、合分闸按钮及防护盖、
工作位转换旋钮、接地开关摇柄孔与电磁锁、柜门）。**遥控面板 `hvgp`** 引出起动/停止/调速、
合闸/分闸/灭磁与同步表，**微机综合保护装置 `prot1`** 经 CT（出口/入口/中性点）与 PT 采样，
执行差动、短路、过载、接地、欠压、逆功率保护并驱动 `qf1` 跳闸。

汇流排第 4 口接 **高压接地监视仪 `hv_ground_monitor`**（液晶三行显示 A/B/C 相绝缘电阻，带「确认」「复位」按钮），
第 5 口经 10 MΩ **绝缘支路 `r_insul`** 接地；第 6 口由 **母联断路器 `vcbs2`** 送 **右段汇流排 `bus_s2`**，
右段带 2# 简化高压机组 `gen_s`（经 `vcbs`）、高压三相负载 `hvload`，并经 `vcbs3`/`vcbs4` + `tf1`/`tf2`（6600/440 V）
与空气开关 `aq1`/`aq2`/`aq3` 供两段 440 V 低压母线，低压母线上三盏白炽灯作馈出指示。

## 保护配置（`prot1`）

| 保护 | 判据 | 动作 |
|---|---|---|
| 纵联差动 | 机端（出口）与中性点（入口）两侧电流之差 > 定值 | 约 0.2 s 确认后瞬时跳闸（**绕组内部相间短路的唯一有效保护**） |
| 相间短路（速断） | 机端电流突增超过速断定值 | 瞬时跳闸（出口短路时两侧电流同增，差流≈0，由本保护动作） |
| 过载 | 电流 > 过载定值并持续 | 长延时跳闸 |
| 定子接地 | 中性点零序电流/电压超限 | 报警/跳闸（配合接地监视仪） |
| 欠压 / 逆功率 | 机端电压过低 / 有功倒送 | 延时跳闸 |

差动保护的关键：**出口短路时故障电流同时穿过机端 CT 与中性点侧 CT，差流≈0，差动不动**；
**绕组内部（如两相中点）短路时电流只在绕组内部环流，机端侧几乎测不到，差流很大，差动立即动作**。

## 操作项目（工具栏任务下拉框）

| 项目 | 内容 |
|---|---|
| 1. 高压发电机差动电流超过阈值 | 5 步：供电 → 故障界面设置「两相绕组中点短路」观察差动跳闸 → 按 F1 看入口/出口电流 → 清除故障 + 复位 + 重新合闸 + 测试题 |
| 2. 日用变压器高温导致跳闸保护 | 5 步：供电 → 合母联与 1# 变压器两侧开关（灯亮）→ 设置「变压器严重散热不良」观察 130 ℃ 高温跳闸 → 断开 aq1 改由 2# 变压器供电 → 修复故障温度回落 |
| 3. 左汇流排接地故障判断 | 6 步：供电并合母联 → 设置「电网单相接地」报警后按「确认」消音 → 断母联报警保持（判定在左段）→ 分闸停机 → 兆欧表逐相测量找接地相 + 测试题 |
| 4. 真空断路器隔离切换操作 | 12 步：合闸工作状态 → 五防题 → 分闸停机摇至试验位 → 五防题 → 合接地开关 → 五防题 → 开门检修 → 检修安全题 → 关门断接地 → 摇回连接位重新供电 → 五防题 |
| 5. 微机综合保护装置说明 | 5 步：识别装置 → CT/PT 采样填空 → 信号传递、高压特有保护、内部短路跳闸三道题 |

> 全部按最新范式编写：`mode:'check'` 的每步都用 `op` 数组、每个子操作自带 `act()`，
> 演示引擎逐个执行「**闪烁箭头指向目标 → 立即执行 → 停留观察**」；
> 按钮/旋钮/开关/摇柄**一律模拟真实操作**（`getClickablePartNode(partId).fire('click'/'mousedown'/'mouseup')`），
> 故障走**故障设置界面**，兆欧表走**选择仪表界面** + 动画接线，等待一律用条件轮询 `_waitFor`。

## 操作要点

- **供电**：工具栏「起动系统」＝自动接线 → 复位台架 → 遥控起动 1# 机组 → 合闸；也可手动按遥控面板
  「起动」→ 待建压稳定 → 按「合闸」（断路器需先由储能电机充满储能）。
- **参数界面**：右键组件 →「参数设置」修改电压、变压器高温阈值与延时等，改完必须点「保存」。
- **默认不接线**：初始化后画布无任何预接线（`applyAllPresets({init:true})` 直接返回）；
  只有「自动接线」「起动系统」或工作流 op 才会接线（本电路 60+ 根，> 8 根，允许瞬时接线）。
- **工具栏**：撤销 / 恢复 / 自动接线 / 起动系统 / 5点步进 / 故障设置 / 重置系统 / 任务选择 /
  自动演示 / 单步演示 / 演练 / 评估 / 选择仪表。`fiveStep` 为空实现。

## 故障

| 故障项 | 性质 | 现象 |
|---|---|---|
| 发电机出口两相短路 | 机端短路 | 两侧 CT 电流同增、差流≈0 → 相间速断保护跳闸 |
| 发电机两相绕组中点短路 | 绕组内部短路 | 入口电流远大于出口、差流超定值 → 差动保护 0.2 s 跳闸 |
| 1# 变压器严重散热不良 | 温升故障 | 通电持续升温，约 15 s 到 130 ℃，3 s 延时后跳开 `vcbs3`，断电冷却 |
| 电网单相接地 | 绝缘故障 | C 相绝缘降至 10 Ω，接地电流剧增，监视仪红灯闪 + 蜂鸣，按「确认」消音消闪 |

全部故障通过工具栏「故障设置」界面勾选并「应用设置」生效，取消勾选即修复；
故障未清除前，保护装置拒绝复位、断路器无法重新合闸。
