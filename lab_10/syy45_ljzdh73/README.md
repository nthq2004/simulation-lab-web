# 差压变送器的功能测试

基于 Konva.js 的**电动差压变送器功能测试**仿真，用于教学中训练
"**气路/电路接线 → 三阀组投运 → 零点与量程两点调校**"。

画布上是一套单页测试台架：**差压变送器 `difftr`**（量程 0~1 MPa，二线制 4~20 mA，
面板有 LCD 差压显示与 Z 零点、S 量程两只微调旋钮），低压室 L / 高压室 H 经
**三阀组 `3valve`**（高压阀 vH、低压阀 vL、平衡阀 vE）接两路可调压力：
**调压阀1 `pressreg`**（高压侧）与 **调压阀2 `pressreg2`**（低压侧），压力来自
**三通 `tee`** ← **截止阀 `stopvalve`** ← **气瓶 `cab`**（2 MPa）。

电气回路为二线制：**24V 电源 `dcpower`** p(+) → **可调电阻 `varires`**（250 Ω）→
变送器 p(+) → 变送器 n(−) → **电流表 `ampmeter`**（0~20 mA）→ 电源 n(−)。

## 操作项目（工具栏任务下拉框）

| 项目 | 内容 |
|---|---|
| 1. 电动差压变送器的结构、电路、气路连接(项目7.3) | 6 步：气瓶→截止阀→三通右口 → 三通下口→调压阀2→三阀组 inl → 三通上口→调压阀1→三阀组 inh → 三阀组输出→变送器 L/H → 24V+→可调电阻→变送器 p → 变送器 n→电流表→24V− |
| 2. 电动差压变送器的零点和量程调整(项目7.3) | 12 步：连线检查 → 通电开阀（4 mA）→ 开平衡阀 → 开 vH/vL 关 vE 投运 → 加 0.1 MPa 差压（5.60 mA）→ 调零至 4 mA → 升 0.9 MPa（16.8 mA）→ 调量程至 20 mA → 回到 0.1 MPa → 再调零 → 回到 0.9 MPa → 再调量程至 20 mA |

> 全部按最新范式编写：`mode:'check'` 的每步都用 `op` 数组、每个子操作自带 `act()`，
> 演示引擎逐个执行「**闪烁箭头指向目标 → 立即执行 → 停留观察**」；
> 电源键 / 截止阀手柄 / 三阀组手柄**一律模拟真实操作**（`fire('mousedown'/'click')`），
> 调压阀设定压力走**参数配置界面**（弹框 → 填值 → 点「保存」），
> 零点 / 量程**按住旋钮微调**（`fire('mousedown')` → 等电流到位 → `fire('mouseup')`），
> 等待一律用条件轮询 `_waitFor`。

## 操作要点

- **起动系统**：复位台架 → 自动接线 → 通电 → 开截止阀 → 三阀组投运 → 加 0.1 MPa 差压（H 0.4 / L 0.3）。
- **参数界面**：右键调压阀 →「参数设置」修改设定压力，改完必须点「保存」。
- **默认不接线**：初始化后画布无任何预接线（`applyAllPresets({init:true})` 直接返回）；
  只有「自动接线」「起动系统」或工作流 op 才会接线（共 12 根，≤8 根/步，逐根动画接线）。
- **5 点步进**：差压依次取 0 / 0.25 / 0.5 / 0.75 / 1.0 MPa（低压侧固定 0.3 MPa），
  便于核对 0/25/50/75/100% 差压 ↔ 4/8/12/16/20 mA 的线性度。
- **工具栏**：撤销 / 恢复 / 自动接线 / 起动系统 / 5点步进 / 故障设置 / 重置系统 / 任务选择 /
  自动演示 / 单步演示 / 演练 / 评估 / 选择仪表。
