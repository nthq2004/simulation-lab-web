# PID数字调节器的接线和参数调整

基于 Konva.js 的 **PID 数字调节器**仿真，用于教学中训练
"**4 条回路接线 → 观察 PV/MV 电流 → 逐个改 P/I/D 看输出变化**"。

画布上是一套单页台架：**PID 数字调节器 `pid`**（PV/SV 双显示、A/M·SET·▲·▼ 面板按键、
输入 pi1/ni1、输出 po1/no1，量程 0~100℃、SV=60℃），测量通道由
**可调电阻 `varires`**（模拟 PT100：R = 100 + 0.3851·T）→
**温度变送器 `temptr`**（三线制输入 l/m/r，二线制 4~20mA 输出 p/n）→
**测量电流表 `ampmeter`** → PID 输入组成；输出通道由 PID 输出 →
**输出电流表 `ampmeter2`** → **电动调节阀 `valve`**（4~20mA → 开度 0~100%）→ 回到 PID no1 组成；
**24V 直流电源 `dcpower`** 给 PID 供电。

## 操作项目（工具栏任务下拉框）

| 项目 | 内容 |
|---|---|
| 1. PID调节器接线及功能(项目7.4) | 8 步：24V→PID 供电 → 通电 → PT100 三线制输入 → 测量回路 → 输出回路 → SV/PV 概念题 → 电阻 119.25Ω（50℃）看测量电流 → 切手动、OUT=60% 看输出电流 |
| 2. PID调节器的参数调节(项目7.4) | 10 步：自动接线通电 → 切自动 → 平衡态（123.11Ω/60℃，OUT=50%、12mA）→ 偏差 10℃ 比例作用（OUT=90%、18.4mA）→ P 4→3（OUT=80%、16.8mA）→ 加积分 Ti=20s → 积分题 → 加微分 Td=5s → 微分题 → 比例带/比例系数题 |

> 全部按最新范式编写：`mode:'check'` 的每步都用 `op` 数组、每个子操作自带 `act()`，
> 演示引擎逐个执行「**闪烁箭头指向目标 → 立即执行 → 停留观察**」；
> 电源键、A/M、▲、▼ **一律模拟真实按下**（`fire('mousedown'/'mouseup')` 触发组件自身按键逻辑），
> 电阻阻值与 P/I/D 走**参数配置界面**（弹框 → 填值 → 箭头指向「保存」→ 真点保存），
> 等待一律用条件轮询 `_waitFor`。

## 接线（4 条回路、11 根导线）

| 回路 | 从 | 到 |
|---|---|---|
| ① 工作电源 | `dcpower` p / n | `pid` vcc / gnd |
| ② PT100 三线制 | `varires` l / r / r | `temptr` l / m / r |
| ③ 测量回路（PV） | `pid` pi1 → `ampmeter` → `temptr` p/n → `pid` ni1 | — |
| ④ 输出回路（MV） | `pid` po1 → `ampmeter2` → `valve` l/r → `pid` no1 | — |

## 操作要点

- **起动系统**：复位台架（PID 置 AUTO、PT100 置 0℃）→ 自动接线 → 通电。
- **参数界面**：右键组件 →「参数设置」；可调电阻改阻值、PID 改 P/I/D/SV，改完必须点「保存」。
- **面板按键**：A/M 切换手动/自动；▲/▼ 在**手动**模式改 OUT（每次 ±1%），在**自动**模式改 SV。
- **默认不接线**：初始化后画布无任何预接线（`applyAllPresets({init:true})` 直接返回）；
  只有「自动接线」「起动系统」或工作流 op 才会接线（共 11 根，逐根动画接线）。
- **5 点步进**：手动模式 OUT 依次取 0/25/50/75/100%；自动模式 PT100 依次取
  115.40/119.25/123.11/126.96/130.81Ω（40/50/60/70/80℃，对应 4/8/12/16/20mA）。
- **工具栏**：撤销 / 恢复 / 自动接线 / 起动系统 / 5点步进 / 故障设置 / 重置系统 / 任务选择 /
  自动演示 / 单步演示 / 演练 / 评估 / 选择仪表。
