# 自动控制系统各模块的功能测试

基于 Konva.js 的 **自动控制系统**台架仿真，用于教学中训练
"**传感器 → 变送器 → 调节器 → 执行器逐段功能测试**"。

画布上是一套单页台架：**可调电阻 `varires`**（模拟 PT100：R = 100 + 0.3851·T）→
**温度变送器 `temptr`**（三线制输入 l/m/r，二线制 4~20mA 输出 p/n）→
**测量电流表 `ampmeter`** → **PID 数字调节器 `pid`**（PV/SV 双显示、A/M·SET·▲·▼ 面板按键、
输入 pi1/ni1、输出 po1/no1，量程 0~100℃、SV=60℃）→
**输出电流表 `ampmeter2`** → **电动调节阀 `valve`**（4~20mA → 开度 0~100%）→ 回到 PID no1；
**24V 直流电源 `dcpower`** 给 PID 供电，再由 PID 配电给变送器。

## 操作项目（工具栏任务下拉框）

| 项目 | 内容 |
|---|---|
| 1. 传感器、变送器的功能及测试（项目8.2.1） | 9 步：24V→PID 供电 → 通电并置自动 → PT100 三线制输入 → 测量回路 → 传感器/变送器概念题 → 阻值 109.62/119.25/128.88/138.51Ω（25/50/75/100℃），看变送器显示与测量电流 8/12/16/20mA |
| 2. PID调节器的功能及测试（项目8.2.2） | 9 步：供电 → 通电并置自动 → PT100 → 测量回路 → 输出回路 → 调节器概念题 → 60℃（123.11Ω）平衡 OUT=50%/12mA → 50℃ 偏差+10℃ → OUT=90%/18.4mA → 70℃ 偏差−10℃ → OUT=10%/5.6mA |
| 3. 执行器的功能及测试（项目8.2.3） | 9 步：供电 → 通电并置手动 → 输出回路 → 气动执行器题 → 阀门定位器题 → 用 ▲/▼ 把 OUT 调到 25/50/75/100%，看输出电流 8/12/16/20mA 与阀门开度 25/50/75/100% |

> 全部按最新范式编写：`mode:'check'` 的每步都用 `op` 数组、每个子操作自带 `act()`，
> 演示引擎逐个执行「**闪烁箭头指向目标 → 立即执行 → 停留观察**」；
> 电源键、A/M、▲、▼ **一律模拟真实按下**（`fire('mousedown'/'mouseup')` 触发组件自身按键逻辑），
> 电阻阻值走**参数配置界面**（弹框 → 填值 → 箭头指向「保存」→ 真点保存），
> 接线箭头指向**端口**、操作箭头指向**子部件**，等待一律用条件轮询 `_waitFor`。

## 关键部件与可操作部位

| 组件 | id | 可点击部件（`part`） |
|---|---|---|
| PID 调节器 | `pid` | `am`（A/M 键）、`set`（SET 键）、`up`（▲）、`down`（▼）、`display`（PV/SV 显示区） |
| 温度变送器 | `temptr` | `lcd`、`zero`（Z 旋钮）、`span`（S 旋钮），端子 l/m/r/p/n |
| 可调电阻 | `varires` | `slider`（阻值滑块）、`l` / `r`；阻值在「参数设置」中改 |
| 电流表 | `ampmeter` / `ampmeter2` | `dial`（表盘）、`lcd`（读数） |
| 电动调节阀 | `valve` | `wheel`（手轮）、`mode-sw`（REMOTE/MANUAL）、`motor`；端子 l/r |

## 接线（4 条回路、11 根导线）

| 回路 | 从 | 到 | 根数 |
|---|---|---|---|
| ① 工作电源 | `dcpower` p / n | `pid` vcc / gnd | 2 |
| ② PT100 三线制 | `varires` l / r / r | `temptr` l / m / r | 3 |
| ③ 测量回路（PV） | `pid` pi1 → `ampmeter` → `temptr` p/n → `pid` ni1 | — | 3 |
| ④ 输出回路（MV） | `pid` po1 → `ampmeter2` → `valve` l/r → `pid` no1 | — | 3 |

三条流程的接线范围不同：8.2.1 只接 ①②③，8.2.2 接满 ①②③④，8.2.3 只接 ①④。

## 操作要点

- **起动系统**：复位台架（PID 置 AUTO、PT100 置 0℃）→ 自动接线 → 通电。
- **参数界面**：右键组件 →「参数设置」；可调电阻改阻值，改完必须点「保存」。
- **面板按键**：A/M 切换手动/自动；▲/▼ 在**手动**模式改 OUT（每次 ±1%），在**自动**模式改 SV。
- **默认不接线**：初始化后画布无任何预接线（`applyAllPresets({init:true})` 直接返回）；
  只有「自动接线」「起动系统」或工作流 op 才会接线（共 11 根，逐根动画接线）。
- **5 点步进**：手动模式 OUT 依次取 25/50/75/100/0%；自动模式 PT100 依次取
  109.62/119.25/128.88/138.51/100Ω（25/50/75/100/0℃，对应 8/12/16/20/4mA）。
- **工具栏**：撤销 / 恢复 / 自动接线 / 起动系统 / 5点步进 / 故障设置 / 重置系统 / 任务选择 /
  自动演示 / 单步演示 / 演练 / 评估 / 选择仪表。
