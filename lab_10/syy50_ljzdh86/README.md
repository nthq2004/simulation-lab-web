# 辅锅炉自动控制系统的功能测试

基于 Konva.js 的船用辅锅炉（D 型立式水管锅炉，蒸发量 1500 kg/h、工作压力 0.7 MPa）PLC 控制仿真教学工程。
以教材「第六章 船舶辅助设备的自动控制」图 6-3-18~6-3-23 为原型，
覆盖**自动/手动起动、预扫风、点火、小火稳定、大火运行、蒸汽压力自动控制、停炉后扫风**，
以及 7 类安全保护与 4 类可注入故障的处理。

## 被控对象

| 被控量 | 检测 | 执行机构 | 方式 |
|---|---|---|---|
| 汽包水位（正常 35%~70%） | 液位继电器 + 电极 HH 85% / H 70% / L 35% / LL 20% | 1#/2# 给水泵（停止/自动/手动） | 双位（两段式） |
| 蒸汽压力（0.5~0.7 MPa） | 压力继电器 ×3 + 压力表 | 燃烧器大小火（1#/2# 电磁阀）、自动起停 | 双位 + 起停 |
| 重油温度（目标 115 ℃） | 油温继电器（<90 ℃ 报油温过低） | 重油加热器（电加热） | 双位 |

仿真初始为**冷炉状态**：压力 0 MPa、水位 56 %、重油温度 115 ℃。

## 操作

- **起动系统**：合总电源 → 选 1# 油泵 → 按燃烧准备 → 燃烧控制转「自动」，按 1× 实时速率走完整个起动时序。
- **5 点步进**：停炉 → 预扫风 → 点火 → 小火 → 大火（临时提高仿真倍率，便于快速观察各阶段）。
- **手动方式**：燃烧控制旋钮依次转「扫风」→「点火」→「小火」→「大火」；停炉时先把旋钮转「扫风」后扫风约 20 s，再转「停止」，最后按「燃烧停止」按钮。
- **参数调整**：右键系统图 → 参数配置 → 「仿真时间倍率」（1~20，默认 1×）。
- **故障设置**：火焰监视器故障、风门卡死、重油加热器故障、压力继电器故障。
- **选择仪表**：7 种仪表默认隐藏（万用表、指针万用表、示波器、信号发生器、过程校验仪、数字功率计、兆欧表）。
- **操作项目**（工具栏任务下拉框）：
  1. 辅锅炉自动起动与运行；
  2. 手动起动辅锅炉和停炉；
  3. 锅炉安保功能测试。

## 仿真时序（与教材一致，100 ms 时基）

| 定时器 | 作用 | 设定 |
|---|---|---|
| T101 | 自动预扫风 | 36 s |
| T109 / T110 | 点火位置 / 点火准备 | 3 s / 5 s |
| T102 | 自动点火（喷油窗口） | 3 s |
| T103 | 小火稳定 | 20 s |
| T104 | 停炉后扫风（TOF） | 20 s |
| T107 / T105 | 手动点火变压器 / 手动点火超时 | 3 s / 5 s |
| T106 | 点火监视（无火判定） | 8 s |
| T108 | 风压检测起始延时 | 20 s |

压力整定：大小火转换 0.62 MPa（回落 0.50）、自动起停 0.70 MPa（回落 0.56）、
蒸汽超压 0.78 MPa、安全阀起座 0.85 MPa（回座 0.765）。

## 故障与保护

7 路报警（水位过高/过低、油温过低、风机失压、蒸汽超压、故障熄火、点火失败）经
M0.1「报警汇总」统一断油、停炉、后扫风并声光报警；每路有独立消声记忆（M1.x，故障消失自动复位）。

4 类可注入故障：`flame_sensor` 火焰监视器故障、`damper_stuck` 风门卡死（风压仅 0.45）、
`oil_temp_low` 重油加热器故障、`over_pressure` 压力继电器失灵（屏蔽 I2.3，由 I2.6/安全阀兜底）。

## 实现要点

- `tools/BoilerSolver.js`：锅炉过程模型（汽压、水位、油温、风压、火焰、安全阀）+ 虚拟 I/O 桥；
  每扫描周期把面板与过程开关量写入 PLC 的 I 过程映像，并读回 Q 输出。重油初始温度 115 ℃。
- `tools/S7200Solver.js`：S7-200 SMART 语句表解释器（定时器按实际时间累计，支持 `sys.ioBridge` 钩子）。
- 组件：`BoilerSystemDiagram`（系统图）、`BoilerLocalPanel`（机旁操纵台）、
  `BoilerWiringDiagram`（外部接线图）、`PlcInternalMonitor`（内部位监视）、
  `S7_200_SMART_SR40` / `S7200_EM_DQ08`（CPU 与扩展模块）、`STEP7PC`（上位机）、`GroundSymbol`（PE）。
- `lib/PageManager.js`：多页显隐（页 0 索引、页 1/2 电路页），`page` 字段与 `PROJECT_PAGES.comps` 一一对应。
