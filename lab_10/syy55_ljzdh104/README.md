# 火灾报警系统的功能实验

基于 Konva.js 的船舶**火灾报警系统（FAS）**仿真教学工程（**单页工程**，全部组件同屏显示），
覆盖火灾报警控制器的接线与总线通信、7 类探测器件的功能测试、自检与故障处理。

## 页面内容（单页，1920×1080 基准）

- **火灾报警控制器（FAS 主机）**：LCD、STATUS / MENU 页、消音 / 复位 / 隔离键、7 只状态灯、
  火警与故障列表，两路 CAN 接口（can1/can2）。
- **两路 CAN 探测回路**：回路 1（LOOP1）感烟 #1、感光 #2 → ZONE1 发电机，感烟 #3、手报 #4 → ZONE2 主机；
  回路 2（LOOP2）感烟 #5、感温 #6 → ZONE3 锅炉，感烟 #7、手报 #8 → ZONE4 分油机。
  每路经 4 个总线连接器链式互联，回路 1 末端接 CAN 总线分析仪（双击打开抓包界面）。
- **电源**：主电、备电两路 220 V 交流电源。
- **外设与工具**：声光报警器（由控制器报警输出直接驱动）、地址写入器、备用感烟探测器（未设地址，
  不能通信），以及测试用打火机（感光，3 s）、电吹风（感温，8 s）、烟雾发生器（感烟，5 s）。

## 被控对象

| 对象 | 检测元件 | 现象 |
|---|---|---|
| 火警（4 个分区） | 感烟、感温、感光探测器 + 手动报警按钮（8 个可寻址节点） | 控制器 LCD 显示火警、声光报警器响、面板对应分区灯亮、探测器报警灯亮 |
| 系统监视 | 主电 / 备电、回路通信、探测器在线状态 | 故障指示、故障列表、消音（MUTE）/ 复位（RESET） |

## 操作

- **自动接线**：按项目配置接好电源、两路 CAN 回路、报警输出与分析仪线路，并广播 NMT 使探测器节点进入运行。
- **起动系统**：复位后接通控制器内部电源开关，进入自检（状态灯 → 功能键 → 声光报警短鸣）→ RUN。
- **5 点步进**：控制器切到 STATUS 页，依次浏览 4 个探测回路的报警与正常状态。
- **测试探测器**：把打火机（感光）、电吹风（感温）、烟雾发生器（感烟）拖到探头旁对准开启，持续作用数秒即报警。
- **地址写入器**：把探测器 CAN 接口接入写入器 → 读地址 → 写地址，未写地址的探测器不能通信。
- **故障设置**：`fire-loop-comm` 探测器通信故障、`fire-main-power` FAS 主电源故障。
- **选择仪表**：7 种仪表默认隐藏（万用表、指针万用表、示波器、信号发生器、过程校验仪、数字功率计、兆欧表）。
- **操作项目**（工具栏任务下拉框）：
  1. 火警系统的认识；
  2. 火灾报警系统的自检和故障测试；
  3. 火灾探测器的功能测试。

## 实现要点

- `components/FireAlarmController.js`：FAS 主机（LCD、STATUS / MENU 页、消音 / 复位 / 隔离、7 只状态灯、
  火警与故障列表 `activeAlarms` / `faultAlarms`、分区灯 `zoneAlarm`）。
- `components/DetectorBase.js` 及 `SmokeDetector` / `HeatDetector` / `FlameDetector` / `ManualCallPoint`：
  可寻址探测器件（节点地址、回路、分区、在线状态、报警灯）。
- `components/BusConnector.js` + `can/CANBUS.js`：CANopen 风格总线（NMT、节点状态、广播帧、通信故障判定）。
- `components/AddressWriter.js`：烧写探测器节点地址；`components/CanAnalyzer.js`：双击打开报文抓包界面。
- `components/Lighter.js` / `HairDryer.js` / `SmokeGenerator.js`：拖动到探头旁作用以触发对应探测器。
- 本工程为单页工程：`PROJECT_PAGES` 导出为空数组，`consys.js` 不创建 `pageMgr`；
  工具栏不保留「主页 / 上一页 / 下一页」按钮，`main.js` 也不绑定它们。
- 本工程不使用任何过程模型求解器（锅炉 / 燃油 / 冷却水 / 副机等模型均不参与），
  火警逻辑由控制器与探测器组件按 CAN 帧推进。
