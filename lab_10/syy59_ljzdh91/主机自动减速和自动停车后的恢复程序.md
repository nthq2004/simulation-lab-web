# 主机自动减速和自动停车后的恢复程序

本文只讲操作，配合本仿真工程的四条操作流程使用；元件原理与整机结构请参阅其他资料。

---

## 一、Alarms 报警菜单与报警项的处置

### 1. 子菜单一览

按驾控台（或集控台）面板上的 **Alarms**，菜单区切换为 6 个二级按钮：

| 子菜单 | 内容 |
|---|---|
| Sys. Critical | 系统级致命报警（如 ESU 主电源故障、车钟系统故障） |
| Sys. Non-Crit. | 系统级非致命报警（如起动失败/阻塞、SHUTDOWN/SLOWDOWN CANCELLED、LIMITS CANCEL） |
| ComErr Crit. | 通讯错误——致命（ACP–ECR、DPU 通讯中断等） |
| ComErr Non-Crit. | 通讯错误——非致命 |
| I/O Fail | I/O 故障（测点开路/短路、急停开关、转速探头等） |
| Alarm History | 报警历史 |

除 **Alarm History** 外，各页都有两态：**第一次点 → 显示全部参数；再点同一项 → 只显示尚未复位的报警项；再点 → 回到全部**。滚动条上下三角可翻页。

### 2. 报警项的三种状态

| 状态 | 显示 | 含义 |
|---|---|---|
| 未应答 | 红字、`AL. CLOSE`、Active 灯红（闪烁） | 故障刚出现，值班人员还没确认 |
| 已应答 | **黄字**、`AL. CLOSE`、Active 灯仍红 | 人已确认，但故障仍在 |
| 已恢复未应答 | 红字、Value 显示 `NORMAL`、无 `AL. CLOSE`、Active 灯灭 | 故障自己消失了，但还没人确认 |

### 3. 两种处置顺序的差别

* **先复位（ACK）后排故障**：按 ACK 时故障还在 → 该行转**黄**、报警声光停止，报警栏保留；之后故障排除 → **该行自动消失，不需要再按一次 ACK**。
* **先排故障后复位**：故障先消失 → 该行转成 `, NORMAL` 的**红色记忆**（Active 灯灭）；此时**必须再按一次 ACK** 才从列表里消失，历史里留下一条记录。

无论哪种顺序，**Alarm History 都会保留本次出现过的报警**：未应答为红色、已应答为黄色、故障已恢复为**绿色并显示 `NORMAL`**，绿色行只作为记录保留，不再消失。

> 提示：自动减速（SLOWDOWN）的原因消失后，主界面报警栏里那一行会**直接移除**；但 `SLOWDOWN ACTIVE` 会锁存，直到把车钟拉到 40 rpm 以下（见第四节）。

## 二、操纵部位转换

### 1. 三个操纵部位

驾驶台 **BRIDGE**、集控室 **ECR**、机旁 **LOCAL**。同一时间只有一处拥有控制权，其它位置的按钮只发"请求"。

### 2. 转移步骤（以 驾驶台 → 集控室 → 机旁 为例）

1. **驾驶台**按 `ECR` 按钮 → 发出交出请求：该按钮闪烁，状态条第 3 段显示 **`Control Transfer`**，蜂鸣器响。
2. 到**集控室**面板，**先把集控室车钟推到与驾驶台一致的档位**（无扰动切换），再按本面板的 `ECR` 按钮 → 接管成功，状态条恢复显示 `ECR`（黄底），蜂鸣器停。
3. **集控室**按 `Local` 按钮 → 向机旁发出交出请求。
4. 到**机旁**面板：先按**按键式车钟**把机旁车令对到与驾驶台一致，再把**调速手柄**拖到同一转速，最后按本面板的 `Local` 按钮 → 接过控制权。

### 3. 要求与注意事项

* **车钟必须一致**才能接管：驾驶台↔集控室要求两边车令差 **≤1 rpm**；转机旁时按"按键式车钟相容规则"——集控室在 STOP 时机旁必须也在 STOP，集控室不在 STOP 时**档位差 ≤2 档**即可。
* 车钟不一致时接管**无效**：按钮继续闪、蜂鸣器继续响，须先对车钟。
* 控制权在机旁时，其它位置按自己的位置键**不能**直接接管，只能由机旁按目标位置键**交出**。
* 转移完成后 `LEVER` **不会跳变**——系统把当前转速给定写进新位置的手柄，避免扰动。
* 没有控制权的位置也可以自由扳动车钟手柄和机旁调速手柄，用于"预置"；把机旁手柄对到与驾驶台一致时，驾驶台车钟上闪烁的提示档位随之消失。

## 三、越控的实施

越控 = 暂时取消某项自动停车 / 自动减速 / 限制，让主机在故障条件下继续运行。分**整体越控**与**单项越控**两种。

### 1. 整体越控（面板左侧三个按钮）

`Cancel SHD`、`Cancel SLD`、`Cancel Limits`，均为**切换型**：

* 按一次 → 该类动作整体越控，按钮左上指示灯亮，并产生报警（`SHUTDOWN CANCELLED, ACTIVE` / `SLOWDOWN CANCELLED, ACTIVE` / `LIMITS CANCEL FROM ACP, ACTIVE`）；
* 再按一次 → 复位（灯灭）。

要点：

* **指示灯是各面板独立的**（本轮在哪块面板按下，只有该面板的灯亮），但**动作作用于全船**——任何一块面板按下都立即生效；
* `Cancel SLD` 只对**尚未触发的减速**有效：预报警弹窗期间按下 → 本次减速被取消，弹窗消失、预报警信息一并移除；**已经触发的减速不能靠 Cancel 复位**，仍需把车钟拉到 40 rpm 以下；
* `Cancel Limits` 生效时，Show Limiters 页除"最低稳定转速、临界转速、扫气压力、转矩"外一律显示 `CANCELLED`，扫气/转矩各点燃油开度上限 +10 %。

### 2. 单项越控（Safety System 页逐项取消）

1. 进入 **Safety System → Shut Down**（或 **Slow Down**）页；
2. **点击某一故障行** → 该行选中（底色变亮）；再点一次取消选中；
3. 该行右侧出现蓝色按钮 `Cancel SHD` / `Cancel SLD`（只有带 Cancelled 灯的行才有）；
4. 按一次 → 该行 `Cancelled` 灯变红、行转橙色、ALARM 清空，**只是这一项**的自动停车/减速被取消；再按一次还原；
5. 当本页所有"可越控且正在动作"的项都被取消后，系统级的 `cancelSHD` / `cancelSLD` 才置位（等效于按了整体按钮）。

> 再点同一子菜单可在"全部条目 / 仅故障条目"之间切换，便于只看正在动作的项。

## 四、自动减速与自动停车的复位

### 1. 自动减速（SLOWDOWN）

* 触发：温度（滑油进口温度高、缸套水出口温度高）等超过限值并持续**安保延时**（默认 6 s，可在 `Param. Change → Safety` 修改）→ 主机自动减到 40 rpm。
* 复位分两步：
  1. **原因消失**：温度回落到回差值以内 → 报警栏中该条原因**直接移除**（历史留绿色记录）；
  2. **动作复位**：把**拥有控制权**的车钟（或机旁调速手柄）**拉到 40 rpm 以下**，`SLOWDOWN ACTIVE` 锁存解除、报警栏该行清除。只做第 1 步，主机仍保持在 40 rpm 不能加速。
* 若在**预报警**（弹窗 `SLOW DOWN ACTIVE / CANCELLABLE`）阶段就按 `Cancel SLD` → 本次减速被取消、不会触发，报警栏只留越控记录；事后需再按一次 `Cancel SLD` release。

### 2. 自动停车（SHUTDOWN）

* 触发：滑油低低压、缸套水进口低压、推力轴承高高温、增压器滑油低低压等 A 级保护，延时到即**切断燃油、主机停车**，并产生 `…, SHUTDN` 报警与 `START FAIL/BLOCK`。
* 复位分两步：
  1. **排除故障**（把引起停车的条件恢复到正常值）；
  2. **把车钟拉回 STOP** → 停车状态解除（`shutDown`、低低压标志清除，状态条回到 `Eng. Ready`，报警按应答状态清除/恢复）。也可用 `Cancel SHD` 越控后重新起动。

### 3. 举例：滑油压力低导致自动停车

| 步 | 操作 | 现象 |
|---|---|---|
| 1 | 第 10 页点三通阀 `cv3c`，把**滑油压力开关的取压切到手摇泵** | 压力开关改由手摇泵加压 |
| 2 | 按 ▼ 把手摇泵压力降到 **0.14 MPa** | 低于下限 0.15 MPa → 压力开关 **NC 触点闭合** |
| 3 | 回驾控台观察 | 监控系统 `ME-LO-PR-SW`（A 级、安保延时 6 s）到点 → **主机自动停车**，报警 `MAIN L.O. LOW-LOW PRESS, SHUTDN`；按**消音**、**ACK** |
| 4 | 回第 10 页按 ▲ 把手摇泵升到 **0.21 MPa**（越过复位值 0.20 MPa） | 触点断开、压力开关复位；再把 `cv3c` 切回**滑油入口管路** |
| 5 | 回驾控台，把**车钟手柄拉回 STOP** | 自动停车复位：报警清除、`Eng. Ready` 恢复，可重新起动 |

要点：**先恢复压力、再回 STOP 复位**；若先回车钟而不恢复压力，开关仍闭合，下一次延时到还会再次停车。
