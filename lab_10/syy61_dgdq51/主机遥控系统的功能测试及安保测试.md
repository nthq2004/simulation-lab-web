# 主机遥控系统的功能测试及安保测试

## 一、概述

本仿真以 **AC 600 主机遥控系统** 与 **K-Chief 600 监视报警系统** 为原型，串联了**备车 → 冲车/慢转 → 起动 → 调速 → 安全保护**的完整链路。
驾驶台、集控室、机旁三块面板共享同一套主机模型，任一处操作都会即时反映到其余各处。五条教学流程分别对应五个环节：

| 编号 | 流程 | 对应功能 |
|---|---|---|
| 1 | 主机的起动功能测试 | 备车条件与起动空气系统 |
| 2 | 主机的调速功能测试 | 控制权转移与车钟调速 |
| 3 | 主机超速保护实验 | 转速检测与超速停车 |
| 4 | 主机滑油低压保护实验 | 压力开关与自动停车（SHD） |
| 5 | 曲轴箱油雾浓度高保护实验 | 自动减速（SLD）与越控 |

### 共性原理

**① 控制位置**：`BRIDGE / ECR / LOCAL` 三处互斥，**只有持有控制权的位置才能操车**，其它位置拨车钟只移动手柄。
转移需两步：一方按目标位置（GIVE）→ 对方按自己位置（TAKE），且**两侧车钟差 ≤1 rpm**（转机旁按档位差 ≤2）。

**② 车钟与给定**：11 档车钟（NAV FULL 68、FULL 57、HALF 41、SLOW 27、DEAD SLOW 21、STOP 0、
倒车 −21…−55 rpm）决定车令 `rpmCmd`，再经限制环节得到调速器给定 `SETP`，实际转速 `rpm` 追随 `SETP`：

- 加速 2 rpm/s、减速 3 rpm/s；
- 57↔68 rpm 之间走 Load Up / Load Down 程序（分钟级）；
- 30~37 rpm 临界转速禁区自动避让；
- 最低稳定转速 21 rpm（车令低于 21 时给定保持 21，STOP 除外）；
- 主机惯性最大约 4.5 rpm/s（限制全部取消时也不会瞬变）。

**③ 备车（起动联锁）**：盘车机脱开、空气分配器在工作位、**主起动阀在工作位**、**控制空气导通**、
起动空气 ≥15 bar 才允许起动。起动时主起动阀开启、起动空气转车约 3 s，发火后按 SETP 升速。

**④ 扫气与辅助机械**：扫气箱压力 = 增压器（每 10 rpm +0.02 MPa）+ 鼓风机（运行 0.04 / 停止 0.001 MPa）；
遥控下 <0.03 MPa 起鼓风机、>0.08 MPa 停。机带液压泵 20 rpm 以上建压（28 MPa），电动 HPS 泵遥控时"停机投运、20 rpm 以上停"。

**⑤ 副车钟（航行工况）**：`At Sea / Standby / FWE` 由驾驶台与集控室**两步回令**切换；
`At Sea` 要求车钟在 NAV FULL，`FWE` 要求主起动阀与空气分配器都关闭。

## 二、流程 1：主机的起动功能测试（7 步）

**目的**：验证从停车状态安全起动主机的全过程，理解"备车—冲车—慢转—试车"逻辑。

| 步 | 操作 | 原理与看点 |
|---|---|---|
| 1 | 驾控台点 **Engine State** | 查看 STATE / START FAIL-BLOCK / ENGINE NOT READY 三组灯，判断主机是否备妥 |
| 2 | 气动页：主起动阀置**工作**、空气分配器置**工作位**、接通**控制空气** | 三者是起动联锁的硬条件；阻塞/锁闭时主起动阀无法开启，控制空气不导通则电磁阀无动力 |
| 3 | 机旁起动开关打**慢转**，再回**自动** | 慢转电磁阀得电，起动空气把主机以约 5 rpm 缓慢盘转，用于长时间停机后预润滑、检查有无卡阻 |
| 4 | 机旁起动开关打**冲车**，再回**自动** | 起动电磁阀 A 得电，吹除气缸内积油积水，转速升到约 20 rpm 并保持 |
| 5 | ME 主机页确认鼓风机、HPS 泵、压力正常，关闭示功阀 | 扫气压力 0.040 MPa、液压 28.0 MPa；示功阀只在测取示功图时开启，正常运转应关闭 |
| 6 | 机旁调速手柄推到**正向慢速**试车，回 STOP | 车令→起动程序→升速；停机后转速按惯性回落 |
| 7 | 机旁调速手柄推**反向慢速**试车，回 STOP | 验证换向：倒车车令时起动空气**反向**转车，转速为负值 |

> 机旁起动旋钮与调速手柄只在**控制权在机旁**时才输出信号。

## 三、流程 2：主机的调速功能测试（11 步）

**目的**：演练"机旁 → 集控室 → 驾驶台"的控制权转移与车钟调速、副车钟工况切换。

| 步 | 操作 | 原理与看点 |
|---|---|---|
| 1 | 气动页三项置工作位 | 同流程 1 第 2 步 |
| 2 | 机旁按 **ECR** | 控制权在机旁时，机旁按目标位置即发出 GIVE 请求（目标灯闪烁、蜂鸣器响） |
| 3 | 集控台按 **ECR** 接管，再按 **Bridge** 移交 | 接管要求两侧车钟差 ≤1 rpm；接管后本位置车钟对齐当前给定，LEVER 不跳变 |
| 4 | 驾驶台按 **Bridge** 接管 | 完成 LOCAL → ECR → BRIDGE 的链式转移 |
| 5 | 车钟推 **SLOW** | 车令 27 rpm，按 2 rpm/s 加速限制升速 |
| 6 | 车钟推 **FULL** | 车令 57 rpm；SETP 显示正在执行的限制（Accel. Lim.） |
| 7 | 保持 FULL，驾驶台按 **Standby** 发起备车 | 副车钟为两步回令：发起方灯闪烁、请求待确认 |
| 8 | 集控台按 **Standby** 回令 | 工况转为机动备车（STANDBY） |
| 9 | 车钟推 **NAV FULL** | 57→68 rpm 走 Load Up 程序，转速缓慢爬升 |
| 10 | 驾驶台按 **At Sea** | 航行工况请求（需车钟已在 NAV FULL） |
| 11 | 集控台按 **At Sea** 回令 | 进入海上全速航行工况（SEA） |

## 四、流程 3：主机超速保护实验（6 步）

**原理**：转速检测系统由两套独立探头（Pickup 1/2）与两套超速保护回路（SYS.1 / SYS.2）组成，
动作值由 **Overspeed Level** 设定（默认 78 rpm，高于额定 68 rpm）。**实际转速一旦超过动作值**，
保护立即动作：切断燃油 → 主机停车 → 锁存，并发出 `OVERSPEED SYS.1/2 - SW BACKUP, SHUTDN` 报警；
此时备车条件丢失，须查明原因并复位后才能重新起动。

| 步 | 操作 | 说明 |
|---|---|---|
| 1 | 点击**起动系统** | 主机进入海上全速运行（68 rpm），控制权在驾驶台；实验设定值复位为 78 rpm |
| 2 | 集控台 Safety System → **RPM Detector** | 打开转速检测页（本实验在集控台 ACP 完成） |
| 3 | 观察 78 rpm > 实际 68 rpm | 动作值高于实际转速，保护不动作 |
| 4 | 把 **Overspeed Level 改为 60 rpm** | 动作值低于实际转速 → 保护**立即**动作（燃油切断、主机停车） |
| 5 | 驾控台消音 + **ACK** | 故障仍在，复位后报警转黄（已确认） |
| 6 | 把 Overspeed Level **改回 78 rpm** | 超速条件消失 → 停车解除、恢复备车；报警按应答状态清除 |

> 要点：把设定值改到实际转速以下等价于让主机超速；动作值须调回高于实际转速才能复位。

## 五、流程 4：主机滑油低压保护实验（6 步）

**原理**：主滑油进口压力由 **YT1226 压力继电器**监视。继电器的**下限**（报警动作值）与**上限**
（复位值）由机身两颗螺钉整定（给定值 % 与幅差 % 换算）；压力低于下限时 **NC 触点闭合**，
K-Chief 测点 `ME-LO-PR-SW` 判定报警（A 级、SHD 安保、延时 6 s）；延时到仍未越控 → **自动停车**：
燃油切断、车钟回 STOP、报警栏 `MAIN L.O. LOW-LOW PRESS, SHUTDN`。
压力回升到上限以上（越过幅差）→ 触点断开 → 报警转"已恢复"，**停车仍需把车钟拉回 STOP 复位**。

| 步 | 操作 | 说明 |
|---|---|---|
| 1 | 点击**起动系统** | 主机全速运行、滑油泵运行，作为实验初始状态 |
| 2 | 第 11 页把压力开关取压切到**手摇泵** | 便于人工"制造"低压，不动真实油路 |
| 3 | 手摇泵降压到 **0.14 MPa** | 低于下限 0.15 MPa → NC 触点闭合 |
| 4 | 回驾控台等安保延时 → 自动停车，消音 + ACK | 观察停车动作与报警 |
| 5 | 升压到 **0.21 MPa**（越过上限 0.20）开关复位，取压切回滑油管路 | 报警转"已恢复" |
| 6 | 车钟拉回 **STOP** | 才能解除自动停车、恢复备车 |

## 六、流程 5：曲轴箱油雾浓度高保护实验（5 步）

**原理**：曲轴箱油雾浓度高是可燃油雾爆炸的前兆，属**自动减速（Slow Down）**保护：越限先给出
`OIL MIST HIGH IN CRANKCASE, SLOWDN` 预报警（面板弹出 `SLOW DOWN ACTIVE / CANCELLABLE`），
在 `Param. Change → Safety` 设定的**延时（默认 6 s）**内未越控 → 执行减速：SETP 压到 40 rpm，
主机按 3 rpm/s 降速，报警栏追加 `SLOWDOWN ACTIVE`。
减速动作**锁存**：即使故障消失，也要把车令降到 **40 rpm 以下**才复位；延时内按 Cancel SLD 可暂停本次减速。

| 步 | 操作 | 说明 |
|---|---|---|
| 1 | 点击**起动系统** | 全速运行，控制权在驾驶台 |
| 2 | 故障设置界面勾选「**曲轴箱油雾浓度高**」并应用 | 6 s 后自动减速（本次不越控） |
| 3 | 驾控台消音 + ACK | 报警转黄，故障仍在 |
| 4 | 故障设置界面**取消勾选**并应用 | 油雾浓度恢复正常，减速原因清除（动作仍锁存） |
| 5 | 车钟拉 **SLOW**（27 rpm < 40） | 解除减速锁存，报警清除 |
