# 在线学习平台自动化学习工具

## 目标
自动完成 study.enaea.edu.cn 学习平台的 225 分钟学习任务。

## 功能
1. **自动登录** - 首次手动登录后，浏览器会记住登录状态
2. **自动选课** - 自动找到未学习的课程并点击"学习"
3. **弹窗自动确认** - 每20分钟弹出的确认界面自动点击确定
4. **进度监控** - 实时显示学习进度

## 安装步骤

### 1. 安装 Python（如果没有）
从 https://www.python.org/downloads/ 下载安装 Python 3.8+

### 2. 安装依赖
打开终端（cmd / PowerShell），进入项目目录：
```bash
cd "E:\BaiduSyncdisk\03 教学材料\仿真软件制作\网站\temp\webauto"
pip install playwright
playwright install chromium
```

### 3. 运行脚本
```bash
python auto_popup.py
```

## 使用流程

### 第一次运行
1. 运行 `python auto_popup.py`
2. 浏览器会自动打开学习平台
3. **在浏览器中手动输入账号密码并登录**
4. 登录成功后，脚本会自动：
   - 找到未学习的课程
   - 点击"学习"按钮开始学习
   - 每15秒检测一次弹窗
   - 发现弹窗自动点击"确定"

### 后续运行
- 浏览器会记住登录状态，无需重新登录
- 直接运行 `python auto_popup.py` 即可

## 重要提醒

### 首次运行时需要确认弹窗类型
第一次运行时，当20分钟弹窗出现时，请**记下弹窗的特征**：
1. 弹窗中的文字是什么？（如"请确认本人学习"、"继续学习"等）
2. 确认按钮的文字是什么？（如"确定"、"确认"、"继续"等）
3. 弹窗是否在 iframe 内？

然后修改 `auto_popup.py` 中的 `popup_keywords` 和 `selectors` 列表，添加对应的关键词和选择器。

### 注意事项
1. **不要最小化浏览器** - 某些平台检测到窗口最小化会暂停计时
2. **保持网络连接** - 断网会导致学习中断
3. **不要手动操作浏览器** - 运行脚本期间让脚本自动操作
4. **后台运行** - 如果需要做其他事，可以用远程桌面或VNC

## 文件说明
- `auto_popup.py` - **推荐使用** 简化版脚本，直接运行即可
- `auto_study.py` - 完整版脚本，功能更全面
- `popup_config.py` - 弹窗选择器配置文件
- `browser_data/` - 浏览器数据目录（自动创建）

## 故障排除

### 问题：脚本检测不到弹窗
解决：运行脚本后，等20分钟弹窗出现时，按 F12 打开开发者工具，找到弹窗的 HTML 代码，把对应的 CSS 选择器添加到脚本中。

### 问题：浏览器打开后白屏
解决：检查网络连接，或者尝试关闭浏览器重新运行。

### 问题：点击"学习"后没有反应
解决：可能是新窗口被拦截，检查浏览器的弹窗拦截设置。
